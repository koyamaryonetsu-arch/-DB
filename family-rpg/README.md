# きずなの紋章 ― 家族で遊ぶオープンワールドRPG

家族だけで遊ぶための、ブラウザで動くRPGです。
一人でこつこつ冒険する日も、みんなで集まってストーリーを進める日も楽しめます。

- **一人でも・家族いっしょでも** … 最大4人パーティー。家族がいない時は、酒場の仲間やモンスターの仲間でうめられます
- **仲間はそれぞれ育つ** … 酒場で仲間を探して、いつでも入れかえ。仲間ごとにレベル・装備・転職・作戦（「めいれいさせろ」で自分でコマンドも選べる）
- **モンスターが仲間になる** … 紋章の力「魔物の心」に目覚めると、たおした魔物がときどき起き上がって仲間になりたがります
- **配合と図鑑** … 育てたモンスター2匹をかけ合わせると、親の技と強さを受けついだ子が生まれます。配合でしか生まれないモンスターも。出会った魔物は「図鑑」にのります
- **船で海を冒険（第2章）** … 船「しおかぜ号」で海を自由に進めます。港町・灯台・小島・洞窟・嵐の塔
- **装備で見た目が変わるドット絵** … よろい・かぶと・たて・武器がフィールドのすがたに出ます
- **家族だけ** … 家のWi-Fiの中だけで動きます。家族の「合言葉」がないと入れません。知らない人とはつながりません
- **オープンワールド** … 村・町・平原・森・湖・沼・洞窟・海を自由に歩けます（シンボルエンカウント）
- **2.5D（立体）の画面** … 地面・建物・山・木が3D、キャラはドット絵のまま。ななめ上から見下ろすカメラ（設定で昔ながらの2Dにももどせます）
- **リアルタイムターン制バトル** … 素早さで行動ゲージのたまる速さが変わります。戦闘は昔のドラクエのような1画面
- **転職（基本職 → 上級職 → 超級職）** … 職業レベルは戦いに勝った数で上がります（最大10）。基本職を2つきわめると上級職、上級職をきわめると竜の騎士・大魔道士・勇者などの超級職になれます
- **掛け合わせ** … 呪文や特技を組み合わせた技（魔法剣・メドロ・スターストラッシュなど。使えるのは上級職から）と、仲間どうしの「連携」「合体」「きずな技」

今は **序章〜第2章（嵐の将軍ストルムまで）** が遊べます。

### 画面の文字について

ゲームの中の文字は、**小学4年生までに習う漢字は必ず漢字で書く** ようにしています（「戦う」「呪文」「道具」「仲間」など）。
5〜6年生で習う漢字と、ゲームでよく使う一部の漢字（呪・嵐・洞窟 など）も使います。それ以外の漢字はひらがなです。
言葉と言葉の間にスペースは入れません。`npm test` でこのルールを自動でチェックしています（`tools/kanji-check.mjs`）。

## 遊び方は2つ

| | ひとりで遊ぶサイト | 家族サーバー |
|---|---|---|
| 開き方 | スマホで <https://koyamaryonetsu-arch.github.io/-DB/kizuna/> を開くだけ | 家のPCで動かして、スマホから `http://192.168.…:3000` |
| PC | いらない | 家のPCの電源を入れておく |
| いっしょに遊ぶ | できない（ひとり用） | できる（4人まで。招待した人のストーリーを手伝う） |
| 外出先 | どこでも遊べる | 家のWi-Fiの中だけ（[Tailscale](#外出先から家族サーバーにつなぐtailscale) を入れると外からも） |
| セーブ | そのスマホのブラウザの中 | 家のPC（ホームフォルダの `kizuna-save`） |
| 新しい版 | Claude が更新すると、自動で新しくなる | 起動するたびに GitHub を調べて、自動で新しくなる |

- **家族サーバーには、いつも一番新しいデータが入ります。** サイトの「🏠 家族サーバーで遊ぶ」で行くと、そのスマホで進めたキャラも持っていって保存します。
  家族サーバーを直接開いた時も、ときどき自動でサイトのデータを取りに行きます（くわしくは「[家族サーバーとスマホのデータを合わせる](#家族サーバーとスマホのデータを合わせる)」）
- ひとりで遊んだぶんも、家族サーバーで遊んだぶんも **両方合わせて残ります**（経験値・お金・道具・仲間・ストーリー）。だから、それぞれ一人でレベルを上げてから、集まっていっしょに遊べます
- アプリが新しくなっても、**セーブは消えません**（どちらも、セーブはアプリの外にあります）

## 家族サーバーの作り方（はじめの1回だけ）

このゲームは GitHub の **`claude/elegant-bell-al2f1w` ブランチ** に入っています。

1. **Node.js を入れる**：<https://nodejs.org/ja> から「LTS」をダウンロードしてインストール（ボタンを押していくだけ）
2. **ゲームをダウンロード**：PCのブラウザで <https://github.com/koyamaryonetsu-arch/-DB/tree/claude/elegant-bell-al2f1w> を開き、
   緑の「**Code**」→「**Download ZIP**」→ ZIPを開く（Windows は右クリック →「すべて展開」）
3. **動かす**：中の `family-rpg` フォルダの **`start.bat`**（Windows）か **`start.command`**（Mac。はじめは右クリック →「開く」）をダブルクリック
4. 黒い画面に出る **アドレス** と **合言葉** を、家族のスマホの Safari で開いて入れる（ホーム画面に追加すると、アプリのように使えます）

- **2回目からは 3 だけ**。起動するたびに新しい版を自動で入れます（ZIPのダウンロードはもういりません）
  - 新しい版がうまく動かなかった時は、自動で前の版にもどして動かします
  - 自動の更新を止めたい時は、`kizuna-save/config.json` に `"autoUpdate": false` と書きます
- セーブと合言葉は、ホームフォルダの `kizuna-save` にあります。アプリのフォルダを消しても、ZIPをどこに開きなおしても、そのまま続きから遊べます
- 前の版（アプリの中の `data` にセーブしていた版）を使っていた時は、はじめて起動した時にセーブを自動で引っこします（くわしくは「[セーブとバックアップ](#セーブとバックアップ)」）

## 遊び方

### ひとりで遊ぶサイト（PCなし）

スマホの Safari などで **<https://koyamaryonetsu-arch.github.io/-DB/kizuna/>** を開くだけで遊べます（アカウントもいりません）。

- セーブは、そのスマホのブラウザの中に残ります。ブラウザを閉じても消えません
  - ブラウザの「履歴とWebサイトデータを消去」をすると消えます。Safari は、長いあいだ開かないサイトのデータを消すことがあります
  - 大事なキャラは、家族サーバーに連れていくか、引っこしコードをメモに残しておくと安心です
- 家に帰ったら「**🏠 家族サーバーで遊ぶ**」。このスマホで進めたキャラも家族サーバーに保存されます（はじめての時だけ、家族サーバーのアドレスを入れます。家族サーバーの「📱 ひとりで遊ぶサイトへ」から開いたサイトなら、アドレスを覚えています）
- サイトは GitHub Pages（`gh-pages` ブランチの `kizuna/` フォルダ）に置いてあります。`family-rpg` を変えて push すると、テストをしてから自動で新しくなります（`.github/workflows/kizuna-pages.yml`。同じ場所にあるほかのゲームのファイルはそのまま）
- claude.ai のアーティファクトで開いた時は、claude.ai にセーブされます（「クラウドセーブ」）

### 家族サーバーで遊ぶ（一人でも家族でも）

家のPCを1台「サーバー」にして、家族のスマホ・タブレット・PCからブラウザでつなぎます（作り方は上の「[家族サーバーの作り方](#家族サーバーの作り方はじめの1回だけ)」）。

1. **Node.js を入れる**（はじめの1回だけ）
   <https://nodejs.org/ja> から「LTS」をダウンロードしてインストール（18以上ならOK）
2. **このフォルダをPCに置く**（上の「ダウンロード」、または `git clone`。git で取ってきた時は自動の更新はしないので `git pull` で新しくします）
3. **サーバーを動かす**（`family-rpg` フォルダの中で）
   - Windows … `start.bat` をダブルクリック
   - Mac … `start.command` をダブルクリック（はじめは右クリック →「開く」）
   - Linux … `./start.sh`
   - コマンドで動かすなら `npm start`（または `node server/index.js`）
4. **画面に出るアドレスをブラウザで開く**

   ```
   ★☆★ きずなの紋章　家族サーバーが動きました ★☆★

   このPCで遊ぶ:  http://localhost:3000
   同じWi-Fiのスマホ・タブレットから:
      http://192.168.1.23:3000
   家族の合言葉:  482915
   ```

5. **家族の合言葉を入れる** → キャラクターを作ってスタート！

- 家族の合言葉は最初に自動で決まり、セーブの場所（ホームフォルダの `kizuna-save`。サーバーの画面にも出ます）の `config.json` の `password` に書かれています。好きな言葉に変えてOK（変えたらサーバーを再起動）
- 終わる時はサーバーの画面で `Ctrl + C`。セーブは自動です
- Windows で「ファイアウォールでブロックされています」と出たら「プライベートネットワーク」だけ許可してください
- ポート番号を変えたい時は `kizuna-save/config.json` の `port`

> **大事：** このサーバーをインターネットに公開（ポート開放など）しないでください。家のWi-Fiの中だけで使う想定です。
> 遠くに住む家族と遊びたい時は、下の Tailscale（家族だけのVPN）を使う方法が安全です。

### 外出先から家族サーバーにつなぐ（Tailscale）

ふつうは、家のPCと同じWi-Fiにいないとつながりません（外出先ではマルチプレイできません）。
**Tailscale**（個人は無料）を入れると、外出先や別の家からでも、家族だけが家族サーバーにつながれます。インターネットに公開はしないので安全です。

1. 家族サーバーのPCに Tailscale を入れてログイン（<https://tailscale.com/download>）
2. 家族のスマホに「Tailscale」アプリを入れて、**同じアカウント** でログイン（VPN の追加を「許可」）
3. 家族サーバーを起動すると、黒い画面に **「外出先から（スマホの Tailscale をONにして）: `http://100.x.x.x:3000`」** が出ます
4. スマホの Tailscale を ON にして、そのアドレスを Safari で開く（家の中でも外でも同じアドレスで開けます）

- ひとりで遊ぶサイトの「🏠 家族サーバーで遊ぶ」のアドレスも、この `100.x.x.x:3000` にしておくと、外出先からでもデータを合わせられます（「だれで遊ぶ？」→「アドレス」で変えられます）
- 家族サーバーのPCの電源とスリープに注意してください（スリープ中はつながりません）

### iPhone で遊ぶ

1. iPhone を家のWi-Fiにつなぎ、Safari でサーバーのアドレス（`http://192.168.x.x:3000` など）を開く
2. **ホーム画面に追加すると、アプリのように画面いっぱいで遊べます**
   Safari の共有ボタン（□に↑）→「ホーム画面に追加」。次からはホーム画面の「きずな」アイコンで開けます
   （ホーム画面から開いた時は、合言葉をもう一度入れます）
3. たても・横もどちらでも遊べます（戦いの画面も向きに合わせて変わります）

- メニューやお店は、右上の「**✕ 閉じる**」か、まどの外をタップで閉じます。リストの上の「**← もどる**」で一つ前にもどります
- メニュー・お店・「はい／いいえ」・「だれで遊ぶ？」などのウインドウは、直接タップするほかに、画面の下（横向きの時は左右）に出る **十字キー（▲▼◀▶）と A・B** でも選べます。おしっぱなしで続けて動きます
  - いらない時は、メニュー →「設定」→「ウインドウの十字キー：出さない」
- 横向きの時は「メニュー」「チャット」「スタンプ」のボタンが、右上の地図の左に横にならびます（A・B・走るボタンと重なりません）
- 画面が消えたり、ほかのアプリに切りかえても、**3分以内にもどれば続きから** 遊べます（パーティーもそのまま。戦いの間はオートで戦います）
- 設定（メニュー →「設定」）
  - 「画面：2.5D（立体）／2D（ドット）」… 動きが重い時や古い機械では 2D がおすすめ
  - 「ウインドウの十字キー：出す／出さない」… ウインドウの時に十字キーとA・Bを出すか
  - 「遊んでいる間は画面を消さない」… ON がおすすめ（家族との通信がとぎれにくい）
  - 「マナーモードでも音を出す」… iPhone のサイレントスイッチが ON でも音を鳴らす
- 音が出ない時は、画面を一度タップしてください（iPhone はさわるまで音を止めています）

## 一人で遊ぶ／家族で遊ぶ

- **パーティーは4人まで。** 家族を「さそう」と同じパーティーになり、いっしょに戦えます
- **みんな自由に動けます。** 別々の場所（町と洞窟など）にいてもOK
- **いっしょに戦うルール（ドラクエ10風）**
  - だれかが魔物にふれると、**近く（画面にうつるくらい）にいる仲間** がいっしょに戦います
  - はなれている仲間は引きこまれません。仲間の頭に ⚔ と足もとに光る輪が出るので、**そこへかけつけると、とちゅうから参加** できます
  - 会話・お店・イベントのとちゅうの人は引きこまれません
- **ついていく**：メニュー →「仲間」→「リーダーについていく（自動）」で、リーダーのあとを自動で歩きます（洞窟の出入りや船もいっしょ）。小さい子どもにおすすめ
- **ストーリーは、招待した人（リーダー）のストーリーを、招待された人が手伝います**
  - 招待を受けると、リーダーのところへ自動で移動します（ひとりで鍛えたキャラもすぐ合流できる）
  - イベント（ボス戦など）は、同じマップにいる仲間みんなで見て、みんなで戦います
  - **進むのはリーダーのストーリーだけ。招待された人の自分のストーリーは変わりません**（クリアの印・目標・大事な物・ゲスト・いのりの場所・たのまれごと・物語で仲間になる人は、リーダーだけに入ります）
  - 招待された人も、**経験値・レベル・お金・ふつうの道具・装備** はもらえます（いっしょに遊んで強くなれる）
  - 招待された人の画面には「〇〇の目標」としてリーダーの目標が出ます。メニューの「クエスト」では自分の目標も見られます
  - **パーティーをぬける（リーダーが終わる）と、パーティーに入る前の場所にもどります**（つぎにログインした時も、自分の冒険の場所から）
  - 手伝っている間に全滅したら、リーダーといっしょにリーダーのいのりの場所で目を覚まします。教会で記録しても、自分のいのりの場所は変わりません
  - 手伝っている間は、宝箱の大事な物（カギなど）は取りません（自分の冒険の時に開けよう）
  - 仲間がストーリーの人に話しかけても、リーダーのストーリーで進みます。リーダーが近くにいない時は「リーダーといっしょに進めよう」と出て、進みません
  - 自分のストーリーを進めたい時は、自分がリーダーになって家族を招待するか、ひとりで遊んでね
- **仲間（ルミナの町の酒場）**
  - 酒場で仲間（ガルド／ミーナ／ポポロ／リン／ティナ、第1章クリアでルカ）を探して連れていけます。連れていけるのは3人まで。待っている仲間とは **酒場でいつでも入れかえ** できます
  - 仲間は **それぞれ育ちます**（戦いに出た仲間だけ経験値をもらう）。メニューの「装備」「強さ」「呪文」で仲間を選べます。神殿で仲間の転職もできます
  - 作戦を **「めいれいさせろ」** にすると、仲間のコマンドも自分で選べます（オートボタンでみんなまとめてオートにももどせる）
  - 家族のキャラクターも AI の仲間として連れていけます（その人がいない日でもOK）。持ち主には、あとで経験値やゴールドの「お礼」がとどきます
  - 仲間やゲスト（ルカ）はセーブデータに残るので、アプリを落としてもいなくなりません
- **モンスターの仲間**
  - 森の主とのイベントで紋章の力「魔物の心」に目覚めると、**戦いで最後にたおした魔物がときどき仲間になりたがります**（ボスや物語の敵はなりません）
  - パーティーがいっぱいの時は、だれかが酒場へもどります（新しい仲間に酒場で待ってもらうこともできる）
  - モンスターはレベルで技を覚えて育ちます。装備はアクセサリーだけ。名前は酒場で変えられます
  - 第2章の海では、マリンぷるりん・あばれカモメ・シェルナイト・ゆうれい海賊・雷こぞう・ストームバード・サンゴゴーレム・嵐の兵なども仲間になります
- **配合（酒場）**
  - **レベル10以上** のモンスター2匹を選ぶと、新しいモンスターが生まれます（ドラゴンクエストモンスターズ風）
  - 生まれた子は **レベル1** から。でも **親の技を4つまで受けつげます**（自分で選ぶか、おまかせ）
  - 親の強さを少し受けつぎ（装備を外した強さの1割）、「**＋値**」がふえます。＋が多いほどよく育ちます
  - 生まれる種族はふつう1匹目の親と同じ。**特別な組み合わせ** だと、配合でしか生まれないモンスター（キングぷるりん・ふわりん・ちびドラゴン・ストーンゴーレム・ほしがたパンサー・あくまのきし・ちびトレント）が生まれます
  - 親の2匹は旅立っていきます（装備はふくろにもどる）
- **図鑑**（メニュー →「図鑑」）
  - 出会った魔物・仲間にした魔物・配合で生んだ魔物が記録されます。まだ出会っていない魔物はかげだけ
  - 配合でしか生まれない魔物は、かげといっしょに組み合わせのヒントが出ます
- チャットとスタンプで家族とおしゃべりできます

## 町の施設（お店・宿屋・教会）

ドラゴンクエストと同じように、店の人とカウンターごしに話して、「はい／いいえ」で進みます。

### かんばんと地図のしるし

お店の入り口の横には、かんばんがかかっています。地図（M・メニュー →「マップ」）にも同じしるしが出ます（行ったことがある所だけ）。

| しるし | 施設 |
|---|---|
| 剣 | 武器屋 |
| たて | 防具屋 |
| 剣とたて | 武器と防具の店（カモメ港） |
| ふくろ | 道具屋（緑のかんばんは、何でも売っている「よろず屋」） |
| INN | 宿屋 |

### お店の流れ

1. 店の人に話しかける →「どんなご用でしょう？」→ **買いにきた／売りにきた／やめる**
2. **買う**：品物を選ぶと、右のまどに「**装備すると、こう変わる**」が出ます
   - 自分と仲間の一人一人について「攻撃力 52→66 ↑14」のように、強さがどう変わるかを一覧で表示
   - 装備できない人は「装備できない」、もう装備している人は「E 装備している」
   - リストの「↑強くなる」は、だれかが強くなる品物のしるし
3. 「〇〇ゴールドになりますが、よろしいですか？」→ **はい／いいえ**（いいえ＝買わない）
   - 薬草などの道具は、先に「いくつお求めですか？」で数を選べます
4. 装備品なら「**ここで装備していきますか？**」→ はい →「**どなたが装備しますか？**」（自分か仲間を選ぶ。「装備しない」でふくろに入れるだけにもできる）
5. 今まで装備していた物があれば「**〇〇ゴールドで引き取りましょうか？**」→ はい＝売る／いいえ＝ふくろに入れる
6. **売る**：ふくろの品物を選ぶ → 数を選ぶ →「〇〇ゴールドで引き取りましょう。よろしいですか？」→ はい／いいえ（売ると、買ったねだんの4分の3）

どの場面でも、B（X/Esc）や「もどる」で一つ前にもどれます。右上の「✕ 閉じる」で、いつでもお店を出られます。
メニューの「装備」でも、お店と同じ「攻撃力 52→66 ↑14」の形で、強さの変わり方が見られます。
メニューの「道具」で装備品を選んで「装備する」を選ぶと、「だれが装備する？」と聞かれます（みんなの変わり方もいっしょに出ます）。

### 宿屋・教会

- **宿屋**：「ひと晩〇〇ゴールドですが、おとまりになりますか？」→ はい → みんなのHPとMPが全回復（ルミナの町 12ゴールド、カモメ港 20ゴールド）
- **教会**：おいのりをする（ここを「いのりの場所」として記録。全員がたおれたら、ここで目を覚ます）／生き返らせる／毒を治す。どれも寄付のねだんを聞いてから「はい／いいえ」で決めます

## バトル

- **リアルタイムターン制**：一人一人の「行動ゲージ」がたまったらコマンドを選べます。**素早さが高いほどゲージが早くたまる**（武闘家はとても速い）
- 画面の下は、**左の大きいまどがコマンド**、**右の小さいまどがメッセージ** です（スマホのたて画面では、コマンドが下に大きく出ます）
- ゆっくり選びたい時は「ウェイト」をONにすると、コマンドを選んでいる間は時間が止まります（メニュー → 設定。戦いの速さも変えられます）
- **オート** ボタンで AI にまかせることもできます（「めいれいさせろ」の仲間もいっしょにオートになる）
- 攻撃・呪文には、それぞれエフェクトがあります（メラは火の玉が飛んでいく、ヒャダルコは氷の柱、イオラは爆発、ギガデインはいかずち、ドルオーラは竜の光、会心の一撃は画面がゆれる など）
- ボスは1ターンに2回動いたり、大技の前に「ためる」ので、防御・回復のタイミングが大事。HPがへると、仲間を呼んだり、強くなったりするボスもいます
- **連携**：仲間が続けて攻撃するとダメージがふえる（2連携 1.1倍 〜 最大 1.25倍）
- **合体**：ちがう属性で連携すると合体技が発動（炎＋氷＝対消滅、炎＋風＝火炎旋風 など）
- **きずなゲージ**：いっしょに戦うとたまり、満タンできずな技「ミナデイン」。パーティーのみんなが「参加」をおすほど強くなる

## セーブとバックアップ

### セーブの場所

- **家族サーバー**：ホームフォルダの **`kizuna-save`** フォルダ（サーバーの画面の「セーブの場所」にも出ます）
  - Windows … `C:\Users\（名前）\kizuna-save`　／　Mac … `/Users/（名前）/kizuna-save`
  - `save.json` … セーブ（自動）　／　`config.json` … 合言葉・ポート番号・家族の名前
  - `backups/` … 1時間ごとのバックアップ（最新24こ）。新しい版に切りかえる前・引っこしコードで入れかえる前のセーブも、ここに残します
- **ひとりで遊ぶサイト**：そのスマホのブラウザの中（localStorage）。ブラウザを閉じても残ります。ブラウザのデータを消すと消えます
- **claude.ai のアーティファクト**：**claude.ai にセーブ**（クラウドセーブ）。くわしくは下の「クラウドセーブ」
- セーブと合言葉はアプリのフォルダの外にあるので、GitHub にのることはありません

### 新しい版にしてもセーブは消えません

- **家族サーバーは、起動するたびに新しい版を自動で入れます**（アプリの中身だけを入れかえます。セーブ・合言葉・`start.bat` はそのまま）
  - 入れかえる前のアプリは `kizuna-save/app-previous` にとっておきます。新しい版がすぐに止まった時は、自動でそこからもどします
  - インターネットにつながらない時は、今の版で動きます
- **ひとりで遊ぶサイト** も、Claude が更新すると自動で新しくなります。セーブは同じ場所（ブラウザの中）のままです
- セーブはアプリのフォルダの外にあるので、**新しいZIPをどこに開いても、古いフォルダを消しても、続きから遊べます**
- これより前の版は `family-rpg/data` にセーブしていました。新しい版を起動すると、近くのフォルダ（ダウンロード・デスクトップ・書類・OneDrive もふくむ）にある古い版のセーブを自動で見つけて、`kizuna-save` へ引っこします
  - 古いほうのセーブは消しません（そのフォルダに「セーブの引っこし.txt」を置きます）
  - 古い版を起動して遊んでしまっても、次に新しい版を起動すると、あとで遊んだキャラが引っこします（新しい版で消したキャラは、もどってきません）
  - 見つからない時は、古い `family-rpg/data` フォルダを、新しい `family-rpg` フォルダの中にコピーしてから起動してください（自動で引っこします）
- セーブの形が変わる版では、起動した時に自動で新しい形にします（その前のセーブは `backups/` に1回だけ残します）
- 新しい版で遊んだあとに古い版へもどした時など、知らない道具・職業・魔物が入ったセーブも、消さずにとっておきます。また新しい版で読んだ時に元にもどります
- セーブの場所を変えたい時は、環境変数 `DATA_DIR` でフォルダを指定します（この時は古いセーブの自動の引っこしはしません）
- 第1章をクリアしたセーブで新しい版を始めると、目標が「ホシミばあちゃんに話しかけると、第2章が始まるよ」に変わります

### クラウドセーブ（アーティファクトの一人モード）

iPhone の Safari や Claude アプリでは、アーティファクトの中のブラウザのセーブが、ブラウザを閉じると消えることがあります。
そこで、アーティファクトで遊ぶ時は **claude.ai（アーティファクトのデータベース）** にもセーブします。

- セーブは **1人ずつ別の場所**（claude.ai のアカウントごと）。ほかの人からは見えません（アーティファクトの持ち主からも）
- 同じ claude.ai のアカウントなら、Safari・Claude アプリ・PC のどれで開いても同じセーブです
- 遊んでいる間は、変わったところを10秒おき（歩いただけなら1分おき）にセーブ。宿屋・教会の「記録」・「終わる」・キャラを作る・消す時と、ほかのアプリに切りかえた時は、すぐにセーブします
- このブラウザにもいっしょにセーブします。両方にある時は、あとでセーブしたほうを使います
- 「だれで遊ぶ？」の上に、セーブの場所が出ます
  - 「☁ claude.aiにセーブ（ブラウザを閉じても消えません）」… OK
  - 「このブラウザだけにセーブ（…消えることがあります）」… claude.ai にセーブできていません。大事なキャラは、家族サーバーに連れていくか、引っこしコードをメモに残してね
- はじめて開いた時、claude.ai の画面に「許可」の確認が出たら「許可」を選んでください
- **大人の家族にも使ってもらう時**：アーティファクトの Share メニューの「メールで招待（ベータ）」で、家族のメールアドレスを **「編集できる（Can edit）」** で招待します
  - 招待された人は、そのメールアドレスの Claude アカウントでログインして開きます。無料のアカウントでも招待を受けられます
  - 「見るだけ」「コメントできる」のままだと、claude.ai にはセーブできません（このブラウザだけのセーブになります）
  - クラウドセーブを使うアーティファクトは、リンクでの一般公開はできません
- **Claude のアカウントは1人1つ**です。アカウントを家族で共有することは、Anthropic の利用規約で禁止されています。また、アカウントを作れるのは18歳以上です（無料でも同じ）
- **お子さんは家族サーバーで**：家族サーバーならアカウントはいりません。1つのセーブに家族全員のキャラを作って、それぞれ自分のスマホで遊べます（セーブは家のPCに残ります）

### 家族サーバーとスマホのデータを合わせる

**家族サーバーには、いつも一番新しいデータが残ります。** 家族サーバーで遊んでも、スマホのひとりで遊ぶサイトで遊んでも、家族サーバーにつながった時に新しいデータを保存します。

- **サイト → 家族サーバー**：サイトのタイトルか「だれで遊ぶ？」の「**🏠 家族サーバーで遊ぶ**」
  - このスマホで進めたキャラを持って家族サーバーが開き、合言葉のあとで自動で保存します（「〇〇の両方で遊んだデータを合わせました（Lv8→Lv10）」などと出ます）
  - はじめての時は、家族サーバーのアドレス（`192.168.…:3000`。Tailscale なら `100.…:3000`）を聞かれます
- **家族サーバーを直接開いた時**：そのスマホでサイトを使ったことがあれば、ときどき（20分以上たった時）自動でサイトへ行って、サイトのデータを持ってもどってきます（1〜2秒）
  - 家族サーバーのキャラも、この時にスマホのサイトへ保存されます
  - 自分で合わせたい時は、家族サーバーの「だれで遊ぶ？」→「**🔄 スマホと合わせる**」
- **家族サーバー → サイト**：家族サーバーの「だれで遊ぶ？」→「**📱 ひとりで遊ぶサイトへ**」（このスマホで遊んだキャラを持っていきます）
- **両方で遊んでも、なくなりません**：家族サーバーで遊んだ後に、古いデータのままのスマホでひとりで遊んでも、次に合わせた時に両方のぶんをたします
  - 経験値・お金・たおした数・職業の勝った数・種 … 両方でふえたぶんをたす（レベルは経験値から）
  - ストーリーの印・宝箱・行った場所・図鑑 … 両方を合わせる（目標は進んでいるほう）
  - 道具・装備 … 品物ごとに、両方でふえた・へったぶんをたす（使った道具は減る）
  - 仲間 … 両方の仲間を残す（別々に仲間になった魔物は両方とも）
  - いる場所・HP・作戦など … あとで遊んだほう
  - 合わせる前のセーブは `kizuna-save/backups/` に残ります（`save-before-sync-…`）
- 家族サーバーで消したキャラは、スマホから持っていっても、もどってきません（消した後にスマホで遊んでいたら、もどります）
- 同じキャラを2つの端末で同時に遊んでいる時は、あとで合わせます
- 家族サーバーのアドレス以外（家の外の知らないアドレス）へは、だまってデータを送りません（「送りますか？」と聞きます）
- iPhone で「ホーム画面に追加」したサイトは、Safari とは別のセーブになります。行き来は Safari で開いたサイトで使うのがおすすめです
- 家族サーバーで一人で遊ぶこともできます。家族サーバーのキャラは全員が同じセーブにいるので、いつでも「さそう」でパーティーを組めます

### 引っこしコード（コピーして送る・手で連れていく）

- **コピーして送るやり方**（別のスマホへ・LINE などで）
  1. 「だれで遊ぶ？」→「引っこしコード」→「① キャラを書き出す」→ キャラを選ぶ →「コピーする」
     （遊んでいる時は、メニュー →「終わる」で「だれで遊ぶ？」にもどれます）
  2. 別のスマホ・PCへは、LINE・メッセージ・AirDrop・メモなどでコードを送る（同じスマホなら送らなくてOK）
  3. 家族サーバーの「だれで遊ぶ？」→「引っこしコード」→「② コードから連れてくる」→ はりつけて「連れてくる」
  - もういるキャラのコードなら、**コードのほうが後で遊んだデータの時だけ** 入れかえます（入れかえる前のセーブは `backups/` に残ります）
  - 同じ名前の別のキャラがいる時は、名前のうしろに数字がつきます
  - 家族サーバー → 一人モードへも、同じやり方で連れていけます
  - 引っこしコードで連れていった時は、あとで遊んだほうのデータになります（両方のぶんを合わせたい時は、上の「🏠 家族サーバーで遊ぶ」を使ってね）
  - コードは短くしてあるので、仲間がいっぱいでも LINE で1回で送れます（LINE は1回1万文字まで。仲間24人でも7千文字くらい）
  - コードをメモに残しておくと、もしもの時のバックアップにもなります

#### iPhone だけで引っこす（PCの操作はいりません）

家族サーバーのPCは電源を入れておくだけで、操作はいりません。同じ iPhone で遊んだキャラなら、送る手間もありません。

1. ひとりで遊ぶサイト（Safari）で「引っこしコード」→「① キャラを書き出す」→「コピーする」（「🏠 家族サーバーへ連れていく」なら、コピーもいりません）
   - 「コピーしました！」と出れば OK。出ない時は、コードが全部選ばれた状態になるので、青いところを長おし →「コピー」
2. Safari で家族サーバーのアドレス（`http://192.168.…:3000`）を開いて合言葉を入れる
3. 「引っこしコード」→「② コードから連れてくる」→ わくの中を長おし →「ペースト」→「連れてくる」

- ひとりで遊ぶサイトのセーブは、ブラウザを閉じても残ります。ブラウザのデータを消すと消えるので、大事なキャラは家族サーバーに連れてくるか、コードをメモに残しておくと安心です

## 開発向け

```bash
cd family-rpg
npm test                  # 戦い・マップ・ストーリー（第1章・第2章を通しで）・マルチのルール・通信・文字のルールのテスト
node tools/sim.js         # バランスのシミュレーション（第1章）
node tools/sim.js 20 ch2  # 第2章の敵とボス
node tools/kanji-check.mjs  # 画面に出る文字のチェック（使えない漢字・スペース）
npm start                 # 家族サーバー
```

- 依存パッケージなし（Node.js だけで動く）。WebSocket も自前で実装
- `public/js/shared/` … ゲームのルール（サーバーとブラウザの両方で動く）
  - `data/` 職業・技・道具・魔物・ストーリー（`*-ch2.js` は第2章のぶん。`story.js` と `story-ch2.js` が台本）
  - `maps/` マップ（`overworld.js` ミドリナ地方、`sea.js` 風の海、`ch2-rows.js` 港町・洞窟・塔、`ch2.js` 第2章の人・宝箱・出入り口）
  - `world/` 世界の動き（パーティー・仲間・酒場、イベント、戦いの進行）
  - `battle.js` リアルタイムターン制バトル
- `public/js/client/` … 画面・音・操作（ドット絵もBGMもプログラムで作っています）
  - `render/field3d.js` 2.5D の画面（`render/tex3d.js` は3D用の絵）
  - `render/chars.js` キャラのドット絵（装備で服・かぶと・たて・武器が変わる。船もここ）、`render/battlefx.js` 戦いの背景とエフェクト
- `public/vendor/three.min.js` … 3Dのための three.js（MIT）。使う部分だけを `tools/build-three.mjs` でまとめたもの。インターネットにつながなくても動きます
- `server/` … 家族サーバー（合言葉・セーブ・つなぎ直し）。`server/savedir.js` はセーブの場所と古いセーブの引っこし
  - `server/index.js` は起動用（`server/update.js` で GitHub の新しい版を入れてから、本体の `server/main.js` を動かす）
- `tools/build-site.mjs` … ひとりで遊ぶサイトを作る（`?v=版` をつけて、新しくした直後に古いファイルとまざらないようにする）
- `public/js/client/links.js` … ひとりで遊ぶサイトと家族サーバーを行き来するリンク（`#kizuna=コード&server=アドレス`、データを合わせる `#sync=データ&back=もどり先`）
- `public/js/shared/world/sync.js` … 家族サーバーとサイトのデータ合わせ（`KIZUNA-S1-` の形。両方が「やりとりした版」を覚えておき、共通の版を「わかれる前」にして `world/merge.js` の3方向マージでまとめる）
  - 版は、家族サーバーは `kizuna-save/sync/<キャラID>.json`（`server/syncstore.js`）、サイトは localStorage の `kizuna_sync_v1` に残す
  - 画面の流れは `public/js/client/ui/syncui.js`（サイト→家族サーバー、家族サーバー→サイト、家族サーバーからの自動の行き来）
- `public/js/client/input.js` の `bindPad` … スマホのウインドウ用の十字キー。`ListMenu` など `pad: true` のハンドラーが一番上にある時に出して、`#ui` をパッドのない所へよせる（`--pad-h`）
- `public/js/shared/world/save.js` … セーブの版（`SAVE_VERSION`）と引きつぎ。`world/transfer.js` は引っこしコード
- `public/js/client/cloudsave.js` … クラウドセーブ（アーティファクトの `db` の `data/users/<id>/`。`meta` とキャラ1人1文書 `c-<ID>`）。アーティファクトは `capabilities: { db: {}, user: {} }` で公開する
  - **道具・職業・魔物・マップの ID は消さない・名前を変えない**（古いセーブが読めなくなるため）
  - セーブの形を変える時は、`SAVE_VERSION` を1つ上げて、`UPGRADES` に古い形から直す手順をたす。`test/save.test.js` に古いセーブを読むテストがあります
- `tools/kanji-grades.mjs` … 学年別漢字配当表（2020年度から）の1〜6年の漢字
- 新しい章をふやす時は、`data/story-*.js`（台本）と `maps/`（マップ）にたします。船で進めるマップは `sailable: true`
