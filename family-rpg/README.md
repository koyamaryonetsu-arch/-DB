# きずなの紋章 ― 家族で遊ぶオープンワールドRPG

家族だけで遊ぶための、ブラウザで動くRPGです。
一人でこつこつ冒険する日も、みんなで集まってストーリーを進める日も楽しめます。

- **一人でも・家族いっしょでも** … 家族は5人までいっしょに歩いて、いっしょに戦えます。家族がいない時は、酒場の仲間やモンスターの仲間で4人までうめられます
- **仲間はそれぞれ育つ** … 酒場で仲間を探して、いつでも入れかえ。仲間ごとにレベル・装備・転職・作戦（「めいれいさせろ」で自分でコマンドも選べる）
- **馬車と総入れかえ（第1章クリアのあと）** … 戦う仲間3人のほかに、馬車に4人（家族のキャラも）。「総入れかえ」で1〜4番目（戦う仲間）と5〜8番目（馬車）をまとめて決められます。戦いの中でも、馬車の仲間とまとめて入れかえられます
- **モンスターが仲間になる** … 紋章の力「魔物の心」に目覚めると、たおした魔物がときどき起き上がって仲間になりたがります
- **配合と図鑑** … 育てたモンスター2匹をかけ合わせると、親の技と強さを受けついだ子が生まれます。ドラゴンクエストモンスターズのように、図鑑にのっていない魔物ほど生まれやすく、配合でしか生まれないモンスターも（全部で136種）。出会った魔物は「図鑑」にのります
- **船で海を冒険（第2章）** … 船「しおかぜ号」で海を自由に進めます。港町・灯台・小島・洞窟・嵐の塔
- **雪と氷の北の地方（第3章）** … 雪の村・鉱山の町・温泉の里。つるつるすべる氷の洞窟、トロッコとレバーの鉱山、ようがんの流れを変える炎の山、3つの試練の神殿、ふぶきの星竜山。さいごは星の竜の背中に乗って空を飛べます
- **砂の国（第4章）** … 星の竜アステルに乗って、南の砂ばくの「コガネ地方」へ。オアシスの村、古い井戸、砂嵐のかべ、水門のレバーで水を動かす「かれた地下水路」、水がかれた **王都サファラ**（夜の宮殿の中庭のなぞ）、お昼にだけ入口が開く **王家のピラミッド**（歌のボタン・呪文がふうじられた階・流れる砂の迷路・のろいの宝）、月の鏡を持って乗りこむ **夜の宮殿**（まぼろしの分身を見ぬく戦い）、その先の南の砂ばくと、砂の海賊の港 **ドゥナ**（2人で同時にふむ石の板の「砂の古城」・砂の船「すなかぜ号」で進む **砂の海**）、砂クジラが運んでくれる **砂の底の神殿**（3つのレバーで水の高さを動かす階・月の鏡で本物の道が光る「鏡の間」・自分たちそっくりの「鏡のうつし身」）。砂ばくは昼と夜で出る魔物がかわります（夜は月のゆうれいが出て手ごわい）。ボスの「反撃の構え」や「よみがえりの呪文」「まぼろしの分身」「砂にもぐる」を見ぬいて戦おう
- **昼と夜** … げんじつの20分で1日。夜は暗くなり、町のあかりがともります。フィールドには夜だけの魔物（経験値とゴールドが多い）、町には夜の商人やゆうれいの女の子も。宿屋では「朝まで」「夜まで休む」を選べます（王都サファラの宿屋は「昼まで休む」も）
- **ルーラ** … 魔法使い（職業レベル2）と賢者が覚える移動の呪文。行ったことのある町へ、仲間といっしょに飛べます
- **風の大鳥フウラ（第2章クリアのあと）** … 「風の笛」で呼ぶと、山も海もこえて空を飛べます。ミドリナ地方と風の海の間も、ひとっ飛び
- **カジノ（第2章・カモメ港）** … 道具屋のとなりの「7」のかんばんの建物。コインは1枚20ゴールド（ゴールドにはもどせません）。スロット（1・10・100枚かけ。7が3つで250倍）とポーカー（ジョーカー入り・「おまかせ」で残すカードを選んでくれる・勝つと最大5回のダブルアップ）で遊んで、景品コーナーで種や★の装備（はやぶさの剣・星空のマントなど）とこうかん。どちらも少しだけお店が勝つ（スロットのもどりは約93%、ポーカーは約95%）。本物のお金はどこにも出てきません
- **ひみつのダンジョン** … ルミナの町の南門の外。終わりのない地下のめいろを、家族で何階までもぐれるかきそえます（5階ごとに休み所とごほうび、10階ごとに番人。くわしくは「[ひみつのダンジョン](#ひみつのダンジョン何階までもぐれるか家族できそう)」）
- **小さなメダルとメダル王** … 村・町・港のつぼ・たる・本だな・井戸、光っている地面、洞窟や塔の宝箱など、30か所にかくれています（1人1回。パーティーでは見つけた人がもらう）。カモメ港の東の小島の「メダル王の城」でメダルをわたすと、5・10・15・20・25・30枚（40・50枚はこれからの章）でごほうび。持っている数は「道具」と「クエスト」に出ます
- **細かいドット絵** … 人も魔物も、前の4倍の細かさで描いています（目のかがやき・かみのつや・服のしわ・よろいの光り方まで）。主人公と人間の仲間・家族のキャラは、ドラクエ9のように装備ごとに見た目が変わります（よろい・武器・たて・かぶと。布→皮→くさり→鉄→銀→★とランクが上がるほど豪華に。きたえた装備はきらめく）
- **美容室（ルミナの町）** … かみがた18種・かみの色21色・目もと6種・はだの色5種から選んで、見た目を変えられます（30ゴールド）。キャラを作る時も同じだけ選べます
- **家族だけ** … 家族の「合言葉」がないと入れません。ふだんは家のWi-Fiの中だけ。外出先からは Tailscale Funnel で遊べます（家族のスマホにアプリはいりません）
- **オープンワールド** … 村・町・平原・森・湖・沼・洞窟・海を自由に歩けます（シンボルエンカウント）
- **2.5D（立体）の画面** … 地面・建物・山・木が3D、キャラはドット絵のまま。ななめ上から見下ろすカメラ（設定で昔ながらの2Dにももどせます）
- **リアルタイムターン制バトル** … 素早さで行動ゲージのたまる速さが少しだけ変わります（差は小さめ）。戦闘は昔のドラクエのような1画面
- **転職（基本職 → 上級職 → 超級職）** … 職業レベルは戦いに勝った数で上がります（最大10）。基本職を2つきわめると上級職、上級職をきわめると竜の騎士・大魔道士・勇者などの超級職になれます。超級職は、はじめはひみつ。上級職をきわめるたびに、神殿でヒントが出ます（「神殿のうわさ」も聞けます）
- **まじめな職業から、おもしろい職業まで** … 戦士・魔法使いのほかに、遊び人・会社員・アイドル・鉄道員・プロ野球選手。サムライ → ソードマスター・将軍、会社員 → 部長 → 社長、鉄道員 → 運転士 → 京急の運転士、プロ野球選手 → メジャーリーガー → 二刀流スター、小学生 → 中学生 → 高校生、地方公務員 → 国家公務員 → キャリア組（警察官・消防士にも）。スーパースターをきわめると、女性はフルーツジッパー、男性はアラシになれます
- **属性と弱点** … 攻撃呪文には炎・氷・風・爆発・雷・光・闇の属性があり、魔物ごとに得意・苦手があります。弱点は、ためして覚えよう（図鑑にのります）
- **ひらめき（使うほど新しい技を思いつく）** … 同じ技を何回も使っていると、戦いの中で「ひらめいた！」と新しい技を思いつきます（ロマサガ風）。基本職ごとに2つずつ＋新しい職業の道ごとに1〜3つ（界王拳・ノリツッコミ・井戸ばた会議・全員に返信 など）＋掛け合わせ技（魔法剣・メドロ・スターストラッシュなど。使えるのは上級職から）。一覧には今のパーティーの職業に関係する技だけ出ます
- **合体技（2人で出す技）** … 仲間と2人で出す技（対消滅・ライデインストラッシュ・通勤ラッシュ・授業参観・ゴムゴムのかめはめ波・お弁当とどけに来たよ など40種類）。戦いの中で「合体技」を選んでおくと（よやく）、いっしょに出す仲間の行動ゲージがたまった時に出ます。どんな効果かは、一度使うまでひみつ。強さは2人が出した呪文・特技と、**2人の攻撃力・魔力・回復魔力**（強いほう＋弱いほうの半分）で決まります。2人とも強くなるほど、合体技も強くなります
- **何をしたか分かる戦い** … だれが何の技を出したかが名前の札で出ます（オートの仲間は「オート」の印つき）。HP・MPはゲージと数字、HPが半分以下でオレンジ、1割以下で赤
- **長い物語のための装備とドロップ** … 装備には「ランク」があり、物語が進むと店の品ぞろえがふえます。魔物は「よく落とす物」と「レア」を持ち、ボスはかならず特別なアクセサリーを落とします（図鑑にのる）
- **強さのもとはキャラのレベル。職業はそれをおぎなう** … キャラのレベルが上がると、その職業の得意な強さも、いっしょにのびます（Lv21まで）。職業レベルは、技の威力（1つにつき4%）と、得意な強さを少しだけ（1つにつき2%）上げる「補正」です。装備でも大きく強くなります
- **ドラクエのように遊びやすく** … メニューの上にパーティーみんなのHP・MP・Lvと所持金。「まんたん」（呪文で／道具で）、「さいきょう装備」、「ならびを変える」、洞窟から入り口へもどる「みちびきの糸」、道具の「ならべかえ」（あいうえお順・種類順・手に入れた順）、装備を選ぶまどの「入手順／強さ順」、薬草などを続けて使える（使ったあとも「だれに使う？」のまま）。「呪文・技」では技ごとに説明が出て、◀▶でタブ（覚えた技・今使える・お気に入り・ひらめき・合体技）を切りかえられます。「今使える」には、回復や移動など、今その場で使える技だけが出ます。地図には次の行き先（ピンク）と、たのまれごとの報告先（水色・みどり）が出ます
- **ゲームの難しさ（メニュー → 設定）** … 目的地のしるし（メイン・たのまれごと）を出す／出さない、もらえる経験値を ふつう・0.75倍・0.5倍、**敵の強さ** を ふつう・ハード（1.2倍）・ベリーハード（1.5倍）・スーパーハード（2倍）から選べます（キャラごと）
  - **敵の強さ** … 魔物のHP・MP・攻撃・守り・素早さ・魔力が、その倍になります（フィールドの魔物・物語の戦い・ボス・宝の洞窟の魔物・戦いのとちゅうで呼ばれた手下や「まぼろしの分身」もみんな）。**もらえる経験値・ゴールド・落とす物は同じ** です。「敵の強さ」を選ぶと、4つの強さとみじかい説明が出ます
  - 家族サーバーでパーティーを組んでいる時は、**リーダーの「敵の強さ」で戦います**（ストーリーと同じ。招待された人の設定の画面にも「今は〇〇の設定で戦っている」と出ます）。ひとりの時は自分の設定。前の版のセーブは「ふつう」から始まります
  - ふつう以外の時は、戦いの画面の左下に「ハード」「ベリーハード」「スーパーハード」のしるしが出ます
- **フィールドの宝箱ときらきら** … 大陸と海の島には、宝箱がランダムに出ます。開けると消えて、しばらくすると別の場所にまた出ます（中身はその地域に合わせた物）。洞窟・塔・町の宝箱は、開けたまま残ります。光っている「きらきら」は、足もとやとなりのマスでもＡで拾えます（夜も光って見えます）

今は **序章〜第4章（砂の底の神殿で水鏡の魔人モルガナをたおし、水の守り星を取りもどして、第4章クリアまで）** が遊べます。第5章はアップデートで！

### 画面の文字について

ふだんの字は **くっきりしたゴシック**（M PLUS 1p）です。メニュー →「設定」→「**字の形**」で、**丸ゴシック**（M PLUS Rounded 1c）や、昔のゲームのような **ドット**（DotGothic16）にもできます。
まどは細い白わく・小さい角・ひかえめな色（ドラクエ風）で、大人も子どもも見やすいようにしています。

ゲームの中の文字は、**小学4年生までに習う漢字は必ず漢字で書く** ようにしています（「戦う」「呪文」「道具」「仲間」など）。
5〜6年生で習う漢字と、ゲームでよく使う一部の漢字（呪・嵐・洞窟 など）も使います。それ以外の漢字はひらがなです。
言葉と言葉の間にスペースは入れません。`npm test` でこのルールを自動でチェックしています（`tools/kanji-check.mjs`）。

## 遊び方は2つ

| | ひとりで遊ぶサイト | 家族サーバー |
|---|---|---|
| 開き方 | スマホで <https://koyamaryonetsu-arch.github.io/-DB/kizuna/> を開くだけ | 家のPCで動かして、スマホから `http://192.168.…:3000` |
| PC | いらない | 家のPCの電源を入れておく |
| いっしょに遊ぶ | できない（ひとり用） | できる（5人まで。招待した人のストーリーを手伝う） |
| 外出先 | どこでも遊べる | ふだんは家のWi-Fiの中だけ（[Tailscale Funnel](#外出先から家族サーバーにつなぐtailscale) を使うと外からも。スマホにアプリはいらない） |
| セーブ | そのスマホのブラウザの中 | 家のPC（ホームフォルダの `kizuna-save`） |
| 新しい版 | Claude が更新すると、自動で新しくなる | 起動するたびに GitHub を調べて、自動で新しくなる |

- **家族サーバーには、いつも一番新しいデータが入ります。** サイトの「🏠 家族サーバーで遊ぶ」で行くと、そのスマホで進めたキャラも持っていって保存します。
  家族サーバーを直接開いた時も、ときどき自動でサイトのデータを取りに行きます（くわしくは「[家族サーバーとスマホのデータを合わせる](#家族サーバーとスマホのデータを合わせる)」）
- ひとりで遊んだぶんも、家族サーバーで遊んだぶんも **両方合わせて残ります**（経験値・お金・道具・仲間・ストーリー）。だから、それぞれ一人でレベルを上げてから、集まっていっしょに遊べます
- アプリが新しくなっても、**セーブは消えません**（どちらも、セーブはアプリの外にあります）

## 家族サーバーの作り方（はじめの1回だけ）

このゲームは GitHub の **`claude/elegant-bell-al2f1w` ブランチ** に入っています。

1. **Node.js を入れる**：<https://nodejs.org/ja> から「LTS」をダウンロードしてインストール（ボタンを押していくだけ）
2. **ゲームをダウンロード**：PCのブラウザで <https://github.com/koyamaryonetsu-arch/-DB/tree/claude/elegant-bell-al2f1w> を開き、
   緑の「**Code**」→「**Download ZIP**」→ ZIPを開く（Windows は右クリック →「すべて展開」）
3. **動かす**：中の `family-rpg` フォルダの **`start.bat`**（Windows）か **`start.command`**（Mac。はじめは右クリック →「開く」）をダブルクリック
4. 黒い画面に出る **アドレス** と **合言葉** を、家族のスマホの Safari で開いて入れる（ホーム画面に追加すると、アプリのように使えます）

- **2回目からは 3 だけ**。起動するたびに新しい版を自動で入れます（ZIPのダウンロードはもういりません）
  - 新しい版がうまく動かなかった時は、自動で前の版にもどして動かします
  - 自動の更新を止めたい時は、`kizuna-save/config.json` に `"autoUpdate": false` と書きます
- セーブと合言葉は、ホームフォルダの `kizuna-save` にあります。アプリのフォルダを消しても、ZIPをどこに開きなおしても、そのまま続きから遊べます
- 前の版（アプリの中の `data` にセーブしていた版）を使っていた時は、はじめて起動した時にセーブを自動で引っこします（くわしくは「[セーブとバックアップ](#セーブとバックアップ)」）

## 遊び方

### ひとりで遊ぶサイト（PCなし）

スマホの Safari などで **<https://koyamaryonetsu-arch.github.io/-DB/kizuna/>** を開くだけで遊べます（アカウントもいりません）。

- セーブは、そのスマホのブラウザの中に残ります。ブラウザを閉じても消えません
  - ブラウザの「履歴とWebサイトデータを消去」をすると消えます。Safari は、長いあいだ開かないサイトのデータを消すことがあります
  - 大事なキャラは、家族サーバーに連れていくか、引っこしコードをメモに残しておくと安心です
- 家に帰ったら「**🏠 家族サーバーで遊ぶ**」。このスマホで進めたキャラも家族サーバーに保存されます（はじめての時だけ、家族サーバーのアドレスを入れます。家族サーバーの「📱 ひとりで遊ぶサイトへ」から開いたサイトなら、アドレスを覚えています）
- サイトは GitHub Pages（`gh-pages` ブランチの `kizuna/` フォルダ）に置いてあります。`family-rpg` を変えて push すると、テストをしてから自動で新しくなります（`.github/workflows/kizuna-pages.yml`。同じ場所にあるほかのゲームのファイルはそのまま）
- claude.ai のアーティファクトで開いた時は、claude.ai にセーブされます（「クラウドセーブ」）

### 家族サーバーで遊ぶ（一人でも家族でも）

家のPCを1台「サーバー」にして、家族のスマホ・タブレット・PCからブラウザでつなぎます（作り方は上の「[家族サーバーの作り方](#家族サーバーの作り方はじめの1回だけ)」）。

1. **Node.js を入れる**（はじめの1回だけ）
   <https://nodejs.org/ja> から「LTS」をダウンロードしてインストール（18以上ならOK）
2. **このフォルダをPCに置く**（上の「ダウンロード」、または `git clone`。git で取ってきた時は自動の更新はしないので `git pull` で新しくします）
3. **サーバーを動かす**（`family-rpg` フォルダの中で）
   - Windows … `start.bat` をダブルクリック
   - Mac … `start.command` をダブルクリック（はじめは右クリック →「開く」）
   - Linux … `./start.sh`
   - コマンドで動かすなら `npm start`（または `node server/index.js`）
4. **画面に出るアドレスをブラウザで開く**

   ```
   ★☆★ きずなの紋章　家族サーバーが動きました ★☆★

   このPCで遊ぶ:  http://localhost:3000
   同じWi-Fiのスマホ・タブレットから:
      http://192.168.1.23:3000
   家族の合言葉:  482915
   ```

5. **家族の合言葉を入れる** → キャラクターを作ってスタート！

- 家族の合言葉は最初に自動で決まり、セーブの場所（ホームフォルダの `kizuna-save`。サーバーの画面にも出ます）の `config.json` の `password` に書かれています。好きな言葉に変えてOK（変えたらサーバーを再起動）
- 終わる時はサーバーの画面で `Ctrl + C`。セーブは自動です
- Windows で「ファイアウォールでブロックされています」と出たら「プライベートネットワーク」だけ許可してください
- ポート番号を変えたい時は `kizuna-save/config.json` の `port`

> **大事：** ルーターのポート開放などで、このサーバーをそのままインターネットに公開しないでください。
> 外出先や遠くに住む家族と遊びたい時は、下の「[外出先から家族サーバーにつなぐ](#外出先から家族サーバーにつなぐtailscale)」の方法を使ってください。

#### 家族サーバーが動いていない時

- 家のPCの電源が切れている・家族サーバーを動かしていない時は、**ひとりで遊ぶサイト** で遊べます（あとで家族サーバーに行くと、両方のデータが合わさります）
- **ひとりで遊ぶサイトのタイトル** に、家族サーバーが動いているかが出ます（「🏠 家族サーバーで遊ぶ（動いています）」／「🏠 家族サーバー（今はお休み中）」）
- **家族サーバーの画面で遊んでいる時に止まった** ら、「家族サーバーにつながりません」と「📱 ひとりで遊ぶサイトへ」のボタンが出ます（タイトルでは4秒ほど、冒険のとちゅうは15秒ほどたってから）。サーバーがもどれば、そのまま続きから遊べます
- **PCが止まっている時に家族サーバーのアドレスを開いた** 時も、同じ案内のページが出ます。サーバーが動くと、自動でゲームにもどります
- ただし、サイトのタイトルで動いているか分かるのと、止まっている時に開いた時の案内は、**外出先からのアドレス（`https://…ts.net`。下の Tailscale Funnel）で開いている時だけ** です。
  家の中のアドレス（`http://192.168.…`）では、ブラウザのきまりで分からないので、PCが止まっていると Safari の「開けません」になります。その時はひとりで遊ぶサイトを開いてね

#### 黒い画面は開いているのに「家族サーバーにつながりません」と出る時

スマホの案内に、どこで止まっているかが出ます（外出先からのアドレス `https://…ts.net` の時）。

- **「家のPCまで、通信がとどいていません」** … スマホから家のPCまで、まったくとどいていません。家族サーバー（黒い画面）より手前の問題です
  - **PCがスリープしていないか**（いちばん多い原因です）。外から遊んでいる時は、だれもPCをさわらないので、Windows の設定のとおりにスリープします。黒い画面が開いていても、スリープ中はつながりません
    - Windows の「設定」→「システム」→「電源（電源とバッテリー）」→「画面とスリープ」で、**電源に接続時のスリープを「なし」** にしてください（画面は消えてもだいじょうぶ）。スリープする設定の時は、家族サーバーの黒い画面にも「★ このPCは、さわらないで○分たつとスリープします」と出ます
  - **PCの Tailscale がつながっているか**。外からでも、スマホで <https://login.tailscale.com/admin/machines> を開いて（PCと同じアカウントでログイン）、家族サーバーのPCが「Connected」か見られます
    - 「Last seen …（○分前）」… PCがスリープ・電源オフ・インターネットが切れている、または Tailscale が止まっています
    - 「Expired」… Tailscale のログインの期限切れです。PCでログインしなおして、このPCの「…」→「Disable key expiry」を選んでください
    - 「Connected」なのにつながらない時は、PCで `funnel-on` をもう一度ダブルクリックしてください
  - **黒い画面に「★ 外出先からのアドレス（…）が、インターネットに公開されていません」と出ている時** は、PCの中の設定は「Funnel ON」でも、Tailscale の側で Funnel が有効になっていません（外からは、アドレスの名前そのものが「見つからない」）。スマホの Tailscale アプリをONにしている時だけは開けるので、気づきにくいです。次の行に「原因：」（HTTPS が無効・Funnel が許可されていない）か、「許可はそろっています。…登録できていません」が出ます
    - PCで `funnel-on` をもう一度ダブルクリックしてください。黒い画面にリンクが出たら、ブラウザで開いて「Funnel」（と「HTTPS」）を許可して、もう一度 `funnel-on` をダブルクリック
    - Tailscale の管理画面の「DNS」で、MagicDNS と HTTPS Certificates が有効になっているかも見てください
    - 許可したあと、スマホでは5分くらいたってから開き直してください（「見つからない」を、しばらく覚えているため）。家族サーバーの黒い画面にも「もどりました」と出ます
  - スマホで本当のエラーを見たい時は、Safari の **プライベートタブ** でアドレスを開くと、案内ページではなく Safari のエラーが出ます（「サーバが見つからない」なら上の Funnel の問題です）
  - **黒い画面に「★ 外出先用の設定のアドレス（…）が、今のPCの名前（…）と合っていません」と出ている時** は、Tailscale でPCの名前（またはネットワークの名前）を変えたために、外出先用の設定が古いアドレスのまま残っています。`funnel-off` → `funnel-on` の順にダブルクリックすると新しいアドレスで開けます。もとのアドレスのままにしたい時は、Tailscale の管理画面でPCの名前をもとにもどしてください
  - **開いているアドレスが、黒い画面の「★外出先から」のアドレスと同じか**。Tailscale の管理画面でPCの名前を変えると、アドレス（`https://（PCの名前）.….ts.net`）も変わります。古いアドレスのホーム画面のアイコンは使えなくなるので、新しいアドレスを開いて、ホーム画面に追加しなおしてください（iPhone の Safari は、アドレスの頭の「PCの名前」の部分をかくして表示します。アドレスの所をタップすると全部見えます）
  - PCの電源と、インターネット（ルーター）にも注意
- **「家族サーバーが動いていません」** … 家のPCまではとどきましたが、家族サーバー（黒い画面）が止まっています
  - 黒い画面の一番下が「続行するには何かキーを押してください」なら、黒い画面を閉じて、`start.bat` をもう一度開いてください。黒い画面がない時は `start.bat` を開きます
  - 2026年10月6日より前の版は、インターネットの見まわりツールなどからの **へんな形のアクセス**（`/index.php%00.txt` など）が1回来るだけで止まっていました（外出先からのアドレスは、インターネットに公開されるため）。今の版は止まりません
  - 今の版は、思いがけないエラーで止まっても、**黒い画面が自動でもう一度動かします**（家族のスマホも、そのまま自動でつながり直します）
  - 何が起きたかは、セーブの場所（`kizuna-save`）の **`error-log.txt`** に書かれます。何回も止まる時は、このファイルを Claude に見せてください
- 家の中のアドレス（`http://192.168.…`）では、どちらなのかは分かりません（PCとサーバーの両方を見てください）
- Tailscale のログインが切れた時・期限（ふつうは180日）が近い時は、黒い画面に「★ 外出先から遊ぶ時のつながり（Tailscale）…」と出ます
- Windows：黒い画面の中をクリックすると、タイトルに「選択」と出て家族サーバーが一時停止することがあります。その時は Esc キーをおしてください

### 外出先から家族サーバーにつなぐ（Tailscale）

ふつうは、家のPCと同じWi-Fiにいないとつながりません。
**Tailscale**（個人は無料）を使うと、外出先や別の家からでも家族サーバーで遊べます。方法は2つです。

#### A. Tailscale Funnel（おすすめ。家族のスマホにアプリはいりません）

家族サーバーに `https://（PCの名前）.（ランダムな名前）.ts.net` のアドレスがつきます。家族は、そのアドレスを Safari で開くだけ。家の中でも外でも同じアドレスで遊べます。

1. **家族サーバーのPCに Tailscale を入れてログイン**（<https://tailscale.com/download>）。PCだけでOK
2. **合言葉を強くする**：ホームフォルダの `kizuna-save/config.json` の `password` を、**8文字以上（数字だけはだめ）** にします（12文字以上なら数字だけでもOK）。
   例：`"password": "ほしぞらのきずな"`。短いままだと、外出先からは入れません（家のWi-Fiからはいつも通り入れます）
3. **`funnel-on` をダブルクリック**（Windows は `funnel-on.bat`、Mac は `funnel-on.command`。`family-rpg` フォルダの中。Mac は、はじめは右クリック →「開く」）
   - はじめての時は、黒い画面にリンクが出ます。ブラウザで開いて「Funnel」と「HTTPS」を **許可** してから、もう一度 `funnel-on` をダブルクリック
   - `funnel-on` が見つからない時は、家族サーバーを一度起動すると新しい版といっしょに入ります
   - HTTPS を許可すると、PCの名前（アドレスの頭の部分）が公開の証明書の記録にのります。本名などが入っている時は、先に Tailscale の管理画面（Machines →「…」→ Edit machine name）で `kizuna` などに変えておくと安心です
4. **家族サーバーを再起動** すると、黒い画面に **「★ 外出先から（スマホにアプリはいりません）: `https://…ts.net`」** が出ます
5. 家族のスマホの Safari でそのアドレスを開いて、合言葉を入れる（ホーム画面に追加すると、アプリのように使えます）

- やめる時は `funnel-off` をダブルクリック（家のWi-Fiの中だけにもどります）
- **このアドレスはインターネットに公開されます**（アドレスを知っている人なら、だれでもページを開けます）。家族サーバーは次のように守ります
  - 合言葉がないと入れません。外出先から入れるのは、合言葉がじゅうぶん長い時だけ
  - 合言葉を5回まちがえたアドレスは1分待ち。そのあとも、まちがえるたびに待ちが2倍（最大1時間）
  - 外からの人には、家の中のアドレス（`192.168.…`）を見せません
  - インターネットの見まわりツールなどからの、へんな形のアクセスでは止まりません
  - アドレスは家族だけに教えてね（SNS などに書かないで）
- Funnel が ON で合言葉がじゅうぶん長い時は、家族サーバーの「📱 ひとりで遊ぶサイトへ」から行くと、サイトがこの `https` のアドレスを覚えます。
  サイトのタイトルで家族サーバーが動いているか分かり、外出先からでもデータを合わせられます
- 家族サーバーのPCの電源とスリープに注意してください（スリープ中はつながりません）

#### B. 家族のスマホにも Tailscale アプリを入れる（インターネットに公開しない）

1. 家族サーバーのPCに Tailscale を入れてログイン（<https://tailscale.com/download>）
2. 家族のスマホに「Tailscale」アプリを入れて、**同じアカウント** でログイン（VPN の追加を「許可」）
3. 家族サーバーを起動すると、黒い画面に **「外出先から（スマホの Tailscale をONにして）: `http://100.x.x.x:3000`」** が出ます
4. スマホの Tailscale を ON にして、そのアドレスを Safari で開く（家の中でも外でも同じアドレスで開けます）

- ひとりで遊ぶサイトの「🏠 家族サーバーで遊ぶ」のアドレスも、この `100.x.x.x:3000` にしておくと、外出先からでもデータを合わせられます（「だれで遊ぶ？」→「アドレス」で変えられます）

### iPhone で遊ぶ

1. iPhone を家のWi-Fiにつなぎ、Safari でサーバーのアドレス（`http://192.168.x.x:3000` など）を開く（外出先からは Funnel の `https://…ts.net`）
2. **ホーム画面に追加すると、アプリのように画面いっぱいで遊べます**
   Safari の共有ボタン（□に↑）→「ホーム画面に追加」。次からはホーム画面の「きずな」アイコンで開けます
   （ホーム画面から開いた時は、合言葉をもう一度入れます）
3. たても・横もどちらでも遊べます（戦いの画面も向きに合わせて変わります）

- メニューやお店は、右上の「**✕ 閉じる**」か、まどの外をタップで閉じます。リストの上の「**← もどる**」で一つ前にもどります（「← もどる」はリストの上にはりついて、スクロールしても下の行と重なりません）
- スマホを縦にしている時は、メニューのコマンド（道具・装備・仲間など）を選ぶと **画面が切りかわります**。コマンドの一覧が消えて、上に「← もどる　装備」のような見出しだけが出ます（もどると一覧にもどる）。横向き・パソコンでは、選んでいるコマンドが金色になり、ほかのコマンドはうすくなります
- 「道具」「呪文・技」は、カーソルを合わせただけでは中身を出しません（選んだ時に開きます）
- メニュー・お店・「はい／いいえ」・「だれで遊ぶ？」などのウインドウは、直接タップするほかに、画面の下（横向きの時は左右）に出る **十字キー（▲▼◀▶）と A・B** でも選べます。おしっぱなしで続けて動きます
  - いらない時は、メニュー →「設定」→「ウインドウの十字キー：出さない」
- 横向きの時は「メニュー」「チャット」「スタンプ」のボタンが、右上の地図の左に横にならびます（A・B・走るボタンと重なりません）
- 画面が消えたり、ほかのアプリに切りかえても、**3分以内にもどれば続きから** 遊べます（パーティーもそのまま。戦いの間はオートで戦います）
- 設定（メニュー →「設定」）
  - 「画面：2.5D（立体）／2D（ドット）」… 動きが重い時や古い機械では 2D がおすすめ
  - 「文字の大きさ：ふつう／大きい」「字の形：なめらか／ドット」… 読みやすい方を選べます（そのスマホに記録されます）
  - 「ウインドウの十字キー：出す／出さない」… ウインドウの時に十字キーとA・Bを出すか
  - 「遊んでいる間は画面を消さない」… ON がおすすめ（家族との通信がとぎれにくい）
  - 「マナーモードでも音を出す」… iPhone のサイレントスイッチが ON でも音を鳴らす
- 音が出ない時は、画面を一度タップしてください（iPhone はさわるまで音を止めています）

### 動けなくなった・画面が止まった時

- **ほとんどは自動でなおります。** 会話が終わったのに動けない、何も出ていないのにボタンがきかない、画面がまっ暗のまま、などは3秒ほどで自動で立てなおします
- 物語のとちゅうで止まったまま、または動こうとしても4秒以上動けない時は、画面に **「動けない時はここをタップ」** が出ます。タップすると、サーバーから今のようすをもらい直して、止まった会話はそこからもう一度始まります
- 自分で立てなおすこともできます：**メニュー →「設定」→「こまった時」→「動けない・画面が止まった時は（立てなおす）」**
- 戦いの中で
  - 自分の番なのにコマンドが出ない時は、自動でもう一度出します。それでも出ない時は戦いを立てなおします（戦いはそのまま続きます）
  - 戦いそのものがこわれて進まない時は、「逃げた」ことにしてフィールドにもどります。物語の戦いなら、もう一度話しかけるとやり直せます
- **不具合の記録**：メニュー →「設定」→「不具合の記録」で、止まった時のようすが見られます。「コピーする」で LINE などに貼って送ってください。原因さがしに使います
  - 家族サーバーで遊んでいる時は、サーバーの画面と `save.json` の `errorLog`（最新30件）にも残ります

## 一人で遊ぶ／家族で遊ぶ

- **パーティーは家族5人まで。** 家族を「さそう」と同じパーティーになり、いっしょに歩いて、いっしょに戦えます（酒場の仲間が入るのは、家族と合わせて4人になるまで）
- **みんな自由に動けます。** 別々の場所（町と洞窟など）にいてもOK
- **「だれで遊ぶ？」には、名前・職業・レベル・目標だけが出ます**（いつ遊んだか・今だれが遊んでいるかは出ません）
  - 遊んでいる間は、家族が来た時に「〇〇が冒険にやって来た！」、やめた時に「〇〇がひと休みしている」と出ます。家族のキャラはフィールドにも見えます
  - ほかのスマホで遊んでいるとちゅうのキャラを選ぶと、こちらのスマホに切りかわります（前のスマホは「だれで遊ぶ？」にもどります）
- **画面の左上の名前**：家族といっしょの時は、家族（人が動かしているキャラ）の名前が **黄緑** になります（ひとりで遊んでいる時と見分けられる）。HPが半分以下になると **オレンジ**、1割以下で **赤** になります
- **いっしょに戦うルール（ドラクエ10風）**
  - だれかが魔物にふれると、**近く（画面にうつるくらい）にいる仲間** がいっしょに戦います
  - はなれている仲間は引きこまれません。仲間の頭に ⚔ と足もとに光る輪が出るので、**そこへかけつけると、とちゅうから参加** できます
  - 会話・お店・イベントのとちゅうの人は引きこまれません
- **ついていく**：メニュー →「仲間」→「リーダーについていく（自動）」で、リーダーのあとを自動で歩きます（洞窟の出入りや船もいっしょ）
- **ならびかえ**：メニュー →「仲間」→「ならびを変える」で、1番目から順に選びます（リーダーが決めます）。戦いの並びもフィールドの表示も変わり、**先頭ほど敵にねらわれやすく** なります（ドラクエと同じ。かべ役を前に）
- **総入れかえ**（馬車を手に入れたあと）：メニュー →「仲間」→「総入れかえ」で、パーティーと馬車のみんなを **1番目から順番に** 選びなおします（ドラクエ5風）。**1〜4番目が戦う仲間、5〜8番目が馬車**。自分（主人公）はかならず1〜4番目に入ります（1〜3番目を仲間にすると、4番目は自分だけ選べます）。「戦う仲間はここまで」で、のこりをみんな馬車に乗せることもできます。さいごに「これでいい？」→ はい で決まり（「やめる」なら何も変わりません）。1〜4番目の順が、そのまま戦いのならびになります。洞窟や塔の中ではできません（馬車は入り口で待っている）
- **ストーリーは、招待した人（リーダー）のストーリーを、招待された人が手伝います**
  - 招待を受けると、リーダーのところへ自動で移動します（ひとりで鍛えたキャラもすぐ合流できる）
  - イベント（ボス戦など）は、同じマップにいる仲間みんなで見て、みんなで戦います
  - **進むのはリーダーのストーリーだけ。招待された人の自分のストーリーは変わりません**（クリアの印・目標・大事な物・ゲスト・いのりの場所・たのまれごと・物語で仲間になる人は、リーダーだけに入ります）
  - 招待された人も、**経験値・レベル・お金・ふつうの道具・装備** はもらえます（いっしょに遊んで強くなれる）。戦いで仲間になった魔物も、自分の酒場に来ます

### お店の流れ

1. 店の人に話しかける →「どんなご用でしょう？」→ **買いにきた／売りにきた／やめる**
2. **買う**：品物がつめて一覧で出ます（スマホのたて画面で8つほど、横画面で9つほど）。選ぶと、右（たて画面では下）のまどに「**装備すると、こう変わる**」が出ます
   - **パーティー全員が、ならびの順に1人1行** で出ます。装備できる人は「ソラ　攻撃力 52→66 今:木の剣　↑14」のように強さの変わり方、**装備できない人は「装備できない（変化なし）」**、もう装備している人は「E 装備している」
   - 家族のキャラ（いっしょに遊んでいる人・家族サポート）も見るだけ出ます（買った物を装備できるのは自分と自分の仲間）
   - **馬車の仲間** も、パーティーの下の「馬車の仲間」の所に出ます（馬車にいても、その場で装備できます）
   - リストの「↑強くなる」は、だれかが強くなる品物のしるし。品物の名前の横に「ランク3」のように装備のランクが出ます
3. 「〇〇ゴールドになりますが、よろしいですか？」→ **はい／いいえ**（いいえ＝買わない）
   - 薬草などの道具は、先に「いくつお求めですか？」で数を選べます
4. 装備品なら「**ここで装備していきますか？**」→ はい →「**どなたが装備しますか？**」（自分か仲間を選ぶ。**馬車の仲間**（「馬車」のしるし）も選べます。「装備しない」でふくろに入れるだけにもできる）
5. 今まで装備していた物があれば「**〇〇ゴールドで引き取りましょうか？**」→ はい＝売る／いいえ＝ふくろに入れる
6. **売る**：ふくろの品物を選ぶ → 数を選ぶ →「〇〇ゴールドで引き取りましょう。よろしいですか？」→ はい／いいえ（売ると、買ったねだんの4分の3）

どの場面でも、B（X/Esc）や「もどる」で一つ前にもどれます。右上の「✕ 閉じる」で、いつでもお店を出られます。
メニューの「装備」でも、お店と同じ「攻撃力 52→66 ↑14」の形で、強さの変わり方が見られます。**上がる強さは緑、下がる強さは赤** で、どちらも出ます。「**さいきょう装備**」を選ぶと、ふくろの中で攻撃力・守備力がいちばん上がる武器・よろい・たて・かぶとを選び、**何が何に変わるか** を見せてから「これにする／変えない」を選べます。呪文が得意な職業（魔法使い・僧侶・賢者など）の武器は、攻撃魔力・回復魔力の上がり方も見て選びます（やりより、魔力の上がるつえ）。仲間がいる時は、「だれの装備？」の一覧のいちばん下に「**みんなさいきょう装備**」があります（自分と仲間みんなをまとめて。**馬車の仲間も** 入ります。1つしかない物は、戦う仲間がならびの順に先に使います）。

- 武器・よろいなどを選ぶまどには、**その人が装備できる物だけ** が出ます（職業で持てない武器の種類・重いよろい・たて・かぶと、モンスターの仲間の種族のきまりで装備できない物は出ません）。1つの物は2行で「名前」と「変わる強さ（上がる物も下がる物も、いつも同じ順）」を出します（アクセサリーのように強さがいくつも変わる物でも重なりません）
- まどの上の **「入手順」「強さ順」** で、ならびを切りかえられます（選べる物が2つ以上ある時。ボタンをタップ、または ◀▶。スマホはウインドウの十字キーの ◀▶ でも）。どちらにしたかは、そのスマホ（ブラウザ）に記録されます
  - 入手順 … 手に入れた順（ふくろの順）
  - 強さ順 … 強さがいちばん上がる物から。「さいきょう装備」と同じくらべかたなので、**いちばん上が「さいきょう装備」で選ぶ物** です（武器は攻撃力〈呪文の職業は魔力も〉、よろい・たて・頭は守備力。同じなら強さの合計が多い物が上）。仲間が装備している物は、ふくろの物のあとに出ます
  - 「外す」「やめる」は、いつもいちばん下です
- **仲間が装備している物** も「〇〇が装備中」として出ます。選ぶと「〇〇が装備している。装備を入れかえる？」と聞かれ、「はい」で **入れかえ** ます（自分の今の装備は相手に。相手が装備できない物は、ふくろにしまいます）
メニューの「道具」で装備品を選んで「装備する」を選ぶと、「だれが装備する？」と聞かれます（**その物を装備できる人だけ** が出ます。変わり方もいっしょに出ます。馬車の仲間も選べます）。

### 見た目装備（メニュー →「装備」→「見た目装備」）

本当の装備はそのままで、**見た目だけ** を好きな装備に変えられます（ドラクエ10のおしゃれ装備のように）。強さは変わりません。

- 武器・よろい・たて・頭ごとに、「**今の装備と同じ**」（はじめはこれ。本当の装備が見える）・「**装備なし**」（武器を持たない・かぶとをかぶらない・よろいはふだんの服）・**持っている装備** から選びます
- 選べるのは、ふくろの中の物と、自分や仲間（パーティー・馬車）が装備している物です。**職業で装備できない物も選べます**（戦士がつえを持っているように見せる、など）。きたえた物（鉄の剣+2 など）は、もとの物の見た目です
- 選ぶまどでは、カーソルを動かすと上の見本（前と横）がすぐ変わります。「全部今の装備と同じにする」で、もとにもどせます
- 見た目は、フィールド（2D・2.5D）・メニューや酒場の顔・戦いの顔・家族のみんなの画面にも出ます
- 選んだ物を売ったり捨てたりしても、**見た目はそのまま残ります**（もう一度選ぶ時は、持っている物だけ）
- 酒場の仲間・馬車の仲間も、その人の「装備」から変えられます。モンスターの仲間は、絵に装備が出ないので見た目装備はありません

### 道具を続けて使う（メニュー →「道具」）

- 薬草・魔法の聖水・月のしずく・種などの **だれかに使う道具** は、使ったあとも **同じ道具の「だれに使う？」のまま** です。まどの上に使ったけっか（「ソラのHPが35回復した！」）が出て、HP・MPと「残り〇こ」は新しい数になります。カーソルは前に使った人のまま（続けて何回でも、ほかの人にも使えます）
- B（X/Esc）か「やめる」で、道具の一覧の **その道具のところ** にもどります
- 道具がなくなった時（使える人がいなくなった時も）は、道具の一覧の **いちばん近い道具** にカーソルがもどります
- 聖水・すずなど、だれも選ばない道具を使った時・装備した時・捨てた時も、一覧の上にもどらず、その道具のところにカーソルが残ります
- 帰り道の羽・みちびきの糸など、場所が変わる道具は、今までどおりメニューを閉じます

## バトル

- **リアルタイムターン制**：一人一人の「行動ゲージ」がたまったらコマンドを選べます。行動ゲージはHP・MPと見分けやすいように白黒です
- **素早さとゲージ**：素早さが高いほどゲージが **少しだけ** 早くたまります。差は小さめで、**素早さが3倍ちがっても約1.2倍**（素早さ15と45なら、45の人が5回動く間に15の人は約4回）。素早いキャラだけが活躍しないようにしています
  - ピオリムなどで素早さが上がると **約1.25倍**、素早さを下げられると **約0.8倍**（素早さの数字とは別にかかります）
  - ボスは少しゆっくり動きます（そのかわり1ターンに2回動く・大技をためる など）
  - メニューの「つよさ」で、素早さの所に「戦いで約○秒ごとに順番が来る」が出ます
  - 逃げられるかどうか・攻撃をかわすかどうかは、今までどおり素早さの差で決まります
- **ねらい（ドラクエふう）**：
  - 1体をねらう攻撃・呪文は「ゴブリンA」「ゴブリンB」のように **1体ずつ** えらびます
  - グループの呪文・技（ギラ・バギ・ラリホー など）と **ムチ** は「ゴブリン（2ひき）」のように **グループで** えらびます。えらんだ敵には ▼ が出て、同じグループがまとめて光ります
  - 敵全体の呪文・技（イオ など）と **ブーメラン** は、えらばずにすぐ出ます
  - 敵の絵を直接さわって（クリックして）もえらべます（グループの時は、さわった敵のグループ）。キーボード・ゲームパッドでは十字キーとA。「← もどる」で前のメニューにもどります
- **ムチとブーメラン**：
  - ムチのふつうの攻撃は **えらんだ敵のグループ全部** に当たります（「○○はムチをふるった！」）。2体目から少しずつ弱くなります（100%→85%→70%→55%…）
  - ブーメランは **敵全体** に当たって手もとにもどってきます（「○○はブーメランを投げた！」）。左の敵から順に 100%→80%→65%→50%…
  - 会心の一撃は1体ずつ決まります。力ためは、当たった敵みんなにのります
  - ブーメランは剣より攻撃力が低め。木のブーメラン（ランク1・ルミナの町）、鉄のブーメラン（ランク3・森の主のあと）、銀のブーメラン（ランク4・カモメ港・大王イカのあと）、はがねのブーメラン（ランク5・カナトコ・鉱山を取りもどしたあと）、★はやてのブーメラン（ストームバードがごくまれに持っている）
  - ブーメランを装備できるのは 旅芸人・遊び人・忍者・スーパースター・勇者 と、精霊・ゴブリンの仲間の魔物
- **戦いのあとのまど**：「魔物たちをやっつけた！」から **1行ずつ、ボタンをおすまで次の行に進みません**（文字の速さの設定に関係なく）。▼ が出たら、まど・画面のどこかをタップ／クリック、Z・Enter・Space、ゲームパッドのA で次へ
  - **レベルが上がると、レベルアップの曲** が流れて名前が金色に光ります（曲の間は少し長めに待つので、ボタンを連打しても読みとばしません）
  - 道具を手に入れた時・技を覚えた時も、ボタンをおしてから次の行へ
  - 家族で遊んでいる時は、**それぞれのスマホで自分のペースで** 読めます。読んでいる間はほかの人の戦いにまきこまれません（最長2分）。ほかの人は待たずに遊べます
- 画面の下は、**左の大きいまどがコマンド**、**右の小さいまどがメッセージ** です（スマホのたて画面では、コマンドが下に大きく出ます）
- ゆっくり選びたい時は「ウェイト」をONにすると、コマンドを選んでいる間は時間が止まります
- **設定（メニュー → 設定）**：「戦いの速さ（エフェクト）」と「文字の速さ」は別々に5段階。はじめは前より少しゆっくりです。「戦いの文字の大きさ」（小・中・大）と「戦いのコマンドの数」（少なめ・ふつう・多め）も選べます
- **お気に入り**：呪文・特技の一覧で技をえらぶと「☆お気に入り」ボタン。お気に入りは一覧の上の「★ お気に入り」のまどに出ます。ならびはメニューの「呪文・技」→「お気に入り」で入れかえられます
- **前の技から**：呪文・特技・道具は、前に選んだ技の場所からカーソルが始まります（つぎの戦いでも）
- **オート** ボタンで AI にまかせることもできます（「めいれいさせろ」の仲間もいっしょにオートになる）
- **だれが何をしたか**：だれかが動くたびに、画面の上に **名前の札**（「ミーナ　オート ▶ マホトーン」など）が出ます。味方は青、敵は赤、合体技は金、ひらめきは黄色。オートで動いた仲間には「オート」の印がつき、ランダムに選ばれた技（遊び人の「遊ぶ」など）は何が出たかも出ます
- **味方の強さのまど**：名前の横に **Lv（数字）**、HP と MP は **ゲージと数字**（「HP 120/150」）。HPが半分以下で **オレンジ**、1割以下で **赤**
- **呪文・特技の一覧には、今使える技だけ** が出ます（上級職にならないと使えない掛け合わせ技などは出ません。メニューの「呪文・技」ではすべて見られます）
  - 今の職業の技が上に出ます。名前が長い技は、スマホでも折り返さないように **文字を少し小さくして1行に全部** 出します（属性・対象のしるし、MPもいっしょに）
- **コマンドは1つずつわくで囲まれています**。えらんでいるコマンドは金色のわく、タップすると一しゅんへこむので、どれをおしたか分かります
- **技の色**：ダメージの技は赤、回復の技は緑、補助の技は青。攻撃呪文には属性のしるし（炎・氷・風・爆発・雷・光・闇）がつきます。技をえらぶと、下に「炎属性のダメージの呪文」のような説明が出ます
- **弱点**：魔物にはそれぞれ得意・苦手な属性があります。弱点をつくと「弱点をついた！」でダメージが大きく、得意な属性だと「あまり効いていない…」。
  はじめは分かりません。**一度ためした属性は、次から敵をえらぶ時に「弱点！」「効きにくい」と出ます**（図鑑にも残る）
- **レベルの上限は99** です（仲間・モンスターも同じ。99になると「強さ」の「次のレベルまで」は「最大（Lv99）」になります）
- **敵の強さ（メニュー → 設定）** … ハード（1.2倍）・ベリーハード（1.5倍）・スーパーハード（2倍）にすると、魔物のHP・MP・攻撃・守り・素早さ・魔力がその倍になります（もらえる経験値・ゴールド・落とす物は同じ）。ふつう以外の時は、戦いの画面の左下にしるしが出ます。パーティーではリーダーの設定です
- **レベルは上がりにくめ** です（レベルアップに必要な経験値は、はじめの版の2.25倍。設定の「もらえる経験値」で、さらに0.75倍・0.5倍にもできます）。レベルが上がっても強さは少しずつ（力・守り・素早さは1レベルで約1）。職業の得意な強さは、キャラのレベルといっしょにのびます。そこに **職業（職業レベルで技の威力が上がる）と装備** が上のせされます
- 攻撃・呪文には、それぞれエフェクトがあります（メラは火の玉が飛んでいく、ヒャダルコは氷の柱、イオラは爆発、ギガデインはいかずち、ドルオーラは竜の光、会心の一撃は画面がゆれる など）
  - ふつうの攻撃も **武器の種類ごと** にちがいます（剣は大きな斬りあと、オノは重い一撃と地ひびき、やりはつき、ツメは3本のひっかき、ムチはグループを次々に打つしなる線、ブーメランは敵の上を飛んで手もとにもどる、バットは大きなスイング など）。ダメージの数字も大きく出ます（当たった順に）
- ボスは1ターンに2回動いたり、大技の前に「ためる」ので、防御・回復のタイミングが大事。HPがへると、仲間を呼んだり、強くなったりするボスもいます
- **連携**：仲間が続けて攻撃するとダメージがふえる（2連携 1.1倍 〜 最大 1.25倍）
- **転職して使えなくなった技**（その職業で使えない掛け合わせ技、今の武器では出せない剣・こぶしの技など）は、戦いのコマンドには出ません。MPが足りない技は、うすく出ます
- **パソコンでは**、呪文・技の一覧を上下左右のキーで動かせます。前に選んだ技を、前と同じ場所に出したまま覚えています
- **作戦を変える**：戦いの中で、自分や仲間の体力の表示をタップ（クリック）すると、その仲間の作戦をすぐ変えられます（家族のキャラは、その人だけが変えられます）
- **スマホの横画面** では、戦いの画面を大きく、仲間の体力は1人1行で小さくしています（5人でも入ります）
- **バフ・デバフの重ね掛け**：攻撃力・守備力・素早さを上げる（下げる）技は、**2回まで重ねて** 効きます（2回目は効き目が2倍。大防御のようなとても強い技は、少しひかえめ）。3回目からは、効く時間がのびるだけです。体力の表示には「攻↑↑」のように矢じるしが2つ出ます
- **合体技**：コマンドの「**合体技**」から、仲間と2人で技を出せます。仲間のゲージがまだの時は「（よやく）」になり、選ぶと力をためて待ちます（「よやくをやめる」でやめられる）。**仲間の行動ゲージがたまったら**、その番を使っていっしょに出ます。はじめて使うまでは効果が「？？？」（くわしくは下の「掛け合わせ技」）
- **ひらめき**：同じ技を何回も使っていると、戦いの中で新しい技をひらめきます（くわしくは下）
- **きずなゲージ**：いっしょに戦うと少しずつたまり（前の3分の1ほど。たまりにくい）、満タンでコマンドに「★ミナデイン」。パーティーのみんなが「参加」をおすほど強くなる

### 呪文・技の対象

呪文・技の一覧では、名前の横に **対象のしるし** が出ます（1体・1人・自分にはしるしなし）。技をえらぶと、下の説明にも「敵1グループ」などと出ます。

| 対象 | しるし | えらび方 | 例 |
|---|---|---|---|
| 敵1体 | なし | 1体ずつ（A・B…） | ふつうの攻撃・メラ・ヒャド・大地斬・せいけんづき |
| 敵1グループ | グループ | グループをえらぶ | ギラ・バギ・ラリホー・マヌーサ・ヒャダルコ・ベギラマ・マヒャド・ベギラゴン・バギムーチョ・風神の術・ムチの攻撃 |
| 敵全体 | 全体 | えらばない | イオ・イオラ・まわしげり・おたけび・全剣技・ブーメランの攻撃 |
| 敵にランダム | ランダム | えらばない | みだれ斬り・爆裂拳・ナイフジャグリング・ダーツ（何回も、だれに当たるかは運） |
| 味方1人 | なし | 味方をえらぶ | ホイミ・ベホイミ・スカラ・バイキルト |
| 味方全員 | 全員 | えらばない | ベホマラー・スクルト・ピオリム |
| 自分 | なし | えらばない | 力ため・気合いため・めいそう |
| 死んだ味方 | なし | 味方をえらぶ | ザオ・ザオラル・ザオリク |
| 死んだ味方全員 | 全員 | えらばない | 天使の歌声 |

- **グループ・全体の技は、1体あたりの威力が低め** です。同じくらいのMPの1体用の技より弱く、たくさんに当たる分でおぎないます
- 見直した技：ベギラゴン・バギムーチョ・風神の術は **敵全体 → 敵1グループ** に（そのかわり1体あたり少し強く）。全剣技（剣聖）と大地のいかり（戦士のひらめき）は、1体あたりの威力を少し下げました
- 魔物の「グループの呪文」は、今までどおり味方全員に当たります

## 職業と転職

ルミナの町の神殿（神官セレナ）で転職できます。**キャラのレベル**（経験値で上がる）と、**職業レベル**（職業ごと。最大10）は別々です。

- **職業レベルは、戦いに勝った数で上がります**。基本職は137勝でレベル10（上級職は192勝、超級職は247勝）。職業レベルが上がるたびに、その職業の技の威力が4%ずつ上がり、得意な強さも少し（2%ずつ）上がります。強さのもとはキャラのレベルで、職業レベルは「補正」です（2026年10月 第23回：前は職業レベル1つで5%上がり、職業レベル10ではレベル1つ分よりずっと強くなっていたので、上がりかたを下げました。そのぶん、キャラのレベルで得意な強さがのびます）
- 職業をきわめると、転職しても残る「ずっと残るボーナス」ももらえます。いくつ職業をきわめても、ボーナスの合計は、そのレベルの強さの6わりまでです
- **学校の職業（小学生・中学生・高校生）は「のびざかり」**：1回勝つと1.25回分の修行になります（小学生は110勝、中学生は154勝、高校生は198勝でレベル10）
- ただし **1回の攻撃で終わってしまう戦い**（ワンパンチの戦い）は、修行が **半分**（0.5回ぶん）しか進みません。それ以外の戦いは、敵のレベルにかかわらず1回ぶん進みます
- 職業レベル10で「★マスター」。次の職業への道が開きます（道具はいりません）
- **超級職は、はじめは「？？？」でかくれています**。つながりのある上級職をマスターすると「新しい職業のヒントを見つけた！」と出て、神殿のリストに出てきます。
  なるための職業は、マスターしたものだけ名前が出て、ほかは「？？？？」のまま（例：バトルマスターをマスターすると、竜の騎士の「バトルマスター＋？？？？」が見える）。まだなれない超級職は、覚える技の名前もひみつです
- ひみつの職業の「？？？」を選ぶと、**神殿のうわさ** が聞けます。つながりのある職業を始めていると「中学生をきわめると、青春いっぱいの高校に進めるらしい…」のように、名前を出さずに道を教えてくれます
- **体で決まる職業**：フルーツジッパーは女性だけ、アラシは男性だけがなれます（キャラを作る時の「体」で決まります）。神殿には、なれるほうだけが出ます。仲間も同じで、サーバーでも確かめています（古いセーブで体と合わない職業になっていたら、スーパースターにもどります）
- **伝説の職業**（超級職のさらに上。神殿のいちばん下に出ます）：ロトの勇者（勇者＋ほかの超級職2つ）・スーパーサイヤ人3（スーパーサイヤ人2＋ほかの超級職1つ）・ニカ（ゴム人間＋ほかの超級職1つ）・魔王（勇者＋ダ天使）・天才しせつ管理者（ryonetsu＋ほかの超級職1つ）・はかい神（魔王＋ゴッドハンド）

### 掛け合わせ技（ひらめき技と合体技）

掛け合わせ技には2つの形があります。

- **ひらめき技（1人で思いつく）** … 技を使った回数を記録していて、決まった回数をこえると、**関係のある技を使った時に「ひらめいた！」** と新しい技を思いつきます（ロマサガ風。回数ちょうどで20%、回数の1.5倍で60%）
  - ひらめいた技は、**その場ですぐ出ます（はじめの1回はMPいらず）**。そのあとは、ずっと覚えています
  - メニュー →「呪文・技」→「ひらめき」で、使った回数と、あとどれくらいでひらめきそうかが分かります（まだひらめいていない技は ？？？）
  - 町の「ひらめきの賢者」に話しかけると、ヒントが聞けます
  - **一覧に出るのは、今のパーティーに関係する技だけ** です（全部出すと多すぎて分からなくなるので）。ひらめいた技はいつも出ます
    - パーティーの職業 … **いっしょに戦う人**（自分・いっしょに遊んでいる家族・パーティーの仲間）の **今の職業と、そこにいたるまでの職業**（三ツ星シェフなら料理人・パティシエも）と、**マスターした職業**。**馬車の仲間は入りません**（戦いで入れかえて、パーティーに入ると入ります）。馬車の仲間の一覧を見る時は、その人の職業も入ります
    - 関係する技 … その技をひらめく職業か、元になる技の職業が、パーティーの職業にあるもの（掛け合わせ技は、元の技のどちらかの職業があれば出ます）
    - 出していない技の数は、一覧の下に「ほかの職業の技があと〇こ」と出ます
    - ひらめきの賢者の掛け合わせ技のヒントも、パーティーに関係するものだけです
- **合体技（2人で出す）** … 自分の行動ゲージがたまった時に、コマンドの「**合体技**」から選んでおきます。いっしょに出す仲間の **行動ゲージがたまった時** に出ます（もうたまっていれば、すぐ）
  - **はじめて使うまでは、どんな効果か分かりません**（「効果は？？？」）。一度使うと、戦いの一覧とメニューに説明が出ます
  - オートでねらう合体技の設定はなくなりました。合体技は戦いの中で自分で選びます
  - 2人とも、その合体技に必要な技を1つずつ覚えている必要があります（どちらがどちらでもOK）。2人の番とMPを使います
  - 相手が **家族（人が動かしているキャラ）** の時は、相手の画面に「〇〇が合体技にさそっている！」と技の名前が出て、「参加する！／ことわる」を選びます（7秒で答えないと、今回は出ません）。AI・オートの仲間はすぐ参加します
  - 合体技を出す時は、2人の名前と技の名前が大きく出ます
  - メニューの「合体技」の一覧に出るのは、**一度使った合体技** と、**今のパーティーに関係する合体技**（2つの技の組の両方に、パーティーの職業の技か、パーティーのだれかが覚えている技があるもの）だけです

## ストーリー（今遊べるところ）

- **序章「ホシフル村の祭り」** … 星祭りの夜、やみの使いザルバが村の宝「守り星の石」をうばっていく
- **第1章「始まりの星」** … ルミナの町へ。こわれた橋、森のダークトレント、なげきの洞窟のおくにねむる岩の魔獣ゴルドーン…
- **第2章「海をわたる風」** … 第1章クリアのあと、ホシミばあちゃんに話しかけると始まります
  1. 村の南のさんばしで **船長マリナ** から船「**しおかぜ号**」を借りる（さんばしの先の船に話しかけると出航）
  2. 海の上は、行きたい方へそのまま進めます（船は歩くより少し速い）。南西の「風の島」の **カモメ港** へ
  3. 港長ガモンの話を聞き、南の小島の **海鳴りの洞窟** で **大王イカ** をたおして「光の玉」を取りもどす
  4. 東の **灯台島** の灯台守に光の玉をわたすと、灯台に火がともり、嵐のうずの中に **光の道** が開く
  5. 嵐の島の **嵐の塔** をのぼり、四ツ影の1人 **嵐の将軍ストルム** をたおす
  6. 「風の守り星」をカモメ港の北の「風のさいだん」へもどすと、第2章クリア
  - 星の声が「北の山の上で **星の竜** がねむっている」と教えてくれます（第3章へ続く）
- より道：まいごのねこ探し、酒場のコックのゼリー、牧場のウルフ退治、海の小島の宝箱と「びんの手紙」（カモメ港のミナへ）、あちこちの宝箱、レアな「きらきらぷるりん」

  1. 風の大鳥フウラに乗って、ミドリナ地方の **北のはし** をこえる（空の上の「別の地方へ」でも）と、雪の **シロガネ地方** の「雪原の広場」におります。北の **竜守りの村** で長老ハクゲンに会うと、竜のみこ **ユキナ** が仲間に加わります
  2. 白銀の湖の北の **氷の洞窟** へ。つるつるの氷の床をすべって進み、おくであばれる **ブリザマンモス** をしずめると、村の東の大なだれがどきます
  3. **鉱山の町カナトコ** の親方ドンガにたのまれて、町の北の **カナトコ鉱山** へ。レバーでトロッコの行き先を切りかえて谷をわたり、つかまった鉱夫たちを助けて、いちばん下の **マグマゴーレム** をたおします（町の南のトンネルが通れるようになる）

  5. 村の北西の **竜の試練の神殿** で「勇気・ちえ・きずな」の3つの試練をのりこえると、山へつづく **竜の門** がひらきます（試練はどのじゅんばんでもよい）

### しかけのヒント

- **氷の床**：一度すべり出すと、岩かかべにぶつかるか、氷でない床に着くまで止まりません。止まりたい所の先に岩があるかを見て、すべる向きを決めましょう。どの氷の部屋も、とじこめられて出られなくなることはありません
- **白銀の湖**：まん中の小島の宝箱は、氷の岩を使わないと行けません。小島のまわりは岩だらけですが、**東がわに1か所だけすき間** があります（氷つりのおじさんがヒントをくれます）
- **鉱山のトロッコとレバー**：トロッコに話しかけると乗れます。行き先は、そばのレバーで切りかわります。谷の向こうの島へは、トロッコでしか行けません
- **炎の山**：赤く光る **あつい地面** を歩くと、やけどしてHPがへります（HPは1のこります）。氷の洞窟のおくで見つかる「万年氷」を湯守りのおばばにわたすと「**氷のお守り**」を作ってくれて、やけどしなくなります（なくても進めます）。レバーで、ひえたようがんの橋がかかったり、ようがんの流れが変わったりします
- **勇気の間**：竜の番人と戦います。番人の体が光ったら、次の大わざにそなえて身を守りましょう
- **ちえの間**：4つのかがり火を「日と星の道すじ」のじゅんばんにともします（かんばんと神殿の守り人がヒント。答えは **東→南→西→北**）。まちがえると、ぜんぶ消えてやりなおしです
- **きずなの間**：3つのスイッチに、**いっしょに乗る** とひらきます。家族と遊んでいる時は、みんなでスイッチに乗ろう。一人の時は、連れている仲間（酒場の仲間・ゲストのユキナ・馬車の仲間）がのこりのスイッチに乗ってくれます
- **星竜山**：外は前が見えにくいふぶき。中は氷のほらあな（すべる床）と水晶のほらあな。とちゅうの **山小屋** で休んでから、頂上へ向かいましょう
- **みちびきの糸**：第3章のどの洞窟でも、何階からでも、その洞窟の入り口の外へもどれます
- ボスのしるし：マンモス・ゴーレム・フレアード・番人・イグニアは、たおすと **ボスだけのアクセサリー**（氷のキバのお守り・ようがんのうでわ・炎のブローチ・勇気の紋章・炎のイヤリング・魔女の指輪）を落とします

## コガネ地方（第4章）

南の砂ばくの国です。第4章が始まると、星の竜アステルで飛んでいけます（風の海の **南のはし** をこえる）。

| 場所 | あるもの |
|---|---|
| オアシスの村ハミル | 宿屋・よろず屋（砂よけのマントなど）・教会・村長の家・水がへってきたオアシス |
| 小さなオアシス（北東） | キャラバンの人たちが、砂嵐がやむのを待っています |
| 王都サファラ（砂嵐の切れ目の南） | 宿屋（「昼まで休む」もえらべる）・武器と防具の店（ランク6）・市場の道具屋・教会・水の神殿・宮殿・学者ハサンの家・闘技場（大会はお休み中） |
| 砂の港ドゥナ（南の砂ばくの谷の先） | 宿屋・道具屋（砂よけのマント・帰り道の羽など）・教会・かしらの館・さんばしの砂の船「すなかぜ号」 |

- **砂嵐**：南の空と、村の南の「砂嵐のかべ」は、はげしい砂嵐です。竜が飛べるのも、竜を呼べるのも **北の海辺** の上だけ。ほかの場所へは歩いて行こう（ハミルには、一度行けば **ルーラ・帰り道の羽** で飛べます）。砂嵐のかべは、物語が進むと弱まります
- **昼と夜で魔物がかわる**：夜の砂ばくには「月のゆうれい」が出ます。昼の魔物より強いけれど、経験値も多い。強くなりたい時は夜に、安全に進みたい時は昼に歩こう（宿屋の「夜まで休む」、夕焼けのすず・夜明けのすずで時間を変えられます）
- **月のゆうれい**：体がすけて、攻撃がすりぬけることがあります。光の呪文がよく効くそうです
- **サソリ兵**：しっぽの毒ばりで毒にしてきます。毒消し草を持っていこう。氷と雷がよく効きます
- **黄金虫**：とてもかたくて、すぐにげる金色の虫。たおすとゴールドがたくさん手に入ります
- **砂よけのマント**（ハミルのよろず屋）：砂かけ・まぼろしの花粉で目をくらまされにくくなります
- **北の古井戸**：中は砂の洞窟。いちばんおくのへやで、魔物たちにかこまれたアミを助けます（にげられない戦い。回復してから行こう）
- **かれた地下水路**（村の南東）：村長ナディムにたのまれると、入り口の鉄のこうしが開きます。水路の底はかわいていて歩けますが、ところどころに水がたまっています。**水門のレバー** を動かすと、たまり水がとなりの区画へうつります。どこの水がうつるか、よく見て進もう（まちがえても、もう一度レバーを動かせば元にもどります）
- **からからガエル**（地下水路）：長い舌でMPを吸い取ります。かすれた鳴き声で呪文をふうじることも。炎がよく効きます
- **反撃の構え**：サソリの魔物が **はさみを大きくひらいたら**（だいだい色に光って、頭の上に「＞＜」が出ます）、次の番まで「反撃の構え」。そのあいだに **攻撃や物理の技で なぐると、はさみで反撃されます**。呪文で攻撃するか、身を守る・回復しながら構えがとけるのを待とう。ねらう時の名前の下にも「反撃の構え」と出ます。オートの仲間は、構えている敵をなぐりません
- **王都サファラ**：砂嵐の切れ目から、道ぞいに南へ。一度行けば **ルーラ・帰り道の羽** で飛べます（北の門の外におります）。水が足りず、闘技場の大会もお休み中です
- **夜の宮殿**：夜は宮殿の門がしまります。町の南西の **宮殿の地下水路** は、宮殿の中庭の古井戸までつづいています（中の魔物はレベル30〜33。月のゆうれいも出ます）。中庭からは、古井戸を下りれば町へもどれます
- **宿屋の「昼まで休む」**（王都サファラの宿屋だけ）：お昼の少し前（11時半ごろ）まで休めます。夜からでも選べます
- **わらべ歌**：町の子どもたち4人（北の門のそば・市場・水の神殿のそば・宮殿の前の広場）が、1行ずつ知っています。子どもたちは夜は家に帰っているので、昼に聞こう。歌のじゅんばんは、きっと大事です
- **よろい大サソリ**（地下水路のおく）：2回行動のボス。氷と雷がよく効き、炎は効きにくく、毒は効きません。HPが半分になるとサソリ兵を呼び、のこり少なくなるとおこって毒のしっぽをふり回します。たおすと **サソリのブローチ**（毒を受けなくなる）

### 王家のピラミッド（第4章 Step 4）

- **入り方**：王都の **東の門** を出て、道ぞいに東へ。ピラミッドの前の広場は魔物が出ません。広場の **オベリスク**（大きな石の柱）の影は、朝は西へ、昼すぎは東へのびます。**昼の12時ごろ（11時〜13時。パーティーのリーダーの時計）** には影がまっすぐ北へのびて、ピラミッドの入口のとびらをさします。そのときにとびらを調べると開きます（一度開いたら、もうしまりません）。時間は、王都の宿屋の「昼まで休む」（11時半ごろに目がさめる）で合わせるのがかんたん。宿屋からとびらまでは、まっすぐ歩いて20びょうくらいです（ゲームの1時間は、だいたい50びょう）。夜明けのすずを使ったときは、朝から昼まで待ちます。広場にいる学者の弟子ユスフに話しかけると、今が何時ごろかを教えてくれます
- **ピラミッドの中では、みちびきの糸・帰り道の羽・ルーラは使えません**（道具もMPもへりません）。帰りは来た道を歩いてもどろう。薬草は多めに
- **1階（歌のボタン）**：大広間の4つのボタン（太陽・砂・月・星）を、**わらべ歌の順番（太陽 → 砂 → 月 → 星）** におします。ならびは歌の順番とちがうので注意。まちがえると光が全部消えて、ゆかがぬけて **地下（ミイラのへや）** へ落ちます。地下の東のかいだんから1階へもどれます。東のへやのあなからも地下へ下りられます
- **2階（呪文がふうじられた階）**：むらさきのもんしょうが、呪文の力をすいこみます。戦いでもメニューでも **呪文は使えません**（特技と道具は使える）。入口の探検家のゆうれいがおしえてくれます。回復は薬草か、回復の特技で
- **3階（流れる砂の迷路）**：流れる砂に乗ると、**矢じるしの向き** へ運ばれます（とちゅうで曲がる流れもある）。流れの行き先を目でたどってから乗ろう。**ありじごく** に入ると、2階の「3階へのかいだん」の西どなりの小べやへ落ちます（すぐにもどれます）。流れに乗って着いた **まん中のへや** と **かいだんのへや** の **レバー**（2本）を引くと、石のとびらが開いて、次からは流れに乗らずに、入口から4階へのかいだんまで歩いて行けます
- **金色のつぼ**：中に宝がありそうですが…じつは「のろいのつぼ」。MPをすいとります（にげてもよい）。たおすと中の宝が手に入ります
- **のろいの宝**：4階の前の間の西のかべに、ひびが入っています。くずすと **かくしべや** に「**王家の黄金の剣**」（とても強い剣）。ただし、ぬくとのろわれて、**ピラミッドの中の魔物がたくさんあらわれ、遠くからおいかけてくる** ようになります。ピラミッドの外に出ると、のろいはとけます（とらなくても先へ進めます）
- **ミイラ兵**：たおしても1回だけ起き上がります。**炎か光でとどめをさす** と起き上がれません。**砂岩ゴーレム** はうでをふりかぶったら、次の番に大ぶりの一撃（身を守ろう）。夜の王家の墓の砂ばくには **ランプの魔人**（強い炎の呪文。氷が効く）
- **ミイラの王アンク**（4階の王のへや）：2回行動のボス。**王のミイラ兵** 2体といっしょに出ます。炎と光がよく効き、闇と毒は効きにくい
  - 「**古い言葉をとなえ始めた…**」は **よみがえりの呪文** の前ぶれ（むらさきに光り、頭の上にゲージが出ます）。次の番に、たおれた王のミイラ兵がみんな生き返ります。となえている間に **アンクのHPの1わり（650）くらいのダメージ** をあたえると、呪文が止まります（ゲージが金色でいっぱいになる）
  - 目があやしく光ったら、次の番に「**王の呪い**」（みんなに毒とマヌーサ）。ミイラの手はMPをすいとります
  - HPが半分になると、王のミイラ兵がもう2体。のこり4分の1で「王のいかり」（攻撃力が上がる）
  - **アンクをたおすと、王のミイラ兵もくずれおちます**。ミイラ兵ばかりたおすより、アンクをねらおう。たおすと **王家のうでわ**（守りと魔力が上がり、マヒとマヌーサにかかりにくい）
- アンクのあと、王の台の前にうかぶ **月の鏡**（だいじなもの）を手に入れたら、Step 4 はおしまいです

### 夜の王の間と南の砂ばく（第4章 Step 5）

- **王の間へのとびら**：中庭と王の間をつなぐとびらは、カギがかかっています。月の鏡でてらせるのは **夜だけ**（パーティーのリーダーの時計）。昼は鏡がくもって、力が出ません。王都の宿屋の「夜まで休む」が便利です
- **まぼろしの分身**：王の間の戦いでは、相手のすがたが3人にふえます（見た目も名前も同じ）。分身を攻撃すると「まぼろしだった！」と消えますが、どこからかわらい声がひびいて、**攻撃した人のMPがへります**（全体の呪文でも）。よく見ると、**本物の足もとにだけ、小さな影** があります
- **月の鏡（戦いの「道具」）**：パーティーのだれでも使えます。分身がすべて消えて、本物はまぶしくて **1回動けなく** なります。使ったあとは、鏡の光がもどるまで（本物が3回動くまで）使えません（道具の右に「あと3」のように出ます）。分身は、消えてから本物が3回動くと、またあらわれて、3人の場所が入れかわります（その1つ前の番に「まわりの空気が、ゆらゆらとゆれ始めた…」）
- **つづけて2回目の戦い**：1回目のあと、そのまま **本当のすがた** と戦います（あいだに月の鏡の光で、HPは全部、MPは少しだけ回復します。たおれた仲間も起きます）。2回行動。**氷と風** がよく効き、炎と爆発は効きにくい。「**砂がうずをまき始めた…！**」の次の番は「砂の大うず」（みんなに大ダメージ）。身を守ろう。砂嵐（マヌーサ）・砂の手（1人が動けなくなる）も使います。HPが半分になるとおこって、攻撃が強くなります
- 1回目の戦いのごほうびは **まぼろしの指輪**（素早さと魔力が上がり、混乱しにくい）、2回目は **魔神のランプ**（アクセサリー。そうびしたまま、戦いの「道具」から1回の戦いで1回、みんなのMPを少し回復。魔力と守りも上がる）
- **南の砂嵐**：王都の南も、はげしい砂嵐でとざされています。王の間の戦いのあと、**道のある所だけ** 弱まって通れるようになります（ほかの所は、まだ砂嵐）。竜も、王都や南の港の近くまで飛べるようになります（東のはしの空は、まだ砂嵐）
- **南の砂ばく**（南の砂嵐の先）：**サンドワーム** は砂にもぐったら（「足もとの砂が、もり上がっていく…！」）、次の番に飛び出して大きくかみつきます。身を守ろう（雷がよく効く）。**砂嵐の精** は風の呪文と目つぶし（氷がよく効く）。夜は黒い **やみサソリ**（毒ばりと反撃の構え。氷と雷）が出ます
- **砂の港ドゥナへの谷**：道ぞいに南へ行くと、砂の海賊が木のさくで谷をとざしています（谷のまわりは魔物が出ません）。見張りに **女王の手紙** を見せると、かしらに知らせに行ってくれます（前のアップデートで門を開けてもらえなかった人は、もう一度話しかけよう）

### 砂の港ドゥナと砂の海（第4章 Step 6）

- **砂の港ドゥナ**：谷を下りた先の、砂の海賊の港町です（町の中は魔物が出ません。谷には出ます）。一度行けば **ルーラ・帰り道の羽** で飛べます（町の北の門の外におります）。ドゥナと砂の海の上では、竜は呼べません（谷を上って、南の砂ばくから）
- **かしらバルガ**：広場の東の「かしらの館」にいます。話を聞くと、むすめの **サラ** が仲間になります。サラはムチを使う海賊で、**パーティーの人数とはべつに、5人目として** いっしょに戦ってくれます（レベルは主人公と同じくらい。オートで戦います）
- **砂の古城**：町の **東の門** を出て、がけの道を北へ。東の門は、サラが仲間になると開きます。古城の中には、からっぽの **古城のよろい**（かたい。まとめてなぎはらう。たてをかまえると守りが上がる。**雷と爆発** がよく効く）や月のゆうれいが出ます
- **2つの石の板**：1階の北の広間の、西と東のすみに、石の板が1つずつあります。**2つを同時にふむ** と、北の鉄のこうしが上がります（かべの文字もヒント）
  - 家族で遊んでいる時は、2人で1つずつふもう（同じ階なら、はなれていてもだいじょうぶ）
  - ひとりの時は、片方の板にのると、サラがもう1つの板にとびうつってくれます。サラがいない時は、パーティーの仲間（酒場の仲間・馬車の仲間）がかわりにのってくれます。仲間がだれもいないと開きません
- **船のかじ**：2階の北のおくの、たからべやにあります。古城のよろい2体が守っています（にげられない戦い。回復してから行こう）。かじをバルガにとどけると、すなかぜ号で出航できます
- **すなかぜ号**：さんばしの先の砂の船。話しかけて「出航する」と、**砂の海** へ。砂の上を、行きたい方へそのまま進めます（第2章のしおかぜ号と同じ）。砂の海のさんばしにもどると、ドゥナの港に帰れます。小島には宝箱も。東のはしは、まだ砂嵐
- **砂ザメ**（砂の海）：せびれだけ出して泳ぐサメ。2回つづけてかみついてきます。**雷** がよく効きます
- **砂クジラ**（砂の海のまん中の「クジラのねどこ」）：砂のうずに近づくと目をさまします。船の上の戦い（にげられない）。2回行動。**雷と氷** がよく効き、炎と風は効きにくい
  - 「**砂クジラは砂の中にもぐった！**」のあとは、次の番まで **攻撃がとどきません**（ねらえない。呪文をえらんでもMPはへらずに空ぶり）。そのあいだに、回復や身を守るのに使おう
  - 「**砂がもり上がった…！**」の次の番は、飛び出して大ジャンプ（みんなに大ダメージ）。**身を守ると半分** になります
  - 砂しぶき（マヌーサ）と、大きな口で1人にかみつく技もあります。HPが半分になると砂ザメを2ひき呼び、のこり4分の1で少し速くなります
  - たおすと **砂クジラのお守り**（HPと守りが上がり、マヌーサと毒にかかりにくい）
- 砂クジラのあと、サラはドゥナのさんばしで待っています。話しかけると、続きが始まります（下の「砂の底の神殿」）

### 砂の底の神殿（第4章 Step 7）

- **はじまり**：ドゥナのさんばしのサラに話しかけると、サラがもう一度仲間になります（ゲスト。第4章クリアまでいっしょ）。すなかぜ号で砂の海のまん中の「クジラのねどこ」に近づくと、砂クジラが船ごと砂の底へ運んでくれます（2回目からは、ねどこの砂クジラに話しかけて「もぐる」）
- **空気のドーム**（入口）：砂の下の大きなあわの中です。魔物は出ません
  - **砂の海賊のほこら**：何度でも、ただでHPとMPが回復して、記録（セーブ）もできます
  - **かべ画**：「水は、上から下へ。光は、下から上へ」。神殿のしかけのヒントです
  - すなかぜ号に話しかけると、地上（砂の海）へもどれます
  - 神殿の中では **みちびきの糸・帰り道の羽** が使えません（なくなりません）。ルーラも天井にぶつかります。歩いてドームまでもどろう
- **地下1階「水のかいろう」**：3つのレバーで水の高さ（上・中・下）が変わります。水の高さで、通れる道と、とどく宝箱が変わります
  - 赤（上の水門）を開けると、水が「中」に。赤と青（中の水門）が開いていると「下」に。下で黄（下の水門）を開けると、下りのかいだんの前の水がひきます
  - 赤がしまっていると、ほかの水門を開けても水は動きません（水は、上から下へ）
  - まちがえても、レバーをもどせばやり直せます。水が高い時と低い時で、出る魔物がかわります
  - 宝箱の **水の羽衣**（ランク7のよろい）は、水が「中」の時にとどきます
- **地下2階「鏡の間」**：入るとすぐ、**鏡の騎士** 2体が待ちかまえています（にげられない戦い）
  - **鏡のゆか**：見ただけでは、どこが本物のゆかか分かりません。にせの所をふむと、すいこまれて手前へもどされます。**月の鏡** を持って鏡のゆかを調べると、本物の道だけが光ります（光は、下から上へ）
  - 光る道の先の **大きな鏡** を調べると、パーティーそっくりの **鏡のうつし身** があらわれます（にげられない戦い）
  - 鏡がくだけたおくには **いやしの泉**。HPとMPが全部回復します（1回だけ。空気のドームへもどって、神殿に入りなおすと、また使えます）
- **地下3階「水のろう」**：水の柱のろうに、サラの母さん **水のみこミラ** がとじこめられています。ろうの前で、モルガナの声と **ろうの番人** 2体（にげられない戦い）。番人をたおすと、ろうの水が下がってミラが目を覚まし、下への水のまくが消えます。ミラはモルガナとの戦い方のヒントも教えてくれます
- **最深部「水鏡の広間」**：大きな水鏡に、遠い空にうかぶ島がうつっています。魔物は出ません
  - **水鏡の魔人モルガナ** と2回つづけて戦います（にげられない）。1回目のあと、ミラのいのりで **HPもMPも全部回復**（たおれた仲間も起きる）してから、**モルガナ（真の姿）** との戦いになります
  - 王都で **わらべ歌を4つとも** 聞いていると、ミラのいのりが「**水の守りの歌**」になります（真の姿との戦いのはじめが、少し楽になります）
  - 負けた時は、教会からやり直し。もう一度、水鏡の広間のおくへ進む（モルガナに話しかける）と、1回目の戦いから始まります
- **第4章クリアのあと**
  - 王都サファラの宮殿前の **ふん水** から水がふき上がり、オアシスの村ハミルのまわりに緑がもどります。町の人の話も変わります
  - 王都の水の神殿に、**水のみこミラ** と **水の守り星** がいます
  - **砂の港ドゥナ** の道具屋のとなりに、**ランク7（プラチナ）の武器と防具** の店が開きます（海賊のムチ・プラチナソード・水の羽衣 など）
  - **サラ** が、**ルミナの町の酒場** で仲間にできるようになります（海賊。ムチを使う）
  - 南の砂嵐ののこりと、砂の海の東の砂嵐も晴れます。竜で **コガネ地方のどこへでも** 飛べます

### 砂の底の神殿の戦い（第4章 Step 7）

- 神殿の中は、水の高さで出る魔物がかわります（水が高いと **水の精・水竜**、低いと **砂ガニ** などの砂の魔物）。水の魔物は **雷** がよく効きます。水の精は仲間を回復するので、先にたおそう
- **鏡の騎士・まどわしの鏡**：体が **まぶしく光ったら**、次の番まで **呪文をはね返します**（はね返った呪文は、となえた人に当たる）。光っている時は武器で、光っていない時は呪文で。鏡の騎士は守りがとてもかたいので、光っていない時は呪文が効きます
- **鏡のうつし身**：鏡の間の大きな鏡から、**自分たちそっくり** のすがたが出てきます（同じ職業・同じ見た目・同じ技）。家族で遊んでいると、家族のうつし身も出てきます
- 神殿のおくの戦いは、**相手のようすのかわり**（光る・水をまとう・水がうずをまく・前ぶれのことば）をよく見て、作戦を変えよう。仲間の「はなす」もヒントになります

## 宝の地図・ふしぎなかじ屋・預かり所・馬車

### 宝の地図（ドラクエ9ふう）

- ルミナの町の **宝探しのダイゴ** に話しかけると、はじめの1まいがもらえます。第1章クリアのあとは、魔物をたおすと地図を拾うこともあります（強い魔物ほど出やすい）
- 地図には、宝がねむる場所のまわりの地形がかいてあります。地図を開くと、**目じるし（村・町・洞窟の入り口・湖・島など）から何の方角へ何歩くらいか**（「星見の丘から南へおよそ20歩」）と、まわりの地形が出ます。同じ地方にいる時は、**今いる場所からの方角と歩数** も出ます
- 宝の場所は、地面から **赤むらさき色の光の柱** が立っています（ひろえるキラキラ＝白と黄色の十字とは、色も形もちがいます）。家族の冒険を手伝っている時は、リーダーの地図の場所が光ります
- 光っている場所で地面を調べる（A）と **宝の洞窟** の入り口があらわれます。洞窟は地図ごとに形がちがいます（土・氷・炎の洞窟）
- いちばんおくの **洞窟の主** をたおすと、宝箱と新しい地図が手に入ります。地図のレベルが高いほど、洞窟は深く、魔物も宝も強くなります
- 家族といっしょなら、パーティーのみんなが地図をもらえます。持っている地図はメニューの「道具」で見られます（20まいまで）
- 洞窟から出たい時は、入ってきた階段を上るか、帰り道の羽か **みちびきの糸**（地図の場所のそばにもどる）を使います

### ふしぎなかじ屋（ルミナの町・カモメ港・カナトコ）

- **作る**：素材（けもののキバ・鉄のかけら・魔法の粉・風の羽・竜のうろこ など。魔物が落とす）とゴールドで、店では買えない装備を作れます
- **きたえる**：武器・よろい・たて・頭の装備を **+1 → +2 → …** ときたえられます（アクセサリーはできません）。**きたえられる回数は装備のランクで決まります**（ランクが高い装備ほど、たくさんきたえられる）。+3 からは星のかけらもいります。きたえた装備は、フィールドのすがたもきらめきます

  | ランク | 例 | きたえられる回数 |
  |---|---|---|
  | 1（木と皮） | 木の剣・皮のたて | +1 まで |
  | 2（銅と石） | 銅の剣・皮のよろい | +2 まで |
  | 3〜4（鉄・銀と海） | 鉄の剣・銀の剣 | +3 まで |
  | 5〜6（はがね・魔法） | はがねの剣 | +4 まで |
  | 7〜（プラチナ〜伝説） | これからの章の装備 | +5 まで |

  - 前のきまりで +3 までにきたえた装備は、そのまま使えます（それ以上はきたえられません）
  - どこまできたえられるかは、かじ屋の画面と、道具の説明に出ます

### 預かり所（ルミナの町・カモメ港・カナトコ）

- お金と道具を預けられます（道具は60しゅるい・1しゅるい99個まで）。どちらの預かり所でも、同じ物を出し入れできます
- **全滅すると、持っているお金が半分になります**（ドラクエと同じ）。預けたお金はへりません。物語で負けてもよい戦いでは、へりません

### 馬車（第1章クリアのあと）

- ルミナの町の **酒場のマスター** からもらえます。いっしょに歩く3人のほかに、**4人まで** 馬車に乗せておけます
- 馬車はパーティーの後ろをついてきます。町の中や洞窟・塔には入らず、門や入り口の前で待ちます（空を飛んでいる時は見えません）
- **馬車の仲間も、戦いに出なくても経験値と職業の修行を半分もらえます**（馬車がいっしょの時）
- **家族のキャラも乗れます**。馬車に乗っている家族の持ち主には、パーティーで戦った時の **半分** の経験値のおすそわけがとどきます（お金のおすそわけはなし）
- **総入れかえ**：メニューの「仲間」→「総入れかえ」（酒場でも）で、1〜4番目（戦う仲間・自分はかならずここ）と5〜8番目（馬車）をまとめて決められます。くわしくは「[一人で遊ぶ／家族で遊ぶ](#一人で遊ぶ家族で遊ぶ)」
- 戦いの「**いれかえ**」で、自分や仲間を馬車の仲間と交代できます（その人の番を使う。リーダーだけ）。家族のキャラも入れかえられます
  - いちばん上の「**総入れかえ**」では、戦っている仲間と馬車の仲間の中から、戦う仲間を1人目から選びなおして **1回でまとめて** 入れかえます（自分はそのまま。使うのはその人の番1回だけ）。あいている場所があれば、人数をふやすこともできます
- メニューの「仲間」→「馬車」で1人ずつの乗りかえも、酒場でも乗りかえられます
- 新しく仲間になった魔物や、酒場で連れていく仲間は、パーティーがいっぱいなら馬車に乗ります
- **馬車の仲間も、フィールドで回復できます**（薬草・回復の呪文・「まんたん」。「だれに使う？」に「（馬車）」のしるしで出ます）。馬車の仲間が回復の呪文を唱えることもできます。洞窟や塔の中では、馬車は入り口で待っているので回復できません
- 家族といっしょの時は、リーダーの馬車がついてきます（いっしょに遊んでいる家族の人は、馬車には乗りません）

## ひみつのダンジョン（何階までもぐれるか、家族できそう）

- **入口**：ルミナの町の **南門を出てすぐ東** にある石のアーチ（かんばんが目じるし）。ルミナの町に着くと開きます。中の「入口の広間」に **案内人** と **家族の記録の板** があります
- **終わりのないダンジョン**：地下1階から始まり、終わりはありません。下り階段をさがして、1階ずつ下へ。**同じ階は、家族みんな、何回入っても同じ形** なので、「あの階の階段は右のおく」と教え合ったり、きそったりできます
- **強さ**：1階はおすすめ **レベル5** くらい。1階下りるごとに魔物のレベルが1つ上がります（10階 Lv13・20階 Lv23・30階 Lv33・40階 Lv43）。31階からは、さらに **1階ごとに3%ずつ強く**（40階 1.3倍・50階 1.6倍・70階 2.2倍）。物語の進みぐあいに関係なく入れて、これから行く章の魔物も出てきます
- **10階ごとに色が変わる**：こけむした石の階（1〜9階）→ 青いすいしょうの階（10〜）→ むらさきのきりの階（20〜）→ 赤い炎の階（30〜）→ 黄金の古代の階（40〜）→ 星空のはての階（50〜）
- **魔物は仲間にならない**（図鑑にはのります）。**みちびきの糸・帰り道の羽・ルーラは使えません**
- **5階ごとに休み所**（5・10・15…階）：魔物が来ない部屋です
  - **回復の泉**：いっしょにいる家族みんなのHP・MPが回復
  - **ごほうびの宝箱**：1回のちょうせんで1人1回。**その階に初めて着いた時は大きなごほうび**、2回目からは小さなごほうび（お金・薬草・魔法の聖水・種・よみがえりの花・星のかけら のどれか1つ）

    | 初めて着いた休み所 | 大きなごほうび（深いほど良い物） |
    |---|---|
    | どの休み所でも | 階×100ゴールド（5階 500G・30階 3000G）と種（30階からは2個） |
    | 5・15・25…階 | 店の装備を1つ（5階はランク2、15階は3 … 55階からはランク7） |
    | 10・20・30…階 | **小さなメダル**（メダル王にわたせる） |
    | 20・40・60…階 | ★の装備を1つ |
    | 50・60・70…階 | よみがえりの花2個 |

  - **休み所のようせい** に話しかけると「**先へ進む**／**地上へもどる**」を選べます。地上へもどると、そのちょうせんは終わり（記録はのこります）
  - **10階ごとの休み所には番人**（宝の洞窟の主や、各章のボス）が下り階段を守っています。泉で回復してから話しかけよう。勝つとそのまま下の階へ
- **全滅すると入口の広間にもどります**。ひみつのダンジョンでは **お金はへりません**。着いた階の記録はのこります
- **ちょうせんはいつも地下1階から**（とちゅうの休み所からは始められません）。アプリを閉じても、次に遊ぶ時は同じ階のつづきから
- **家族といっしょに**：今までどおりパーティーを組んで入れます。階段は、同じ階にいる家族 **みんなでいっしょに** 下ります（だれがふんでもOK）。いっしょに下りた家族 **みんなに記録** がつき、記録の板には「〇〇といっしょ」と出ます
  - とちゅうの階でさそわれて来た人は、その回は記録になりません（ごほうびは小さな物だけ）。記録は1階からきそおう
  - 手伝っている人も、まだルミナの町に着いていなくても、リーダーといっしょなら入れます
- **家族の記録の板**：いちばん深く行けた階の上位10人（日付・いっしょにいた人）。家族サーバーでは家族みんな、ひとりで遊ぶサイトでは、そのスマホのキャラたちの記録です。自分の最高の階は、メニューの「クエスト」と「強さ」でも見られます

## 昼と夜・ルーラ・空の旅

### 昼と夜

- 1日は げんじつの **20分**（明け方 → 昼 → 夕方 → 夜）。ちずの左下の小さな丸の中を、お日さまとお月さまが動きます
- 時計は サーバー（ひとりモードでは ブラウザの中の サーバー）が決めます。**家族サーバーでは パーティーごとに時計** があり、パーティーの仲間は リーダーの時間を見ます。だれかが宿屋で休んでも、ほかのパーティーの空は変わりません（パーティーをぬけると、自分の時間にもどります）
- **夜のフィールド** … 昼の魔物のかわりに 夜の魔物がうろうろします。月夜ぷるりん・夜ふかしフクロウ・ひとだまランプ・闇ウルフ・夜光ぷるりん（海）など。少し強いけれど、経験値とゴールドが多めです。洞窟や塔の中は、昼も夜も同じです
- **夜の町** … 子どもたちは家に帰り、門番は夜の門番に交代。ルミナの町の広場には **夜の商人**（月のしずく・夜明けのすず・夕焼けのすず）、ホシフル村のはずれには **ゆうれいの女の子**（星見の丘で、夜だけ光るオルゴールを探してあげよう）。物語の人・お店・宿屋・教会は 夜もいつも通り
- **宿屋** … 昼は「夜まで休む」も選べます。さそわれて手伝っている人は、リーダーの時間を変えません
- **夜明けのすず・夕焼けのすず** … 鳴らすと すぐに朝・夜になります（リーダーだけ使えます）

### ルーラ

- 魔法使い（職業レベル2）と賢者（レベル1）が覚えます（MP2）。メニューの「呪文・技」→「ルーラ」→「使う」で、行ったことのある町（ホシフル村・ルミナの町・カモメ港・竜守りの村・鉱山の町カナトコ・温泉の里ユノハ）を選びます
- 「ついていく」にしている仲間も いっしょに飛びます（帰り道の羽も同じ）
- **パーティーでは、行き先はリーダーと同じ** です。リーダーの冒険に来ている間は、自分が行ったことのない町でも、リーダーが行ったことのある町へ飛べます（帰り道の羽も同じ。パーティーをぬけると、自分の行き先にもどります）
- 洞窟や塔の中では「天井に頭をぶつけた！」で使えません（MPはへりません）。戦いの中でも使えません

### 風の大鳥フウラ（第2章クリアのあと）

- 「風の笛」を持っていると、フィールド（ミドリナ地方・風の海）で「**大鳥**」ボタン（F キー、道具の「風の笛」→「ふく」）を押すと、フウラが空からおりてきて乗れます。町・村・港の中では呼べません
- 空の上では マップのはしまで どこへでも飛べます（山・森・海の上も）。歩くより ずっと速く、魔物には会いません。出入り口（洞窟・塔）やイベントの場所には入れず、人とも話せません
- ミドリナ地方の **南のはし** をこえると 風の海の北のはしへ（その反対も）。「風の海へ」「ミドリナへ」ボタンでも 別の地方へひとっ飛び
- 「**降りる**」ボタン（空の上ではAボタンでも）で 歩ける地面に降ります。水の上・建物の中・出入り口の上には降りられません（すぐそばに地面があれば、そこへ降ります）
- **パーティーで乗る**：リーダーが大鳥（竜）に乗ると、仲間の画面に「**いっしょに乗る？**」と出ます。「いっしょに乗る」を選ぶとリーダーのそばの空へ行き、リーダーについて飛んで、リーダーが降りるといっしょに降ります（別の地方へもいっしょ）。「乗らない」を選ぶと地上にのこって、自分で歩けます。戦いの中やメニューを開いている時は、終わってから聞かれます（1分たつか、リーダーが先に降りると、聞かれなくなります）
- 乗ったままセーブしても、次は空からつづけられます
- **シロガネ地方（第3章）**：第3章が始まると、ミドリナ地方の **北のはし** をこえて（「別の地方へ」ボタンでも）雪のシロガネ地方へ飛べます。はげしいふぶきのため、はじめは南の **雪原の広場** の上でしか飛べず、大鳥を呼べるのもそこだけです（ほかの場所へは歩いて行こう）
- 第3章のさいごで **星の竜アステル** に乗せてもらえるようになると、空の旅はフウラのかわりに星の竜の背中になります（大きなつばさで ゆったりはばたきます）。星の竜は大鳥より速く、シロガネ地方の空もどこでも飛べます。家族サーバーでは、ほかの人の画面でも 竜に乗った姿で見えます
- **コガネ地方（第4章）**：第4章が始まると、風の海の **南のはし** をこえて（「別の地方へ」ボタンでも）南の砂ばくへ飛べます。砂嵐のため、はじめは **北の海辺** の上でしか飛べず、竜を呼べるのもそこだけです。夜の王の間の戦いのあとは、**王都サファラや南の港の近く** まで飛べるようになります（東のはしの空は、まだ砂嵐）。谷の下の **砂の港ドゥナ** と **砂の海** の上では、竜は呼べません（ドゥナへは、ルーラ・帰り道の羽か、谷を歩いて）。砂の底の神殿でモルガナをたおすと、砂嵐がすっかり晴れて、**コガネ地方のどこへでも** 飛べるようになります

## セーブとバックアップ

### セーブの場所

- **家族サーバー**：ホームフォルダの **`kizuna-save`** フォルダ（サーバーの画面の「セーブの場所」にも出ます）
  - Windows … `C:\Users\（名前）\kizuna-save`　／　Mac … `/Users/（名前）/kizuna-save`
  - `save.json` … セーブ（自動）　／　`config.json` … 合言葉・ポート番号・家族の名前
  - `backups/` … 1時間ごとのバックアップ（最新24こ）。新しい版に切りかえる前・引っこしコードで入れかえる前のセーブも、ここに残します
- **ひとりで遊ぶサイト**：そのスマホのブラウザの中（localStorage）。ブラウザを閉じても残ります。ブラウザのデータを消すと消えます
- **claude.ai のアーティファクト**：**claude.ai にセーブ**（クラウドセーブ）。くわしくは下の「クラウドセーブ」
- セーブと合言葉はアプリのフォルダの外にあるので、GitHub にのることはありません

### 新しい版にしてもセーブは消えません

- **家族サーバーは、起動するたびに新しい版を自動で入れます**（アプリの中身だけを入れかえます。セーブ・合言葉・`start.bat` はそのまま）
  - 入れかえる前のアプリは `kizuna-save/app-previous` にとっておきます。新しい版がすぐに止まった時は、自動でそこからもどします
  - 家族サーバーの本体は、見はり役（`server/index.js`）が動かしています。思いがけないエラーで止まっても、自動でもう一度動かします（何が起きたかは `kizuna-save/error-log.txt`）
  - インターネットにつながらない時は、今の版で動きます
- **ひとりで遊ぶサイト** も、Claude が更新すると自動で新しくなります。セーブは同じ場所（ブラウザの中）のままです
- セーブはアプリのフォルダの外にあるので、**新しいZIPをどこに開いても、古いフォルダを消しても、続きから遊べます**
- これより前の版は `family-rpg/data` にセーブしていました。新しい版を起動すると、近くのフォルダ（ダウンロード・デスクトップ・書類・OneDrive もふくむ）にある古い版のセーブを自動で見つけて、`kizuna-save` へ引っこします
  - 古いほうのセーブは消しません（そのフォルダに「セーブの引っこし.txt」を置きます）
  - 古い版を起動して遊んでしまっても、次に新しい版を起動すると、あとで遊んだキャラが引っこします（新しい版で消したキャラは、もどってきません）
  - 見つからない時は、古い `family-rpg/data` フォルダを、新しい `family-rpg` フォルダの中にコピーしてから起動してください（自動で引っこします）
- セーブの形が変わる版では、起動した時に自動で新しい形にします（その前のセーブは `backups/` に1回だけ残します）
- 新しい版で遊んだあとに古い版へもどした時など、知らない道具・職業・魔物が入ったセーブも、消さずにとっておきます。また新しい版で読んだ時に元にもどります
- セーブの場所を変えたい時は、環境変数 `DATA_DIR` でフォルダを指定します（この時は古いセーブの自動の引っこしはしません）
- 第1章をクリアしたセーブで新しい版を始めると、目標が「ホシミばあちゃんに話しかけると、第2章が始まるよ」に変わります

### クラウドセーブ（アーティファクトの一人モード）

iPhone の Safari や Claude アプリでは、アーティファクトの中のブラウザのセーブが、ブラウザを閉じると消えることがあります。
そこで、アーティファクトで遊ぶ時は **claude.ai（アーティファクトのデータベース）** にもセーブします。

- セーブは **1人ずつ別の場所**（claude.ai のアカウントごと）。ほかの人からは見えません（アーティファクトの持ち主からも）
- 同じ claude.ai のアカウントなら、Safari・Claude アプリ・PC のどれで開いても同じセーブです
- 遊んでいる間は、変わったところを10秒おき（歩いただけなら1分おき）にセーブ。宿屋・教会の「記録」・「終わる」・キャラを作る・消す時と、ほかのアプリに切りかえた時は、すぐにセーブします
- このブラウザにもいっしょにセーブします。両方にある時は、あとでセーブしたほうを使います
- 「だれで遊ぶ？」の上に、セーブの場所が出ます
  - 「☁ claude.aiにセーブ（ブラウザを閉じても消えません）」… OK
  - 「このブラウザだけにセーブ（…消えることがあります）」… claude.ai にセーブできていません。大事なキャラは、家族サーバーに連れていくか、引っこしコードをメモに残してね
- はじめて開いた時、claude.ai の画面に「許可」の確認が出たら「許可」を選んでください
- **大人の家族にも使ってもらう時**：アーティファクトの Share メニューの「メールで招待（ベータ）」で、家族のメールアドレスを **「編集できる（Can edit）」** で招待します
  - 招待された人は、そのメールアドレスの Claude アカウントでログインして開きます。無料のアカウントでも招待を受けられます
  - 「見るだけ」「コメントできる」のままだと、claude.ai にはセーブできません（このブラウザだけのセーブになります）
  - クラウドセーブを使うアーティファクトは、リンクでの一般公開はできません
- **Claude のアカウントは1人1つ**です。アカウントを家族で共有することは、Anthropic の利用規約で禁止されています。また、アカウントを作れるのは18歳以上です（無料でも同じ）
- **お子さんは家族サーバーで**：家族サーバーならアカウントはいりません。1つのセーブに家族全員のキャラを作って、それぞれ自分のスマホで遊べます（セーブは家のPCに残ります）

### 家族サーバーとスマホのデータを合わせる

**家族サーバーには、いつも一番新しいデータが残ります。** 家族サーバーで遊んでも、スマホのひとりで遊ぶサイトで遊んでも、家族サーバーにつながった時に新しいデータを保存します。

- **サイト → 家族サーバー**：サイトのタイトルか「だれで遊ぶ？」の「**🏠 家族サーバーで遊ぶ**」
  - このスマホで進めたキャラを持って家族サーバーが開き、合言葉のあとで自動で保存します（「〇〇の両方で遊んだデータを合わせました（Lv8→Lv10）」などと出ます）
  - はじめての時は、家族サーバーのアドレス（`192.168.…:3000`。Tailscale なら `100.…:3000`）を聞かれます
- **家族サーバーを直接開いた時**：そのスマホでサイトを使ったことがあれば、ときどき（20分以上たった時）自動でサイトへ行って、サイトのデータを持ってもどってきます（1〜2秒）
  - 家族サーバーのキャラも、この時にスマホのサイトへ保存されます
  - 自分で合わせたい時は、家族サーバーの「だれで遊ぶ？」→「**🔄 スマホと合わせる**」
- **家族サーバー → サイト**：家族サーバーの「だれで遊ぶ？」→「**📱 ひとりで遊ぶサイトへ**」（このスマホで遊んだキャラを持っていきます）
- **両方で遊んでも、なくなりません**：家族サーバーで遊んだ後に、古いデータのままのスマホでひとりで遊んでも、次に合わせた時に両方のぶんをたします
  - 経験値・お金・たおした数・職業の勝った数・種 … 両方でふえたぶんをたす（レベルは経験値から）
  - ストーリーの印・宝箱・行った場所・図鑑 … 両方を合わせる（目標は進んでいるほう）
  - 道具・装備 … 品物ごとに、両方でふえた・へったぶんをたす（使った道具は減る）
  - 仲間 … 両方の仲間を残す（別々に仲間になった魔物は両方とも）
  - いる場所・HP・作戦など … あとで遊んだほう
  - 合わせる前のセーブは `kizuna-save/backups/` に残ります（`save-before-sync-…`）
- 家族サーバーで消したキャラは、スマホから持っていっても、もどってきません（消した後にスマホで遊んでいたら、もどります）
- 同じキャラを2つの端末で同時に遊んでいる時は、あとで合わせます
- 家族サーバーのアドレス以外（家の外の知らないアドレス）へは、だまってデータを送りません（「送りますか？」と聞きます）
- iPhone で「ホーム画面に追加」したサイトは、Safari とは別のセーブになります。行き来は Safari で開いたサイトで使うのがおすすめです
- 家族サーバーで一人で遊ぶこともできます。家族サーバーのキャラは全員が同じセーブにいるので、いつでも「さそう」でパーティーを組めます

### 引っこしコード（コピーして送る・手で連れていく）

- **コピーして送るやり方**（別のスマホへ・LINE などで）
  1. 「だれで遊ぶ？」→「引っこしコード」→「① キャラを書き出す」→ キャラを選ぶ →「コピーする」
     （遊んでいる時は、メニュー →「終わる」で「だれで遊ぶ？」にもどれます）
  2. 別のスマホ・PCへは、LINE・メッセージ・AirDrop・メモなどでコードを送る（同じスマホなら送らなくてOK）
  3. 家族サーバーの「だれで遊ぶ？」→「引っこしコード」→「② コードから連れてくる」→ はりつけて「連れてくる」
  - もういるキャラのコードなら、**コードのほうが後で遊んだデータの時だけ** 入れかえます（入れかえる前のセーブは `backups/` に残ります）
  - 同じ名前の別のキャラがいる時は、名前のうしろに数字がつきます
  - 家族サーバー → 一人モードへも、同じやり方で連れていけます
  - 引っこしコードで連れていった時は、あとで遊んだほうのデータになります（両方のぶんを合わせたい時は、上の「🏠 家族サーバーで遊ぶ」を使ってね）
  - コードは短くしてあるので、仲間がいっぱいでも LINE で1回で送れます（LINE は1回1万文字まで。仲間24人でも7千文字くらい）
  - コードをメモに残しておくと、もしもの時のバックアップにもなります

#### iPhone だけで引っこす（PCの操作はいりません）

家族サーバーのPCは電源を入れておくだけで、操作はいりません。同じ iPhone で遊んだキャラなら、送る手間もありません。

1. ひとりで遊ぶサイト（Safari）で「引っこしコード」→「① キャラを書き出す」→「コピーする」（「🏠 家族サーバーへ連れていく」なら、コピーもいりません）
   - 「コピーしました！」と出れば OK。出ない時は、コードが全部選ばれた状態になるので、青いところを長おし →「コピー」
2. Safari で家族サーバーのアドレス（`http://192.168.…:3000`）を開いて合言葉を入れる
3. 「引っこしコード」→「② コードから連れてくる」→ わくの中を長おし →「ペースト」→「連れてくる」

- ひとりで遊ぶサイトのセーブは、ブラウザを閉じても残ります。ブラウザのデータを消すと消えるので、大事なキャラは家族サーバーに連れてくるか、コードをメモに残しておくと安心です

## 開発向け

```bash
cd family-rpg
npm test                  # 戦い・マップ・ストーリー（第1章・第2章を通しで）・マルチのルール・通信・文字のルールのテスト
```
