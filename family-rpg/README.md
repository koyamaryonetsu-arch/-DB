# きずなの紋章 ― 家族で あそぶ オープンワールドRPG

家族だけで あそぶための、ブラウザで うごく RPG です。
ひとりで こつこつ ぼうけんする日も、みんなで あつまって ストーリーを すすめる日も たのしめます。

- **ひとりでも・家族いっしょでも** … 最大4人パーティー。家族が いない ときは 酒場の なかまや モンスターの なかまで うめられる
- **なかまは それぞれ そだつ** … 酒場で なかまを さがして、いつでも いれかえ。なかまごとに レベル・そうび・転職・さくせん（「めいれいさせろ」で じぶんで コマンドも えらべる）
- **モンスターが なかまに なる** … 紋章の ちから「まもののこころ」に めざめると、たおした まものが ときどき おきあがって なかまに なりたがる
- **そうびで みための かわる ドット絵** … よろい・かぶと・たて・ぶきが フィールドの すがたに でる
- **家族だけ** … 家の Wi-Fi の なかだけで うごく。家族の「あいことば」が ないと 入れない。知らない人とは つながらない
- **オープンワールド** … 村・町・平原・森・湖・沼・洞窟を じゆうに あるける（シンボルエンカウント）
- **2.5D（たちたい）の がめん** … じめん・たてもの・やま・き が 3D、キャラは ドット絵の まま。ななめ うえから みおろす カメラ（せっていで むかしながらの 2D にも もどせる）
- **リアルタイムターン制バトル** … すばやさで こうどうゲージの たまる はやさが かわる。戦闘は むかしの ドラクエのような 1画面
- **転職** … いままでの 呪文・特技は 転職しても つかえる。ただし 本職でないと MPが ふえる／いりょくが さがる
- **掛け合わせ** … 呪文や特技を くみあわせた 技（魔法剣、メドロ、スターストラッシュ など）と、なかまどうしの「れんけい」「合体」「きずな技」

いまは **じょしょう〜だい1しょう（さいしょの ボス ゴルドーンまで）** が あそべます。
もんだい なければ、ここから ストーリーや しょくぎょうを ふやしていく よていです。

## あそびかた

### ひとりで ためす だけなら

サーバーが なくても、ファイルを くばる だけの ばしょ（Claude の アーティファクト など）で ひらくと
じどうで「ひとりモード」に なります。セーブは その ブラウザの なかに のこります。
（家族と いっしょに あそぶ・キャラを 家族で きょうゆう する には 下の 家族サーバーを つかいます）

### 家族サーバーで あそぶ（ひとりでも 家族でも）

家の PC を 1だい「サーバー」に して、家族の スマホ・タブレット・PC から ブラウザで つなぎます。

1. **Node.js を いれる**（はじめの 1かい だけ）
   <https://nodejs.org/ja> から「LTS」を ダウンロードして インストール（18 いじょう なら OK）
2. **この フォルダを PC に おく**
   GitHub の「Code → Download ZIP」で ダウンロードして かいとう、または `git clone`
3. **サーバーを うごかす**（`family-rpg` フォルダの なかで）
   - Windows … `start.bat` を ダブルクリック
   - Mac … `start.command` を ダブルクリック（はじめは 右クリック →「開く」）
   - Linux … `./start.sh`
   - コマンドで うごかすなら `npm start`（または `node server/index.js`）
4. **がめんに でる アドレスを ブラウザで ひらく**

   ```
   ★☆★ きずなの紋章 家族サーバーが うごきました ★☆★

   このPCで あそぶ:  http://localhost:3000
   おなじ Wi-Fi の スマホ・タブレットから:
      http://192.168.1.23:3000
   家族の あいことば:  482915
   ```

5. **家族の あいことばを 入れる** → キャラクターを つくって スタート！

- 家族の あいことばは さいしょに じどうで きまり、`data/config.json` の `password` に かかれています。すきな ことばに かえて OK（かえたら サーバーを さいきどう）
- おわるときは サーバーの がめんで `Ctrl + C`。セーブは じどうです（`data/` フォルダ）
- Windows で「ファイアウォールで ブロック されています」と でたら「プライベート ネットワーク」だけ ゆるして ください
- ポート番号を かえたい ときは `data/config.json` の `port`

> **だいじ：** この サーバーを インターネットに こうかい（ポート開放 など）しないで ください。家の Wi-Fi の なか だけで つかう そうていです。
> とおくに すむ 家族と あそびたい ときは、Tailscale などの「家族だけの VPN」を つかう ほうほうが あんぜんです。

### iPhone で あそぶ

1. iPhone を 家の Wi-Fi に つなぎ、Safari で サーバーの アドレス（`http://192.168.x.x:3000` など）を ひらく
2. **ホーム画面に ついか すると、アプリのように がめん いっぱいで あそべます**
   Safari の 共有ボタン（□に ↑）→「ホーム画面に追加」。つぎからは ホーム画面の「きずな」アイコンで ひらけます
   （ホーム画面から ひらいた ときは、あいことばを もういちど いれます）
3. たても・よこも どちらでも あそべます（たたかいの がめんも むきに あわせて かわります）

- メニューや お店は、みぎうえの「**✕ とじる**」か、まどの そとを タップで とじます。リストの うえの「**← もどる**」で ひとつ まえに もどります
- がめんが きえたり、ほかの アプリに きりかえても、**3ぷん いないに もどれば つづきから** あそべます（パーティーも そのまま。たたかいの あいだは オートで たたかいます）
- せってい（メニュー →「せってい」）
  - 「がめん：2.5D（たちたい）／2D（ドット）」… うごきが おもい ときや ふるい きかいでは 2D が おすすめ
  - 「あそんでいる あいだ がめんを けさない」… ON が おすすめ（家族との つうしんが とぎれにくい）
  - 「マナーモードでも おとを だす」… iPhone の サイレントスイッチが ON でも おとを ならす
- おとが でない ときは、がめんを いちど タップしてください（iPhone は さわるまで おとを とめています）

## ひとりで あそぶ／家族で あそぶ

- **パーティーは 4人まで。** 家族を「さそう」と おなじ パーティーに なり、いっしょに たたかえます
- **みんな じゆうに うごけます。** べつべつの ばしょ（町と どうくつ など）に いても OK
- **いっしょに たたかう ルール（ドラクエ10 ふう）**
  - だれかが まものに ふれると、**ちかく（がめんに うつるくらい）に いる なかま** が いっしょに たたかいます
  - はなれている なかまは ひきこまれません。なかまの あたまに ⚔ と あしもとに ひかる わ が でるので、**そこへ かけつけると とちゅうから さんか** できます
  - かいわ・お店・イベントの とちゅうの 人は ひきこまれません
- **ついていく**：メニュー →「なかま」→「リーダーに ついていく」で、リーダーの あとを じどうで あるきます（どうくつの でいりも いっしょ）。ちいさい こどもに おすすめ
- ストーリーの イベント（ボスせん など）は、おなじ マップに いる なかま みんなで みられます。先に すすんでいる 人が いても、あとから おいつけるように なっています
- **なかま（ルミナの町の 酒場）**
  - 酒場で なかま（ガルド／ミーナ／ポポロ／リン／ティナ、1しょう クリアで ルカ）を さがして つれていけます。つれていけるのは 3人まで。まっている なかまとは **酒場で いつでも いれかえ** できます
  - なかまは **それぞれ そだちます**（たたかいに でた なかまだけ けいけんちを もらう）。メニューの「そうび」「つよさ」「じゅもん」で なかまを えらべます。神殿で なかまの 転職も できます
  - さくせんを **「めいれいさせろ」** に すると、なかまの コマンドも じぶんで えらべます（オートボタンで みんな まとめて オートにも もどせる）
  - 家族の キャラクターも AIの なかまとして つれていけます（その人が いない 日でも OK）。もちぬしには あとで けいけんちや ゴールドの「おれい」が とどきます
  - なかまや ゲスト（ルカ）は セーブデータに のこるので、アプリを おとしても いなくなりません
  - 家族と パーティーを くむと、リーダーの なかまが ついてきます（にんげんが ふえて 4人を こえる ぶんは いったん まっています）
- **モンスターの なかま**
  - 森の ぬしとの イベントで 紋章の ちから「まもののこころ」に めざめると、**たたかいで さいごに たおした まものが ときどき なかまに なりたがります**（ボスや ものがたりの てきは なりません）
  - パーティーが いっぱいの ときは、だれかが 酒場へ もどります（あたらしい なかまに 酒場で まってもらう ことも できる）
  - モンスターは レベルで わざを おぼえて そだちます。そうびは アクセサリー だけ。なまえは 酒場で かえられます
- チャット と スタンプで 家族と おしゃべり できます

## バトル

- **リアルタイムターン制**：ひとりひとりの「こうどうゲージ」が たまったら コマンドを えらべます。**すばやさが たかいほど ゲージが はやく たまる**（武闘家は とても はやい）
- ゆっくり えらびたい ときは「ウェイト」を ON に すると、コマンドを えらんでいる あいだ 時間が とまります（メニュー → せってい。たたかいの はやさも かえられます）
- **オート** ボタンで AIに まかせる ことも できます（「めいれいさせろ」の なかまも いっしょに オートに なる）
- こうげき・じゅもんには それぞれ エフェクトが あります（メラは ひのたまが とんでいく、ヒャダルコは こおりの はしら、イオラは ばくはつ、かいしんの いちげきは がめんが ゆれる など）。まものの こうげきは みかたの まどに ひっかきや ほのおが でます
- ボスは 1ターンに 2かい うごいたり、大技の まえに「ためる」ので、ぼうぎょ・かいふくの タイミングが だいじ
- **れんけい**：なかまが つづけて こうげきすると ダメージが ふえる（2れんけい 1.1ばい 〜 最大 1.25ばい）
- **合体**：ちがう ぞくせいで れんけいすると 合体技が はつどう（ほのお＋こおり＝対消滅、ほのお＋かぜ＝火炎旋風 など）
- **きずなゲージ**：いっしょに たたかうと たまり、満タンで きずな技「ミナデイン」。パーティー みんなが「さんか」を おすほど つよくなる

## しょくぎょう と 転職

| しょくぎょう | とくちょう |
|---|---|
| 戦士 | たくましく、なかまを まもる。剣技「大地斬」「海波斬」 |
| 武闘家 | とても すばやい。こぶしの わざで かいしんを ねらう |
| 僧侶 | かいふく呪文「ホイミ」で パーティーを ささえる |
| 魔法使い | こうげき呪文「メラ」「ヒャド」「ギラ」 |
| 旅芸人 | おどり・うたで ささえる。きようで 転職ペナルティが かるい |

- ルミナの町の 神殿で 転職できます。**キャラの レベル** と **しょくぎょうごとの レベル** が あります
- 前の しょくぎょうで おぼえた 呪文・特技は **ずっと つかえます**。ただし 本職で ないと…
  - 呪文：MP 1.5ばい・いりょく 75%（おなじ けいとうの しょくぎょう なら MP 1.25ばい・90%）
  - 特技：MP 1.25ばい・いりょく 70%（おなじ けいとう なら MP そのまま・85%）
  - その しょくぎょうを **レベル15 まで きわめる** と ペナルティは はんぶん
  - 旅芸人は どの わざも「おなじ けいとう」あつかい
- 技の いちらんでは、本職でない 技に「他」マークと じっさいの MPが でます

### 掛け合わせ（ダイの大冒険・ロトの紋章 ふうの くみあわせ技）

2つ いじょうの わざを おぼえると、あたらしい 技が つかえるように なります。
町の「ひらめきの けんじゃ」に はなしかけると、まだ おぼえていない くみあわせの ヒントが きけます。

| 技 | くみあわせ |
|---|---|
| 魔法剣 | 剣技 × こうげき呪文（メラ＋大地斬 ＝ メラ大地斬 など、くみあわせで かわる） |
| 閃華裂光拳 | せいけんづき × ホイミ |
| 火炎旋風 | ギラ × バギ |
| におうだち | かばう × スカラ |
| いやしのまい | ハッスルダンス × ホイミ |
| はやてづき | ピオリム × せいけんづき |
| まどろみのうた | ラリホー × ハッスルダンス |
| メドロ | メラ × ヒャド（魔法使い レベル8 いじょう） |
| スターストラッシュ | 大地斬 × 海波斬 × 空裂斬 |

## かいはつ むけ

```bash
cd family-rpg
npm test            # たたかい・マップ・ストーリー（だい1しょう クリアまで）・マルチの ルール・通信の テスト
node tools/sim.js   # バランスの シミュレーション（ボスの 勝率 など）
npm start           # 家族サーバー
```

- いぞん パッケージ なし（Node.js だけで うごく）。WebSocket も じぶんで じっそう
- `public/js/shared/` … ゲームの ルール（サーバーと ブラウザの りょうほうで うごく）
  - `data/` しょくぎょう・わざ・どうぐ・まもの・ストーリー（`companions.js` は なかまに なる モンスターの のびかたと わざ）
  - `world/` せかいの うごき（パーティー・なかま・酒場、イベント、たたかいの しんこう）
  - `battle.js` リアルタイムターン制バトル
- `public/js/client/` … がめん・おと・そうさ（ドット絵も BGM も プログラムで つくっています）
  - `render/field3d.js` 2.5D の がめん（`render/tex3d.js` は 3D よう の え）
  - `render/chars.js` キャラの ドット絵（そうびで ふく・かぶと・たて・ぶきが かわる）、`render/battlefx.js` たたかいの エフェクト
- `public/vendor/three.min.js` … 3D の ための three.js（MIT）。つかう ぶぶん だけを `tools/build-three.mjs` で まとめた もの。インターネットに つながなくても うごきます
- `server/` … 家族サーバー（あいことば・セーブ・つなぎなおし）
- `tools/make-icons.mjs` … ホーム画面の アイコンを つくる
- あたらしい しょう を ふやす ときは `data/story.js`（台本）と `maps/`（マップ）に たします
