## 2. 週の きまり

- **月曜 0:00（日本時間）** に 入れかわる。週の 番号 = 日本時間の 日の 番号から（1970-01-05 が 月曜）。サーバーの 時計（`world.now()`）を 使う
- 毎週 **3つ**。週の 番号を 種に した らんすうで えらぶ（`pickWeek`）。えらんだ 3つは 世界の 状態に しまう ので、その 週の 間は かわらない（家族サーバーの 全員が 同じ）
- **同じ 物が 2週 続かない**: 先週の 3つを さけて えらぶ（先週の 記録が ない 時は、週の 番号から きまる 先週の 3つを さける）
- **開いて いない しくみは 出さない**: 「今 遊んで いる 家族」（さいきん 4週の 間に 遊んだ キャラ・今 いる キャラ。だれも いなければ 全員）の **いちばん 進んで いない 人** でも できる 物だけ（下の 表の「出す 時」）。週の はじめに 1回 きめる
- のこりの 日数は 今日も 入れる（月曜は 7・日曜は 1）
- ばつは なし。できなくても 何も へらない。何週 あいても こわれない

## 4. 数え方（サーバーだけ）

- **クライアントの 申告は 信じない**。数えるのは サーバーの 戦いの 終わり（`finishBattle` の はじめ）・宝箱を 開けた 時・階だんで 移った 時だけ
- **人間の キャラが 2人 いじょう** の 時だけ:
  - 戦い … その 戦いに 出た 人間（`ctx.sids`。同じ パーティーで 近くに いた 人・あとから かけつけた 人）が 2人 いじょう。家族の キャラを 仲間（AI）として 連れて いる だけでは 数えない
  - 宝箱・階 … 同じ パーティーの 人間が 同じ マップに 2人 いじょう（とぎれて いる 人は 入れない）
  - モンスター闘技場の その場の 対戦（家族どうしの 対戦）は 数えない
- **ひとりモード（ひとりで遊ぶサイト）** では 何も 数えない・何も 書かない
- 家族の 合計で 1つの 数。**今週 ひとりずつが 足した 数**（ミッションごと）・いっしょの 戦いの 回数・たおした 数も おぼえる（家族の 記録の「今週のがんばり」）
- 達成した 時: 遊んで いる 家族 みんなに トースト（音つき）・チャット（「家族ミッション」から）・家族のけいじ板

## 5. ごほうび

### 毎週（達成した ミッションごと）

| ならび | 道具 | お金 |
|---|---|---|
| 1つ目 | 魔法の聖水×2 | 受けとる キャラの レベル×20G（100〜2000G） |
| 2つ目 | よみがえりの花×1 | おなじ |
| 3つ目 | 帰り道の羽×3 | おなじ |

- 受けとれる 人: **その 週に 1回でも いっしょに 遊んだ キャラ**（2人 いじょうの 戦い・宝箱・階に 入った）。メニューの「家族ミッション」の「ごほうびを受けとる」
- **1つの ミッションに つき 1回だけ**（とちゅうで 受けとって、あとで 達成した 分は また 受けとれる）
- **きめた こと: 先週の 分は 次の 週の 間だけ 受けとれる**（「先週のごほうびを受けとる」）。その あとは 消える（家族の 記録の「先週の結果」には のこる）
- 強さに ひびかない 物だけ（種・装備・メダルは 出さない）

### 3つとも 達成した 週の 合計（ここだけの しょうごうと スタンプ）

- **きめた こと: 「続けて」では なく「合計」で 数える**。家族が 毎週 遊べるとは かぎらない ので、1週 とぎれても なくならない
- キャラごとに 数える（その 週に いっしょに 遊んだ キャラ。3つとも 達成した あとで 来た 人も 入る）
- もらった 時に 自分の 画面に 知らせ。あたらしい しょうごうは すぐ つく（「家族ミッション」で かえる・はずす）

| 合計 | しょうごう | スタンプ |
|---|---|---|
| 2週 | なかよしパーティー | いっしょだと楽しい！ |
| 4週 | きずなの仲間 | チームワーク！ |
| 8週 | 家族の星 | 家族さいこう！ |
| 12週 | きずなの勇者たち | ミッション達成！ |
| 20週 | 伝説の家族 | ずっといっしょ！ |

- しょうごうは **チャットの 名前の 横**（「パパ〈なかよしパーティー〉」）と 家族ミッションの 画面に 出る。強さには 関係 ない
- スタンプは「スタンプを変える」→「ことばを選ぶ」の なかまわけ「家族ミッション」で えらべる（新しい 絵は かかない）

## 6. 保存の 場所

- **家族サーバーの 世界の 側**: `world.data.missions`（`kizuna-save/save.json` の 中。キャラの 引っこしコードには 入らない）
  - `week` … 今週（`no`・`list:[{k,need}]`・`prog`・`at`〈達成した 時こく〉・`by:{キャラid:{name,n,b,k}}`・`got:{キャラid:[0/1…]}`・`kinds`・`floors`・`full`・`fullCred`）
  - `prev` … 先週（小さく した 物）/ `hist` … さいきん 12週の 達成の 数
  - `total` … 家族の 記録（`kills`・`wins`・`battles`・`full`・`done`・`weeks`・`boss:{魔物:回数}`）/ `fullBy` … キャラごとの 3つとも 達成した 週の 合計
- **キャラ**: もらった しょうごう・スタンプ だけ `c.famm = { t: [2, 4], w: 4 }`（もらう 前は 項目が ない → 引っこしコードに 入らない。`transfer.js` は さわって いない）
- 読みこむ 時に こわれた 所を なおす（`missionState`・`cleanFamm`）

## 7. 画面

- メニューの「家族ミッション」（冒険のしおりの 下）。カーソルを あわせると 右に 今週の 3つ。えらぶと 画面いっぱいの まど
  - 今週の ミッション（のこり ○日）: 3まいの カード（文・棒・数・自分が 足した 数・ごほうび・達成！／受けとりずみ）
  - ごほうび: 「ごほうびを受けとる（○こ）」・「先週のごほうびを受けとる（○こ）」
  - しょうごう・スタンプ: 今の しょうごう・3つとも 達成した 週・つぎの しょうごうまで（えらぶと かえる・はずす）
  - 家族の記録を見る → いっしょに たおした 魔物・勝った 戦い・3つとも 達成した 週・達成した ミッション・今週の がんばり（ひとりずつ）・先週の 結果・いっしょに たおした ボス
- よこ画面・PC は 2〜3列、たて画面は 1列。まどの 中は たてに だけ スクロール。キーボード・ゲームパッド・タップ（`ListMenu`）。もどるで 1つ 前・閉じる
- 冒険のしおり: 家族サーバーでは「のこっていること」の いちばん 上に「家族ミッション n/3」（くわしくは 3つの 文と 数）
- **ひとりで遊ぶサイト**: 「家族サーバーでいっしょに遊ぶと進みます」だけ。しおりには 出ない。エラーに ならない

## 8. ネタバレ

- ミッションの 文に ボスの 名前・物語の 先は 書かない（「ボスを1体」）
- 家族の 記録の「いっしょにたおしたボス」は **見て いる キャラが もう たおした ボスだけ** 名前を 出す。まだの ボスは 名前も 数も 出さない（サーバーが おくらない）
- しくみが 開いて いない 家族には その ミッションを 出さない

## 9. 気を つける こと・この あと

- 1つの 戦いに 人間が 2人 いれば、ひとりずつの「足した 数」は 2人とも 同じ 数（いっしょに やった ので）
- 宝箱の ミッションは、ダンジョンの 宝箱を ぜんぶ 開けた 家族でも フィールドの 宝箱で できる
- しょうごうを「強さ」の 画面にも 出すのは、ほかの 係の ファイル（`client/ui/job-trials.js`）なので 今回は しない
