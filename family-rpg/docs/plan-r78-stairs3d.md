## 2. きめた きまり（さわれる 物の 見え方。`render/mark3d.js` の `TOUCH_LOOK`）

- **行き来する 所（階段・くさり・縄ばしご）**: 立体の 形 ＋ 上に **▲（上り・のぼる）／▼（下り）** の 目じるし。
  色は 明るい 水色（`#7ee8ff`）に こい ふち（`#1b1330`）。ゆっくり 上下に ゆれる（1.6 びょう・0.07 マス）。足もとに うすい 水色の 光。
  くらやみ・よるの 上に かく（くらい 階でも 見える）。手前の 物の 向こうの ときは うすく（0.55）。
- **宝箱・とびら・しかけ**: 目じるしは つけない（ふえると 階段が 目立たなく なる）。これまでどおり 立てた 絵（ふちどり つき）。
- ほかの しるしと まぜない: きらきら（白と 黄色の 十字）・宝の地図（赤むらさきの 光の 柱）。
- 目じるしを 出さない 時: イベント中（`game.busy`）・メニュー・だいほんで 見る 場所が かわって いる 時・戦い・その 階段の 上に 立って いる 時。
- 設定の 項目は ふやさない（いつも 入）。

## 3. 直した 所

- `render/mark3d.js`（新しい。three.js を つかわない きまりと 絵）
  - `markKind`（タイル → ▲／▼。縄ばしごは たて穴に かけた 方が ▼）・`collectMarks`（2マス はばの 階段は 1つ）・
    `stairCuts`（階段の 手前の 高い かべを ひくく: すぐ 手前は 0.3・2つ 手前は 0.85。水門などの とびらは そのまま）・
    `hiddenBehind`・`markBob`・`marksShown`・`nearMark`・`drawMark`（ドットの ▲▼）・`drawMarkGlow`・`chainCanvas3d`（太く 明るい くさりの 絵）
- `render/field3d.js`
  - 階段を 立体に（`addStairs`）: 上りは 南から 北へ 3だん 上がる 石の 段（うえは 明るく・まえの めんは くらく）。
    下りは ゆかに 四角い 穴と 北へ 3だん 下りる 段（おくほど くらい）・穴の おくと よこの かべ。下の ゆかは まわりの ゆかの え。
  - 階段の 手前の かべを ひくく（`stairCuts` を `spec` に。すぐ 手前は ひくい ふち・2つ 手前は こしの 高さ）。
    2D の かべの きまり（ぶつかる）は かわらない。かくれて いた 階段が かべの きりこみの おくに 見える。
  - いかりの くさり: 太い 明るい 絵で まっすぐ 立てる（うしろの 木に ささらない）。かくれた 所は 水色の シルエットで うすく（じぶんの シルエットと おなじ しくみ）。
  - 目じるしを かく `drawMarks`（`field.js` の `render3d` から 1行で よぶ。くらやみ・よる・天気の 上）。
  - たてた え の アトラス: 16×24 の わく → 高さ 48 の 行に よこへ ならべる（いかり・くさり・風車・鐘 などの 上が 切れて いた・はばの ひろい え が となりに かさなって いた のも なおる）。
- `client/field.js`: `render3d` に `this.r3d.drawMarks?.(ctx, P, t)` を 1行。
- 足した 物の 数（スマホの おもさ）: かげ・光（ライト）は ふやして いない。階段 1マスに つき 四角 10〜13まい（いままでの チャンクの メッシュに 入れる → 描く 回数は ふえない）。
  くさりの ある マップだけ メッシュ 2つ（くさり・シルエット）。うえの 2D に 目じるし 1つに つき 光 1つと 四角 十数こ（画面の 中の 階段だけ）。

## 5. 気を つける こと・のこり

- 階段の 手前の かべは 2.5D では ひくく 見える（ぶつかる きまりは 2D と おなじ）。かべの 下に 道が ある ように 見えないか、家族に 見て もらう。
- 暗い 階で 階段が しずむ のは 2D でも おなじ（今回は 2D を かえて いない）。
- 宝箱・とびら・しかけは きまりを 書いた だけ（見た目は かえて いない）。後半（3-9 の のこり）で きまりに そって 見直す。

## 6. 第82回: 矢印を やめた

家族の ねがい「階段とかの 矢印は いらない」。2.5D の 階段・くさり・縄ばしごの 上の **▲▼ の 目じるしと 足もとの うすい 光を やめた**（いつも 出さない。設定の 切りかえは 作らない）。
のこした 物: 立体の 階段（上りは 段・下りは 穴）・手前の かべを ひくく（`stairCuts`）・太く 明るい いかりの くさり。
消した 物: `mark3d.js` の `markKind`・`collectMarks`・`MARK_LIFT`・`MARK_COLOR`・`markBob`・`marksShown`・`nearMark`・`drawMark`・`drawMarkGlow`・`isClimbTile`、
`field3d.js` の `drawMarks` と `this.marks`、`field.js` の よびだし 1行。`TOUCH_LOOK` は 立体に するかの 項目（`solid`）だけ のこした。
`hiddenBehind` は テストで「どの 階段も 手前の かべに かくれない」を しらべる ために のこした。
矢印の かわりに ひかえめに おぎなった: 上りの 段の てまえの ふちを すこし 明るく（1.15 → 1.3）・下りの 穴に 細い 明るい 石の ふち（0.05 マス。`STAIR_EDGE`）。
暗い 洞窟でも 光の 中なら 穴の 形が わかる（やみの 外は 2D と おなじく 見えない）。2D の 表示・マップの データは かえて いない。
