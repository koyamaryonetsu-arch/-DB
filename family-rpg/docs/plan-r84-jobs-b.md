## 3. しくみ（`shared/battle-r84b.js`。どれも 戦いの 中だけ・キャラにも セーブにも 項目を 足さない）

1. **水の すがた／お湯の すがた**（戦いの 人の `c.r84bForm`）
   - **戦いの はじめは お湯の すがた**（`START_FORM`）。すがた なしで 始めると、オートが まず 1回 かぶる ことに なり、ボスで 弱かった（5 の しらべ）。
     お湯から 始めて、ざこが 多い 戦いで 水を かぶる 形に した
   - 水 ＝ 行動ゲージ ×(1＋pct)・物理の よけ ＋pct×0.8（上限 `EVA_CAP` 0.2）／お湯 ＝ 物理の ダメージ ×(1＋pct)・受ける ダメージ ×(1−pct×0.6)
   - pct は 今の 職業の 段（`FORM_PCT`）: 門下生 15%・乱馬 20%・達人 25%。**ほかの 職業に 転職した あと**は「水をかぶる／お湯をかぶる」を 覚えて いれば 15%（`OTHER_PCT`）。覚えて いなければ すがたは ない
   - 「水をかぶる／お湯をかぶる」は 1つの 技。えらぶと「どちらをかぶる？」の メニュー（YAIBA の 玉がえと おなじ 画面。`client/battle-r84b.js` の `formMenu`）。すばやい（行動ゲージ 80 から）
   - **勝手に かわる**: 雨の 天気・水の 属性の 攻撃を 受けた → 水／晴れの 天気・炎の 属性の 攻撃を 受けた → お湯。ひとこと（「雨にぬれて、水のすがたになった！」など）。
     天気は 自分の 番の はじめに 見て、**同じ 天気の 間は 1回だけ**（自分で もどす ことも できる）
   - **前ぶれの ある 大技（`ev.big`）は 水の すがたでも よけられない**（よける だけで ボスの 大技を 受けない、に しない）。呪文も よけられない
   - 札: 仲間の まどに「水のすがた」（水色）・「お湯のすがた」（だいだい）。かわった 時は まどが その 色で 光る。家族 みんなの 画面（pub の r84bForm）
   - 心の水（`c.r84bKokoro = { left }`）: 3回 動く 間 両方の よい 所（札「心の水3」）。乱れ打ちは 水の 8回に お湯の 力の 半分
2. **飛竜しょう天は**（今 ある 反撃の 構えの `c.stance` を 広げた `kind: 'hiryu'`）
   - 次の 自分の 番までに 敵の 攻撃（物理でも 呪文でも。1人でも 全体でも）を 受けると、その 行動の あとで 風の 竜巻を 敵全体へ（1回だけ）
   - 1体ごとの 強さ ＝ 2.0 ×（1 ＋ 0.25 × その 敵の 強化の 数）× 水の すがたなら 1.4（お湯の すがたは ふつうの 物理と おなじく ×1.2）
   - **強化の 数**（`boostCount`）: ふつうの 強化（攻撃力アップ などの バフ・かいひ・力ため）は 1つずつ。**ボスの しかけ**（ずっと 続く 強化〈left が Infinity〉）は いくつ あっても **1つだけ**。
     **形態・前ぶれ・かまえ は 数えない**。かけひきで おこって いれば ＋1。ぜんぶで **4 まで**（`BOOST_CAP`。いちばん 強くて 2倍）
   - **攻撃が 来なかった 時**: 次の 自分の 番の はじめに 弱い 風の 一ふり（敵全体 0.8）＋ 使った MP の 半分が もどる
   - 飛竜こうりんだん（伝説）: かまえ なし。敵全体 2.2 ×（1 ＋ 0.2 × 強化の 数〈4まで〉）
3. **かけひき**（`t.r84bIkari = { left, atk, by }`）
   - 敵を おこらせる: 攻撃力 ×1.1・守備力 0.6（ボスは 0.8）。長さ 4回（ボスは 2回）。当たる わりあい 90%（ボス 70%）
   - **守り下げは ほかの 守り下げと 足し算に しない**: 今の 守り下げの 方が 強い ときは 長さだけ のばす。かさねがけの 2だんかいめにも ならない
   - おこった 敵は **おこらせた 人を ねらいやすい**（1人を ねらう 攻撃・技だけ。ふつう 60%・ボス 40%。前ぶれの 大技・全体の 技は かえない。`r84bTaunt`）。
     → 飛竜しょう天はで やり返しやすく なる（設計に ない 足し: かまえても 攻撃が 来ない ことが 多く、オートで 弱かった ため）
   - かけひき・極 は 敵全体。軍師の 強化ふうじの 間も おこらせられる（おこるのは 強化では ない）
4. **どげざ**: 今 ある 行動ゲージを 下げる しくみ（`atbSet`。ボスは 今の きまりで 効く わりあい 半分・下がり方も 半分）。**敵前だい逃亡**: 仲間全員 `r84bDodge`（1回 動いたら 消える）・戦いからは にげない
5. **乱れ打ち・手数・自信の気だん**: phys の しるし `effect.r84b`（'midare'・'te'・'jishin'）。battle.js の 'phys' の はじめで `r84bPhys`
6. **身を 守るのも 1回の 行動**: 身を 守った 時も 心の水・敵前だい逃亡・かまえの のこりを すすめる（battle.js の 防御に 1行）
7. **オート**（ai.js の decideAlly の 4.95: `r84bPlan`。わりあいは `R84B_AI`）
   - すがた: ボスで 水なら お湯に もどす・ざこが 3体 いじょうで お湯なら 水を かぶる（70%）
   - 前ぶれ → 飛竜しょう天は（30%）／自分が おこらせた 敵が いる → 飛竜しょう天は（60%）／敵の 強化が 2つ いじょう → 飛竜しょう天は（50%）
   - ボスで まだ おこって いない → かけひき（4%）・心の水（6%）／前ぶれ → 敵前だい逃亡（40%）／敵 3体 いじょう → あまぐりけん・千手（50%）
   - ボスで HP 6わり いじょう・MP 2わり5分 いじょう → 自信の気だん（強い 方。35%）
   - 運（rng）を 使うのは その 技を もつ 時だけ（ほかの 職業の オートの ながれは かわらない。テストで たしかめた）
8. 職業の試練の まぼろしは すがた・かまえ・かけひき・敵前だい逃亡・心の水を 使わない（battle-trial.js の NO_USE）

  4. MP を 魔力から うつした（乱馬 0.9 → 1.0・達人 1.05 → 1.2）。自信の気だん・極 3.4 → 4.4（MP 14 → 11）・自信の気だん 2.6 → 3.0（MP 10 → 8）・こうりんだん 1.9 → 2.2（MP 32 → 28）・
     飛竜しょう天は 1.5 → 2.0（水 1.2 → 1.4・一ふり 0.6 → 0.8）

    → かまえと かけひきは「たまに 使う 大技」に して、ふだんは 自信の気だん で 戦う 形に した（4 で 83%・470びょう）

  （USES=1・20回。1戦で 大技を 受けた 回数 達人 0.2〜8.6／スーパーサイヤ人3 0.1〜8.6／飛天 0.1〜5.4、ふつうの 攻撃を よけた 回数 達人 0.5〜2.5／ほかの 伝説 0.2〜1.6。
  大技を よけたのは 0〜0.5回で、前から ある 素早さの よけ だけ〈すがたの よけは 大技に 効かない〉）
- オートの やり返しは 1戦 0.1〜0.5回（かまえは「たまに」）。家族が 手で「かけひき → 飛竜しょう天は」と つなぐと よく 決まる（ブラウザで たしかめた）
