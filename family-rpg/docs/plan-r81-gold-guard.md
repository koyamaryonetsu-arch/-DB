# 第81回: 負けた 時に へる お金が 少なく なる アクセサリー

> 家族の お願い（そのまま）:「ボスに負けてもお金が減る量が少なくなるアクセサリーをつくって」
>
> 第80回で「ボスに 負けた 時の ヒント」と「もう一度いどむ」が 入った。ヒントを 見ながら 何回も いどむと、そのたびに
> お金が 半分に なって 子どもには きびしい。それを やわらげる。

## 1. 今の 決まり（お金が へる 所）

お金が へるのは `shared/world/battles.js` の `finishBattle` の `outcome === 'lose'` の 1か所だけ。
戦いに 出た 人（`sessions` … その 戦いに いる 家族の 人。ひとりなら 自分だけ）ごとに、その 人の 持っている お金を
`shared/world/bank.js` の `wipeGoldLoss` で へらす（預かり所の お金は へらない）。そのあと `world.respawn` が
いのりの場所で 目を 覚ます 知らせ（toast）に「所持金が半分になってしまった…」を 足す。

| 場面 | 今まで | 第81回の あと |
|---|---|---|
| ひとりで ふつうの 戦い（フィールド・ダンジョン・宝の地図の 洞窟）で 全滅 | 持っている お金が 半分 | つけて いれば さいふ 4分の1・お守り 10分の1 |
| ひとりで ボス（きまった 戦い・`loseOk` なし）で 全滅 | 半分（ヒント・もう一度いどむ が 出る） | 同じく 少なく へる。ヒント・もう一度いどむ は そのまま |
| 家族の パーティーで 全滅（いっしょに 戦った 家族の 人 みんな） | 1人ずつ、自分の お金が 半分 | 1人ずつ、**自分が つけて いる** 物で きまる（つけた 人だけ 少なく） |
| 戦いの とちゅうで 手伝いに 来た 家族（`joinBattle`） | その 人も `sessions` に 入るので 自分の お金が 半分 | 同じく 自分の 装備で きまる |
| 酒場から つれて いった 家族の キャラ・サポート仲間・ゲスト・馬車の 仲間・魔物の 仲間 | お金を もたない（へる 所が ない） | かわらない |
| ひみつのダンジョン（`MAPS[ctx.map].sd`） | へらない（「ひみつのダンジョンでは、お金はへらない。」） | かわらない |
| サファラ闘技場（`loseOk`） | へらない | かわらない |
| モンスター闘技場（`ctx.finish` … べつの おわり方） | へらない | かわらない |
| 負けても 物語が すすむ 戦い（リオンの けいこ・時のまぼろし・職業の 試練 など `loseOk`） | へらない | かわらない |
| にげた | へらない | かわらない |

## 2. 作った 品（`shared/data/items-r81.js`）

| ID | 名前 | 効き目 | 強さ | 店 | ねだん |

- どちらも アクセサリー（`type: 'acc'`）。だれでも つけられる（魔物の 仲間も つけられるが、お金を もたないので 効かない）
- `wipeDiv` … へる 分 ＝ 持っている お金 ÷ `wipeDiv`（はしたは へる 方へ 切り上げ。ふだんは 2 ＝ 今までと 同じ。7G → 3G）
  - 例: 1000G → さいふ 750G・お守り 900G・つけない 500G
- `perk`（`wipeQuarter`・`wipeTenth`）… メニューの せつめいの「★」の 文（`items-r31.js` の `PERK_TEXT` に まぜる）。
  `perk` の ある 品は 今の 決まりで「みんなさいきょう装備」で はずさない・分解できない
- 店の 品（レア度 0・★1）。きたえられない
- せつめい文: 「つけていると、全滅した時にへるお金が、半分から4分の1になる。強さは上がらない。」（お守りは 10分の1）

### 店と ねだんの 理由

- 序章〜第1章の 店で アクセサリーを 売って いるのは **ホシフル村のよろず屋**（ネコのすず 80G）だけ。ルミナには アクセサリーの 店が
  ないので、お金の 品として 自然な **ルミナの道具屋** にも 置いた。どちらも 物語に 関係なく いつも ならぶ（`more` の `show` が から）。
  第1章の ころの 装備は 10〜760G。さいふは ネコのすず と ルミナの 銅の 武器の 間の **150G**（はじめての 全滅 1〜2回で 元が とれる）
- 第2部の 店は どこも アクセサリーを 売って いない（装備は 武器屋・防具屋 だけ。いちばん 上は 白雪の里の 防具屋 16000G）。
  お守りは「お金を 守る 道具」として **千年前の 町の 道具屋 4つ** に 置いた（第8章の 家族が ルーラ・帰り道の羽で 千年前の
  どの 町にも すぐ 行ける。第8章には 新しい 町が ない）。第2部の 店の 装備の 上の 方（13500〜16000G）に 合わせて **15000G**。
  第8章の ふつうの 魔物は 1ぴき 1150〜1760G なので、10回 ほど 戦えば 買える。持って いる お金が 3万G を こえて いれば、
  1回 全滅 するだけで 元が とれる（半分 → 10分の1 で 4割 多く のこる）
- 今 第8章に いる 家族は、千年前の 道具屋（お守り）・ルーラで 行ける ホシフル村・ルミナ（さいふ）の どちらでも すぐ 買える
- 第2部の 道具屋の 品の ならび（`PAST_SHOP_TOOLS` など）は ほかの 店と 同じ 配列を 使って いて、テストが「道具だけ」を 見て
  いるので かえない。`addR81Shops` が 店の `more` に 足す（`shops.js` と `shops-c7*.js`。何回 よんでも 1回だけ）

## 3. きめた こと

1. **ボスでも ふつうの 戦いでも** 効く（お金が へる 全滅なら いつも）。もともと へらない 場面は そのまま（1. の 表）
2. **つけて いる その キャラ 自身の お金だけ**（`shared/world/perks.js` の `wipeGuard(m.char)`）。家族で 負けた 時は 1人ずつ
   自分の 装備で きまる。お金を もつのは 家族の 人の キャラだけなので、馬車の 仲間・魔物・サポート仲間が つけて いても
   だれの お金にも 効かない（「キャラの 装備の 効き目は その キャラ だけ」… しあわせのぼうし・こうふくのくつ と 同じ 考え）
3. **足さない**: 装備の 中で いちばん 少なく へる 1つだけ（今の アクセサリーの わくは 1つ。わくが ふえても お守りの 10分の1 が いちばん）
4. **強さの ボーナスは なし**。強い アクセサリーの わくを 1つ 使う かわりに お金を 守る、えらぶ 楽しみ
5. **見た目装備では 効かない**: `wipeGuard` は `char.equip` だけを 見る。見た目装備（`look-equip.js`）は 武器・よろい・たて・頭 だけで
   アクセサリーは もともと ない（`LOOK_SLOTS`）。本当に 装備して いる 時だけ 効く
6. **引っこしコード**: キャラに 新しい 項目は ない（ただの 品）。品の ID は 文字の まま 書き出す（KIZUNA-5 の 圧縮の 辞書 `transfer-prime.js` は かえない）ので、つけた まま 書き出して もどせる
