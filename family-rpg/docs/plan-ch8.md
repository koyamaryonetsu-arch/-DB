# 第8章「千年の約束」の計画（第2部の さいごの 章）

> ネタバレ注意。物語の これまでは `docs/plan-ch6.md`（第2部の 全体・14-5）と `docs/plan-ch7.md`。
> 家族への 報告は「遊べる所・しくみ」だけ。カイの ひみつ（第7章 第3幕）は 報告に 書かない。

## 1. 家族が 決めた こと（2026-11-10）

1. いちばん さいごの 戦いの 場所: **時のはざま**（千年前と 今が まざった ふしぎな 世界。歩くと 時代が かわる。この 章だけの 場所）
2. 「千年前と 今で 同時に 戦う」は **ダンジョンだけ**（ボス戦は いつもどおり 1つの 戦い）
3. さいごの ボス: **ソリトゥスの 本当の すがた**（第1部からの 敵。この 章だけの オリジナルの 絵。何回も 変身する。細かく 描く）
4. 物語: **第2部の おわり ＋ 第3部へ**（千年の約束の 物語は きちんと おわる。エンディングの あと、第3部の はじまりを 少しだけ）
5. 長さ: **4幕**（長い ダンジョン 4つ）
6. 中ボスの もと（名前は もじる）: **ジャファー（アラジン）・フリーザ（ドラゴンボール）・ハデス（ヘラクレス）・クッパ（マリオ）**
7. いっしょに 作る もの: **千年前の 4人が ゲストで 戦う**・**手下の 魔物 ＋ 闘技場・地図の 上の 段**・**クリア後の 裏ダンジョン**・**お仕事いらい・より道**
8. エンディングに とくに 入れる もの: なし（物語の 場面と「第3部へ」だけ）

## 2. 4つの 幕（案。家族に 見せて「作って」で 1幕ずつ 作る）

| 幕 | Step | 舞台 | 長い ダンジョン（2つの 時代） | 中ボス | ゲスト | 敵の Lv |
|---|---|---|---|---|---|---|
| 第1幕「月の王宮の うらぎり」 | 1・2 | 千年前の コガネ地方（緑の王国）と 今の サファラ | **月の王宮の 地下迷宮**（今の サファラ王宮の 地下と かさなる） | **ジャファー** が もと（王の そばに 仕える へびの 魔術師。とちゅうで 大きな コブラ → ランプの 魔人に） | カリム | 80〜83 |
| 第2幕「よみの 青い火」 | 3・4 | 千年前の 海（クモイ）の 海の底 | **よみの 海底神殿**（今の 海の 底の 遺跡と かさなる。青い 火を ともすと 道が 見える） | **ハデス** が もと（青い 炎の かみの、よみの国の 王。炎の 色で 弱点が かわる） | カイ | 83〜86 |
| 第3幕「くろがねの 空中要塞」 | 5・6 | 千年前の ミドリナ地方（はじまりの 泉の里の 空） | **くろがねの 空中要塞**（千年前は 空を とぶ 要塞・今は 森に おちた 残がい） | **クッパ** が もと（千年前の クッパの ご先祖「大魔王」。今の クッパとは 別の すがた） | ミナモ | 86〜89 |
| 第4幕「時のはざま」 | 7・8 | 時のはざま（千年前と 今が まざる） | **時のはざま の 回廊**（歩くと 時代が かわる。これまでの 場所の かけらが うかぶ） | **フリーザ** が もと（何回も 変身する 門番。Step 7 の さいご） → さいごの ボス **ソリトゥス**（Step 8） | リオン（さいごは 4人 そろう・第1部の 人たちも かけつける） | 89〜95 |

- **2つの 時代で 同時に**（ダンジョンだけ）: どの ダンジョンも、千年前の 階と 今の 階が かさなる。片方の 時代で しかけを 動かすと、もう 片方の 道が 開く。家族が「千年前の組」と「今の組」に 分かれると 早く すすむ。**ひとりでも 必ず とける**（時の砂時計で 行き来する。第6・7章の きまり: 交代する しかけは となりあわせない・待てる マスを 置く）
- **ゲスト**: 各幕で 千年前の 4人の うち 1人が ゲスト（大事な 戦いで いっしょに 戦う）。第4幕は 4人 そろう。さいごの 戦いの 前に、第1部の 人たち（ノクト・サラ・ルカ・ばあちゃん・アステル など）が 時を こえて かけつける場面
- **ボス**: 中ボス 4体と ソリトゥス は どれも 細かく 描く（`artScale: 0.5`）。読める しかけ（知っている 人は 9わり 勝てる）。ソリトゥスは 3だん くらいの 変身
- **エンディング**: 千年前の ふういん → 今の 世界へ「千年の約束」が つながる → 第2部 完 →「第3部」の はじまりを 少しだけ（中みは まだ 決めない）

## 3. いっしょに 作る もの（どの 幕と いっしょに 作るか）

- 手下の 魔物: 各幕 4〜5しゅ（どれも 仲間に なる。新しい 絵は 各幕 3しゅ まで）
- モンスター闘技場・サファラ闘技場の 新ランク、宝の地図の 上限（40 → 45 → 50）: 第2幕と 第4幕の あとに 上げる
- お仕事いらい・より道（時をこえる手紙など）: 各幕に 少しずつ
- **クリア後の 裏ダンジョン**: 第4幕の あと（第8章クリアで 開く）。とても 強い 敵と かくしボス（第2部 ぜんぶの ボスの 強い すがた など）。中みは 第4幕を 作る 時に 家族に 聞く

- 第7章と 同じ: A … 世界と 物語・B … 戦い・品、ほかに C … 強さの 上の 段・D … いらい・より道。1幕ずつ「作って」で 作る
- 4-4 の きまり（`docs/plan-ch7.md`）は ぜんぶ 守る
- 名前の 約束（物語の フラグ・マップの 先頭・出現表・タイル ID）は、幕を 作る 時に この ファイルに 書く（第1幕: フラグ `c8_*`・マップ `c8a_*`）
