# 第78回 3-6: メニューの「かんたん表示」（係の 文書）

設計は `plan-r78.md` の 0（家族が きめた こと）と 2。ここは 係の 実装の きろく。

## 1. 何を 作ったか

- 設定（メニューの「設定」→「画面と音・戦い」の いちばん 下）に **「メニューの表示：くわしい／かんたん」**。えらぶ たびに 切りかわる。
- **キャラごと**（サーバーの キャラの データ。ひとりモードも 同じ しくみ〈ブラウザの 中の 世界〉）。
  - ふだんは **くわしい**（今の キャラも 新しい キャラも。家族の 決定）。
  - 仲間の「呪文・技」の 画面も、**自分（主人公）の 設定**に したがう。
- かんたん の 時、呪文・技の 画面の 右上（タブの 下の すみ）に **「かんたん表示（設定で変えられます）」**。

### かくす 物・のこす 物

| 場所 | くわしい（ふだん・前の とおり） | かんたん |
|---|---|---|
| 覚えた技 | 「種類で見る／職業で見る」・呪文／特技・種類（職業）の タブ。L・R（Q・E）で タブ、Y で 見方。中は 弱い じゅん。列は 設定の「コマンドの数」（3なら 3列） | **強い じゅんの 1つの 一覧**（ダメージ・回復の ある 技が 強い じゅん → そのほかは MPの 多い じゅん）。**2列だけ**。見方・タブ・L/R・Y は 出ない |
| お気に入り | えらぶと「動かす／はずす／命令の一覧に出さない／やめる」。つかんで 十字キーで ならびかえ | えらぶと **「お気に入りからはずす／やめる」**。ならびは 前の まま（戦いの ★の タブにも その まま 出る） |
| 回復・回復以外・覚えた技の えらぶ まど | 「使う／お気に入り／命令の一覧に出さない（出す）／やめる」 | **「使う／お気に入り／やめる」**。命令に 出さない 技には「今は、戦いの命令の一覧に出していない（くわしい表示で変えられる）。」と 出す |
| 回復・回復以外の タブ | そのまま | **そのまま**（使う・お気に入り・MPが 足りない 時の わけ） |
| 戦いの 技の 一覧（`client/battle.js`） | L・R の 種類・左右の ブロック移動・★・☆お気に入り（Y・長おし） | **かわらない**（`battle.js` は かんたん表示を 見ない） |
| ひらめき・合体技の タブ | そのまま | そのまま |

### かくす だけ（データは さわらない）

- `autoOff`（オートで 使わない 技）・`cmdOff`（命令の 一覧に 出さない 技）・`favorites`（お気に入りと ならび）は、かんたん に しても **かわらない・消えない・そのまま 効く**。
  戦いの 一覧（cmdOff で のぞく）・オートの AI（autoOff）・★の タブ（favorites）は どちらの 表示でも 同じ。
- くわしい に もどすと 前の とおり（覚えた技の 見方・タブは この 機械の `kizuna_learnview` に のこって いる ので、前に 見て いた 所に もどる）。
- 覚えた技の かくす しるし（「かくす」の 札・点線の わく）は かんたん でも 出す（戦いで 出ない わけが わかる ように）。

## 2. 保存の しかた

- `char.menuView = 'simple'` … **かんたん の 時だけ**。くわしい（ふだん）は 項目を **消す**（知らない 値も くわしい）。
- サーバー: `menu` の `settings` に `menuView: 'simple' | 'full'`（`shared/world/services.js`。ほかの 設定〈戦いの 速さ・難しさ〉は かわらない）。
  返事（menuRes）を まって 設定の 画面を 作りなおす。
- きまり: `shared/menu-view.js`（`menuSimple`・`menuViewOf`・`setMenuView`・`simpleLearnOrder`・`MENU_VIEWS`・`SIMPLE_NOTE`）。
- **引っこしコード**（`shared/world/transfer.js`）: キャラを そのまま JSON に するので、くわしい（項目なし）は コードに 入らない。
  かんたん の 時だけ `"menuView":"simple"` が 入る（ちぢめた あとで 十数文字）。**`transfer.js` は さわって いない**。
  KIZUNA-3／4 の 仲間の はぶき（`COMP_EMPTY`）は 仲間の 項目だけ なので かんけい ない（menuView は 主人公だけ）。
- セーブの 直し（`save.js` の `repairChar`）・ロード（`world.js` の `normalizeChar`）も 項目を けさない（ほかの 項目と 同じ）。

## 4. 気を つける こと

- 覚えた技の かんたんの 一覧は **1つの 一覧** なので、職業を たくさん きわめた キャラ（テストの 賢者 Lv60・上級職まで ぜんぶ きわめた キャラ）では 800こ ほどに なる。
  強い じゅん なので 上は 他の 職業の 強い 技（「他」の 札）が 多い。家族が 見て 長すぎる なら「今の職業の 技を 先に」などを 足す（家族に 聞く）。
- 同じ 名前の 技（大神官と 大賢者の ザオリク など）は、くわしい と 同じ ように 2つ 出る（前から）。
- 設定は 自分の キャラごと。家族サーバーで 子どもの キャラだけ かんたん に できる。仲間の 画面も 主人公の 設定。
