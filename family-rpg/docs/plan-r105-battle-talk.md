# 第105回 戦いの 中の 会話を 1行ずつ 読む（設計と メモ）

## 家族の 声（そのまま）

「ボス戦で、攻撃ではなく会話の時に、文字がどんどん進んでいきます。ちゃんと一行一行を読めるようにして。オートの時は文字が自動で流れていいけども、オートじゃない時は、タップもしくは、クリック、コントローラー操作して文字が進むようにして。会話の時は、キャラクターのコマンドや、ターンが来るまでのゲージは止まるようにして」

## 1. 会話の イベントの 見分け方（`isTalkEvent(ev, b)`）

1. ボスの ファイルが `ev.talk = true` / `false` を つけた … それに したがう（目安で まちがう 物だけ）。
2. 戦いの とちゅうの 場面（`SCENE_KEYS`。今は 八つめの 音 `c11dEight` … `{ lines, arts, ms }`）… 会話。読む 文は 場面の 文。
3. 攻撃・回復の 結果が ない（`results` が 空で、どく・反撃・合体技・いれかえ・じわじわ回復 でも ない）:
   - `'msg'`（行動では ない 知らせ。戦いの はじめの ことば・すがたが かわる 時 など）… **せりふが 1行 でも あれば 会話**。
   - `'act'`（だれかの 行動）… **せりふが 2行 いじょう**（やりとり・ひとりごと・なぞの 問い）なら 会話。**1行だけは 技の かけ声**（「オウムがえしだ！」＋ しくみ）として 攻撃の あつかい。
4. 結果が ある（攻撃・回復）… さいごの 結果の 行（ダメージ・回復・倒した・死んでしまった・生き返った・ミス …）より **あとに せりふが 2行 いじょう**、または **ボスを たおした・この 行動で 勝ちが きまった**（女王が 手を 下ろす など、たおれずに 終わる ボスも）行動で あとに せりふが ある … 会話。ほかは 攻撃（「くらえ！」＋ ダメージ など）。

- せりふ … `名前「…」` の 形の 1行（名前は 16字 まで・空白／かっこ／句読点を ふくまない）。名前の ない `「…」` だけの 行も（「○○だよ！もう、ひとりじゃないよ！」）。`（「手をつなぐ」で…）` の ような ヒント・`…よんだ！「スピカ！」` の ような 文の 中の かぎかっこは せりふでは ない。
- はっきり つけた 所: `battle-c11d.js` の `names`（女王が 星の 名前を よぶ 番。回復が つくので 4 では 会話に ならない → `ev.talk = true`）。八つめの 音の 場面は 2 で 会話。
- 1つの イベントに 会話の しるしを つけると、攻撃の 文も ふくめて その イベントの 行は ぜんぶ 1行ずつ（たおれる 時の ことばの 前の「〇〇に 233の ダメージ！」も タップ）。

## 3. サーバーの 待ち（`talkWait` の 戦いだけ）

- 会話の イベントを `emit` すると `b.talk = { seq, autoMs, after }`。つづけて 会話が 出たら 番号を 新しく する（読み終わりは 新しい 番号まで）。
- `tick` の はじめ（合体技の さそいの 時間を へらす より 前）で `talkHold`: 待つ 人の だれかが まだ 読んで いなければ **何も すすめない**（ゲージ・どく・前ぶれの 待ち〈tellHold〉・合体技の さそいの のこり時間・`this.time`・`lock`）。
- **待つ 人**（`talkReaders`）… 戦いに いる 味方（馬車に もどった 人を のぞく）の `controller` で、`auto` で ない 人。キャラが たおれて いても 待つ（画面は 見て いる）。
  - つながりが 切れた 人・戦いから 出た 人 … `battleLeave`（world/battles.js）が その 人の キャラを オートに する ので 外れる。
  - とちゅうで オートに した 人 … 外れる（ほかの 人が ぜんいん 読んで いれば すぐ 進む）。
  - とちゅうから 入った 人（`joinAlly`）… 今の 会話は 見て いない ので 読んだ ことに する。つなぎ直した・画面を 立てなおした 人（`battleStart` の `resume`・`joined`）は 画面が `talkSeq` を 読んだ ことに して 送る。
- ぜんいんから `{ t: 'battle', talk: 番号 }` が とどいたら `{ t: 'talkDone', seq }` を 出して 次へ。会話の あとに 攻撃の 文が もう 出て いない 時は、会話の 分の `lock` を 0 に（読み終わった あとに むだに 待たない）。
- **待つ 人が いない**（人が ぜんいん オート）… 読める 速さで 自動で 流れる: `lock = max(lock, 行の 数 × 1500ms ÷ 文字の 速さ)`。場面は 1行 `max(場面の ms, 1500 ÷ 文字の 速さ)`（今の ms を 下回らない）。ふつうの 文字の 速さ 0.8 で 1行 約 1.9秒（前は 2行で 約 1.4秒）。
- 待つ 時間に 上限は ない。
- 会話の 間も、作戦の 変更・オートの 切りかえ・コマンドの うけつけ（キューに 入るだけ）は できる。

## 4. 画面（`client/battle-talk.js`）

- 会話の イベントは メッセージの まどに 1行ずつ。前の 行は うすい 色で 上に のこる（7行 まで。まどに 入らない 時は 古い 方から 上に 消える）。スマホの たてむきは 会話の 間 まどを 高く（3行 → 5行 くらい）。
- 1行 出したら 止まり、右下に ▼（上下に ゆれる）。次の 行へ:
  - タップ・クリック … 戦いの 画面の どこでも（オートの ボタン・つよさの まど〈作戦〉・作戦の まど・合体技の さそいの まどは そのまま 使える）
  - キー … Enter・スペース・Z（決定）、X・Esc（もどる）でも
  - コントローラー … A（決定）、B でも
  - 1行 出て 0.18秒 は うけない（2回 おしで とばさない）
- さいごの 行で 進めたら 読み終わりを 送る。ほかの 人が まだ 読んで いる 時は「ほかの人が読み終わるのを待っています…」（0.45秒 たっても `talkDone` が 来ない 時だけ）。
- 自分の キャラが ぜんいん オート … 行は 自動で 流れ（▼ なし）、さいごに 自動で 読み終わりを 送る。会話の とちゅうで オートを 切ると、その 行から ▼ が 出て タップで 進む（オートに すると その 行から 流れる）。
- 会話の 間（ほかの 人を 待つ 間も）は コマンドを えらべない: コマンドの まどに おおい（うすく・おせない）、キーと コントローラーは 会話が うける（コマンドの まどは `blur`）。番が 来ても コマンドの まどは 開かない。会話が 終わったら 前の まど（開いて いた コマンド）に もどし、えらぶ 番の キャラが いれば 開く。「えらぶまで、待っているよ」（前ぶれの 待ち）は 会話の 間 かくす。
- ゲージの 見た目は 会話の 間（ほかの 人を 待つ 間も）のびない（画面の 中の 予想の のびも 止める）。
- 八つめの 音の 場面 … 場面の 絵の 上の 文も 1行ずつ（`playEightScene(scene, e, { manual: true })` の `show(i)`・`end()`）。メッセージの まどにも 同じ 行。オートの 時は 1行 `max(場面の ms, 1.5秒 ÷ 文字の 速さ)`。
- `talkWait` で ない 戦い（テストで 作った 画面）は 今までどおり 時間で 流れる。

## 7. 設計と ちがう 所・家族に 見て ほしい 所

- **行動の かけ声 1行は 攻撃の あつかい**（1 の 3）。せりふが 1行の しくみの 行動（ムスカリ「な、なぜだ…！」は 1回の 戦いで 16回 など）を ぜんぶ 会話に すると、2人で 遊ぶ 時 何度も 2人とも タップが いる ため。すがたが かわる 時の 1行（ストルム「出よ、嵐の兵たちよ！」など）も 今までどおり 流れる。読みにくければ ボスの ファイルで `ev.talk = true` を 足す。
- **会話に なる しくみの 行動**（せりふ 2行）: オボロの「わすれの衣」（1回の 戦いで 9回 くらい）・デデドン大王の 皿を 見る 番（5回 くらい）・キラジョの 目が回る（4回 くらい）・なぞかけ と こたえる。毎回 タップが いる。多すぎる 時は `ev.talk = false` で 外せる。
- 攻撃の あとの ことば（たおれる 時の ことば など）は、ダメージの 行も ふくめて 1行ずつ タップに なる。
- 1行の 長い 文は まどの 中で 2〜3行に おりかえす（1行 ＝ サーバーの 文 1つ）。
