## 店に 出る 決まり

- 幻の職業 1つに つき 乗り物 1つ。**その 幻の職業に 1度でも なった ことが ある キャラの 店（ルミナの乗り物屋）に だけ** ならぶ
  - 今の 職業の 乗り物と おなじ しくみ（`VEHICLES[id].jobs` と `vehicleShelf` / `jobsEver`）。新しい しくみは 足して いない
  - まだ なって いない 人には 名前も とどかない（店の たな `shelf` に 入らない。幻の職業は ひみつ）
  - 1度 買えば、職業を かえても ずっと 持っている（今の 乗り物と おなじ）
- 乗り物屋の 一らんでは「幻」の しるし（むらさき。`client/ui/vehicles.js` の `jobTag`）
- 速さは ほかの 乗り物と おなじ（乗り物は 絵だけ。強さに かかわる 数字は 足さない）
- 持ち方（`char.vehicles` の id の ならび）・セーブ・引っこしコードは 今の まま（新しい 項目なし）
