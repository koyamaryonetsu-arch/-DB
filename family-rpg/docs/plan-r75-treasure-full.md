# 第75回: 宝の地図が いっぱいの ときに 捨てる 地図を 選ぶ

家族の 声:「宝の地図が一杯の時は、今持っている地図を捨てるか選ばせて。」

## 前の うごき
- 持てる 地図は 20まい（`TM_MAX`）。
- いっぱいの ときに 新しい 地図を もらうと、主を たおした いちばん 古い 地図と **だまって 入れかえ**。
  主を たおした 地図が ないと、新しい 地図は **なくなる**（「もう地図がいっぱいで持てない…」）。
- 手に入れかたは 3つ: 洞窟の 主（いっしょに 戦った みんな）・戦いで 拾う（第1章クリアの あと）・宝探しのダイゴ。家族の あいだで 地図を わたす しくみは ない。

## 新しい うごき
- いっぱいの ときは だまって 入れかえない。新しい 地図は **あずかり**（`c.tmPending`。セーブに のこる。3まいまで＝`TM_PEND_MAX`）に 入れる。
  - 主: 会話で「でも、〇〇の地図はいっぱい！このあと、どの地図を捨てるか選んでね。」
  - 戦い: けっかの まどに「でも、地図がいっぱい！あとで、どの地図を捨てるか選んでね。」
  - ダイゴ: 「おや、地図がいっぱいじゃな…」。あずかりが ある 間は もう くれない。
  - あずかりも いっぱい（めったに ない）なら 前と おなじ「もう持てない」と 知らせる。
- 画面（`client/ui/treasure.js` の `askTreasureFull`）: フィールドで 落ちついた とき（会話・戦い・メニューが ない）に 自動で まどが 出る。
  - 上に 新しい 地図（名前・レベル・ほったか・洞窟の しゅるい・主・場所）。
  - 「新しい地図をあきらめる」「あとで決める」と、持っている 地図の 一覧（おなじ 説明。主を たおした 地図 → 入り口を 見つけた 地図 → まだの 地図、古い じゅん）。
  - 地図を 選ぶ → 「〇〇を捨てて、〇〇を持ちますか？」→ 捨てる。あきらめる も たしかめる。
  - B・「あとで決める」: しまう（そのページでは もう 自動で 出さない）。メニューの「道具」→「宝の地図」の いちばん 上の「いっぱい」の 行から いつでも 選べる。ページを 開きなおすと また 聞く。
  - 今 いる 洞窟の 地図は 選べない（「今いる洞窟」。サーバーも ことわる。主の フラグが 消えて 主が また 出る のを ふせぐ）。
- サーバー（`world/treasure.js`）: `menu`/`tmap` の `op: 'pendKeep'`（pid と 捨てる id）・`op: 'pendGive'`（pid）。サーバーが 決める（画面は 聞くだけ）。
- いつでも 捨てる: 前から ある 地図の まどの「地図を捨てる」（たしかめる まど つき）。捨てて 空いたら あずかりの 地図が 自動で 入る。ログインの ときも 空きが あれば 入れる。
- セーブの 手直し（`repairTreasureMaps`）: あずかりも おなじ 形に。持っている 地図と おなじ・こわれた 地図は のぞく。20まいより 多い 地図（家族サーバーと 合わせた など）は なくさず あずかりへ。

## なぜ この 形か
- 戦いの おわりや 主の 会話の とちゅうでは 一覧を 出しにくい・つうしんが 切れる ことも ある。
  あずかりに 入れて セーブして おけば、どの 手に入れかたでも おなじ しくみで、あとで 落ちついて 聞ける（なくならない）。
- パーティーの みんなが 地図を もらう 時も、それぞれの 画面で それぞれ 聞く。
