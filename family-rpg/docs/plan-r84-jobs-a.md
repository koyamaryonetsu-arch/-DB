## 3. しくみ（`shared/battle-r84a.js`。どれも 戦いの 中だけ・キャラに 項目を 足さない）

1. **れい丸の 数**（`c.r84aRei` … 戦いの 人〈combatant〉の のこりの 数。まだ うって いない ＝ まんたん）
   - れい丸の 技（`effect.rei` の ある phys）は MP の ほかに れい丸を 使う。戦い 1回に 持てる 数（`reiMax`）は **今の 職業の 段**:
     ふりょう 0・れい界探てい 2・うら飯ゆう助 4・魔界の王の子 6（`REI_BY_TIER`）。戦いの はじめは まんたん（次の 戦いも まんたん）
   - 足りない 時は **えらべない**: battle.js の validate（わけ「れい丸がもうない」「れい丸が2発いる（のこり1発）」）・ai.js の canUse（オートも えらばない）・
     命令の 一覧（client/battle.js。うすく・せつめいの 先に【わけ】。れい丸の 技には「丸1」「丸2」「丸全部」の しるし）
   - 「れい力をためる」で 1発・「とう気をねる」で 2発 もどる（上限まで。`r84aCharge`）
   - のこりを 全部 うつ 技（`rei.all`）: フルパワーは 2発まで こめる（`upTo: 2`。上級職では 全部）・多いほど 強い／超・れい丸は 2発 いじょう いる・うった 数だけ 当てる（`hitsPer`）
   - 札: 仲間の まど 全員の 画面に「れい丸3」（0 の 時は うすい 色）
   - **ほかの 職業に 転職した あと**: れい丸の 技を 1つでも 覚えて いれば 2発（`OTHER_REI`。ふりょうに もどった 時も 2発）。覚えて いなければ 0（えらべない）
   - 合体技の 強さ（battle-dual.js の memberPower は 入った 人の いちばん 強い 技で きまる）: れい丸の 技は **使う 数の √ で わって** 数える（`reiDualMult`。
     1発の 技は そのまま・2発の 技は 0.71倍・6発 全部 うつ 技は 0.41倍）。合体技は れい丸を 使わない ので、何発ぶんも まとめて 数えると 強すぎた（下の 5）
2. **1回だけ 立ち上がる**（jobs の `passive.rise`。うら飯ゆう助 `{ hp: 0.3 }`・魔界の王の子 `{ hp: 0.5, pow: 1.3, acts: 3 }`。味方だけ）
   - 攻撃の ダメージで HP が 0 に なった 時、戦い 1回に 1度だけ、たおれずに 最大HPの 3わり（伝説は 半分）で 立ち上がる。伝説は そのあと 3回の 行動の 間 物理の 力 1.3倍（札「本気3」）
   - ひとこと: 「まだ、終わってねえ！」（伝説は「へっ…これくらいで、ねてられるかよ！」）
   - **順番**: battle.js の damage の さいご、kill の 前（かばう・作戦・おすわり・守りの旗・先読みの策 などで へらした あとの ダメージで 0 に なった 時）。
     たおれる 前に 立ち上がるので、ほかの 生き返り（ザオラルなどの 呪文・ゲームの神の ロード・合体技の 生き返り）より いつも 先。
     自動で 生き返る 道具・しくみは 今 ない。生き返った あとでも 2回めは ない（`c.r84aRose`）
   - **立ち上がらない 時**: 毒・はね返り（もろばぎり）の ダメージ・ボスの「そくし」あつかいの しかけ（ハデロスの けいやくしょ など、kill を 直接 よぶ もの）・敵（職業の試練の まぼろし も）
   - 全めつの 判定（checkEnd）は 生きて いる 人を 数えるだけ。立ち上がった 人が いれば 戦いは つづき、2回め で たおれれば ふつうに 全めつ
3. **仲間のために**（`c.r84aNakama = { left: 3, base: 1.1, per: 0.2, cap: 1.7 }`）: 3回の 行動の 間、物理の 力が 1.1 ＋ 0.2 × たおれた 仲間の 数（1.7倍まで。札「仲間3」）
   - 合体技の 2人の かげ（dualProxy）には のらない（自分の 項目〈own〉だけ 見る。立ち上がった あとの 力も おなじ）
4. **身を 守るのも 1回の 行動**（仲間のために・本気の のこりを へらす。battle.js の command の 防御に 1行）
5. **オート**（ai.js の decideAlly の 4.95: `r84aPlan`・chooseAttack: `r84aAdjust`）
   - れい丸の 技は 強い 敵（ボス・すぐ たおせない 敵 ＝ fightWeight の hard）にだけ。ざこには 0.02倍に して ほぼ 使わない
   - のこりを 全部 うつ 技は れい丸が まんたんの 時だけ（まんたんなら 1.6倍に して 見せ場で うつ・へって いる 時は 0.3倍）
   - れい丸が 0 で 強い 敵: 40%で ためる（HP が 6わり より 少なければ HP も もどる とう気を 先に）。ほかは こぶしの 技
   - たおれた 仲間が いれば 60%で 仲間のために（ボスでは いなくても 10%）
   - 運（rng）を 使うのは その 技を もつ 時だけ（ほかの 職業の オートの ながれは かわらない）

battle.js に 足した 行: import・validate（れい丸）・command の 防御・executeNext（行動の はじめ）・applyAbility の 'phys' の はじめ（れい丸の 技）・case・calcPhys・damage（立ち上がる）・pub。
