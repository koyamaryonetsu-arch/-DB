家族の ねがい: 「超級職で 終わってしまう 系統は ダメ。伝説の職業に つなげて」。

## きまり（どの 班も 同じ）

- 伝説の職業は tier 3。なり方は 今の 伝説と 同じ形（`req` の 超級職を きわめる。1つだけの ときは `reqSuper: 1`
  ＝ほかの 超級職も 1つ きわめる。竜魔人と 同じ）。「どれか 1つ」は `reqAlt`（賢者・スーパースターと 同じ しくみ）
- 強さは 今の 伝説の 職業の はんい（mods の 合計・`tools/sim-jobs.mjs` で まん中くらい）。技は Lv1〜10 で 6〜8こ＋看板の 技（Lv10・`<id>_sig`）
- 1つの 職業に いる もの（今の 伝説の 職業〈竜魔人 ryumajin・京急の社長 keikyu_president など〉を まねる）:
  - 職業の データ（`jobs-legend-r66<班>.js` の `LEGEND_R66<班>_JOBS`。ならびは `LEGEND_R66<班>_ORDER`。jobs.js は もう つないで ある）
  - 技（`abilities-r66<班>.js`）・ひらめき技（`hirameki-r66<班>.js`）・合体技の タグ（job-tags.js。3つ いじょう）
  - 職業の 説明（JOB_HINTS）・転職の ひとこと（job-talk.js）・師しょうの ことば・職業の試練（job-trials.js の TRIAL_WORDS・battle-trial.js の PHANTOM_ADJ〈3つ。三の試練まで〉）
  - 見た目（`client/render/hero-r66<班>.js`。今の つなぎかたで）・看板の 技と 大事な 技の えんしゅつ（`client/render/battlefx-r66<班>.js`）
  - 乗り物（どの 職業にも いる きまり。test/vehicles.test.js）
  - テスト（`test/legend-r66<班>.test.js`）・漢字の きまり（`tools/kanji-check.mjs` の gameFiles に 新しい ファイルを 足す。使えない 字は かなに）
- 名前に つく 字: 習わない 字は かなに（例: 扉 → とびら なら「真理のとびらをひらく者」。家族の 名前の 形は できるだけ のこす）
- ほかの 班の ファイルは さわらない。みんなで 使う ファイル（jobs.js・job-tags.js・job-talk.js・job-trials.js・battle-trial.js・hero-outfit.js など）は **足すだけ**（行を けさない・ならべかえない）
- お知らせ（news.js）・README は さわらない（あとで まとめて 書く）
- IDs は 下の 表の まま（ほかの 班が 当てにする）
