# 第78回: ゲストの 強さの きまり（設計メモ `docs/plan-design-r77.md` の 3-8）

「ゲストは 家族の 平均より 少し 下」を しくみに した。物語の ゲスト（`data/shops.js` の `GUESTS`）は、戦いが 始まる 時に きまりで 強さが きまる。

- しくみ: `public/js/shared/guest-rule.js`
- 戦いに 入れる 所: `public/js/shared/world/battles.js` の `makeBattle`（サーバーも ひとりモードも ここを 通る）
- シミュレーター: `tools/sim-ch7.mjs`・`tools/sim-ch8.mjs`（ゲストは きまりを 通る。`GRULE=0` で 前の 作り方）・前と 後の 表は `tools/sim-guest-r78.mjs`
- テスト: `test/guest-rule-r78.test.js`

## 1. 今までの ようす（しらべた こと）

- ゲストは 台本の `['guest', id]` で 入る → `world/party.js` の `guestChar` が `makeNpcSupportChar(def, max(minLevel, その時の リーダーの レベル))` で 1回だけ 作る（職業レベルは レベル×0.4〈7まで〉・装備は `def.gear`、ない 所は レベルの ふつうの 装備・技は `def.skills`）
- 戦いでは その キャラが そのまま 5人めに 入る（`kind: 'guest'`・いつも オート）
- そのため 強さは「minLevel」と「`gear` に どの 品を 書くか」を 手で 合わせる しか なかった。第7章の 装備の カイ（`kai`）だと 第8章で たおれやすく、第8章の 装備に した（`kai8`）ら ボスが かんたんに なり、ボスを 直した

## 2. 物さし

### そのままの 力（fightPower）

```
力 ＝ 最大HP ÷ 3 ＋ max(こうげき, 魔力, 回復) ＋ 守り ÷ 2 ＋ すばやさ ÷ 2
```

- ダメージは「こうげき÷2 − 守り÷4」なので、守り 1 は こうげき 1/2 ぶん
- HP は ほかの 数の 2〜3倍 ある ので ÷3
- すばやさは 手番の 多さ（守りと おなじ 重さ）
- こうげき・魔力・回復は いちばん 大きい 1つ（戦士は こうげき・魔法使いは 魔力・僧侶は 回復）
- 足す だけ なので、ぜんぶの 数を k 倍 すると 力も ちょうど k 倍（倍率で 合わせやすい）
- 今までの `breed-calc.js` の `powerScore` は 装備を 入れない 数なので 使わなかった

### 育ちの 力（growPower。きまりで くらべる 数）

```
育ちの 力 ＝ そのままの 力 × レベルの ふつうの 力 ÷ 素の 力
```

- 素の 力: 装備と たねを はずした その 人の 力（職業・職業レベル・レベルは そのまま）
- レベルの ふつうの 力: 職業の 得意・不得意の ない、その レベルの 能力（`stats.js` の `baseStats`）の 力
- つまり「レベル」と「装備・たねで どれだけ 強く なったか」で くらべる。職業の 得意・不得意は ならす
- **理由**: そのままの 力で くらべると、忍者の カイは 家族の 平均の 0.52 倍、ガーディアンの カリムは 0.76 倍（HP が 少ない・こうげきが 弱い 職業）。0.94 に するには 倍率 1.7 が いり、職業の 個性が こわれる（倍率の はば 0.85〜1.15 では とどかない）。育ちの 力では 第7章の 装備の ゲストが 0.84〜0.87・第8章用に 手で 強く した ゲスト（`kai8`・`rion8`）が 1.05〜1.08 で、「きつかった」「かんたんに なりすぎた」の 話と ぴったり 合う。0.94 は その まん中

## 3. きまり

ゲストの 育ちの 力 ＝ **その 戦いに 出る 家族の キャラ（人間）の 育ちの 力の 平均 × 0.94**（はば 0.90〜0.97）

1. **レベル**を 家族の 平均レベル（四捨五入）に 合わせる（minLevel 〜 レベルの 上限 の 中）
2. ずれる ぶんは 戦いの 中の 能力に **倍率 k**（0.85〜1.15）を かける: 最大HP・こうげき・守り・魔力・回復・すばやさ（MP は かけない）
3. 倍率の はばで とどかない ときは、レベルを ずらして とどく レベルを さがす（平均レベルに いちばん 近い もの）
4. **てんじょう**
   - レベルは「その ゲストの 上限（`maxLevel`。ない ときは minLevel ＋ 8）」と「家族の いちばん 高い レベル」の 小さい ほうまで（minLevel より 下には しない）
   - 力は 家族の いちばん 強い 人を こえない（育ちの 力でも、そのままの 力でも）
5. **床**: その ゲストの minLevel・きまった 装備・倍率 1 の 力は 下回らない（育ちの 力でも、そのままの 力でも）。**床は てんじょうより 先**（家族が とても 弱くても ゲストは 助けに なる）

そのほか:

- **数える 家族**: その 戦いに 出る 人（プレイヤーの キャラ）と 家族の キャラの 仲間（`kind: 'family'`）。魔物の 仲間・酒場の 人の 仲間・ゲストは 数えない。人数は 1〜4人 どれでも 平均（1人なら その 人）。家族が 0人の ときは 戦いに 出る 人間の 仲間、それも いなければ 床（minLevel・倍率 1）
- **戦いの 中で 変わらない**: 戦いが 始まる 時に 1回だけ きめる（とちゅうで 家族が かけつけても かえない）。乱数を 使わないので、同じ 家族なら 同じ 結果。サーバーと ひとりモードは どちらも `makeBattle` を 通る（テストで 同じ 数を たしかめた）
- **個性は かえない**: 職業・技（`skills`）・作戦・見た目は そのまま。装備は いつも **minLevel で 作った ときの もの**（`gear` と、ない 所は minLevel の ふつうの 装備）。レベルが 上がっても 見た目の 装備は かわらない
- **パーティーの ゲスト**（`party.guests` の キャラ。メニュー・宿・教会で 見る もの）は 今まで どおり。戦いの 中は きまりで 作った べつの キャラで、HP と MP は **割合**で うつす（戦いの 前 6わり → 戦いの はじめも 6わり。戦いの あとは 戦いの 中の 割合を もどす。たおれたら 0）

## 5. はばの 中に 入らない とき

- 第8章 第2・3幕の ゲスト（`kai8`・`rion8`）は、ふつうの 家族では 割合 1.04〜1.12。これは 手で 合わせた minLevel と 装備が 0.97 より 上だから（床が てんじょうより 先）。今の ボスは この 強さで 合わせて あるので、そのまま に した
- 床で 0.97 を こえない ように したい ときは、その ゲストの minLevel を 下げる か `gear` を 1つ 前の 幕の 品に する（そのあと ボスの 勝率を たしかめる）
- 家族が とても 強い とき（minLevel ＋ 8 より 上）は、倍率 1.15 でも とどかず 0.90 を 下回る ことが ある（ゲストが 強く なりすぎない ための てんじょう）

## 6. これからの ゲストの 足し方

`data/shops.js` の `GUESTS` に 書く:

```js
GUESTS.xxx = {
  id: 'guest_xxx', name: '…', job: '…', look: { … }, tactics: 'balanced',
  skills: ['…'],                // その 人の 技
  gear: { weapon: '…', armor: '…', head: '…' },  // 装備の 見た目（その 幕の 品）
  minLevel: 92,                 // その 幕の はじめの レベル（＝床）
  // maxLevel: 100,             // 2つの 幕に 出る 時だけ（ない ときは minLevel ＋ 8）
};
```

- 強さを 手で 合わせない（minLevel を 高く したり、強い 品を わざと 足したり しない）。強さは きまりが きめる
- `gear` は その 幕の ★の 品か、1つ 前の 幕の 品が よい（minLevel・`gear` の 強さが 床。強すぎる 品だと 床が 0.97 を こえる）
- たしかめ: `test/guest-rule-r78.test.js` は `GUESTS` の ぜんぶを 見る（新しい ゲストも 自動で 入る）。シミュレーターで ボスと 戦わせる ときは `tools/sim-ch7.mjs` の `ruledGuest(id, 家族, レベル)` で ゲストを 作り、`Battle` を 作った あと `scaleGuestActor(ゲスト, k)` を よぶ（`tools/sim-ch8.mjs` と おなじ）
- 1つの ゲストを 2つの 章で 使う ときは `maxLevel` を あとの 章の レベルに（第8章 第1幕の カリムは `maxLevel: 84`）

## 7. 気を つける こと

- 戦いの 中の ゲストの レベル・HP・MP は、パーティーの ゲストの 数と ちがう ことが ある（パーティーの ゲストは 入った 時の レベル。戦いの 中は きまりの レベル。HP は 割合で 同じ）
- 第5章の ノクト（`battle-final.js` が 戦いの とちゅうで 足す）と 第4章の サラ（ゲストで なく 仲間）は `GUESTS` で ないので きまりの 外
- 酒場で 仲間に なった カイ・カリム（`KAI_SUPPORT`・`KARIM_SUPPORT`）は ゲストで ないので きまりの 外（家族の 数にも 入れない）
