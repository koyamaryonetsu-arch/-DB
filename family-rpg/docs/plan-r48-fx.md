# アニメ・作品の職業の 技エフェクト 大改造（第48回。2026年10月25日）

家族の声（まとめ）：
- アニメキャラの 技の エフェクトが 弱い。戦いの 楽しさは 技の グラフィック。ふつうの 攻撃より しょぼい 技が 多い。
- 職業の ランクが 上がるほど、エフェクトも かっこよく して ほしい。
- かめはめ波の なかま（超かめはめ波・10倍…）が ぜんぶ 同じ 見た目。
- 技を 出す 前に「ため」の 動きを 入れて ほしい。
- 技ごとに まず 下書き（このファイル）を 作ってから 作る。アニメの 技は、見て すぐ 原作の 技だと わかる こと。
- 家族は ねている。起きたら びっくり させたい。

このファイルは、明日の夜に **エンジン担当（G0）1人＋作品グループ担当（G1〜G6）6人が 並行で** 作るための 設計図。
ここに 書いて いない ことは、各担当が「原作らしさ・段の 予算・読みやすさ」の 3つを 守って 決めて よい。

---

## 0. ゴールと 守ること（全員）

1. 対象の 技（6章の 表に ある 技 ぜんぶ）は、それぞれ **自分だけの 新しい anim（`ax_…`）** を 持つ。同じ 作品の 「なかま技」は 目で 見て ちがい、ランクが 上がるほど 大きく・長く・色が 増える。
2. どの 技も **ふつうの 攻撃より はっきり 豪華**（3章の 数の 下限）。
3. 技を 出す 前に **ため**（4章の charge kind）。ランクが 上がるほど ためが 長く、画面が 暗く なり、ゆれ、伝説は カットイン。
4. 戦いは 読みやすい まま：1技の 長さは 段の 予算（3章）の 中。2回目からは ためが 半分。おそい 設定でも 長く なりすぎない（5-6）。
5. 原作の 絵や ロゴは 使わない。この ゲームの ドット／キャンバスの 絵で、形・色・動き・音で「あの 技だ」と わかる ように する（名前の 文字を 画面に 大きく 出して ごまかさない。技名は もともと メッセージ窓に 出る）。
6. 子どもが 見る：こわすぎる 表現（血・ドクロの アップ など）は なし。黒の組織・はかい・地球はかいばくだん も コミカル寄りに。
7. スマホで 重く しない：つぶは 段ごとの 上限（3章）まで。毎フレーム グラデーションを 作らない（`glowSprite` の キャッシュを 使う）。DOM は transform と opacity だけ 動かす。
8. 古い anim（`kamehameha`・`*_sig`・`r33_*` など）は **消さない**（敵・合体技の とどめ・テストが 使う）。対象の 技の データの anim を `ax_…` に 付けかえる だけ。
9. コミットメッセージは 英語。家族への 報告は 日本語（CLAUDE.md）。

### 1-2. 戦いの 速さ（「speed」設定）
- 段は `public/js/shared/battle.js` 103行 `BATTLE_SPEEDS = [0.6, 0.75, 0.85, 1, 1.25]`、ふつう `DEFAULT_BATTLE_SPEED = 0.85`。文字は `TEXT_SPEEDS`。

## 2. 段の 予算（tier budget）

`fx段` は 技ごとに 6章の 表で きめる。ふつうは 職業の ランク（基本職 B・上級職 A・超級職 S・伝説 L）。
- その 職業の Lv1〜3 の 小技は 1段 下でも よい（表に 書いた）。
- 味方・自分に かける 技（回復・補助）は 同じ 段の **下半分の 長さ**。ただし 変身（★を つけた もの：超サイヤ人系の オーラ・界王拳・ギア2〜5・きつねの衣・せん人モード・竜闘気・両手の竜の紋章・メイクアップ など）は 段の 予算 いっぱい 使って よい。
- 看板の 技（Lv10・`*_sig`）と ひらめき技は 段の 上の はし。

| 段 | 合計の 長さ（tempo 1・ため こみ） | ため | 画面 | ゆれ・止め | つぶ（同時の 最大） | ふつうの 攻撃との 差（下限） | カットイン |
|---|---|---|---|---|---|---|---|
| **B 基本** | 0.6〜0.9s | 0〜0.3s（小さな 光・火花・構え） | 暗く しない | `hitStop` 80〜120ms・amp 1〜1.3 | 〜140 | 同時の つぶ 52こ 以上（剣の 会心の 2倍）・自分の 形が 1つ | なし |
| **A 上級** | 1.0〜1.4s | 0.3〜0.5s | 暗く 0〜0.2（好みで） | `hitStop` 150〜220ms・amp 1.5〜2 | 〜200 | 90こ 以上・命中に 輪＋火花＋光 | なし |
| **S 超級** | 1.5〜2.2s | 0.6〜0.9s | **暗く 0.35〜0.45**（ためで 暗く → 命中で 一しゅん 明るく → もどる） | **画面ゆれ** 300〜450ms・amp 2〜3、命中の フラッシュ | 〜280 | 140こ 以上・画面の 1/3 以上を おおう 形 | canvas の 帯（ななめの 色の 帯・集中線）だけ |
| **L 伝説** | 2.2〜3.2s | 1.0〜1.4s | **暗く 0.55〜0.65 ＋ 全画面の 背景**（作品の 色の 背景・集中線・空・太陽 など） | 大きな 命中（白フラッシュ＋衝撃波＋がれき）＋ ゆれ 500〜700ms・amp 3〜4、**余韻** 0.4〜0.6s（光の 残り・火の粉・羽・きらきら） | 〜360 | 200こ 以上・画面の 半分 以上 | **DOM の 顔カットイン**（ため の 最初 0.6s。5-4）＋canvas 背景 |

- 合計の 長さは「ため 開始 → 余韻の 最後の つぶが 消える」まで。テストで ±150ms（5-9）。
- 命中（ダメージの 数字が 出る しゅんかん）は `ため + hit`。`hit` は 発射から 最初の 命中まで（ビームなら 届いた とき）。
- 敵 全体の 技は 敵ごとに 40〜80ms ずらして 当てる（全体で +0.3s まで）。
- 2回目から（同じ 戦いで 同じ 人が 同じ 技）：**ため 半分**（L の カットインも 省く）。
- おそい 設定：ax の えんしゅつは tempo 0.85 より おそく しない（0.6・0.75 でも 0.85 の 速さ）。速い 設定（1・1.25）は そのまま 速く なる。→ 伝説でも 実際 3.8s 以内。
- 合体技の ax（G1〜G6 が 持つ 合体技）：DOM カットインが もう あるので **ため なし**（発射から）。長さは S の 予算。

## 4. 全体の 流れ（1技）

```
[L のみ] DOM 顔カットイン 0.6s ─┐（ためと 同時）
ため（charge kind・段の 強さ・暗く・背景）──────→ 発射（release：グループが 描く）──→ 命中（hit）──→ 余韻 ─→ おわり
0                              charge.ms            charge.ms + hit                            charge.ms + total
```
- ダメージの 数字は 命中の とき（`axHitMs`）。
- 画面の 暗さ・背景は エンジンの ヘルパーで（グループが `release` の 中で よぶ。強さは 段で きまる 値を 使う）。

### 5-3. battle.js の なおし（G0）
- anim の きめ方：**`isAx(fx.anim)` なら それを いちばん 先に**。`const anim = (isAx(fx.anim) && fx.anim) || sigAnim(ev.ability) || r27Anim(ev.ability) || fx.anim || …`（`ANIM_OVERRIDE` の テラデイン・`SIG4` の 看板の 技も ax が 勝つ）。
- 敵に 当たる：`this.fx.play(anim, enemyPts, …)`（今と 同じ）。`Effects.play()` の **いちばん はじめ**で `if (playAx(this, anim, targets, element, opts)) return;`。
- 命中の 時間：`hitDelay = isAx(anim) ? axHitMs(anim, plan) : (r27Hit(...) ?? HIT_DELAY[anim] ?? 0)`。
- 味方・自分に かける（`AX_TIME[anim].party`）：`this.fx.play(anim, allyTargets.map(allyPt) || [allyPt(actor)], element, { fromAlly: true, party: true, from: allyPt(actor) })`。`playAllyR27` は よばない（`allyFx` の 窓の 光は のこす）。
- 敵が みかたに（`actor.side === 'enemy'` で `isAx(anim)`）：ポケモンと 同じ 道で `play(anim, allyPts, …, { fromAlly: false, toParty: true, from: 敵の 中心 })`、`closeUp` は よばない。
- 混乱した 味方が 味方に：`toParty: true`・`from: allyPt(actor)`。
- ため の あいだ、出した 人の ステータス窓を 光らせる（`glowStatus` を 250ms ごと、ための 色）。
- L の 顔カットイン（5-4）：出した 人が 味方 で、`plan.cutin` の とき。
- 音：`ax` の 技は `ANIM_SFX` を 使わず、`fx.at(0, ため の 音)`・`fx.at(charge, release 音)`・`fx.at(charge+hit, hit 音)`（`Effects` には 音が ないので battle.js から `fx.at` で）。
- `ev.axRepeat`（サーバーが つける。5-5）を `opts.repeat` に。合体技（`fx.type === 'dual'`）は `opts.dual = true`。

### 5-4. 伝説の 顔カットイン（DOM）
- `render/dualfx.js` の CSS を 使い回して 1人版 `playAxCutin(stage, { face, name: 技の 名前, colors, word?, tempo })` を `axfx.js` か `dualfx.js` に。ななめの 帯（作品の 色の グラデーション）に 顔（`faceURL`。超サイヤ人系は もう 金の かみの 絵）が 右から すべりこみ、帯の 上に 技名、0.6s で 消える。顔の うしろに ため の kind の 光（ki 金なら 金の 炎の 光）。
- canvas の 背景（`axBg`）は その 下で つづく。

### 5-5. サーバー（`shared/battle.js`）
- `executeNext` の おわり（650行）：`const ax = AX_TIME[ev.fx?.anim]` が あれば、`plan = axPlan(ax, { speed: this.speed, repeat, dual })` で、`ev.extraLock = Math.max(ev.extraLock || 0, plan.lockMs)`。`lockMs` は「ため＋total − 450」（tempo 1 の ms。pace が すでに 450 を 持つ）を おそい 設定の しぼり（5-6）で なおした 値。**次の 行動の 絵が 余韻の 最後 200ms より 前に 始まらない**こと（テスト）。
- `repeat`：その 戦いで その 人が その 技を 前に 使ったか（`c.axUsed = Set`）。`ev.axRepeat = true` を つけて クライアントへ。
- ひらめいた しゅんかん（`doHirameki`）は いつも 1回目 あつかい（ため フル）。

### 5-6. `axPlan(ax, { speed, repeat, dual })`（共有。サーバーと クライアントで 同じ 計算）
- `charge = dual ? 0 : repeat ? ax.charge.ms * 0.5 : ax.charge.ms`、L で `repeat` なら カットイン なし。
- おそい 設定の しぼり：`ts = max(1, 0.85 / speed)`（えんしゅつの 時計を これだけ 速める）。クライアントは `playAx` の あいだ `fx.add` を 包んで 足す つぶに `ts` を つける（`Effects.update` で `dt * tempo * (p.ts || 1)`）。`fx.at` も 同じ。
- かえす もの：`{ charge, hit, total, ts, cutin, lockMs }`（ms は tempo 1。実際は ÷ (speed × ts)）。

### 5-7. Effects の 足し算（battlefx.js。G0）

## 6. 技ごとの 下書き（ぜんぶの 対象の 技）

列の 見かた：
- **段** = `段 合計s（ためs）`。`AX_TIME` の `total` = 合計 − ため、`charge.ms` = ため。★ = 変身（予算 いっぱい OK）。「※補助」= 味方・自分に かける（段の 下半分）。「L1→S」などは 小技なので 1段 下の 予算。
- **いま** = 今の `anim つぶ数/長さs ×共有数`（1-4）。
- **ため** = `kind-variant`（3章）＋ その 技だけの 足し算（`chargeExtra`）。L は 顔カットイン（5-4）つき。
- **発射 → 命中 → 余韻**：`暗く` = `axDim`、`背景` = `axBg` の style、`ゆれ` = `axShake`。
- 色・数・長さは めやす。原作の 見分けポイント（太字）は 守る。
- `xxx@masc` は 男の子の 版（`ABILITIES[xxx].masc.anim` に 入れる。今 `masc.anim` が ない 技は 足す）。
