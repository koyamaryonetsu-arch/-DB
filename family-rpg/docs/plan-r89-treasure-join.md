# 第89回: 宝の地図を 捨てる タイミング と、ボス戦に とちゅうから 入る（設計。2026-11-17）

> 家族の 声
> 「宝の地図を捨てるタイミングがおかしいです。もらったタイミングで捨てるものを選ばせて。あとでメニュー開かれて選択するのはおかしい。」
> 「そのせいか、ボス戦で参加できない時がありました。ボス戦も、フィールド戦と同じように接近すれば参加できるハズだったのにできないことがありました。」

## 1. 今の うごき（プログラムを 読んで たしかめた）

### 1-1. 宝の地図
- 地図が いっぱい（20まい）の 時に 新しい 地図を もらうと、サーバーは「あずかり」（`c.tmPending`）に 入れる（`shared/world/treasure.js` の `grantTreasureMap`）。
- 画面は、**フィールドで 動ける ように なってから 0.7びょう あとに**、かってに まどを 開く（`client/ui/treasure.js` の `watchTreasureFull`。`client/game.js` の `frame` から。「動ける」＝ 会話・戦い・メニューが ない。**歩いて いる とちゅうでも 開く**）。
- まどが 開いて いる 間、画面は「メニュー中」（`game.menuOpen = true`）に なり 動けない。**サーバーは この まどを 知らない**（`s.busy` は 空の まま）。
- 「あとで決める」を えらぶと、次は メニューの「道具」→「宝の地図」から 選ぶ。

### 1-2. ボス戦に とちゅうから 入る
- 画面: 動ける 時だけ、戦って いる 同じ パーティーの 人に 2.0マス まで 近づくと `joinBattle` を 送る（`client/field.js` の `checkJoin`。「メニュー中」は 送らない）。
- サーバー（`shared/world/battles.js` の `joinBattle`）: 次の どれかだと **だまって ことわる**（わけを 出すのは「1人の けいこ」と「いっぱい」だけ）。
  - 自分が ほかの ことを して いる（`s.busy`）・通信待ち・空を 飛んで いる
  - 相手と マップが ちがう／2.4マス より 遠い
  - 戦いが 終わりかけ
- ボス・物語の 戦いは だいほん（`world/scripts.js`）から 始まる。始まった 時に **同じ マップに いて、ほかの ことを して いない** パーティーの 人だけが 入る。
- だいほんの 中の `teleport` で、入った 人だけが ボスの 場所へ 運ばれる ことが ある。おくれた 人は 近づけない。

### 1-3. 入れなく なる すじ道（考えられる もの。係が テストで 1つずつ 再現して たしかめる）
| # | すじ道 | 何が 起きるか |
|---|---|---|
| H1 | 地図の まどが 開いて いる 間に、リーダーが ボスを 始めた | 画面は 動けない。サーバーは 知らないので だいほんに 入れる → 会話や 戦いの 画面の 上に 地図の まどが かぶる。まどを 閉じても 入力が もどらない おそれ |
| H2 | 地図の まどで 止まって いる 間に、家族が 先へ 進んで ボスを 始めた（べつの マップ・だいほんで 運ばれた 先） | 近づけないので 入れない |
| H3 | 近づいたが、サーバーが だまって ことわった | 何も 起きず、わけも 出ない |
| H4 | 「ついていく」（自動追跡）で 止まる 所が、戦って いる 人から 2.0マス より 遠い | 自分で もう 1歩 近づかないと 入れない |
| H5 | 前の 戦いの けっかを 読んで いる 間に ボスが 始まった | 読みおわった 時には もう 始まって いて、H2・H3 と 同じ |

## 2. 直し方

### 2-1. 宝の地図: もらった その 場で えらぶ
**きまり: 地図が いっぱいの 時は、「地図を 手に入れた」の 流れの 中で、すぐに えらぶ まどを 出す。あとから かってに 開く まどは なくす。**

| もらう 場面 | えらぶ タイミング |
|---|---|
| 戦いの あとに 拾う | 戦いの けっかの まどで「宝の地図を拾った！」の 行の **すぐ あと**（けっかの まどを 閉じる 前）。えらぶまで けっかは 閉じない |
| 洞窟の 主を たおした あと | だいほんの「宝の地図を見つけた！」の **すぐ あと** |
| 宝探しの ダイゴから もらう | 会話の「手に入れた！」の **すぐ あと** |

- えらぶ まどの 中み: 新しい 地図の 説明／「捨てる 地図を 選ぶ」（今の ならび）／「新しい地図をあきらめる」。
- **「あとで決める」は なくす**。B ボタン・まどの 外を おした 時は「新しい地図を あきらめますか？」と 聞く（「やめる」で えらぶ まどに もどる）。
- 文も 直す:「このあと、どの地図を捨てるか選んでね」→ その 場で 聞くので、この 行は 出さない。
- **サーバーが 知って いる 形に する**: えらんで いる 間は、その 人を `s.busy = 'tmfull'`（名前は 係が 決めて よい）に する。
  - ほかの 人の 戦い・だいほんに まきこまれない。魔物にも 当たらない。
  - えらぶと（または あきらめると）すぐ 動ける。
  - 家族と いっしょの 時: ほかの 人の けっかの まど・だいほんは 待たせない。リーダーが けっかを 閉じても（`resultClose`）、えらんで いる 人の まどは 閉じない。
- 通信が 切れた 時だけ「あずかり」が のこる。その 時は、次に 入った **すぐ**（世界に 入った 時）に 聞く。メニューの「道具」→「宝の地図」の 行も のこす（今の まま）。
- `watchTreasureFull`（0.7びょう あとに かってに 開く しくみ）は 消す。

### 2-2. ボス・物語の 戦い: かならず 入れる
1. **「戦いに 入る」ボタン**: 同じ パーティーの 人が ボス・物語の 戦い（`opts.fixed`）を して いて、自分が 入って いない 間、画面に ボタン「⚔ ○○の戦いに入る」を 出す（「ついていく」ボタンと 同じ ならび）。
   - おすと、**どこに いても**（べつの マップでも・運ばれた 先でも）その 戦いに 入る。
   - 自分が ほかの ことを して いる 間（会話・地図を えらぶ・お店）は、ボタンは 出た ままで、終わったら おせる。
   - 戦いが 終わったら ボタンは 消える。入った 人は、戦いの あと 自分の いた 所に もどる（だいほんの 続きは 今の まま リーダーたちだけ）。
   - ふつうの フィールドの 戦いは 今の まま（近づくと 入る）。
2. **近づいても 入れる**（今の まま）。ただし 次を 直す。
   - 画面が 送る きょり（2.0）と サーバーの きょり（2.4）を そろえ、「ついていく」で 止まる 所からでも 入れる きょりに する（係が 追跡の 止まる きょりを 読んで 決める）。
   - 戦って いる 人の **だれか 1人**に 近ければ よい。
3. **だまって ことわらない**: ことわる 時は かならず わけを 出す（「今は 入れない（会話の とちゅう）」「もうすぐ 戦いが 終わる」「戦いの 場所が いっぱいだ」など）。同じ 文を 何回も 出さない（今の 1.5びょうの 間を 使う）。
4. 地図の まどなど 画面だけの まどが、戦い・会話の 上に のこらない ように する（戦い・だいほんが 始まる 時に 画面だけの まどを 片づける。2-1 の あとは 地図の まどは サーバーが 知って いるので 起きない はず）。
