## 2. 案

### 2-1. 強さ：「レベルアップの のび」を上げる（おすすめ）＋「配合のあとの追いつき」

家族の2つの案のくらべ:

| | よいところ | こまるところ |
|---|---|---|
| A. 配合のあとの 基本の強さ（親から受けつぐ強さ）を上げる | 生まれた時から強い | 受けつぐ強さは「決まった数」なので、レベルが上がるほど 小さく なる（後半の弱さは なおらない）。上げすぎると、配合を くり返すたびに ふえつづけて 強くなりすぎる（今は 親の 1/4 ずつ＝合計 1/2 なので、何回くり返しても 2倍で止まる） |
| B. レベルアップの のびを上げる | 後半まで ずっと人と ならんで戦える。ランクの意味も つけられる | 配合した直後（Lv1）の弱さは なおらない |

**おすすめ：B を中心に、A は少しだけ・そのかわり「追いつき」の経験値を足す**

1. **魔物の育ち**（新しい）：レベル1つで 1.2% ずつ 強くなり、Lv51 で 1.6倍で上げ止まり（人の「レベルで得意な強さが のびる」＋「職業のボーナス」の かわり。魔物は転職しないので、レベルだけで のびる）
2. **ランクの強さ**（新しい）：ランクが高いほど のびが大きい（F 1.00・E 1.02・D 1.04・C 1.06・B 1.08・A 1.10・S 1.12・SS 1.15）。ランクを「強さ」ではなく「めずらしさ」で決めるので（2-2）、**めずらしい魔物ほど 少し強い**（ドラクエモンスターズと同じ考え）
3. **レベルの上限を上げる**：ランク F で 70、1つ上がるごとに +10（S で 130・SS で 140）、＋1 ごとに +1、150 まで（今より上の魔物は 下げない）
4. **追いつきボーナス**（新しい）：配合で生まれた子は、強いほうの親の レベルの 3/4 になるまで、経験値が 3倍（Lv1 から すぐ もどれる）
5. 親から受けつぐ強さは 1/4 → **3/10** ずつ（くり返しても 2.5倍で止まる）

### 2-2. ランクを「めずらしさ」で決める

- ランクの点 ＝ **出やすさの点（0〜4）** ＋ **仲間になりにくさの点（0〜4）**
  - 出やすさ：出る表の中の わりあい 30%いじょう 0点・20%いじょう 1点・12%いじょう 2点・6%いじょう 3点・それより少ない 4点（夜だけ・宝の地図だけ・ひみつのダンジョンだけ は +1）
  - なりにくさ：図鑑の4つの段（仲間になりやすい 0点・ときどき 1点・なかなか 3点・滅多に 4点）
  - 点 0〜1 → F・2 → E・3 → D・4 → C・5 → B・6 → A・7いじょう → S
- ためしに今の やせいの魔物で計算すると: F 42・E 49・D 27・C 23・B 5・A 1・S 4（どの章にも F〜C が いて、B〜S は少し）
  - 第1・2章 F16 E9 D8 C6 B1 A1 S2 / 第3・4章 F11 E10 D8 C2 B1 S2 / 第5章 F15 E14 D7 C7 B1 / 第6章 E16 D4 C8 B2
- **これからの章の作り方**：1つの地方に「よく出て なかまになりやすい（F・E）」「ふつう（D・C）」「めずらしい（B・A）を 1〜2しゅ」「とてもめずらしい（S）を 0〜1しゅ」。ランクは 図鑑・酒場に出す（今のまま）
- 配合だけで生まれる魔物：系統・組み合わせの配合は「高いほうの親の ランク」か「1つ上」（今のまま）。きまった組み合わせの子は、親より1つ上まで（A まで）
- 図鑑の「仲間になりやすさ」と ランクが つながるので、家族にも分かりやすい（「めずらしいから S」）

### 2-3. ボス級（SS）を作りにくくする

- **ランク配合（S どうし → SS）を やめる**（おすすめ）。SS は **素材配合（ボスの品 ＋ S 2ひき）** と **4体配合** だけ
  - かわりの案：ランク配合を のこすなら、どちらも S・Lv60いじょう・＋20いじょう・同じ系統 に きびしくする
- S を作るのも少し むずかしく：A → S の「1つ上」は、両親の レベルの合計 100いじょう（今は 68）。B → A は 80（今は 60）
- 素材配合の品（ボスの品）は、そのボスを たおすと 1つ（もう一度戦える強いボスでは 1日1回）
- 今もっている SS の仲間は そのまま（とりあげない）

### 2-4. 技の受けつぎ：両方の親から 4つずつ（合計 8つ）

- 配合の画面で、親A の技から 4つ・親B の技から 4つ を えらぶ（2つの列）。おまかせは それぞれ強い技から
- 両方の親が同じ技を もっている時は 1つと数える（あいた ぶんは、もう片方から えらべる）
- 子が自分で覚える技は 受けつがなくてよい（今のまま、えらぶ一覧に 出さない）
- 受けついだ技は 子の技になる → 次の配合で また受けつげる（強い技が 血統で集まっていく）
- 戦いの技の一らん：魔物の技は 自分で覚える 6〜7つ ＋ 8つ で、多くて 15くらい（人と同じくらい。今の画面で入る）
- **もう1つの案（おまけ）**：系統ごとの「奥義」。Lv30・45・60 で、その系統の強い技を1つずつ覚える（8系統 × 3つ＝24の技）。もともと弱い技しか覚えない魔物も、育てると強くなる
