## 3. しくみ（`shared/battle-r83b.js`。どれも 戦いの 中だけ・キャラ〈セーブ・引っこしコード〉に 項目を 足さない）

1. **生徒を 守る**（`passive.protect`）
   - 敵が 仲間 1人を ねらった 時（`resolveTarget` の あと）、その 仲間の HP が **3わり いか** なら、先生が その 確率で 自動で かばう。ダメージは 先生の 守備力で 計算しなおす（ふつうの かばう と おなじ）。ひとこと「〇〇先生が、△△をかばった！」・バナー「先生が、かばった！」
   - **全体の 攻撃**: 弱った 仲間 **1人ぶんだけ**（1回の 行動で 1回）先生が かわりに 受ける。その 仲間は 受けず、受ける はずだった ダメージを 先生が 受ける（先生は 自分の ぶんと 2回 受ける）。`damage` の はじめ
   - かばわない 時: 先生の HP が **2わり いか**・その ダメージで 先生が たおれる（全体の 時）・ねむり・マヒ・こんらん・地われ・自分が ねらわれて いる。手で えらんだ かばう（cover）が 先
2. **おにの手**（`c.oni = { lv, awake, max }`）
   - 出すと ＋15%。**自分の 番の はじめごとに ＋15%**（ぬ〜べ〜 60%・じごく先生 90% まで）。強く なるのは **物理の 攻撃**（ふつうの 攻撃も 技も。`calcPhys`）
   - かわりに 自分の 番ごとに **最大HP の 6% へる**。**これで たおれない**（HP 1 で 止まる）。番が 来た 時に HP が **15% いか** なら、へらさずに **自動で ふういんに もどる**
   - 「身を 守る」も 自分の 番（battle.js の すぐ 守る 道に 1行。A班も 同じ 所に 1行 足して いて、ぶつからない）
   - もう一度「おにの手を出す」で ふういんしなおす。かくせい（3回の 番 上限で HP が へらない）・最大出力（使うと ふういん）
   - 札: 仲間の まどに「おにの手+45%」「かくせい3」「体をはる」（家族 みんなの 画面）。出した 時 バナー「おにの手！」
3. **ゆうれい・悪魔に 強い**: 技の `vsRace`（spirit・undead・demon ×1.5。物理は 前から ある calcPhys、呪文の おふだは calcMagic に 1行 `r83bMagicMult`）
4. **体をはって守る**: 次の 自分の 番まで cover all ＋ 先生の 受ける ダメージ 0.6倍。**軍師の 作戦（守り）・先読みの策・守りの旗と 合わせても、へらす 前の CUT_FLOOR（0.45倍・身を 守る 人 0.65倍。battle-r83a.js と おなじ）より 下げない**（`r83bShieldCut`。A班の r83aDamage の あと）
5. **オート**（ai.js）: 回復より 前に「HP 4わりを 切ったら ふういんしなおす」（2.9・`r83bSeal`）／4.9 で 仲間の 状態異常に かんのんきょう・ボスか 強い 敵で おにの手を 出す・じごく先生は HP 7わり いかで かくせい・いちばん 強い 時に 最大出力・ゆうれい／アンデッド／悪魔が いたら おふだか おにの手（強い ほう）
   - **この 系統の 技だけ 見る**（`R83B_LINE`）。ほかの 職業の 治す 技・光の 技では 何も せず、運（rng）も 使わない（さいしょ これが なく、大神官 などの オートが かわって ボス戦の 数が さがって いた。直した）

battle.js に 足した 行: import・すぐ 守る 道・executeNext（番の はじめ）・resolveTarget・applyAbility の case・calcPhys・calcMagic・damage の はじめと r83aDamage の あと・pub。
