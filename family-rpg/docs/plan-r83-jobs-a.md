## 3. しくみ（`shared/battle-r83a.js`。どれも 戦いの 中だけ・キャラに 項目を 足さない）

1. **作戦**（`b.r83aPlan = { side, by, kind, pct, boost, boostBy }`）
   - 「作戦を立てる」で えらぶと、**立てた 人（軍師）が たおれるか 作戦を かえる まで**、その 側の 仲間全員に ずっと 効く（時間で 切れない）
     - 攻め（seme）: 与える ダメージ ＋pct ／ 守り（mamori）: 受ける ダメージ −pct ／ 速攻（sokkou）: 行動ゲージの たまる 速さ ＋pct（battle.js の speedMult）
   - 効き目は 立てた 人の 今の 職業の 段: せん人界の道士 15%・太公望 20%・ほう神の大軍師 25%（`SAKUSEN_PCT`）
   - **同時に 効くのは 1つだけ**。軍師が 2人 いても 足さない。**あとから 立てた 方（新しい 方）が 前の 作戦に かわる**
   - **ほかの 職業に 転職した あと**: 「作戦を立てる」を 覚えて いれば 攻め・守りの 2つを **15%**（`OTHER_PCT`）。速攻は この 系統の 太公望・伝説の 時だけ
   - 立てた 人が たおれると、つぎの だれかの 行動の はじめに「〇〇がたおれて、攻めの作戦がとぎれた…」。生き返っても もどらない（立てなおす）
   - 画面: 「作戦を立てる」を えらぶと「どの作戦にする？」の メニュー（YAIBA の 玉がえと おなじ 画面。`client/battle-r83a.js` の `sakusenMenu`。client/battle.js の 技の 一覧に 1行）。
     仲間の まど 全員に「攻め25%」の 札（作戦の 色。pub の r83aPlan。家族 みんなの 画面）
   - 戦いの 人（combatant）に だけ 持つ（`c.r83aPlan` は 札と 速さの ための うつし）。セーブ・引っこしコードには 何も 足して いない
2. **強化ふうじ・太極図**（`c.r83aSeal = { left }`）
   - 敵の **ふつうの 強化**（攻撃力アップ などの バフ〈left が 数〉・力ため）を 消して、3回 行動する 間 強化できなく する（battle.js の applyBuff と 力ためを とめる）
   - **ボスの しかけは 消さない**: ずっと つづく 強化（left が Infinity。おこった 攻撃力・時の 強化・空を とぶ かいひ など、台本で きまった 物）・形態・かまえ・前ぶれ・しるし（c7mal など）は そのまま。
     前から ある `dispel`（ツッコミ など）は かえて いない（この 系統は 自分の `r83aDispel`）
   - 太極図は 仲間全員の 弱体（デバフ）と 状態異常（毒・ねむり・マヒ・混乱・マヌーサ・マホトーン）も 治す。水のろう・地われ など ボスの しかけの 状態は 治さない
   - 敵の 足もとに「ふうじ3」の 札
3. **先読みの策**（`c.r83aSaki`）: 次の 自分の 番まで、前ぶれの ある 大技（ev.big）で 仲間全員が 受ける ダメージ 半分。
   **下げすぎ ふせぎ**: 守りの 作戦・先読みの策・守りの旗を 合わせても 0.45倍まで。身を 守って いる 人は 0.65倍まで（身を 守る 0.5倍と 合わせて 約0.33倍）。`CUT_FLOOR`
4. **軍師の号令**: 仲間 1人の 行動ゲージを まんたんに（すぐ 動ける。社長の ツルの一声と ちがい 1人だけ・すぐ）。自分には かけられない。
   **ほう神計画**: 3回の 行動の 間 作戦の 効き目 2倍（25% → 50%）＋ 仲間全員が すぐ 動ける（自分は のぞく）
5. **ほう神**: magic の 技に しるし（`effect.r83aHoshin`）。battle.js の 'magic' の はじめで battle-r83a.js へ（オートは ふつうの 呪文と して えらぶ）
6. **身を 守るのも 1回の 行動**: 身を 守った 時も 先読みの策・ほう神計画・ふうじの のこりを へらす（battle.js の command の 防御に 1行）
7. **オート**（ai.js の decideAlly の 4.9: `r83aPlan`）: 前ぶれ → 先読みの策（だれも 読んで いない 時）・守りの旗（60%）／作戦が ない → 作戦を 立てる（ボスは 守り・ふつうは 攻め。すぐ おわる 弱い 敵には 立てない）／
   敵が ふつうの 強化 → 2体 いじょう・仲間も 弱って いる 時は 太極図、1体なら 強化ふうじ／ボスで 作戦が ある 時 ほう神計画（30%）・軍師の号令（20%・いちばん 強い 仲間）。
   運（rng）を 使うのは その 技を もつ 時だけ（ほかの 職業の オートの ながれは かわらない）
8. 職業の試練の まぼろしは 作戦・号令・先読み・旗・ほう神計画・太極図を 使わない（battle-trial.js の NO_USE。太極図は まぼろしが 何回も 使って 攻撃しなく なる ため）

battle.js に 足した 行: import・speedMult（速攻）・command の 防御・executeNext（行動の はじめ）・applyAbility の 'magic' の はじめ（ほう神）・case・力ため・applyBuff・damage・pub。
