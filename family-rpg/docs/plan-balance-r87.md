# 第87回 職業の 強さの 見直し（2026-11-16。設計だけ。まだ 何も かえて いない）

> 家族から「職業の パワーバランスを 確認して。1人で 戦う わけでは ないので、**パラメータと 覚える 技の 関係** を 見て ほしい。ミナデインと 4人の 合体技が 強すぎるのは 知って いる。こうした 方が いい 案だけ 考えて」。
> はじめに 出した 調べ（ボス戦で 席を 入れかえて 長さを くらべる）は 分かりにくく、聞かれた ことと ちがったので **やめた**。この 文書は 書き直した もの。

## 0. 見た こと
職業には 能力の 倍率（HP・MP・力・守り・素早さ・魔力・回復）が あり、技には 使う 能力が きまって いる。
| 能力 | 効く 所 |
|---|---|
| 力 | 物理の 技と ふつうの 攻撃（力が 上がるだけ どこまでも 強く なる） |
| 魔力 | **呪文だけ**（技ごとの めやすの 魔力から ＋150 までで 1倍 → 2倍。**そこで 頭打ち**） |
| 回復 | 回復の 技（魔力と 同じ 形で 頭打ち） |
| MP | 技を 使える 回数 |

見た ことは「高い 能力を 使う 技を 覚えるか」「覚える 技に 合う 能力が あるか」「MP が 足りるか」「あとで 覚える 技ほど 強いか」。
はかる レベルは、基本職 20・上級職 35・超級職 55・伝説 75・幻 90（店の 装備）。

### 3-A. 呪文と 回復の 頭打ち（案 1。`*-r87a`）

- 直し: **頭打ちの あとも、3分の 1 の 速さで のびる**（こえた 分 ÷ 450 を 足す。足す 分は ＋1.0 まで ＝ 全部で 3倍まで）。**味方だけ**（敵・ボスの 呪文は 今の まま）。回復の 技（回復の 能力）も 同じ 形
  - 例: 魔力 240 で 頭打ちの 呪文 … 魔力 255 → 2.03倍・349 → 2.24倍・437 → 2.44倍

- たしかめ: `tools/job-fit.mjs` の「頭打ち」の 見方を 新しい 式に 合わせる（「これより 上がっても 強く ならない」が 0 に なる）。レベル ＋20 の のびが 呪文でも 1.05倍 いじょうに なる
