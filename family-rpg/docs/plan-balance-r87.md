# 第87回 職業の 強さの 見直し（2026-11-16。設計だけ。まだ 何も かえて いない）

> 家族から「職業の パワーバランスを 確認して。1人で 戦う わけでは ないので、**パラメータと 覚える 技の 関係** を 見て ほしい。ミナデインと 4人の 合体技が 強すぎるのは 知って いる。こうした 方が いい 案だけ 考えて」。
> はじめに 出した 調べ（ボス戦で 席を 入れかえて 長さを くらべる）は 分かりにくく、聞かれた ことと ちがったので **やめた**。この 文書は 書き直した もの。

## 0. 見た こと
職業には 能力の 倍率（HP・MP・力・守り・素早さ・魔力・回復）が あり、技には 使う 能力が きまって いる。
| 能力 | 効く 所 |
|---|---|
| 力 | 物理の 技と ふつうの 攻撃（力が 上がるだけ どこまでも 強く なる） |
| 魔力 | **呪文だけ**（技ごとの めやすの 魔力から ＋150 までで 1倍 → 2倍。**そこで 頭打ち**） |
| 回復 | 回復の 技（魔力と 同じ 形で 頭打ち） |
| MP | 技を 使える 回数 |

見た ことは「高い 能力を 使う 技を 覚えるか」「覚える 技に 合う 能力が あるか」「MP が 足りるか」「あとで 覚える 技ほど 強いか」。
はかる レベルは、基本職 20・上級職 35・超級職 55・伝説 75・幻 90（店の 装備）。

## 3. 直し方（2026-11-16 家族「修正して。修正の 実際は Opus で」）
設計は メイン、実装は Opus の 係 3つ（A・B・C）。6 の 合体技は 家族に 3つの 案から えらんで もらってから。

### 3-A. 呪文と 回復の 頭打ち（案 1。`*-r87a`）
- 今: 倍率 ＝ 1 ＋（魔力 − 技の めやす）÷ 150 を 0〜1 に 切る（1倍 → 2倍で 頭打ち）
- 直し: **頭打ちの あとも、3分の 1 の 速さで のびる**（こえた 分 ÷ 450 を 足す。足す 分は ＋1.0 まで ＝ 全部で 3倍まで）。**味方だけ**（敵・ボスの 呪文は 今の まま）。回復の 技（回復の 能力）も 同じ 形
  - 例: 魔力 240 で 頭打ちの 呪文 … 魔力 255 → 2.03倍・349 → 2.24倍・437 → 2.44倍
  - めやすの レベルでは 超級職 ＋1〜5%・伝説 ＋5〜15%・幻 ＋15〜25%（頭打ちを 大きく こえて いた 職業ほど 上がる）
  - 技に `scaleCap` が 書いて ある 物（頭打ちを わざと 低く して いる 技）は、その 技の きまりの まま
- たしかめ: `tools/job-fit.mjs` の「頭打ち」の 見方を 新しい 式に 合わせる（「これより 上がっても 強く ならない」が 0 に なる）。レベル ＋20 の のびが 呪文でも 1.05倍 いじょうに なる

### 3-B. むだな 能力を うつす（案 2・3。`*-r87b`）
- **能力の 合計は かえない**（段の はんいの テストも そのまま 通る）
- **魔力が むだな 20こ**: 魔力を 1.0 に 下げ、下げた 分を **HP・守り・MP** へ（力と 素早さには 入れない ＝ 攻撃は 強く しない。もう 強い 職業を さらに 強く しない ため）
- **名探てい・のぶドラ** は 魔力を 下げず、**覚える 技を 2つずつ 魔力で うつ 技に かえる**（名探てい: キック力増強シューズ・ターボエンジン付きスケボーは のこし、弱体だけの 技の うち 2つに 魔力の ダメージを 足す ／ のぶドラ: ひみつ道具の 光線 など。名前と 見た目は できるだけ そのまま・技の 数は かえない）。同じ 段の 魔法の 職業の 呪文を 物さしに
- **力が むだな 7こ**: ふつうの 攻撃には 効くので、**1.2 を こえる 分の 半分** だけを HP・守り・MP へ（はかい神は 力の 神 なので 1.95 → 1.6 まで）
- **回復が むだな 3こ**: 回復を 1.0 に 下げ、HP・MP へ
- 係が 前と あとの 表を 文書に 書く

### 3-C. MP と 看板の 技（案 4・5。`*-r87c`）
- **MP（19こ）**: めやすの レベルで **看板の 技を 4回** うてる ように。やり方は 職業ごとに: (a) MP の 倍率を 上げる（上げた 分は その 職業が 使わない 能力〈魔力・回復〉から 取る。合計は かえない）(b) 足りない 分は 技の MP を 下げる（1つの 技で 3わりまで）
- **看板の 技（21こ）**: 1体が 相手でも、**看板の 技が その 職業で いちばん 強い**（先に 覚える 技の 1.1倍 いじょう）ように
  - 職業の「いちばん 強い 技」の 強さは **今の 1.1倍まで**（合体技の 強さは、入った 人の いちばん 強い 技で きまる。ここを 大きく 上げると ボス戦が くずれる）
  - なので: 看板を 上げて とどく なら 上げる。とどかない 時（海賊王・伝説の超勇者・楽天ブラックカードマン・飛竜しょう天はの達人 など 2倍 いじょう 開いて いる 物）は、**先に 覚える 技の 方を 下げて** 合わせる（下げるのは 2わり半まで。それでも 足りない 分は 看板を 上げる）
  - 看板の 技の MP は かえない
- 係が 前と あとの 表を 文書に 書く

### 3-D. 3つの 係に 共通
- 直すたびに `node tools/job-fit.mjs` を 回して、自分の 一覧から 消えた ことを たしかめる
- ボスの 強さの テスト（第3〜8章の sim を 使う テスト）・職業の試練の めやす（6〜9わり）が くずれたら、**テストを ゆるめずに**、職業の 数字の 方を 合わせる。どうしても 合わない 時は 報告に 書く
- 取りこんだ あとに 全部の テスト ＋ ページが 立ち上がるか（`scratchpad/smoke.mjs`）

### 3-E. ミナデイン（案 6。2026-11-16 家族が えらんだ: **ミナデインは 戦い 1回に 1度だけ**。`*-r87d`）
- ミナデイン（`dt_minadein`）は、1つの 戦いで パーティーが 1度 出したら、その 戦いの 間は もう 出せない（だれが 出しても）。ほかの 合体技・倍率・ボスへの 上限は 今の まま
- 出した あとは、命令の 一覧で うすく・わけ「ミナデインは1回の戦いに1度だけ」。オートも えらばない
- 物語で きまって いる ミナデイン（さいごの 一撃 など 台本の 場面）は 止めない。段に 分かれた ボスで 戦いが つづきの 時の 数え方（段ごとに 1度か・全部で 1度か）は、係が 今の 作りを 見て「戦いの かたまり ごとに 1度」に きめて 文書に
- ボスの 強さの テストが くずれたら、テストを ゆるめずに 報告に
