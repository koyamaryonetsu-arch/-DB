# 第37回：闘技場・カジノ（ルーレット・すごろく）・乗り物

家族のおねがい（2026年10月18日）
- 王都サファラの闘技場が、ストーリーをクリアしても開かない。内容を決めて作って
- カジノにルーレットとすごろくを足す。宝の地図のクリア数が多いほど景品を豪華に。すごろくは景品だけでなく、すごろくの中みを豪華にしていく
- 「走る」の時の絵を変えられるように。乗り物屋さんを作り、職業にちなんだ乗り物を売る。乗ると、走る時にその乗り物に乗っている絵になる（絵だけ。速さは同じ）。乗っている時は仲間もいっしょに乗っているあつかいで、仲間の絵は出さない。マルチプレイでは、ひとりずつ自分の乗り物に乗る。乗りかえられる
  - 例：サイヤ人＝舞空術、暴れんぼう将軍＝馬、少年探てい団（コナン）＝スケートボード

## B. カジノ：ルーレットとすごろく

- **宝の地図のクリア数**（キャラごと。消えない数として数える。今までのクリアも数えなおす）で「豪華さの段」が上がる：段0（0〜2）・段1（3〜5）・段2（6〜9）・段3（10〜14）・段4（15〜）
- **景品**：今の景品に、段ごとの景品を足す（段が上がるほど、めずらしい種・★4〜★5・カジノでしか手に入らない品）。景品のたなに「宝の地図をあと〇こクリアすると、新しい景品が入る」と出す
- **ルーレット**：0〜36。数字（36倍）・赤／黒・奇数／偶数・前半／後半（2倍）・12ずつ（3倍）。1回に いくつもかけられる。コインは 1・10・100
- **すごろく場**（カジノの中に入口）：すごろく券（コインか小さなメダルで買う）で1回あそべる。自分のこまが さいころで進む。マスは ゴールド・道具・宿屋・わな・前へ／後ろへ・ワープ・？？？（できごと）・戦い・ゴール（大きな景品）。さいころをふれる回数が決まっていて、なくなると終わり
  - **段ごとに、すごろくそのものが豪華になる**（景品だけではない）
    - 段0「はじまりのすごろく」：まっすぐ20マス。かんたんなマスだけ
    - 段1「砂漠のすごろく」：30マス。分かれ道・戦いのマス・宝箱のマス
    - 段2「空のすごろく」：ワープ・スイッチで道がかわる・とくべつなさいころ（2こふる・数を選ぶ）
    - 段3「黄金のすごろく」：40マス以上。スロットのマス・ボスのマス・宝部屋・お店のマス
    - 段4「伝説のすごろく」：いちばん大きい。ゴールの景品は★5。段3までの仕かけが全部と、ここだけの仕かけ
  - 上の段になっても、下の段のすごろくも選べる
- マルチプレイ：ルーレット・すごろくは ひとりずつ（家族は同じカジノで、それぞれ遊べる）

## C. 乗り物

- **乗り物屋**：町に1つ（はじめの方から行ける大きな町）。ゴールドで買う。1度買えば、ずっと持っている
- **品ぞろえ**：ふつうの乗り物（馬・自転車・キックボードなど）は いつも売っている。**職業にちなんだ乗り物**は、その職業（の系統）に1度でもなった人にだけ たなに出る（かくれた職業のネタバレをさけるため）。職業の系統ごとに1つ以上
  - 例：サイヤ人の系統＝舞空術（オーラと風）、暴れんぼう将軍＝白馬、少年探てい団の系統＝スケートボード、ネコ型ロボットの系統＝タケコプターふう、魔法学校の生徒の系統＝ほうき、鉄道員・運転士の系統＝トロッコ／電車、消防士＝消防車、警察官＝白バイ … など
- **乗る**：メニューの「乗り物」で、持っている乗り物から えらぶ（「乗らない」もある。いつでも乗りかえられる）。**走っている時だけ** 乗り物の絵になる。歩く時はいつもの絵。速さは同じ
- 乗っている間は、仲間・馬車・ついてくる魔物の絵を出さない（みんなで乗っているあつかい）。止まる・歩くと、もどる
- マルチプレイ：ひとりずつ自分の乗り物。ほかの人にも その人の乗り物が見える
- 絵：4方向・動き（2〜3コマ）。主人公の見た目（かみ・服）が分かるように乗せる。2.5D と 2D の両方
- 乗り物に乗れない所（ダンジョンの中・町の中など）は 作らない（どこでも走れば乗る）。ただし船・竜に乗っている時は、そちらが先

### 実装メモ（C 乗り物）

- **データ**：`shared/data/vehicles.js`（53しゅるい。ふつう5・職業48）。`jobs` が ある物は、その職業に1度でもなった人（`char.jobs` のキー＋今の職業）にだけ たなに出る。もう持っている物は いつでも出る。117の職業は、どれも どれかの乗り物の `jobs` に入っている（test/vehicles.test.js）
  - 名前は 商標を さけた：タケコプター→「竹とんぼプロペラ」、舞空術→「ぶくう術」（舞は 習わない漢字）、ゴムゴム→「ゴムのロケット」。職業名は 今までどおり
- **セーブ**：`char.vehicles`（持っている ID のならび）・`char.vehicle`（えらんだ ID か null）。新しい項目なので 版は上げず、`save.js` の `repairChar` で `cleanVehicles`（ない時は []／null。知らない ID も けさずに のこす。持っていない物に 乗っている ことには しない）。スマホと家族サーバーの 合わせは `merge.js` で 両方を 合わせる（mergeSet）
- **サーバー**：`shared/world/vehicles.js`。乗り物屋 `['vehicles']`（`facilities.js` の `vehicle_shop`。`scripts.js` の ui の なかま）・`svc` kind `vehicles`（buy・ride）・メニュー `menu` action `vehicle`（id: null で 乗らない）
- **走っている ことの 同期**：クライアントの `move` に `run`（`me.running`）を 足した。サーバーは `s.running`。snap に `vh`（走って 動いている・とんでいない・たたかい中で ない 時だけ）
- **絵**：`client/render/vehicle-art.js`。人と同じ 32×42 の こまかさ（du）で かいて Scale2x → res 4。型は 4つ（馬・自転車やバイク・車や電車・板やふしぎな乗り物）＋それぞれの 色と 小物。層は back／人／front と、すきとおった fx（オーラ・風・花びら・けむり）。残像（忍び走り・桜の風）と のびる うで（ゴムのロケット。はだの色は 人の絵から とる）は 人の絵から つくる。よこ向きは ひだりを かいて、みぎは はんてん。コマは 2〜3（120ms で 回す）
- **field.js**：`myVehicle()`（えらんだ乗り物 × 走っている × 船・大鳥や竜（よぶ・おりる えんしゅつ中も）・トロッコ・かくれている で ない）／`otherVehicle(o)`（snap の vh × 動いている × とんでいない × 船でない）。2D の `drawPlayerOnFoot` と 2.5D の `entities3d` で、人の絵の かわりに 乗り物の絵（2.5D は 大きい物ほど かげを 大きく）。乗っている間は 自分の仲間（酒場の仲間・魔物・ゲスト）・ほかの人の仲間を かかない。馬車（render/wagon.js）は 動きは つづけて 絵だけ かかない（止まると すぐ もとの 場所に 出る）
- **乗り物屋**：ルミナの町 TW(26〜32, 23〜26) の あき地に 7×4 の たてもの（やね teal・とびら TW(29,26)・かんばん TW(30,26) の 自転車の しるし）。店の人「乗り物屋のハヤテ」TW(29,24)。UI は `client/ui/vehicles.js`（カウンター。みぎに 自分が乗って くるくる回る 見本 → 買う → 「さっそく乗っていく？」）
