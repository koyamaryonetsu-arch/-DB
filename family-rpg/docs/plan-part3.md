**もりあがりを つなぐ 所**
- さかさのピラミッド: `audio-scene.js` の `fieldState` で、その 場所の 曲が `c9c_pyramid` の 時だけ **だん ＝ `flipStageOf(game)`**（0 ふつう・1 さかさ）を `setPhase` で 送る。**A班が 出す 画面の 状態 `flipStage`**（`game.field.flipStage` か `game.flipStage`。数・true/false・関数 どれでも よい。出て いない 間は 0）。`addFormKey('flipStage')` も 入れた。かわるのは 次の 小節の 頭から。さかさに なると さかさの 形（fi → fA → fB → fC。fi で 音階を 上から 下へ）、もどると イントロ（音階を 下から 上へ）から。テンポと 調は かえない
- ピラミッドの 階: マップを `kind: 'dungeon'`・`bgm: 'c9c_pyramid'` に すると、今の「ダンジョンの 深さ」で `c9c_p1`〜`c9c_p4` → 強さ 0.4・0.6・0.8・1.0（1階は ふし・ベース・オルゴール・のばし、0.5 から ハープ、0.7 から たいこ）。上ほど 広い 形に 合う
- 川・少年・星の音: 曲の id を マップ（`bgm`）や 台本の 場面に 書くのは A班。夜の 楽器の かえは しない（`night: {}`。地下）。星の音は くり返さない（ジングルと 同じく おわると 前の 曲へ もどる）
- なぞの番人・3人組: ボスの 戦いの `bgm` を `c9c_riddle`・`c9c_trio2` に するのは B班（`battleBgm` は snap.bgm を そのまま 使う）。ボスの だんは ふつう（HP 半分で キーと テンポが 少し 上がる）。ピンチは 主音と 半音上。ふつうの 戦いは c9c の マップでも battle3（今の まま）
- 今の 鳴り方は かわらない（c9c で 始まる マップが まだ ない）
