# 第70回: 作れる 魔物から 選ぶ（配合の さがし表・メモ）

> 魔物の配合で、今の保有している魔物で作れる魔物から、配合モンスターを選べるようにできるようにして。
> 魔物が増えて、毎回配合2種を調べて何が産まれるのかを確認するのが時間がかかります。
> 何が産まれるのか、それの配合が何と何なのかを確認して、選べるようにして。

## 1. 計算（shared/breed-finder.js）

- `breedParents(c)` … 親に なれる 魔物。酒場の 配合と 同じ きまり（world/breed.js の `breedPreview`）:
  仲間の 魔物（パーティー・馬車・酒場で 待つ）＋ あずかり所の 魔物、レベル `BREED_MIN_LEVEL`（10）いじょう。人間の 仲間は 入らない。
  `where`: `party` / `wagon` / `tavern` / `storage`（名前は ui/monarena-team.js の `WHERE_LABEL`）。
- `breedMatrix(parents, MONSTERS, c, { room })` … 2ひきの 組（順番なし）を みんな ためして、`breedCandidates` を そのまま 使う。
  本当の レベル・＋・血統・ふくろの 品で 見るので、ランクが 1つ上の 子・minLv の 特定配合・4体配合・素材配合も 手で えらぶ 時と 同じ。
  子ごとに `pairs: [{ a, b, kind, low, item, plus, trend }]`（`plus` は `breedPlus`・`trend` は `breedForecast` と 同じ）。
  `room`（配合して あける モード）では あずかり中 どうしの 組を 入れない（酒場の 画面と 同じ）。
- 組の ならび: ランクが 下がらない → ↑→↓ → ＋が 大きい → パーティー・馬車に いない 親（旅立つと こまる）→ 親の ならび。
- 子の 一覧（`kidList`）: ランクの 高い じゅん → 図鑑に ない 子 → 名前。ランクが 下がる 組でしか 生まれない 子は、ふだんは かくす。
  子の しるし（`kind`）は いちばん めずらしい 配合（4体 → 素材 → 特定 → …）。
- はやさ: `breed-calc.js` に `breedTrend(A, B, child, plus, memo)`（`breedForecast` と 同じ ↑→↓。親の 能力・受けつぐ 能力を 覚える）。
  40ひき（780組）で 0.13秒、100ひき（4950組）で 0.6秒くらい。

## 2. サーバー（world/breed.js の breedFinder・world/services.js）

- `{ t: 'svc', kind: 'tavern', action: 'breedFinder', child?, low?, room? }` → `svcRes.finder`（みるだけ）。
  - child なし: `kids`（子の 一覧）・`hidden`（かくした 子の 数）・`parents`（key → 名前・Lv・＋・いる ところ）
  - child あり: `child`・`pairs`（よい じゅん。60組まで ＋ `more`）。生まれない 子は ok: false
- さがし表は セッション（`s.breedFinderMemo`）に 覚える。親・品が かわったら 作りなおす（一覧 → 組 と きいても 計算は 1回）。

## 3. 酒場の 画面（client/ui/services.js）

- 「モンスターの配合」の いちばん 上に「★ 作れる魔物から選ぶ」（1ぴきめを えらぶ 前・親に なれる 魔物が 2ひき いじょう）。
- 作れる魔物: 絵・名前（まだ 見たことが ない 子は いつもと 同じ ？？？と かげ）・ランク・NEW・配合の しるし（4体配合・素材配合・とくべつ・新生配合・まぜ配合）・使う 品・組の 数。
  いちばん 上に「ランクが下がる子も見る：見ない／見る」。右（たてでは 下）に 子の みほんと いちばん よい 組の ＋・↑→↓。
- 子を えらぶ → 組の 一覧（2行: 親A Lv・いる ところ ＋ 親B Lv・いる ところ。右に ＋と ↑→↓・しるし・品・ランク↓）。
  右に 生まれる 子の みほん（えらんだ 子で）と 親 2ひきの 強さ・技。旅を して いる 親は「旅立っていく」と 出す。
- 組を えらぶ → いつもの 配合（`breedWith(a, b, child)`。子を えらぶ まどだけ 出さない。色の石・受けつぐ 技・たしかめ・「名前をつける？」は いつもと 同じ）。
  やめると 組の 一覧（カーソルは そのまま）。配合したら 一覧を 作りなおして、同じ 子が まだ 作れれば その 行へ。
- もどる: 組 → 子の 一覧（えらんでいた 子）→ 配合の 画面（「作れる魔物から選ぶ」の 行）。
- 配合して あける モードでも 使える（あずかり中 どうしは 出ない。配合したら まっている 仲間の ところへ）。
