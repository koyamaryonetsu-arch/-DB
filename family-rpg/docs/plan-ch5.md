## 1. ひとことで

**空にうかぶ島々「クモイ地方」は、大地の守り星をうしない、少しずつ雲の海へしずみ始めていた。**
守り星をうばったのは、四ツ影の4人目にして最後の影 ――「えらばれなかった紋章の子」**ノクト**。
紋章の子らは、星の塔をのぼって雲の上へ行き、しずみゆく島々を守り、ノクトの思い出の中に入り、最後に、雲の海からうかび上がる **影の城** で、魔王ソリトゥスのめざめにいどむ。

テーマは **「きずな」と「ひとりぼっち」**。魔王の名前ソリトゥスは「ひとりぼっち」から来ている、という話にする（第1章からある名前をそのまま生かす）。

## 4. 舞台「クモイ地方（空にうかぶ島々）」

雲の海の上に、大小の島がうかぶ地方です。島と島は「風の道」（第2章の風の守り星の力）でつながっています。

```
                    ☆ 影の城（第6幕で雲の海からうかび上がる）
     ～～～～～～～～～～～ 雲の海 ～～～～～～～～～～～
   ◇ 星読みの里（小島）        ● 雲の上の町ハネノ（いちばん大きな島）
        ＼ 風の道                  │ 風の道
   ▲ しずみゆく島（古い神殿）   ◎ 大地の神殿（島々のまん中・下の方）
                                   │
   ┃ 星の塔（地上のホシフル村の北の山から、雲の上までのびる）
   ━━━━━━━━━━━━━━━━━ 地上 ━━━━━━━━━━━━━━━━━
      ● ホシフル村（はじまりの村）
```

- 行き方：第4章クリアのあと、**ホシフル村の星の石** に3つの守り星をささげる → アステルに「星の羽」→ でも、雲の上には「天のとばり」があって、竜だけでは入れない → **星の塔** をのぼって、塔のてっぺんから「とばり」を開く
- **島がしずむ**（新しいしくみ）：大地の守り星がないので、島はゆっくりしずんでいる。物語が進むと、しずんで行けなくなる所と、新しく雲から出てくる所がある（町の人の話と見た目でわかる。時間ぎれで負けるしくみにはしない）
- **風の道**（新しいしくみ）：島と島をつなぐ風の流れ。乗ると決まった方向へ流される（第4章のありじごくと同じ考え方）。風の向きを変える「風見の石」がある

## 5. あらすじ（6つの幕）

### 第1幕「星祭りの夜、もう一人の紋章の子」（Step 1）

1. 第4章クリアのあと、ホシフル村で2回目の星祭り。ばあちゃんが「4つの守り星のうち3つがもどった。星の石にささげておくれ」
2. 祭りの人ごみの中に、フードをかぶった子ども。主人公をじっと見て「…きみが、えらばれた子か」と言って消える（ノクトの初登場。名前はまだ出ない）
3. 星の石に3つの守り星 → アステルが「星の羽」をえる → でも空の上の「天のとばり」にはじかれる
4. 王家の古い書物（ネフィから）とばあちゃんの話：「ホシフル村の北の山に、昔の勇者がのぼった星の塔がある」

### 第2幕「星の塔」（Step 2・**長いダンジョン 1**）

1. 地上から雲の上までのびる、**8階建て** の塔。下の階は石、上へ行くほど星空になる
2. しかけ：**昇降の床**（重さで動く。家族2人なら1人がのる、ひとりなら仲間・馬車の仲間を「のせる」）、**星座の床**（夜にだけ光る星をなぞる）、**風の窓**（強い風で押し出される。風見の石で止める）
3. 4階に休み所（記録と回復）。**1度通った階には近道**（エレベーター）ができる
4. 8階の番人：**星の番人アルゴス**（目が3つ。前ぶれのある「見通しの目」で、次にだれが何をするか読まれる → 行動を変えると外れる）
5. てっぺんで、紋章を「天のとばり」にかざす → とばりが開き、雲の上へ

### 第3幕「雲の上の町ハネノとしずみゆく島」（Step 3〜4・**長いダンジョン 2**）

1. 雲の上の町ハネノ。ハネビトの長ソラネ「大地の守り星がうばわれ、島々がしずみ始めました」
2. ハネビトの子ピピ「ノクト兄ちゃんは、悪い人じゃないよ。ぼくと遊んでくれたもん」→ ノクトの名前が出る
3. 西の **しずみゆく島** の古い神殿に、守り星の「かけら」がのこっているらしい
4. しずみゆく島の古い神殿：**7階**（上から下へ）。しかけは **かたむく床**（島がかたむくと、床の上の岩や水が流れる）と **重さのてんびん**（岩・仲間をのせて、とびらを開く）。島がしずむにつれて、下の階に雲が入ってくる（雲の中は魔物が強い・宝もよい）
5. 最下層：**島をむしばむ大ムカデ「ガイアイーター」**（島の土を食べている。ばらばらの体を順にたおす多部位の戦い）
6. 守り星のかけらで、島のしずみが少し止まる。かけらにうつったのは、ひとりで泣いている小さな子の思い出

### 第4幕「星読みの里と、えらばれなかった子」（Step 5・**長いダンジョン 3**）

1. 星読みの里のカナタ「13年前の星読みには、こう書かれていた。『星祭りの夜、紋章の子が2人生まれる。ひとりはえらばれ、ひとりはえらばれぬ』」
2. 「でも、それはまちがって読まれていた。本当は『ひとりはえらばれ、ひとりは **えらぶ**』――自分で道をえらぶ子、という意味じゃった」
3. ホシミばあちゃん（竜で来る）が、儀式の日のことを話す。光らなかった紋章、こわがった村人、出ていったノクト。「わしが、あの子をひとりにしたんじゃ…」
4. **ノクトの思い出の迷宮**：星読みの水晶から、ノクトの思い出の中へ入る。**6階**（思い出の年ごとの階：5さい・7さい・9さい・11さい・13さい・今）
   - しかけ：**光と影**（ランプを持つと影ができ、影の側にしか見えない道がある）、**思い出のかけら**（拾うと、その年のノクトの場面が見られる。全部集めると、最後の場面がかわる）
   - 魔物は「ひとりぼっち」の形をした影の魔物（さびしさのゆうれい など）
5. 最後の階で、今のノクトの影と戦う：**ノクトの影**（ボス。主人公たちの職業をまねる。第4章のうつし身の考え方）
6. 迷宮から出ると、本物のノクトがいる。「見たのか、ぼくの思い出を。…同情なんかいらない」

### 第5幕「大地の神殿」（Step 6〜7・**長いダンジョン 4**）

1. ノクトは大地の神殿で、大地の守り星の力を使い、雲の海の下にねむる **影の城** をうかび上がらせようとしている
2. 大地の神殿：**8階**（島々のまん中の下へ下へ）。しかけは **根の道**（大きな木の根が、のびたりちぢんだりする）・**土の守り手**（岩のゴーレムを動かして道を作る）・**2つに分かれる道**（家族が2組に分かれて、同時にスイッチをおす。ひとりなら仲間が手伝う）
3. 5階に休み所。こわれた昇降の床を直すと、入口からの近道
4. 最下層：**ノクト（1回目）**。強い。HPが半分になると、ノクトは戦いをやめる「…今のは、ほんの小手しらべだ」→ 守り星を持ったまま、影の城へ
5. 大地がゆれて、雲の海から **影の城** がうかび上がる

### 第6幕「影の城と、ひとりぼっちの魔王」（Step 8〜9・**いちばん長いダンジョン**）

1. ハネノに、これまでの人たちが集まる（ネフィ・バルガ・サラ・ミラ・ユキナ・ルカ・ばあちゃん）。それぞれから、最後の戦いのための力（道具や守り）をもらう
2. **影の城：12階**（3つの「ふういんのとびら」で3つに分かれる）
   - 1〜4階「風の階」：ストルムのまぼろしと再戦（第2章のボスの強い形）
   - 5〜8階「炎の階」：イグニアのまぼろしと再戦
   - 9〜12階「水の階」：モルガナのまぼろしと再戦
   - 4階・8階に休み所。とびらを開けるたびに、入口から近道
3. てっぺん「星のない広間」で、**ノクト（2回目・本気）**
   - 戦いのとちゅうで、思い出のかけらを全部集めていると、ことばが変わる（第4幕のかけら）
   - たおすと、ソリトゥスがノクトの心から出てきて「この子のさびしさは、わたしのものだ」
4. **魔王ソリトゥス**（最後のボス・3段階）
   - 第1段階：ひとりぼっちの闇（だれか1人を「ひとりにする」→ その人は仲間の回復・補助を受けられない。仲間が話しかける（新しいコマンド「よびかける」）ともどる）
   - 第2段階：きずなを食べる（きずなゲージをへらす大技。前ぶれで防げる）
   - 第3段階：ノクトがゲストで加わる。ノクトの紋章が初めて光り、**家族みんなの「きずな技」**（全員の名前が出る特別な技）が使える
5. エンディング：ソリトゥスは光になって消え、大地の守り星が島々をささえる。ノクトとばあちゃん。ピピの羽が開く。5つの守り星が光り、星祭りの夜空。**第5章クリア＝第1部の完結**（このあと、やりこみと、次の部の伏線）

## 6. ダンジョンを長くする（家族の要望）

これまでのダンジョンは 2〜4階でした。第5章は、次のように長くします。

| ダンジョン | 階 | 休み所 | 近道 |
|---|---|---|---|
| 星の塔 | 8階 | 4階 | 通った階へのエレベーター |
| しずみゆく島の古い神殿 | 7階 | 4階 | 2階と5階につながる縄ばしご |
| ノクトの思い出の迷宮 | 6階 | 3階 | なし（短めの階） |
| 大地の神殿 | 8階 | 5階 | 昇降の床を直すと入口から5階へ |
| 影の城 | 12階 | 4階・8階 | ふういんのとびらを開けるたびに入口から |

長くても「つらい」にならないように：

1. **休み所**（記録と回復、何度でも）を3〜4階ごとに。ここまでは糸・ルーラで帰っても、次は近道から始められる
2. **近道** を開けると、次からは入口からすぐ先へ（DQの「近道のとびら」）
3. 1つの階に **1つの見どころ**（しかけ・宝・小さな話）を入れて、同じことのくり返しにしない
4. 階ごとに魔物の組み合わせを少しずつ変える。深い階ほど経験値とお金が多い
5. 家族で遊ぶ時は、2人スイッチ・2組に分かれる道など、**協力すると早い** しかけを入れる（ひとりでも、仲間・馬車の仲間でとける）
