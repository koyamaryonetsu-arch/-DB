# 31回目のお願い（合体技・レベルアップ・酒場・レア装備）

家族と相談して決めたこと（2026-10-12）。メインストーリー（第5章 Step 3〜）は、これが終わってから。

## 1. 合体技（担当 A）
- 「職業が誰でもよい」合体技は廃止。どの技も「今ついている職業」で判定する（マスターしたかは関係なし）。
- 全員集合：4人が同じ職業、または4人とも同じ基本職から分かれた系統の職業（今の職業で判定）。
- グランドフィナーレ：剣・こぶし・攻撃呪文・いやし のそれぞれで「上級職以上」が1人ずつ。
- 家族会議・なぞはすべて解けた！：4人目も職業しばりにする（誰でもよい枠をなくす）。
- ミナデイン：「きずな技」をやめ、合体技に生まれ変わる。勇者の系統（勇者・ロトの勇者など）が1人いれば、あとの3人は誰でもよい（家族が決めた例外）。ドラクエ最強格の技として、合体技の中でいちばん強くする（バランスは見る）。
- きずなゲージ・きずな技は、ゲームからなくす。ゲージをためる技（bondUp）は別の効果に変える。古いセーブは安全に読めるようにする。
- 4人技の強さは「ミナデインより下」にしばらない。ただし簡単に出せて強すぎることのないよう、条件の重さに合わせる。
- 待ち中の取り消し：2人技もふくめ、合体技の予約で「ゲージがたまって待っている人」がダメージを受けると、その人のゲージは半分からやり直し。ゲージがまだたまっていない人は影響なし。
- 合体技の表示名を大きくする（戦いのコマンド・メニューのタブ）。「〇〇といっしょに」などの補足は、名前の行ではなく効果の説明のほうに書く。
- 子ども向けにやさしくする考えはやめる（子どもは日々成長する）。

## 2. レベルアップ・酒場・仲間（担当 B）
- 戦いのあとのレベルアップは1レベルずつ出さない。1人1〜2行で「Lv12→15・上がった能力の合計・おぼえた技」を1画面にまとめ、1回のタップで閉じる。
- 酒場：入口で「人間の仲間／モンスターの仲間／モンスターの配合」を選ぶ。人間とモンスターを同じ一覧にしない。配合を選んだら配合だけの画面。2匹目をキャンセルしても1匹目は選んだまま。
- 酒場で新しく仲間になる人は Lv1 から（今いる仲間のレベルはそのまま）。
- しあわせの帽子（頭）：つけた人の経験値2倍。ただしパーティーでいちばんレベルが高い人がつけても効果なし。カジノの景品。
- こうふくの靴（アクセサリー）：10歩あるくごとにMPが1回復。宝の洞窟（レア度高め）とメダル王のごほうび。

## 3. レア装備（担当 C）
- 宝の洞窟の宝箱の装備は「ランク4まで」に固定、★も3〜8%しか出ず、強い装備が手に入らなかった（しらべた結果）。
- レア度 ★1〜★5 を作る。店の品は★なし（レア度低い）。名前の色と★の数でレア度がわかる。
- 新しい武器・防具を約100こ。ゲーム・アニメ・本・神話・歴史・映画・ファンタジー・今の職業から連想する。
- 手に入る所：
  - 宝の洞窟：地図の名前（氷・炎・ねむり・大地…）にちなんだ特性の装備。地図のレベルが高いほど強い。主の宝箱はレアが出やすい。
  - ボス・強敵のドロップ：そのボスにちなんだ装備。
  - ふつうの魔物のまれなドロップ。
  - 秘密のダンジョン：深いほど強い、ここでしか手に入らない★の高い装備。
- こうふくの靴（B が作る）は宝の洞窟の高いレアとして出す。

### 実装メモ（C）
- レア度：items の `rarity`（0〜5）。新しい装備は `data/items-rare.js` に書き、ほかは `assignRarity` が決める（店の品 0・かじ屋や指輪など店で買えない品 ★1・むかしの `star` ★2（ランク7から★3）・ボスの `unique` ★3）。きたえた品（+1〜）はもとと同じ。`star`・`unique` はそのまま残す（店・ボスの品のきまりは今まで通り）。B の品は `RARITY_OVERRIDE`（こうふくの靴 ★4・しあわせの帽子 ★3。品がある時だけ）
- 色：★1 緑・★2 青・★3 むらさき・★4 オレンジ・★5 金とにじのグラデーション（どれも くらいまどの上でコントラスト7以上をテストで確かめる）。名前のあとに小さい★。`client/ui/rarity.js` で 道具・装備・店で売る・宝箱（会話のまど）・戦いのけっか に色をつける
- 新しい装備 112こ（宝の洞窟55・ボス19・地方15・ひみつのダンジョン23）。強さはランクのめやす（剣・服）×武器の種類×レア度（★2 1.04〜★5 1.15）。武器の種類は今あるものだけ。刀4つは今ある刀の絵
- とくせい：今ある `resist`・`onHit` に、`crit`（会心+3〜8%）と `mpRegen`（行動するたびにMP+1〜3）を足した（`stats.js`・`battle.js` に数行）
- 宝の洞窟：地図のことば → なかま（大地・岩→守り/HP、まぼろし→混乱/マヌーサ、ねむり、ひみつ→会心、古代→MP回復、氷・炎の洞窟は氷/炎）。ランク＝`2+floor(Lv/2)`（Lv10 7・Lv12 8）。ふつうの宝箱はレア 6〜13%（★2〜★4）、主の宝箱は75%（Lv12 で ★4 が3割）。店の装備のランクも `equipRankOf` で Lv12 は7まで上がる。こうふくの靴は主の宝箱1つあたり Lv4 で約5%・Lv12 で約7.5%、ふつうの宝箱は Lv6 から約0.3〜0.4%（`ITEMS.koufuku_kutsu` がある時だけ）
- ボス：物語のボス19体に1つずつ、4回に1回（図鑑に「ときどき」）。ふつうの魔物：魔物のレベルで地方（〜9・〜16・〜28・〜38・39〜）、200体に1体
- ひみつのダンジョン：20階から。ランク＝20〜29階5 … 70階から10。★4（〜49階）・★4/★5（50階台）・★5（60階から）。休み所の大きなごほうびに毎回1つ・小さなごほうびは30階からまれに・魔物150体に1体・番人3回に1回。専用品はほかで出ない（テスト）
