### 実装メモ（B）
- 入るたびに変わる階：seed は **マップの ID に入れた**（`sd_<階>_<seed の36進>`。宝の洞窟の `tm_…` と同じ形）。サーバーで run の seed だけ持つ形にすると、画面がマップを作れない・2つの家族が同じ階に同時にいると形がぶつかるので、ID のほうが安全。`startRun` で `newSdSeed(world.rng)`（1〜2^31−1）を作り、いっしょに入る人みんなの `c.sd.run.seed` に入れる。下りる時は今の階の ID の seed で次の ID を作るので、いっしょに下りる家族は同じ形。ログインしなおしは `c.pos.map` の ID で同じ形。前の版の `sd_<階>`（seed なし）は今までどおり読めて、次の階から新しい seed。`repairSecret` は正しい seed だけのこす。記録の数えかた（1つずつ下りた階・`mid`）は変えていない（宿屋・お店の階も1階と数える）。出現表は今までどおり階の番号で決まる（形だけが変わる）
- 回復の泉はなくした（休み所の泉の場所は水晶のかざり）。番人をたおすと `['flash'], ['heal'], ['sfx', 'heal']`＋「ふしぎな光が、みんなをつつみこんだ…。HPとMPがすっかり回復した！」。回復するのは、いっしょに戦った人・仲間・馬車（台本の `heal` と同じ）。番人の強さ（`sdGuardLv`・`sdGuardEncounter` の `enemyLv`/`enemyPow`）はさわっていない（A の数式を入れる所。`data/secret.js` の「番人（10階ごと）」のかたまり）
- 宿屋・お店の階：`sdSpecialOf(f, seed)`。6階から、5の倍数でない4つの階（6〜9・11〜14 …）ごとに 6割の運で1つ。宿屋とお店は半分ずつ（seed 400 × 29 かたまりで 0.6±0.05 をテスト）。着いた時はトーストに「ふしぎな宿屋がある！」だけ（会話のまどは出さない）
  - 宿屋：`sdInnPrice(f)` = (15＋5×階) を10G きざみ（7階 50G・18階 110G・30階 170G・60階 320G）。「休む／やめる」の1回だけ。はらうのは話しかけた人、回復はいっしょにいる家族みんな
  - お店：今の店の画面（`client/ui/shop.js`）をそのまま使う。店は `ensureSdShop(f, seed)` が `SHOPS` に数えない形で入れる（40こまで）。レア装備は `items-rare.js` の `tm`・`boss`・`region` の品から（`rareIds` を使う。`sd` の★4〜★5 は出さない）。ランク＝`2＋階/8`（6階 2・24階 5・48階から 8）の2つ下まで、★は 15階まで ★2 多め・35階から ★3 多め。ねだんは売り値の4倍（`prices`。`world/services.js` と `shop.js` に数行足した。店の一覧の名前にレア度の色）
  - 回復薬（`data/items-secret.js`、運で2〜3こならぶ）：地底の泉の水 1200G（HP400・MP80）・星くずの聖水 1500G（MP160）・いやしの大すず 1800G（戦いの中で全員HP250）・不死鳥の羽 2500G（HPまんたんで生き返り）。HPとMPをいっしょに回復する `multi` は、戦いの `useItem` に数行足した（フィールドはもともと使える）。全員の薬は戦いだけ（`client/battle.js` は相手をえらばない）
- 敵の強さ：`sdEnemyLv(f) = 3 + f`・`sdPower(f)`（31階から1階3%）は、もともと上限がない（50階 Lv53・90階 Lv93・200階 Lv203、200階は 6.1倍）。番人の数とつながっているので式は変えず、999階（ID の上限）まで HP・攻撃・経験値などが有限・NaN なし・1e12 未満をテストした
- 色ちがい（`data/variants.js`）：`makeVariant(baseId, kind)`・`registerVariant(baseId, kind)` → ID `v_<kind>_<baseId>`。`MONSTERS` には **数えない形（enumerable: false）** で入れるので、`Object.keys(MONSTERS)`（図鑑のならび・魔物の数のテスト・配合）は変わらない。しゅるい：ダーク（むらさき・HP1.3 力1.2・経験値1.6）・シャドウ（はい色・素早さ1.45・経験値1.8）・レッド（赤・HP1.35 力1.35・経験値2）・ゴールド（金・HP1.5・経験値2.5・お金6倍）。色は `tint.hueTo`（`render/themes.js` の `tintCanvas` に1行）で色あいをそろえる。レベルはもとと同じ（ひみつのダンジョンでは階のレベルまで強くなる）
  - ひみつのダンジョン：40階から（`sdVariantRate` 40階 15%・60階 27%・90階から 45%）。40階〜 ダーク、50階〜 シャドウ、60階〜 レッド、ゴールドはどの階もまれ（色ちがいの中の15%）。とうろくは `registerSdVariants()`（`data/secret.js` を読んだ時。40階より下で出る魔物15しゅ×4＝60）
  - 図鑑：出さない（見た・たおした記録は色ちがいの ID でのこる）。ドロップ：もとと同じ（素材 `MAT_DROPS` は落とさない。ひみつのダンジョンの★4〜★5 のまれなドロップは、ほかの魔物と同じく出る）。仲間：ならない（`MONSTER_FRIENDS` に入れない＋`noBefriend`）
  - 物語で使う時：データのファイルで `registerVariant('frost_wolf', 'dark')` をよんで、出現表や戦いに ID を書く（読みこんだ時にとうろくすれば、サーバーと画面の両方で引ける）
- テスト：`test/secret-r32.test.js`（12）。前提を直したテスト：`secret-dungeon`（階の ID に seed・泉なし・台本の名前）・`field-r27`（階の ID に seed・いっしょに入った家族は同じ seed）

## 7. 錬金・ドロップ（担当 C）
- 錬金がま（ドラクエ8がベース）：装備や道具を2〜3こ入れて合成。少し歩くと完成。レシピは本棚・町の人・宝箱のメモでわかる。錬金でしか作れない★装備も入れる。
- 同じ武具を2つ入れると、レア度は変わらないが「きたえられる回数」がふえる。
- 風来のシレンのように、弱い武器もきたえ続けると別の武器になる（かくし要素）。
- ボスのドロップは必ず落とす。ただし品はそこまで強くない。ふつうの魔物のレアは500体に1体くらい。
- 章を進めるたびに、強い装備が出る地図やダンジョンの宝・武具を足していく（今後の方針）。
