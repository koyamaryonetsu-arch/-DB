## 4. しくみ（`shared/battle-r86a.js`。どれも 戦いの 中だけ・キャラにも セーブにも 項目を 足さない）

### 人とようかいのかけ橋（守るほど 強い）
1. **ためた力**（`c.r86aTame`）: かばって 受けた ダメージの 5わり（`TAME_RATE`）を ためる。上限は 最大HPの 6わり（`TAME_CAP`）。
   かばう ＝ 手で えらんだ かばう（きずなの守り・ほかの かばう 技）・自動で かばう・人とようかいのきずな。自分を ねらわれた ぶんは ためない。
   次の 自分の 攻撃の さいしょの 1回に そのまま 足す（1体に 自分の 物理の 2.5倍〈`HIT_CAP`〉まで）。ためた力の返し風（`tameAll`）は 当てた 敵 みんなに × 0.6。
   うつと 0 に もどる（行動の おわり）。札「ためた力850」（仲間 みんなの 画面に 出る）
2. **自動で かばう**（`passive.r86aGuard` 0.8）: じごく先生と おなじ きまり。弱った 仲間（HP 3わり いか）への 1体の 攻撃を かばう。敵全体の 攻撃は 弱った 仲間 1人ぶん（1回の 行動で 1回）。
   じごく先生も いて かばえる 時は 先生だけ（2人 いても 1回の 攻撃に かばうのは 1人。`ev.r83bAll` を いっしょに 使う）。自分の HP が 2わり いか・その ダメージで たおれる 時は かばわない
3. **きずなの力**（`c.r86aKizuna = { mult, left }`）: 4回の 行動の 間、物理 1.6倍。命令できる まま・HP は へらない。
   ようかい化・大よう化（攻撃力が 上がる）と おにの手（＋％）が 同時に かかって いる 時は 足し算・かけ算に しない（全体で 強い 方だけ ＝ max）
4. **人とようかいのきずな**（2だん）
   - 1だん目: 次の 自分の 番まで 仲間全員を かばう（1体の 攻撃は かばう〈cover all〉・敵全体の 攻撃も 仲間の ぶんを かわりに 受ける）。受ける ダメージは ×0.55。
     軍師の 作戦・まどか・守りの旗 などと 重ねても **0.45倍（身を 守って いれば 0.65倍）より 下げない**（`r86aMark` で もとの ダメージを おぼえ、`r86aCut` で 下限）。
     その ダメージで たおれる 時は かわりに 受けない（自分の ぶんだけ）。札「みんなを守る」
   - 2だん目: 次の 自分の 番の はじめに 敵全体へ 風（物理 1.7 ＋ ためた力 × 0.75。1体に 物理の 4.0倍まで）。その あと ふつうに 動ける（ばくりゅうはの 風の 一ふりと おなじ 形）。
     ボスの 前ぶれの 大技を みんなの ぶん 受けて、次の 番に 返す 形
