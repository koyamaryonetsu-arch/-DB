## しくみ（`shared/battle-r82b.js`。どれも 戦いの 中だけ）

- **今の 玉** `c.tama`: 戦いの 人（combatant）に だけ 持つ。キャラ・セーブ・引っこしコードには 項目を 足して いない（戦いごとに 作りなおすので いつも 雷から）
- **持てる 玉** `tamaSet(c)`: 今の 職業の 段で きまる。サムライ小ぞう なし（属性なし）／雷神けんの剣士 雷／ヤイバ 雷・火・水・氷／竜神けん ＋風・竜神（光）
  - ほかの 職業に 転職した あと: 玉がえを 覚えて いれば 雷・火・水・氷（竜神けんの 技も 覚えて いれば ＋風・竜神）。覚えて いなければ 雷だけ。この 系統の 技を 覚えて いなければ なし
- **技の しるし** `effect.yb`: `'tama'` 今の 玉の 属性 ／ `'fix'` 技の 属性の まま（雷光斬り など）／ `'strike'` 四つ玉・七つ玉
  - battle.js の `'phys'` の はじめで `r82bPhys`（monPal と おなじ 形）。オートの みつもりは `calcPhys` の はじめの `r82bElement`
- **玉がえ** `type: 'tamagae'`: コマンドの `tama`（ない 時は オートの えらび方）。`ev.atbAfter = 80`（すぐ 次の 番）。画面は 「どの玉をはめる？」の メニュー（`client/battle-r82b.js` の `tamaMenu`。client/battle.js の 技の 一覧に 1行）
- **画面の しるし**: 仲間の まどに「雷玉」（玉の 色）・「きょだい4」・「雷守4」（`battle-buffs.js` の unitMarks に 1行。家族 みんなの 画面に 出る）。えんしゅつは 玉の 色で 剣の 光が かわる（`battlefx-r82b.js`）
- **雷の 天気**: 今の 天気の しくみ（`battle-weather.js`）の まま。味方の 雷の 天気で 雷・風の 技は ×1.3。雷神のいかりは `thunderMult: 1.5`（ぜんぶで ×1.5）。かみなり雲よ来いは 天候の 職業と おなじ 天気（天気は 1つだけ。上書きは ふつうの きまり）。オートは 味方の 天気が ある 時は よばない
- **四つ玉・七つ玉**: 玉ごとに 1回。弱点（1.2倍 いじょう）なら weakBonus。**効かない（0倍）玉と、すいこむ よろい（闘技場の 王者の `arArmor`）と おなじ 玉は 使わない**（「〜の玉は、効かないので使わなかった」）。呪文を はね返す 敵は 物理なので かんけい ない
- **きょだい化** `c.kyodai`: 3回の 行動の 間、この 系統の 剣の 技（`yb`）が 敵全体に とどく（1体・グループの 技は 0.85倍）
- **雷神の守り** `c.raiGuard`: 3回の 行動の 間、敵の 雷の ダメージの かわりに 半分 回復（`damage` の 中で `r82bDamage`）
- **オート**（ai.js の decideAlly、補助の 前に `r82bPlan`）: 分かって いる 弱点（この 戦いで ためした 属性。四つ玉斬りで 4つ わかる）の 玉に かえる・分からなければ 雷の まま・味方の 雷の 天気なら 天気の 倍率も 数える（1.2倍の 弱点より 雷）。かみなり雲は MP 4わり いじょう・強い 敵・25%。きょだい化は 敵 3体 いじょう
