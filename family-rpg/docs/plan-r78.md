## 2. 3-6 かんたん表示（設計）
- 設定に「メニューの表示：くわしい／かんたん」。**キャラごと**。ふだんは くわしい（今の キャラも 新しい キャラも）
- かんたん で **かくす** もの（技の しくみ 4つの うち 3つ）
  - 覚えた技の「種類／職業」の 切りかえ → 強い じゅんの 1つの 一覧（2列）だけ
  - お気に入りの 並べかえ（つかんで 動かす）
  - 「オートで使う」「命令の一覧に出さない」の 切りかえ（えらぶ ポップアップは「使う／お気に入り／やめる」だけ）
- **のこす** もの: 技を 使う・お気に入りの 入／切・回復／回復以外の 分け・戦闘中の L/R と ブロック移動
- かくすだけ。前に きめた 中み（オートで 使わない 技・命令に 出さない 技・お気に入りの 並び）は **そのまま 効く**・消さない
- ほかの メニューで 子どもに むずかしい 所が ないか 係が しらべて 表に する（足すのは 家族に 聞いてから。今回は 技の 所だけ）
- かんたん の 時は、技の 画面の すみに「かんたん表示（設定で変えられます）」

## 3. 3-10 家族ミッション・家族の 記録（設計）
- **週がわり**: 月曜 0:00（日本時間）に 入れかわる。毎週 3つ。週の 番号から きまる（家族サーバーの 全員が 同じ）
- **数え方**: **人間の キャラが 2人 以上 同じ パーティーに いる 時だけ** 進む（家族の 合計で 数える）。ひとりで 遊んで いる 間は 進まない
  - 例: いっしょに 魔物を ○ひき・いっしょに 戦いに ○回 勝つ・いっしょに 合体技を ○回・いっしょに 宝箱を ○こ・いっしょに 宝の地図の 洞窟を 1つ クリア・いっしょに ボスを 1体
  - 大きさ: 2人で 1〜2時間 いっしょに 遊べば 3つとも とどく くらい。ばつは なし（できなくても 何も へらない）
- **ごほうび**
  - 毎週: 達成した ミッションごとに 道具と お金（強さの バランスに ひびかない 物）。その 週に 1回でも いっしょに 遊んだ 人が 受けとれる
  - 続けて 達成（3つとも 達成した 週の 数）: 2週・4週・8週… で **ここだけの 称号や かざり**（もう ある 見た目の しくみ ＝ チャットの スタンプ など を 使う。強さには 関係 なし）
- **家族の 記録**: いっしょに たおした 魔物の 数・いっしょに 勝った 戦い・続けて 達成した 週・今週の ひとりずつの がんばり・前の 週の 結果。ネタバレに なる 物（まだ たおして いない ボスの 名前 など）は 出さない
- **ひとりで遊ぶサイト**: マルチプレイが ないので 進まない。画面には「家族サーバーでいっしょに遊ぶと進みます」
- 入口: メニュー ＋ 達成した 時の 知らせ。冒険のしおり（3-5）からも 行ける
