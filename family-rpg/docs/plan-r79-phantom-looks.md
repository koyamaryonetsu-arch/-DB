# 第79回 幻の職業の 衣装（12こ）

家族の お願い:「幻の職業の衣装がありません。作って」

## 原因

- キャラの 絵（`render/hero.js` の `paintHero`）は、職業の 服を `hero-outfit.js` の `JOB_OUTFIT`、からだの とくちょう（かみ・オーラ・もちもの）を `JOB_BODY`、
  ぼうしを `hero-gear.js` の `JOB_HAT`、古い 小さな え を `chars.js` の `JOB_LOOK` から とる。
- 伝説の職業までは 回ごとの ファイル（`hero-r29.js`・`hero-r66a.js` など）の 表を これらに まぜて いたが、
  第51回の 幻の職業 12こ（`shared/data/jobs-phantom-*.js`）は 絵の 表が どこにも なかった。
- 表に ない 職業は `JOB_OUTFIT[job] || JOB_OUTFIT.warrior` で **戦士の ふつうの 服（えらんだ 服の 色の チュニック）** に なり、
  からだの とくちょう・ぼうしも なし。はじめの 装備（`STARTER_EQUIP`）も ないので 武器も もたない。
  → 幻の職業に なると、もとの 2つの 職業の 衣装も きえて、いちばん ふつうの すがたに 見えていた。
- 絵は フィールド・メニュー（立ち絵・見た目装備の 見本）・2.5D（`field3d.js` も 同じ 絵を 使う）・戦いの 顔（`faceURL`）で 同じ もの。

## 作り方

- 新しい ファイル `public/js/client/render/hero-r79.js` に 表を まとめ、前の 回と 同じ ところに まぜる
  （`R79_OUTFIT`→`JOB_OUTFIT`、`R79_BODY`→`JOB_BODY`、`R79_HAT`→`JOB_HAT`、`R79_HAIR`→`JOB_HAIR_RAMP`、`R79_OLD_LOOK`→`JOB_LOOK`、
  `R79_MASC`→`masc33`、`AURA79`→`hero-aura.js` の `AURA`）。
- 服の 形・ぼうし・もちもの・オーラは 今 ある 物を 組み合わせる。前の 回の しかけ（`r29` の まえに ひらいた マント・`r33` の マフラーと マントの うら・
  `r40` の 足もとまでの ドレス・`r41a` の メダルと 手ぶくろ）も 表の フラグで つかう。
- 足した 部品（小さく、`hero-r79.js` の 中）:
  - `combo79` … 2つの ぼうしを かさねる（麦わらぼうし＋金の かんむり、探ていの ぼうし＋かんむり。`hero-gear.js` の `drawHeadgear` の さいしょ）
  - `pad79` … まえに ひらいた マントと 金・銀の かたかざり（`drawR29` を つかう）
  - `capeIn` … マントの うらの 色、`holo79` … すける ホログラムの マント
  - `dual79` … こしの 二本目の 刀、`stars79` … マントと ドレスの 星、`sun79` … 頭の うしろの 日輪
  - もちもの `staff79`（王の つえ。玉の 色 `orb79`）・`glass79`（大きな 金の 虫めがね）
  - `hand79` … 両手の 光（左右で 色が ちがう）
  - オーラ `pk79`・`sun79`・`magus79`・`saint79`・`okan79`・`chaos79`（`cols2`: みぎ半分の 色）・`weather79`
- からだの とくちょう（かみ・オーラ・もちもの・耳かざり）は よろいを 着ても のこる。服と ぼうしは 布の服（と 見た目装備の よろい「装備なし」）の とき。
  これは 伝説の職業までと 同じ きまり。
