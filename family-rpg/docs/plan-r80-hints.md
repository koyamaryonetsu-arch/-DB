# 第80回 E班: ボスに 負けた 時の ヒント

> **ネタバレ注意**: この 文書には ボスの しかけの 答え（ヒントの 文）が 書いて あります。家族への 報告・お知らせには ヒントの 文と ボスの 名前を のせない。

## 1. 今の 全滅の 流れ（さわる 前に しらべた こと）

- ボスの 戦いは 台本の `['battle', id]`（`shared/world/scripts.js`）→ `startFixedBattle`（`shared/world/battles.js`）。負けると `finishBattle` の `outcome === 'lose'`:
  - 負けても よい 戦い（`loseOk`。闘技場・リオンの けいこ・時のまぼろし・職業の 試練）… その場で 回復して 物語の つづきへ
  - ひみつのダンジョン … お金は へらない・入口の 広間へ
  - それ いがい（ボスも）… **持って いる お金が 半分**（預かり所の お金は そのまま。`bank.js` の `wipeGoldLoss`）→ けっかの まど →
    `world.respawn`: **いのりの場所**（`char.spawn`。家族で 手伝って いる 人は リーダーの いのりの場所）で **HP・MP 満タン**で 目を 覚ます（「無理はいけませんよ」の おしらせ）
  - 台本は `ctx.resolve('lose')` で 止まる（`scripts.js` の `abort`）。ボスの マスに もう一度 入ると 台本が はじめから
- ひとりモード（`client/offline.js` が ブラウザの 中で `GameWorld` を 動かす）と 家族サーバー（`server/main.js`）は **同じ コード**。ちがいは ない
- 第4幕より 前は、負けても 何の 手がかりも 出なかった

## 3. 流れ

1. ボスの きまった 戦い（`boss: true`・`loseOk` で ない・`solo` で ない・`BOSS_HINTS` に ある）で 全滅 → `bossHintAfter` が その 戦いに 出た 人 みんなの キャラに 1 足す。人ごとに `s.bossHint` を おく
2. いのりの場所で 目を 覚まし、けっかの まどを とじた あと（`world.js` の tick。台本・戦いの 中で ない 時）に、その 人だけの 台本:
   - その 戦いの **ゲスト**（第7章 第1・2幕は カリム・カイ、第8章 第1〜3幕は カリム・カイ・リオン など。いない 時は **トキネ**）が 前おき 1行 ＋ ヒント 1行
   - 前おき: 1回目「さっきの戦い、くやしかったね…。ヒントを1つ、思いついたよ。」・2回目「もう一度、よく考えてみたよ。」・3回目より あと「こうすれば、きっと勝てるよ！」
3. **リーダー**（ひとりの 時は 自分）だけ「どうする？ もう一度いどむ／あとにする」。家族の ほかの 人は「（もう一度いどむかは、リーダーが決めるよ）」
   - もう一度いどむ → 暗く なって ボスの マスの 手前へ。**いっしょに 戦って 同じ 所で 目を 覚ました 家族**も いっしょに → 「この先に、さっきの相手がいるよ。」
   - あとにする → その まま（いのりの場所）。「ヒントは、冒険のしおりの「物語」でも見られるよ」
   - 行き先が 分からない 戦いは えらぶ 文を 出さない（ヒントだけ）
4. 勝つと その 戦いの 数を 消す（その 戦いに 出た 人 みんな）
5. ボスで ない 戦い・闘技場・宝の地図の 主・時のまぼろし・リオンの けいこ・職業の 試練・ヒントの 表に ない ボスには 何も 出ない

## 4. 数え方

- `char.bossLoss = { 戦いの id: 回数 }`（1〜9 で 止める）。**ふだんは 項目が ない**。勝つと その id を 消し、空に なったら 項目ごと 消す
- 物語の フラグには しない（`c7_witch` の ように 戦いの id と フラグの 名前が 同じ 物が ある ため）
- 引っこしコード: キャラ まるごと 入るが、負けて いる 間だけ 十数文字（テストで 60文字 より 小さい ことを 見る）。勝てば もとの 長さ
- 家族で いっしょに 負けた 時: その 戦いに 出た 人 **それぞれ** に 1 足す。ヒントは **人ごとの 回数** で 全員の 画面に 出る（手伝いに 来た 人が 前に 負けて いれば、その 人は 先の ヒント）
- もう 1度 聞ける: 冒険のしおりの「物語」の だん（えらぶと「ボスのヒント1：…」「ボスのヒント2：…」）。1まい目の 物語の らんにも「ボスのヒントがあるよ」。ボスの 名前は 出さない

### 第4幕（B班）の 足し方

## 9. 気を つける こと

- **全滅の 決まりは かえて いない**: ボスで 何回も 負けると、そのたびに 持って いる お金が 半分に なる。子どもが 何回も 挑む ボスでは きびしい かも
  （かえる なら: ボスの 戦いで 2回目より あとは へらさない・へる 上限を きめる など。今回は 報告だけ）
- もう一度いどむ は ワープ なので、いのりの場所（村）から ダンジョンの 奥へ 直接 行ける（歩いて もどる 手間を はぶく ための もの）。HP・MP は いのりの場所で 満タンに なった まま
