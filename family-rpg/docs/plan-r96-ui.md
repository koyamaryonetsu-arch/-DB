# 第96回 U班（画面の使いやすさ）実装メモ

## 家族の声（そのまま）

1. 「道具で装備品を見る時、装備品の紹介が多すぎてスクロール欄が小さくなりすぎる。紹介文は紹介文のスクロールで対応して。装備品の紹介で欲しいのは、強さと効果。必要な情報を見れるように」
2. 「タップすると選択されたことになってしまう。上下コマンドだと移動が遅いから一気にスクロールしたときに、タップで止めるとそれが選択になる。タップの場合は2回目の同じ場所へのタップで選択として。ただし、はい。いいえなどの選択のときは除く」

## 1. 道具のまどの紹介

- 道具のまど（`menu.js` の `itemsList`）に `inv-view` を付け、紹介のらん（`.item-detail`）を**高さ固定**にした（たて・PC: まどの 24%、よこ持ちの低い画面: 30%）。長い時は**紹介のらんの中だけ**スクロールする（`overscroll-behavior: contain`）。前は「中身の高さ・最大 45%」で、品ごとに一覧の高さが変わり、長い紹介では一覧が 3〜5 行になっていた。
- 一覧は残りを全部使う。390×844（たて）で一覧 291px（10 行見える。前は 192px・7 行）。道具のまどの中（わく・すきまをのぞく 467px）の 62%、わくをふくむまど 487px の 60%（下の「計った数」）。
- 続きがある時は紹介のらんの下に「▼」（`dom.js` の `moreMark`。いちばん下まで読むと消える）。お店の説明のまど（`.ct-info`）も同じ。
- 読み方: 指でなぞる・マウスのホイール・**Q・E キー（PageUp・PageDown、コントローラーの L・R）**。PC とコントローラーの時は紹介の終わりに一言。
- 装備品の紹介は `info.js` の `gearSummary`／`gearDetailHtml` で作る。上から:
  1. **強さ**: 装備のまどと同じ作り（`gearRowHtml`: 品そのものの強さは白、今つけている物との差は ↑緑・↓赤）。自分が装備できない品は差なし。
  2. 種類・★とランク・だれが装備できるか（パーティーが 2 人以上なら「装備できる：〇〇・△△」／「みんな装備できる」、1 人なら「装備できる／できない」）。
  3. **効果**（1 つ 1 行）: ふしぎな力・とくせい・とどく広さ・作品の力・玉・使う（技の名前だけ）・形・そろい・生まれ変わる条件・れん金。
  4. その下に今までの紹介（ものがたりの文が先 → もとの強さ・手に入れ方・作品・使う技の説明・そろいの段・装備できる職業の長い文・ふしぎなかじ）。
- 作品の品の文は `shared/gear-r88-view.js` に `r88Parts`（効果の行とくわしい行に分ける）を足した。今までの `r88DetailLines` はそのまま（装備のまど・ほかで使う）。
- 装備ではない道具（薬草など）は今までの文のまま。らんは同じく高さ固定・中だけスクロール。
- お店の説明（`counter.js` の `itemInfo`）も、強さ・ランクの下に同じ「効果」の行を足した。

## 2. タップのきまり

- `ListMenu`（`dom.js`）に `list` を足した。`list: true` の まど（一覧）は:
  - 1 回めのタップ: その行にカーソル（説明のらんもその行に）。決定しない。カーソルがはじめからその行にあっても 1 回めは決定しない。
  - 同じ行をもう 1 回: 決定。ちがう行: カーソルが移るだけ。
  - カーソルが合った時、一覧のまどの下のふちに小さく「もう一度タップで決定」（2.6 秒で消える・ヒントの上はタップが通る）。
  - キーボード・ゲームパッド・画面の十字ボタンは変えていない（上下で動かして決定ボタン）。マウスのクリックはタップと同じ（ダブルクリックで決定）。マウスをのせてカーソルが合っても、1 回のクリックでは決定しない。
- **スクロールを指で止めるタップ・なぞった時**は、カーソルも決定もしない（一覧の種類に関係なく、全部の `ListMenu`）。
  - `document` で `scroll`（capture）と `pointerdown` を見はる。指を置く 0.16 秒前までに、その一覧（か、その上のまど）がスクロールしていた・指を置いている間にスクロールした・指が 12px より動いた → そのクリックはすてる。
  - カーソルの行を見せるためのスクロール（`scrollToSel`・ページ送り・十字キーのスクロール）は数えない（`markProgScroll`）。
- 設定に「**タップ1回で決定：ON／OFF**」（はじめは OFF）。ON で今までどおり（今までの `tapConfirm`: スマホの道具・技・装備は「ちがう行で説明 → もう一度で決定」、カーソルの行は 1 回で決定）。保存は**この端末の localStorage（`kizuna_tap1`）**。文字の大きさ・字の形などの「この端末だけの設定」と同じ所で、キャラのセーブ・引っこしコードには入れない。

## 設計とちがう所・決めたこと

- **メニューの左のコマンド（はなす・道具…）は 1 回**にした。戦いのいちばん上のコマンドと同じ「コマンド」のまどだから。行が多くてスクロールするが、スクロールを指で止めるタップはどの まどでも決定しないので、家族の声の困りごとは起きない。
- **戦いの合体技・魔法剣の一覧は 1 回**のまま（指示の「呪文・特技・道具」に合わせた。合体技は「だれと出す？」が続く選ぶまど）。
- **紹介のらんは「まどの 3 割ほど」ではなく 24%**（たて・PC）。まどの上に分類のタブとならべかえの 2 段があり、3 割にすると 390×844 で一覧が 6 割に届かないため。よこ持ちの低い画面は 30%（一覧の上の「← もどる」が大きく、もともと一覧が 2〜3 行しかない。今回 3〜4 行になった）。
- **お知らせ・困っている人・幻の書・けいじ板**も同じ `.items-view` の作りだが、説明のらん（本文）がそのまどの主役なので、高さ固定はしていない（道具のまどだけ `inv-view`）。タップのきまり（2 回）はそろえた。
- **装備のまどのくらべるまど**（`eq-compare`）は、もともと強さ中心で紹介の文がないので、形はそのまま（2 回タップのきまりだけ）。
- 第2章 第2幕（`c10b`。とちゅうでメインから取りこんだ）の音の鐘「星の音を、えらぶ」は台本の `choice`（`script.js` の えらぶ問い）なので 1 回で決定。スマホのタッチで「やめる」を 1 回タップして閉じるのをたしかめた。第2幕のクライアントの追加（`c10b-view.js`・`battle-c10b.js`）には `ListMenu` の新しい一覧はない。
- 設定の行の文「タップ1回で決定」の「回」「決定」は使ってよい漢字（`kanji-check` 0 件）。
