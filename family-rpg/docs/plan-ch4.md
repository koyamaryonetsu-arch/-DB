## 1. ひとことで

**水の守り星をうばわれた「砂の国」。オアシスはかれ、砂嵐が国をとざし、幼い女王は心を水鏡にとじこめられた。**
紋章の子らは、砂嵐の砂ばくを自分の足でこえ、王家のピラミッドで「月の鏡」を見つけ、大臣の正体をあばき、砂の海賊と手を組んで、砂の海の底の「砂の底の神殿」へいどむ。
待っているのは、四ツ影の3人目 **「水鏡の魔人モルガナ」**。

## 4. 舞台「コガネ地方（砂の国）」

北のシロガネ（白銀）に対して、南はコガネ（黄金）。昼は焼けるように暑く、夜は冷える砂ばくの国です。

```
                 ～～～～～ 風の海 ～～～～～
   ┌──────── 北の海辺（竜がおりられるのは、はじめはここだけ）───────┐
   │   ● オアシスの村ハミル ── 北の井戸（チュートリアル）            │
   │        │            （砂丘）            ▲ 星読みの塔（より道） │
   │   ▼ かれた地下水路                                             │
   │ ═══════════ 砂嵐のかべ（第2幕まで通れない）═══════════          │
   │        │                                                       │
   │   ■ 王都サファラ（宮殿・市場・闘技場）                         │
   │        │        ╲ 岩山                                         │
   │   │ オベリスク   △ 王家のピラミッド                            │
   │        │                                                       │
   │  ⚓ 砂の港ドゥナ（砂の海賊）── ◆ 砂の古城（海賊の試練）        │
   │ ～～～～～～～～ 砂の海（すなかぜ号で進む）～～～～～～～～   │
   │     ◎ 砂の底の神殿（砂の海のまん中、砂の下）   ✦ 砂の古代都市（より道）│
   └──────────────────────────────────────────┘
```

- 行き方：第3章クリアのあと、**風の海の南のはし** から竜でコガネ地方へ（`data/sky.js` に地方を追加）
- **砂嵐**：はじめは竜で飛べるのは北の海辺だけ（第3章のふぶきと同じ `box`）。大臣をたおすと王都・ドゥナの近くまで、モルガナをたおすと全部飛べる。**砂ばくは自分の足で歩かせる** ための大事なしかけです

## 5. あらすじ（6つの幕）

### 第1幕「かわいた村」（Step 1〜2）

1. 竜守りの村でアステルに話すと、南の砂の国のことを聞ける。風の海の南のはしからコガネ地方へ
2. 北の海辺におりると、焼けるような暑さ。オアシスの村ハミルは、ひと月前から水がへり続けている
3. 村の子どもアミが「北の井戸」へ水をくみに行ったまま帰らない → 助けに行く
   - ここで、砂ばくでは **昼と夜で出る魔物がかわる**（夜は強い）ことと、**砂嵐の間は竜で飛びこせない** ことを知る
4. 村の水は「かれた地下水路」から来ていた。おくで **よろい大サソリ** が水をせき止めている
5. 大サソリをたおすと水が少しだけもどる。だが村長は言う。「地下の水そのものが、へっておる…。王都の『水の神殿』の守り星に、何かあったにちがいない」
6. 砂嵐のかべが少しだけ弱まり、王都への道が開く

### 第2幕「王都サファラ」（Step 3）

（2026年10月5日に決めた形。下の「15. 決まったこと」も見る）

1. **王都に着く**：井戸の前に長い行列。宮殿の前のふん水はからから。門番「水は1人1日、コップ1ぱいまでだ」
2. **王都の水の神殿**：守り星の台座がからっぽ。みこ見習いの子「ひと月前の夜、守り星といっしょに、みこのミラさまも消えたの。ミラさまは砂の海賊の一族の人だから、みんな海賊がぬすんだって…」（海賊がうたがわれる理由）
3. **女王ネフィ**：つめたい目で「水の守り星は、砂の海賊がぬすんだのです」とだけ言う。何回話しかけても同じ言葉しか言わない（何かおかしい、と気づける）。大臣ザイード「女王さまはおつかれだ。下がれ」
4. **うわさ集め**：市場・宿屋・井戸の列で話を聞く
   - 「女王さまは、大臣が来てから人がかわってしまった」
   - カギの話「**夜になると**、宮殿の中庭の水がめに、泣いている女王さまがうつるそうだ」
5. **夜の宮殿へ（かれた水路）**：夜は宮殿の門がしまる。水がかれたおかげで歩ける「宮殿の地下水路」（小さなダンジョン。宝箱・夜の魔物）を通って中庭へ
6. **夜の中庭**：水がめの水面に本当の女王「月の鏡で…わたしを…うつして…」
   - 足音がしてかくれると、大臣ザイードが通りすぎる。月明かりにうつった大臣の影が、一しゅんだけ大きな魔神の形に見える（Step 5 の伏線。プレイヤーには見せる）
   - 中庭のベンチに、女王の **絵日記**。「サラとあそんだ日」…海賊の女の子といっしょに遊ぶ絵（ネフィは本当はやさしい子）
7. **サラの初登場**：中庭からの帰り、兵士に追われる少女がムチで屋根にとびのってにげていく。「あんたたち、王国の味方？…ちがうなら、じゃましないで」
   - じつは女王ネフィとサラは幼なじみ。サラは「ネフィがあんなこと言うはずない」と、たしかめに来ていた（第5幕で「あの時の！」と再会）
8. **学者ハサン**：月の鏡は、王家のピラミッドの「王のへや」にねむっている。入口は「太陽が真上に来た時に、オベリスクの影がさす所じゃ」
9. **子どもたち4人の歌**（1人1行ずつ。町のあちこちにいる）：「♪お日さまのぼって、砂がまう。お月さまがねむったら、お星さまがひかるよ」
   → ボタンの順番は **太陽 → 砂 → 月 → 星**。4人ぶん聞くと、目標が「昼の12時ごろ、オベリスクの影がさす所を調べよう」になる（Step 4 へ）
10. そのほか
    - ランク6の店（シャムシール・砂のよろい・砂よけのマント など）
    - 闘技場は建物と受付だけ。「水がもどるまで、大会はお休み」（Step 8 で開く理由）
    - 王都の宿屋は「昼まで休む」もえらべる（Step 4 の日時計のとびらを、長く待たなくていいように）

### 第3幕「王家のピラミッド」（Step 4）

（2026年10月6日に作った形。下の「12. 実装メモ」の「Step 4 で決まったこと」も見る）

- 入口：**昼の12時ごろだけ** オベリスクの影が入口の石をさし、とびらが開く（時間のすずでも合わせられる）
- 1階：4つのボタン（太陽・砂・月・星）。歌の順におす。まちがえると落とし穴でB1（ミイラのへや）へ落ちる（上がる階段はある）
- 2階：**呪文がふうじられたフロア**。入口で昔の探検家のゆうれいが教えてくれる。「ここでは、呪文の力がすいこまれてしまう…」
- 3階：**ありじごく** の迷路。流れる砂の向きを読んで進む。落ちると2階へ
- 4階「王のへや」：ボス **ミイラの王アンク** → **月の鏡** を手に入れる
- かくしべや：**のろいの宝**「王家の黄金の剣」（強いが、取るとピラミッドの中の魔物がたくさん出るようになる。外に出るまで）
- ピラミッドの中では、**みちびきの糸・ルーラ・帰り道の羽が使えない**（来た道を歩いてもどる）

### 第5幕「砂の海賊」（Step 6）

（2026年10月7日に作った形。下の「12. 実装メモ」の「Step 6 で決まったこと」も見る）

1. 砂の港ドゥナ。海賊たちは王国をうらんでいる。谷の見張りに女王の手紙を見せると、かしらの返事で門が開く。バルガは手紙を読んでも「口だけなら、何とでも言える」
2. むすめのサラ：「母さんは、水の神殿にいたの。きっと、まだ生きてる」→ **サラが仲間になる（ゲスト）**
3. バルガの試練：**砂の古城** から、ぬすまれた「船のかじ」を取りもどす（古城へは、町の東の門から。門はサラが仲間になると開く）
   - 古城には **2つのスイッチを同時にふむ** しかけがある（家族なら2人で、ひとりならサラや馬車の仲間が手伝う。第3章の「きずなの間」と同じ考え方）
   - 作った形：1階の北の広間の西と東のすみに石の板が1つずつ（23マスはなれている）。そろうと北の鉄のこうしが上がる。2階のたからべやで、古城のよろい2体をたおして船のかじ
4. バルガ「…むすめが、あんたたちを信じると言うなら」→ 砂の船 **すなかぜ号** で砂の海へ
5. 航海のとちゅうで **砂クジラ** がおそってくる（船の上でボス戦）
   - 作った形：砂の海のまん中の「クジラのねどこ」（砂のうず）に近づくと、砂クジラが目をさます
6. たおすと砂クジラは正気にもどり、「砂の底の神殿の入口は、わたしがねむっていた所の下だ」と教えてくれる
   - 作った形：力がもどるまで待ってほしいと言う（ここで「第4章の続きはアップデートで！」）。ドゥナのさんばしへもどり、サラはパーティーからはなれて、さんばしで待つ

### 第6幕「砂の底の神殿」（Step 7）

1. 砂の下にしずんだ神殿。中には国じゅうから集められた水がためこまれ、大きな水の迷宮になっている
2. **水位のしかけ**：3つのレバーで水の高さを上げ下げすると、通れる道がかわる（第3章の火山のレバーの水版）
3. **鏡の間**：「鏡の騎士」は、体が光った時に呪文をはね返す。物理と呪文を使い分ける
4. 中ほどに **いやしの泉** が1つだけ（入るたびに1回）。糸・ルーラは使えない
5. 最深部：水のろうにとじこめられたミラ。そして **水鏡の魔人モルガナ**
6. ボス戦：**モルガナ** → ミラのいのりで全回復 → **モルガナ（真の姿）**
7. モルガナ「…四ツ影は、もう1人だけ。でも、最後の1人は、わたくしたちとは、ちがう…」
8. 水の守り星を取りもどすと、ためこまれた水が国へもどる。王都のふん水がふき上がり、ハミルのオアシスに緑がもどる
9. 王都で、女王とバルガが手を取り合う。サラとミラの再会
10. アステル「4つの守り星が光った。…残るは、大地の守り星。そして、最後の影」 → **第4章クリア**

## 6. 難しさの設計

### 方針

1. **強さだけでなく「考える」で難しく**：なぞ（歌の順番・日時計・水位）、資源の管理（MP・回復の道具）、ボスのくせを読む
2. **前ぶれのない大技は出さない**：大きな攻撃の前には必ずメッセージが出る（今の `telegraph` のしくみ）。気づけば防げるから、負けても「次はこうしよう」と思える
3. **レベルを上げても、しかけを無視すると負ける**：例えば大波は防御しないと大ダメージ、分身をむやみに攻撃するとボスが回復する。目安は「おすすめより5レベル上でも、しかけを無視すると全滅しうる」
4. **やり直しやすく**：失敗しても失うものは少なく（落とし穴は1つ下の階）、すぐもう一度ためせる

### 3つのかべ

| かべ | どこ | 何がむずかしいか |
|---|---|---|
| 1つ目 | 王家のピラミッド | 糸もルーラも使えない4階建て。呪文のふうじられたフロアで、呪文たよりのパーティーは作戦を変える。最後にボス |
| 2つ目 | 大臣ザイード | まぼろしの分身。月の鏡の使い方に気づかないと、むだに攻撃して反撃を受け続ける |
| 3つ目 | 砂の底の神殿＋モルガナ | 回復は泉1つだけの長いダンジョン。そのあと、水の衣・分身・鏡写し・大波を全部使う2段階のボス |

## 7. ボス

### よろい大サソリ（Step 2・かれた地下水路）

- 段階：HP50%でサソリ兵を2体よぶ／HP25%で攻撃力アップ、毒のしっぽ（全体・毒）をおぼえる
- 落とす物：サソリのブローチ（毒を防ぐ）

### ミイラの王アンク（Step 4・王家のピラミッド）

- 行動：攻撃／ミイラの手（1人のMPをすう）／王の呪い（全体・毒とマヌーサ）

- 落とす物：王家のうでわ
- Step 4 で決めた形：アンクがたおれると王のミイラ兵もくずれおちる。王の呪いにも前ぶれ（目があやしく光る）をつけた。数値とシミュレーションは「12. 実装メモ」の「Step 4 で決まったこと」

### 大臣ザイード → 砂の魔神ザイード（Step 5・夜の宮殿）

  - 3ターンごとに「ザイードはまぼろしを作り出した！」で分身が復活

- **第2段階 砂の魔神ザイード**：Lv36・HP7000。2回行動

  - 前ぶれ：「ザイードの体のまわりで、砂がうずをまき始めた…！」→ 砂の大うず（全体・大）
- 落とす物：魔神のランプ（使うと1回だけ全員のMPを少し回復するアクセサリ）
- Step 5 で決めた形：2つの戦いのあいだに、月の鏡の光で HPは全部・MPは3わり回復（これがないと、つづけて勝てる人がほとんどいなかった）。月の鏡の「3ターンに1回」は **本物のザイードが3回動くまで**、分身の復活は **分身が消えてから本物が3回動いたら**（1つ前の番に前ぶれ）。魔神は HP5800 にした（技の見なおしのあと HP5400）。数値とシミュレーションは「12. 実装メモ」の「Step 5 で決まったこと」
