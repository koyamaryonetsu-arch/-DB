# 第76回: 装備の「もとの強さ」と、大きな画面（装備・お仕事いらい板）

## 家族のねがい

1. 装備を鍛えると、元々の武器の強さがわからなくなる。装備を変える時に、装備品が持つ基礎数値も見えるようにして。
2. 職業のいらいごとは、もっと大きくポップアップを作って。いらいごとにしろ装備品の変更にしろ、画面を大きく使って見やすく。

## 1. もとの強さ（shared/gear-base.js）

- `gearBaseId(id)`: きたえた装備（`x+3`）・限界とっぱ（`x+5_lb2`）から、もとの装備の id（items.js の `baseItemId`）
- `forgeLevel(id)` / `forgeLabel(id)`: きたえた回数（★も 1回。+5★2 は +7 と同じ強さ）と「+5★2」
- `gearOwn` / `gearOwnBase`: その装備そのものの強さ（外した時との差）。もとは きたえ・★・れん金（`char.gearFx[もと]`）をぬく
- `sameForgeId(id, level, char)`: もとの装備を level 回きたえた時の id。かじの表（`maxPlus` ＋ ★`LB_MAX`、生まれ変わる武器は `rebirthOf().at`）で止める。
  れん金で回数をふやした人は ★なしで届く。店の品（★1）は `none`
- `gearCompare(char, slot, cur, cand)`: くらべるまどの数字（今・もと・差・同じだけきたえると）
- `baseStronger`: もとの装備どうしの くらべ（`gearScore` と同じ。れん金もぬく）

「同じだけきたえると」は かじの表（`upgradedItem` で決まる数字）から出せるので のせた。
れん金の効果は その人の その装備のしゅるいに のこるので、きたえた先でも同じに数える。

### 画面

- 装備をえらぶまど（menu.js の `pickGear`）: 一覧の強さの よこに「もと+68」（きたえた・れん金の物だけ）。
  今は弱いが もとが今の装備より強い物に「もとが強い」（おすすめは今までどおり 今の強さで決める）
- くらべるまど（client/ui/equip-compare.js）: 今の装備 → これ。強さごとに「今／もと」の表と ↑↓。
  今の装備のほうが きたえてあれば「今の装備と同じだけ（+5★2）きたえると 攻撃力+144↑15」
- 道具・装備のせつめい（info.js の `itemDetail`）にも「もと：攻撃+68（きたえる前）」

## 2. 大きな画面

- 装備をえらぶまど: 画面いっぱい。よこ画面は 左に一覧・右にくらべるまど、たて画面は 下にくらべるまど。
  タッチは 1回目のタップで くらべるまどに出して、もう一度で装備（`tapConfirm`）
- お仕事いらい板の一覧（せつめいのある `choice`）: まん中に大きく。よこは右・たては下に せつめい
- はり紙（client/ui/paper-pop.js）: 何ページものメッセージを やめて、大きなまど 1まいに
  （たのみごと・会う人と場所・職業の系統と ○いる／×いない・ごほうび・大きなボタン うける／やめる）。
  サーバーは `choice` の 5つ目に はり紙の中み（sidequests-family.js の `boardPaper`）をつける。
  受けているはり紙は「いらいをやめる／つづける」（カーソルは つづける）、すんだはり紙は「もどる」
- 大きなまどの あいだは 下のメッセージを かくす（`body.big-choice`）
