## 3. しくみ（`shared/battle-r85a.js`。どれも 戦いの 中だけ・キャラにも セーブにも 項目を 足さない）

1. **となえる**（戦いの 人の `c.r85aChant = { left }`）
   - となえて いる 間だけ 大砲の 呪文（`effect.r85aBig`: ドラグ・スレイブ・ラグナ・ブレード・ギガ・スレイブ）が えらべる。
     となえて いないと: 命令の 一覧で **うすく なり「となえてから」の 札**（client/battle-r85a.js の `r85aRow`）・battle.js の validate が「先に「となえる」を使おう」で ことわる・**オートも えらばない**（ai.js の canUse）
   - 大砲を うつと 消える。**ふつうの 呪文（magic）を うった 時は、その 呪文が 1.5倍（`CHANT_BOOST`）に なって 消える**（設計の「次の 呪文も 強く なる」）
   - **つづく 長さ**: となえた あと 自分が **3回 行動する まで**（3回めの 行動の おわりに 消える。`CHANT_LEFT`）。
     呪文で ない 行動（攻撃・特技・回復・道具・身を 守る・食べる）では 消えない（身を 守るのも 1回に かぞえる）。もう一度 となえると のこりが 3に もどる
   - **消える 時**: たおれた（damage で HP 0）・ねむり・マヒ・混乱・呪文ふうじ・水のろう・地われ の まま 自分の 番が 来た。ねむり・マヒ・呪文ふうじの 間は 大砲も えらべない。
     **身を 守れない わけでは ない**（ふつうに 動ける）
   - 札: 仲間の まどに 金色の「となえ3」（のこりの 行動の 回数。pub の r85aChant。家族 みんなの 画面）。となえた 時は まどが 金色に 光る
   - となえるは `spellLike`（呪文ふうじ・呪文が ふうじられた 場所では 使えない）
   - **ほかの 職業に 転職した あと**: 「となえる」と 大砲の 呪文を 覚えて いれば、だれでも おなじ きまり（強さは 今 ある 転職の ペナルティ）
   - **早口**（ドラまたの `passive.hayakuchi` 0.25）: となえた ターンに 25% で すぐ もう 1回 動ける（行動ゲージ 100）。「早口！すぐに動ける！」
   - 敵の がわ（職業の試練の まぼろし・鏡の うつし身）は となえずに 大砲を うつ かわり、力は 半分（`ENEMY_BIG` 0.5 ＝ 2ターンで ならした 強さ）。まぼろしは となえるを 使わない（battle-trial.js の NO_USE）
2. **ギガ・スレイブ**（`effect.r85aGiga`）: のこりの MP を 全部 使う（はらった 40 ＋ のこり）。1体ごとの ダメージ ＝ 使った MP × 4（`GIGA_PER`）× 魔力の 倍、
   **上限 4000（`GIGA_CAP`）・ボスは その 最大HP の 3わり（`GIGA_BOSS`）まで** → MP 999 でも ボスを 1発で たおせない。属性 なし。うった あと MP は 0（定食で 回復と 組）。画面の 上に「ギガ・スレイブ！（MP416）」
3. **ラグナ・ブレード**（`effect.r85aPierce`）: 敵の「ききにくい」（闇の 属性が 1 より 小さい）と 身を 守るを むしする。
   呪文には もともと 守備力が きかないので、「守りを 無視」は 呪文の 守り（ききにくい・身を 守る）を むしする 形に した。
   **効かない 属性（0）と ボスの しかけ**（かまえ・前ぶれ・形態・水の衣 など damage の 中の しかけ）は そのまま
4. **食べて 回復**: 大もり定食（MP いらない・自分 HP 70〜86・MP 12〜18）／特もり定食（MP 4・仲間全員 HP 56〜70・MP 6〜10）。
   1回の MP は 大砲 1発（となえる ＋ 36〜40）より ずっと 少ない（大砲を うち続けられない）。どちらも `noAuto`（ふつうの オートの 回復には 入れない。安い 回復を 何十回も 使って しまった ため。下の 5）
5. **お金**: とう賊たいじ（今 ある `hooks.gainGold`。楽天カードの ポイントバックと おなじ しくみ。当てた 敵の お金 ×0.5）。
   ドラまたの `passive.gold: 1.2`（今 ある しくみ。world/battles.js は パーティーで **いちばん 大きい 倍率だけ** なので 足し算に ならない）
6. **フレア・アロー**（`effect.r85aHits`）: ばらばらの 敵に 4本
7. **オート**（ai.js の decideAlly の 4.97: `r85aPlan`。この 系統の 技だけを 見る。わりあいは `R85A_AI`）
   - となえて いる → 大砲: ボスに とどめが させる 時・敵が 2体 いじょうで MP 8わり いじょう → ギガ・スレイブ／敵 1体 → ラグナ・ブレード／ほか → ドラグ・スレイブ
   - MP が 少ない（大砲 ＋ となえる ぶんが ない・3わり 未満）・HP が 3わり 未満 → 定食（60%。みんなの MP が 少ない 時は 特もり定食。1回の 戦いで 30回まで）
   - ボス・こわい 敵（fightWeight の threat 0.13 いじょう）→ となえる（85%）。**ざこ・HP が 多い だけの 敵**（かかし など）には となえず、ふつうの 呪文
   - **前ぶれが 見えて いる 時は となえない**（今の きまり〈5: 身を 守る〉に まかせる）
   - 運（rng）を 使うのは この 系統の 技を もつ 時だけ（ほかの 職業の オートは かわらない。テストで たしかめた）

battle.js に 足した 行: import・身を 守る（2行）・validate（大砲の ことわり）・executeNext（行動の はじめ・行動の あと）・'magic' の はじめ・case・damage・pub。
ai.js: import・canUse（1行）・4.97（2行）。

## 7. 気を つける こと

- **大砲は「2ターンで 1発」**: となえる ターンは 何も 与えない。早口（ドラまた 25%）で 1ターンに なる ことが ある。となえた あとに ふつうの 呪文を うっても 1.5倍で 消える
- ラグナ・ブレードの「守りを 無視」は 呪文の 守り（ききにくい 属性・身を 守る）を むしする 形（呪文には もともと 守備力が きかない）。効かない 属性と ボスの しかけは こわさない
- ギガ・スレイブは MP を 全部 使うので、オートは「とどめ」か「敵が 多くて MP が たっぷり ある 時」だけ。家族が 手で うつ ときも、うった あとは 定食で MP を もどす
- 定食は ふつうの オートの 回復には 入らない（noAuto）。家族が「作戦」で 定食を「使わない」に すると、オートは 食べない
- 引っこしコード: キャラに 項目を 足して いない。職業 3つ・技 21こ（ひらめき こみ）で いちばん 大きな セーブは メインを 2回 取りこんだ あとで 28338文字（3通。見はりの「4通の 90%」の 中）
- 神殿の せつめいの 伝説の 一覧（client/ui/services.js）・お知らせ・README は さわって いない。スレイヤーズの 系統の たのまれごと（お仕事いらい板）は まだ ない
- メインの ブランチ（claude/elegant-bell-al2f1w）を 2回 取りこんだ（1回め 第84回 A班〈幽☆遊☆白書〉・2回め 第85回 B班〈烈火の炎〉。`108fff3a4`）。ぶつかった 23ファイルずつ、両方 のこした。
