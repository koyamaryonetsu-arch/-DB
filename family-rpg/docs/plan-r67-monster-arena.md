# 第67回: モンスター闘技場（2026-11-07 家族が 決めた）

## 家族が 決めた こと

- **新しい 建物**「モンスター闘技場」。魔物が 仲間に なる ころから 遊べる（`monster_bond`。第1章の 森の主の あと）
- 戦うのは **自分が 育てた 魔物だけ**（人は 戦わない）。**4ひき**。動き方は ふだんと 同じ（その 魔物の 作戦。「めいれいさせろ」なら 自分で コマンドを 選ぶ）
- **ランク戦**: ランク F〜S（物語が 進むと 開く）＋ あとで 伝説の部。1つの ランクは 休みなしの 3連戦（サファラ闘技場と 同じ 形）
- **家族どうしの 対戦**（両方 作る）
  1. **登録チームと 戦う**: 家族が 登録した 4ひきと、いつでも 戦える（相手の 魔物は 作戦で 動く。相手が 遊んで いなくても よい）
  2. **その場の 対戦（リアルタイム）**: 2人とも 闘技場に 行って、申しこむ → 申しこまれた 人が うける → おたがい コマンドを 選んで 戦う
- **パーティー選びは ストレスなく**: 戦う 前に いつでも 4ひきを 選びなおせる。登録チーム・前回の チーム・おまかせ（強い 順）から 1回で 選べる。登録チームも 戦う 前に かえられる
- 家族対戦の 強さは **申しこむ 時に えらぶ**:「そのままの 強さ」か「レベルを そろえる（みんな 同じ レベル）」

- **ながれ**（`svc kind:'monlive'`、`op`）
  1. 受付の「その場で家族と対戦」→ `list`（今 マップ `monarena` に いる 家族。魔物が いない・戦っている・話し中は えらべない）→ 相手 → 強さ（そのままの強さ／レベルをそろえる）→ `invite { sid, even }`
  2. 相手の 画面に まど（`{ t:'monLive', state:'ask' }`）。原っぱ・メニュー・受付の 画面の 上に 出る（ほかの 人と 話している 間・戦いの 間は 出せる まで 待つ）。のこり びょうも 出る。
     「受ける！」→ `answer { ok:true }`（メニュー・受付の 画面を とじて、司会の カウンターで 4ひきを 選ぶ）／「ことわる」。30びょうで 時間切れ。申しこんだ 人は「申しこみをやめる」も できる
  3. 2人とも A班の 4ひきを 選ぶ 画面（前回・登録・おまかせ。タイトルに 相手）→ `team { team }`（前回の チームにも なる）→ 相手を 待つ（「チームを選びなおす」`unready`・「対戦をやめる」`cancel`）。3分で 時間切れ
  4. 2人とも 決まると `state:'go'` → 2人とも カウンターを とじて、受付の だいほんが おわったら（`busy` が ない）戦いが はじまる（15びょう まっても だめなら なし）
  - 知らせは かわった 時と 2.5びょうごと（とぎれても 立てなおせる。画面は 9びょう 知らせが ないと「通信がとぎれた」）。闘技場を はなれた・20びょう 以上 とぎれた・戦いを 始めた 人が いると その 話は なし
  - 画面を ✕で とじた 時は へんじの いらない `cancel { quiet:true }`（ほかの 窓口の へんじと まざらない）
- **戦い**: 申しこんだ 人（a）の 魔物が みかたの がわ・受けた 人（b）の 魔物が 敵の がわ（B班の `MonArenaBattle` の `foes`。「めいれいさせろ」の 魔物は controller が b）。
  どちらも 作戦で 動き、「めいれいさせろ」の 魔物は もちぬしが コマンドを 選ぶ（ふだんと おなじ オートの ボタン・戦いの 中の 作戦の 変更も できる。b の 魔物の 作戦も もとの 仲間に のこる）。
  道具なし・にげられない・経験値と お金なし・もとの 仲間の HP は へらない。速さは 2人の おそい ほう、ウェイトは どちらかが ウェイトなら（b が えらぶ 間も 止まる。`humans()` に 敵の がわも 入れる）
  - **b の 画面**: サーバーが 敵と みかたを 入れかえて 送る（`mirrorSnapshot`・`mirrorEvents`。pub の side・fx.side・end の 勝ち負けを 入れかえ、b の 魔物には 技・作戦・魔力などの 項目を 足し、a の 魔物は しゅぞくの 絵で 敵に）。
    名前は 見る 人ごと: 自分の 魔物は そのままの 名前、相手の 魔物に 同じ 名前が あれば「ランスA」（文の 中の 名前も 入れかえる）。クライアントの 戦いの 画面は かえていない
  - 文の 言い方（「〇〇に12のダメージ！」と「〇〇は12のダメージを受けた！」）は a から 見た まま（名前だけ 入れかえる）
  - 通信が とぎれた 人の 魔物は オート（もどったら もとの 設定・b は 入れかえた 見え方で つづき）。20びょう もどらない・ゲームを やめた 時は のこった 人の 勝ち（記録には のこさない）
- **おわり**: 2人とも 戦いの けっかの まど（「〇〇の魔物たちに勝った！」／「負けてしまった…いい勝負だったね！」・「〇〇とのその場の対戦：1勝0敗」）。
  記録は `c.monArena.live[相手の キャラの id] = { w, l, first }`（登録チームとの 対戦の `fam` とは べつ）。はじめて 勝った 時だけ 小さなメダル 1まい（`monarena_live_<charId>`）。受付の 一覧に 相手との 記録が 出る
