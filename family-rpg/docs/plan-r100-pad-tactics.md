# 第100回 U1: コントローラーで 戦いの 作戦を かえる

家族の 声: 「コントローラーでプレイ中、戦闘中の作戦を変更できません。変えられるようにして」

## わけ

- たしかめた こと（にせの コントローラー・標準の ならび・ブラウザで 本当の 戦い）
  - SELECT（ボタン 8）→「戦いのメニュー」→ 仲間の 作戦 → A は、待って いる 時・コマンドの まど・技の 一覧・前ぶれで 待つ 時・自分が オートの 時の どれでも 通って、サーバーの 作戦も かわった。
  - 作戦の まどは `list` なし なので、A 1回で 決まる（第96回の 2回タップの えいきょうは なかった）。
- だから こわれて いた のでは なく、**道が 見つからなかった・とどかなかった** と 見る（うたがい）
  - SELECT を おす ことは 画面の どこにも 書いて いない（「オート」ボタンの title だけ。スマホ・コントローラーでは 見えない）。
  - SELECT の ない コントローラー・ボタンの 番号が ちがう コントローラー（`gp.mapping` が `standard` で ない 物）では、SELECT の 道が ない。
  - 合体技の さそいの 間は 戦いのメニューは 開かない（今までどおり。さそいに こたえる のが 先）。

## かえた 所

- `client/battle.js`（小さく）
  - コマンドの 一覧の さいごに「作戦」（`items.push(TACTICS_CMD)`）・行き先 `case 'tactics': return battlePadMenu(this);`
  - 作戦の まどで 同じ 作戦を えらんだ 時の 知らせ（`tacticsToast`）。かえた 時は 前から サーバーが「〇〇の作戦を「…」にした。」を 出す。
- `client/battle-pad.js`
  - `TACTICS_CMD`・`battleStart`（START の はたらき）・ヒント（「オート」の 下の「SELECT／START：作戦」。`input.pad.on` の 時だけ。おすと 戦いのメニュー）。
  - 戦いのメニューの 仲間の 行の 右に 今の 作戦の 名前。
- `client/input.js`: START（9）を 先に `hot('start')` に わたす。うけとらなければ 今までどおり B。`hot` は 戦いの 中だけ あるので、フィールドの START（メニュー）は かわらない。
- `client/ui/menu.js`: 設定の 操作の せつめいに 1行（タッチ・キーボード）。フィールドの 作戦の 一覧に「今」。
- `css/style.css`: ヒント・「作戦」の 文字の 色（水色。点線は えらべない 物の しるしなので 使わない）。

## ならび

コマンドの まどは 2列。「作戦」は いちばん さいご（いちばん 上に 出る コマンド・合体技・いれかえ が あっても さいご）。
「音を鳴らす」の ある 戦いでも、スマホ（390×844）・PC（1280×800）とも 5行で まどに 入った（はみ出し なし）。

## ボタンの 表（戦いの 中）

| ボタン | まどが ない（待つ・オート） | コマンドの まど | 技の 一覧など ほかの まど | 戦いのメニュー・作戦の まど |
|---|---|---|---|---|
| 十字キー・A | ― | 「作戦」を えらぶ → 戦いのメニュー | ― | えらぶ・決める（A 1回） |
| B | ― | ― | もどる | とじる（コマンドの まどに もどる） |
| SELECT（8）・M キー | 戦いのメニュー | 戦いのメニュー | 戦いのメニュー | とじる |
| START（9） | 戦いのメニュー（**新**） | 戦いのメニュー（**新**） | もどる（今までどおり） | とじる（今までどおり B） |
| タップ・クリック | 味方の つよさの まど・ヒント | 「作戦」・味方の つよさの まど | 味方の つよさの まど | 1回で 決まる |

フィールドの START は 今までどおり メニュー。
