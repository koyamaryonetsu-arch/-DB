# 第71回: 階段の 真上に つく・作れる魔物の 絵（メモ）

> ダンジョンで、階段を上り下りした時、始まるのは、階段の真上から始まるようにして。
> 今だと、階段の隣のマスから始まるので、意図せず階段を往復してしまうことが多々ある。

> 作れる魔物から選ぶ時、選ばられる魔物は名前だけじゃなく、イラストも見せて

## 1. 階段の 真上に つく（shared/world/stairs.js・world.js の onEnterTile）

- マップの データ（`warps` の `to`）は かえない。ワープを ふんだ 時に `warpLanding(fromMap, warp, hasFlag)` で つく 所を きめる。
- 階段から 階段への ワープだけ（`stairsAt`: STAIRS_UP / STAIRS_DOWN。フラグで あらわれる 階段〈gate の open / closed / levels〉も）。
  - 行き先の 階段（`stairsPair`）… 行き先の マップの 階段の ワープで、もとの マップへ もどる もの。`to` から 2.6マス いない・その 行き先が もとの 階段から 3.2マス いない・いちばん 近い もの。
  - とびら・町の 入口・洞窟の 入口・フィールドへの 出口（階段から 井戸・ほこらの 外 など）は これまで どおり（となりの マス）。
  - 行き先の 階段に 立てない（とじた とびら・宝箱・人）・階段から これまでの つく マス（`to`）へ 4歩 いないで 行けない
    （影の城 4・8・12階の 封印の とびらの おくの 階段 など）ときも これまで どおり。とじこめない。
- ついた 階段は `s.stairGuard`（その 階段と、つながっている 階段の マス。2マス はばの 階段）。ほかの マスへ 1歩 うごくと とける。
  そのあと もどって ふむと いつもどおり 上り下り。`placeSession` で いつも とける。
- ついた ときの しかけ（「○階に 来た」など）は これまでの つく マス（`to`）で みる（`checkTriggers`）。おなじ 時に 2回 うごかない。
- ついていく 家族（`warpFollowers`）は これまでどおり 出入り口の 上には 置かない（階段の まわり）。
  クライアント（client/field.js）: ついていく 自動の 歩きは 出入り口を ふまない（`followAuto`・`warpBlocks`・みちさがし・パンくず）。
  リーダーが 階段を 使うと サーバーが いっしょに つれていく。
- しかけの きまりの なおし:
  - 流れる ゆか・風（maps/flow.js の `flowReach`）: 出入り口の 上から 始めても そこから 歩ける（影の城 2階 など）。
  - 時の砂時計（world/time-glass.js の `glassCheck`）: 階段の 上で 使うと、むこうの 時代も 階段なら となりの 立てる 所に 出る（星めぐりの古道 3階 など）。
- しらべた マップ: 階段の ワープ 298 の うち ペア 291（のこり 7つは フィールドへの 出口）。宝の洞窟（`tm_…`）は どれも ペア。
  ひみつのダンジョンの 階（`sd_…`）は ワープでは なく 下りるだけ（台本）なので かわらない。
- みちびきの糸・リレミト・ルーラ・帰り道の羽は マップの `to` を 使う ので かわらない。
