# 水の属性（第47回。2026年10月25日）

家族の声：ポケモンや ほかの技にも 水の技が たくさん あるのに、属性が ない。水の属性を 足してほしい。

## 1. しくみ

- 属性 `water`（名前は「水」）。`data/abilities.js` の `ELEMENT_NAMES`・`ELEMENT_ORDER`（氷の すぐ あと：炎・氷・水・風・爆発・雷・光・闇）
  - `ELEMENT_ORDER` を 使う ところ（図鑑の「属性」の行・見える化・弱点を 見る・推理）は そのまま 水も 出る
  - 推理（`abilities-jobs6.js` の `deduceElement`）の ならびにも 水。同じ 強さの 弱点なら 前の 属性（氷が 先）
  - 仲間の 魔物の たいせいの 下限 0.3（`stats.js`）・装備の とくせいの 文（`rare-loot.js`）にも 水
- 画面：しるしの 色 `.elem.e-water`（`#4f8cff`。氷の `#8ad8ff` より こい 青）。えんしゅつの 色は `ELEMENT_FX.water`（その 属性だけの 色 `#2f7bff`）・`ELEM_COLORS`・`ELEM_COL`。味方の まどの 形と 敵に 当たった 形は 氷と おなじ（水しぶき）
- 古い セーブ・水の ない データ：`resist.water` が なければ `?? 1` で ふつう。図鑑の 水は「？」から（ためすと `el_water`）

## 3. 魔物の 水の 効きぐあい（`data/water.js`）

`monsters.js` の さいごで `applyWater(MONSTERS)`。数えない 形の 魔物も ふくめて、すべての 魔物に `resist.water` を 書く（ふつうも 1）。
上から じゅんに 見て、さいしょに 合った もの。

| じゅん | きまり | 水 | 名前（`WATER_RULE`） |
|---|---|---|---|
| 0 | データに `resist.water` が 書いてある | その かず | data |
| 1 | 1体ずつ きめた もの（`WATER_OVERRIDE`） | 表の かず | override |
| 2 | メタル（炎〜闇が みんな 0） | 0 | metal |
| 3 | 水の 魔物（`WATER_SEA`。海・ぬま・魚・カニ・カメ・くらげ・イカ・水の 竜） | 0.5 | sea |
| 4 | 炎の 魔物（炎 0.5いか かつ 氷 1.2いじょう。`WATER_FIRE` も） | 1.5（竜は 1.25） | fire |
| 5 | 砂・土の 体、砂の 中に すむ（`WATER_SAND`） | 1.5 | sand |
| 6 | 岩・石の 体（`WATER_ROCK`。いちばんの 弱点は 今までの 爆発など） | 1.25 | rock |
| 7 | からくり・機械・鉄（`WATER_MACHINE`。さびる。いちばんの 弱点は 今までの 雷） | 1.25 | machine |
| 8 | 氷の 魔物（氷 0.5いか） | 0.75 | ice |
| 9 | 植物（race plant） | 0.75 | plant |
| 10 | ほか | 1 | none |

- **ボス**：水の 弱点は 1.25まで。そのうえ もとからの いちばんの 弱点（炎〜闇で いちばん 大きい かず）を こえない（`+boss`）。きめた ボスの 作戦（この 属性が 効く）は かわらない
- **ポケモン**：タイプの とおり（ヒトカゲ・リザード・リザードン・ブースター 1.5／ゼニガメ・カメール・カメックス・シャワーズ・フシギダネ・フシギソウ・フシギバナ 0.5／ほか 1）
- **色ちがい**：もとの 魔物の `resist` を うつすので、もとと おなじ
- 1体ずつ きめた もの：第6章の ボス（サンドクロック・ギアドン・カリヨン。しかけで 調整ずみ）は 1／からからガエル（ひからびて いる）は 1
