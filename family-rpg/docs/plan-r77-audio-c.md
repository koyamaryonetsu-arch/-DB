# 第77回 C: 場面で かわる 音楽を ゲームに つなぐ

> エンジンの API と 決まりは `docs/plan-r77-audio.md` の 5。ここは C が きめた わりあてと つなぎ方。

## 0. まとめ
- 新しい ファイル `public/js/client/audio-scene.js`: 「今の 場面 → 音の 設定」を きめる 純粋な 関数（node で テスト）＋ `SceneAudio`（ゲームから よばれ、かわった 時だけ `game.audio` を よぶ。同じ 値は 送らない）
- つないだ 所: `battle.js`（戦いの 曲・ピンチ・だん・おわり）・`game.js`（`SceneAudio` を 作る・フィールドで まいフレーム（250ms ごと）・曲を 鳴らした すぐ あと）・`ui/script.js`（文字の 音）・`ui/menu.js`（設定「まわりの音：あり／なし」）・`audio.js` の `GameAudio`（まわりの音の あり／なし だけ）
- 「前の音」: 戦いの 曲の id だけ かわる（`legacy` で 前の battle が 鳴る）。ほかは エンジンが 何も しない。まわりの音も 鳴らない

## 1. 戦いの 曲（`battleBgm`）
サーバーは フィールドの ふつうの 戦いにも `snap.bgm = 'battle'` を 入れる。だから `snap.bgm` が `'battle'` か ない 時だけ えらぶ（ほかの `snap.bgm`・ボスの `'boss'` は そのまま）。

| じゅん | 曲 | いつ |
|---|---|---|
| 1 | `snap.bgm` | `'battle'` 以外の 曲が きまって いる（ボス・神殿の 戦い など） |
| 2 | `boss` | `snap.bgm` が なく、ボス戦 |
| 3 | `battle_strong` | 強敵（下の 表） |
| 4 | `battle2` | 第2部の 場所 |
| 5 | `battle` | ほか |

`battle2`・`battle_strong` が `_TRACKS` に まだ ない 時は `battle`（B1 が 足せば そのまま つかわれる）。

### 第2部の 場所（`isPart2Map`）
- マップに `past`（`true` 千年前／`false` その 今の すがた）が ある 所 … 時のいせき・星めぐりの古道・止まった時計塔・第7〜8章の ダンジョン（千年前・今の すがた とも）・千年前の フィールド 4つ
- id が `overworld_past` `toki_shrine` `toki_ruin` `hoshimichi` `tokei_` `c7_` `c7s_` `c7i_` `c8a_` `c8b_` `c8c_` で はじまる 所（`past` の ない 時のほこら も ここで 入る）
- 第1部の フィールド（今の ミドリナ・海・シロガネ・コガネ・クモイ）は 第2部の とちゅうで 行っても `battle`

### 強敵（`isStrongBattle`。ボス戦は ふくまない）
| どれ | 見分け方 |
|---|---|
| 宝の地図の 洞窟 | マップの id が `tm_` |
| ひみつのダンジョン | マップの id が `sd_` |
| モンスター闘技場（チャンピオン 以外） | マップの id が `monarena` |
| 物語の きまった 戦い（闘技場の 試合・たのまれごとの 戦い・待ちぶせ など） | `battleStart` の `story`（サーバーの `opts.fixed`）で ボスでは ない |
| 強い 特別な 魔物が まざった 戦い | 敵の だれかの `MONSTERS` に `boss`・`tmBoss`・`phases` が ある |

## 2. ピンチ（`nextPinch`）
- 生きて いる 仲間（`side: 'ally'`）の だれかの HP が **25% を 切る → ON**、全員が **35% 以上 → OFF**。その 間は 前の まま（行ったり 来たり しない）
- 戦いが おわった（`endPending`）・画面を 消した 時は OFF。曲が かわると エンジンでも OFF

## 3. ボスの だん（`battlePhase`。ボス戦だけ）
クライアントが 今 知って いる ことだけ（サーバーから 新しい 情報は 送らない）。

1. ボスの しるし（`c.boss` か `MONSTERS[種].boss`）の ある 敵。いなければ HP の いちばん 多い 敵
2. その 敵の だん ＝ 次の 大きい 方（0〜3）
   - **形態の しるし**（サーバーの 公開する 値。1 が はじめ）: `slPhase`・`zen`・`c7form`・`c8form`・`c8hform`・`bwForm`・`kmForm`・`impForm` は「値 − 1」、`p2` は 1
   - **HP で 行動が かわる ボス**（`MONSTERS[種].phases` の `hpBelow`）: HP の 割合が 下回った 段階の 数
   - どちらも ない ボス: HP が 半分を 切ったら 1（HP の 割合が わかる 時だけ）
3. 戦いの 間は 下げない（回復で テンポが 行ったり 来たり しない）

## 4. ダンジョンの 深さ（`buildFloorIndex`・`depthIntensity`）
- 階は マップの id から: `_3f`・`_b2`・`mine3`・`_top`／`_boss`（いちばん 上の つぎ）。`_now`・`_past` は のぞいて、千年前（`past: true`）と 今は べつの ダンジョン。宝の地図の 洞窟は `map.tm.floor`・`floors`
- 強さ ＝ **0.4 ＋ 0.6 ×（階 − 1）÷（階の 数 − 1）**（最初の 階 0.4 → 最後の 階 1.0）
- 1〜2階しか ない 所（なげきの洞窟・氷の洞窟 など）・階の わからない 所（ひみつのダンジョン・ひとつだけの へや）・フィールド・町 ＝ 1
- 影の城は 1〜12階と てっぺんで 13階として 直線（風・炎・水の 曲ごとに だんだん 強く）
- 送るのは 今 鳴って いる 曲が その 場所の 曲（`areaBgm()`）で、それが マップの `bgm` の 時（山小屋 など `bgmAt` で べつの 曲の 所は 1）。イベントの 曲・ジングルの 間は 送らない
- エンジンは 曲ごとに 強さを おぼえる。C は 曲が かわる たび（`audio.music` が 新しく なる たび）に 送りなおす ので、戦いの あと・階を うつった あと・前の音 ⇄ 新しい音の あとも 正しい 値に なる

## 5. 昼と 夜（`timeOfDayFor`）
| 場所 | 送る 値 |
|---|---|
| 屋外の フィールド（`kind: 'field'`）・町 | `sky.isNight()`（だいほんの 夜 `field.nightOverride` が あれば それ） |
| ダンジョン・`indoor` の マップ・屋根の 下（家の 中）・戦い | `'day'` |
| `bgmAt` で 夜に 曲が かわる 所（コガネの 砂ばく・ドゥナの 谷 → `desert_night`） | `'day'`（二重に しない） |

250ms ごとに 見て、かわったら 送る。

## 6. まわりの音（`ambienceFor`）
| どこ | 音 |
|---|---|
| カモメ港・ナギの村・風の海・千年前の クモイの海・海鳴りの洞窟 | `waves` |
| ルミナの町・王都サファラ・緑の王国（千年前の 都） | `market` |
| 竜守りの村・温泉の里ユノハ・鉱山の町カナトコ・白雪の里・ハネノの町・星読みの里・砂の港ドゥナ | `wind` |
| シロガネ地方・千年前の シロガネ地方・クモイ地方・ハネノ・星読みの里の 島・星竜山の ふぶきの道・頂上 | `wind` |
| 天気が ふぶき・砂あらし | `wind` |
| 星竜山の 山小屋（だんろ） | `fire` |
| くらい 洞窟・鉱山（曲が `cave`・`mine` の ダンジョン）・北の古井戸・氷の洞窟・星竜山の 氷の ほらあな | `cave_drip` |
| 天気が `rain` | `rain`（今の 天気には 雨が ない。だいほんで 雨を 出したら 鳴る） |
| ほか（ホシフル村・ハミル・フィールドの 草原・塔・神殿 など） | なし |

- **戦いの 間は 止める**（1.5びょうで 消える。戦いの 曲と 重ねない）。戦いの あと もどる
- **イベントの 曲・ジングルの 間も 止める**（その 場所の 曲が 鳴って いる 間だけ 鳴らす）
- 家の 中でも そのまま（うすい ので。出入りの たびに 入れかわらない ように）
- タイトル・キャラえらびでは 止める
- 設定「まわりの音：あり／なし」（`localStorage.kizuna_audio` の `amb`。ふだんは あり）。「前の音」では 鳴らない

## 7. 会話の 文字の 音
`ui/script.js` の 話す まど: 話す 人の 名前が ある 時は `g.audio.blip(名前)`（人ごとに 高さが ちがう）、名前の ない 地の 文は 今まで どおり `sfx('talk')`。`ui/counter.js` は そのまま。

## 9. 気を つける こと
- 耳で 聞いて いない。まわりの音の 大きさ・町の えらび方は 家族に 聞いて もらう
- 強敵の「物語の きまった 戦い」には 早い 章の 待ちぶせも 入る。合わなければ `isStrongBattle` から `story` を 外す
- 形態の しるしの 名前（`FORM_KEYS`）は サーバーの 公開する 値に あわせて いる。新しい ボスで 形態を 足したら ここにも 足す
