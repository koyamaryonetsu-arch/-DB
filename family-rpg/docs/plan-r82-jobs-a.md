## 3. しくみ（shared/battle-r82a.js。どれも 戦いの 中だけ・キャラに 項目を 足さない）

1. **ようかい化**: 自分の 番の はじめに HP 3わり いか・つめか 素手・`passive.youkai` が ある → `c.youkai`。力と 素早さが その 倍（戦いの 中の 数だけ かえて、もどる 時に もどす）。
   - 命令を 聞かない: battle.js の `onReady` で コマンドを 出さず、`youkaiCmd` が ふつうの 攻撃か つめの 技（45%・いちばん 強い 物）に する。オートの 人も おなじ
   - もどる: HP が 半分より 上・おすわり！・よう力をおさえる。もどった あと 1〜3回 ならない（`youkaiCalm`）
   - **剣を もって いる 間は ならない**（`clawHand`）
   - 画面（client/battle-r82a.js）: 仲間の まどに 赤い「ようかい化」の 札（pub の youkai。家族 みんなの 画面）・バナー「〇〇がようかい化した！」・
     「めいれいさせろ」の 人の コマンドの ところに「ようかい化して、命令がとどかない…（HPが半分より上にもどるか「おすわり！」でもどる）」
2. **大よう化・せいぎょ**: `c.youkaiCtl`（3回）。命令できる まま 1.6倍。武器は 何でも。札は むらさきの「大よう化」
3. **風の技**（phys の `vsBuff`）: 強化（バフ・力ため。かわしやすさは のぞく）が 1つ ×1.3・2つ ×1.4・3つ いじょう ×1.5（calcPhys の 1行）
4. **ばくりゅうは**（こうか `bakuryu`）: `c.stance = { kind: 'bakuryu' }`。次の 自分の 番までに 敵の 呪文・ブレス・magic の 技・ためた 大技（真は 物理の 技も。ふつうの 攻撃は のぞく）を 受けると、
   その ダメージは 半分。行動の あとで 受ける はずだった ダメージ × ret を 風で 敵全体へ（**1体ごとに「自分の 物理の cap 倍（守りも 入れた みつもり）」まで**）。
   返したら かまえは おわり。受けなかったら 次の 番の はじめに 風の 一ふり（敵全体 swing 倍）
5. **オート**（ai.js の 4.8: `r82aPlan`）: あぶない ようかい化の 仲間に おすわり・つめで HP 45% より 下なら よう力をおさえる／おすわり（ようかい化の 前に）・前ぶれで ばくりゅうはの かまえ・敵 3体 いじょうで 風の技・ボスで ときどき 大よう化
   （運〈rng〉を 使うのは その 技を もつ 時だけ。ほかの 職業の オートの ながれは かわらない）

battle.js に 足した 行: import・onReady（ようかい化は コマンドを 出さない）・executeNext（行動の はじめ・ようかい化の 行動・行動の あとで 返す）・applyAbility の case・calcPhys の 1行・damage の 1行・pub。
