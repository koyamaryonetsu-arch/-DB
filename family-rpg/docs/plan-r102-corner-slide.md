# 第102回 M1班: かどを すりぬける しくみを ゲーム ぜんたいで 直す

家族の 声（C1班の しらべ）: スマホの スティックで 1マス はばの 道の 曲がりかどを 曲がろうと すると、かべに はりついて 止まる 時が ある（少し 横に よせると 通れる）。

## わけ（自分で たしかめた こと）

みんなの 歩き方（`client/field.js` の `update`）は、1フレームに「横 → たて」の じゅんで 動き、進む 向きが かべで 止まった 時に「かどを すりぬける（`nudge`）」で 0.2・0.35 マス 横に ずれれば 進める なら そちらへ 少し ずれる。これが 2つの 所で きいて いなかった。

1. **左右へ 進む 時**: たての いどうの 行き先 `ny` を、すりぬける 前の いちで 計算して いた。左右の すりぬけで たてに ずれても、同じ フレームの `me.y = ny` で もとに もどる（たての 入力が 0 でも `ny` は もとの いち）。なので 左右へ 進む 時の すりぬけは、たての いどうも かべで 止まる 時 しか きかなかった。上下へ 進む 時は、すりぬけ（横）の あとに 横の いどうが ない ので きいて いた。
   - たしかめ: 上から 来て かどの マスに 少し 入った 所で、右へ まっすぐ（たて 0）… 前は 1フレーム たっても いちが まったく かわらない（`test/walk-r102.test.js` の 2つめ）。キーボードの →（まっすぐ）でも 同じ。
2. **スティックが 少し ななめの 時**: すりぬけは「横の ずれが 0.3 より 小さい」時 だけ（スティック いっぱいで 17° くらい まで）。スマホの スティックは 指で 20〜25° くらい ずれる ことが 多い。
   - ずれの 向きが かどの 口の ほう なら、たての いどうで 自然に 入れる。口と 逆の ほう だと、かべに そって 来た 道へ もどって しまう。

3. **（しらべて いて 見つけた）おそい フレームの 時**: すりぬけの「ずれた 先で 進めるか」は 0.1 マス 先 だけを 見て いた。1フレームが 33〜50ミリびょう（おそい スマホ。`game.js` の dt は 50 まで）だと 1フレームの いどうが 0.1 より 長く、まだ かべに とどいて いない 所で「進める」と 見て、ずれの 向きへ すべって 1マスの 口（戸・出入り口）を すぎて いった（ブラウザの ボットで 星座の島の 出入り口に ±10° で 歩いた 時、前も あとも 3マス 横へ すべった）。

ゲームの マップ ぜんぶ（201まい）の「1マス はばの 道の 曲がりかど」で、field.js と 同じ 歩き方を Node で 回した（かどの マスに 入りぐあい 4とおり × スティックの ずれ −25°〜25° の 7とおり × スティックの 強さ 2とおり。1.2〜2 びょう たおして、となりの マスに 入れたか。道具: `scratchpad/m1/allturns.mjs`）:

| | まがれない | 左右へ まがる 時 | 上下へ まがる 時 |
|---|---|---|---|
| 前（C1班の 月の都 だけの すべり なし） | 12695 / 133056 | 10843 | 1852 |
| 前（C1班の すべり あり ＝ 今の main） | 12542 / 133056 | 10716 | 1826 |
| **直した あと** | **765 / 133056** | **98** | **667** |

L の かど（まっすぐ 先が かべ）だけ に しぼると 前 7078 / 93072（左右 6485・上下 593）→ あと **182 / 93072（左右 0・上下 182）**。
のこりの 182 は ぜんぶ「かどの マスに 5% しか 入って いない（まだ 前の 道に いる）」所で、スティックを 口と 逆へ 25° ずらした 時。体の 形（横 0.56・たて 0.38）の ちがいで、上下へ まがる 時は 横に 0.35 より 多く ずれないと 入れない（すりぬけの はばを 広げると「すべりすぎ」に なる ので そのまま）。
ほかの 782（T の かどなど）は、かどを 通りすぎて から ずれの 向きへ 歩いて いく もの（ひっかかり では ない）。

## 直し方

- 歩く 1フレームを `client/walk.js` に 切り出した（DOM なし。Node の テストで そのまま 回せる）。`field.js` は `walkStep((x, y) => this.boxFree(x, y), me, ix, iy, sp)` を よぶ だけ。大鳥（`sky.flyStep`）・氷・流れ・トロッコ・ひとふで書き（`c11aInput`）・ついていく（`followStep`）・船の 速さは 今までどおり field.js の まま。
- `walkStep`:
  1. 横 → たての じゅんは そのまま。**たての いどうは、横の いどう と すりぬけ の あとの いちから**（`me.y + dy`）。横の すりぬけが なかった 時は 前と まったく 同じ 数（`me.y + dy` ＝ 前の `ny`）。
  2. すりぬけて よい 入力（`nudgeOk`）: 前の きまり（横の ずれ < 0.3）**か**、ずれが 進む 向きの 0.58ばい（30° くらい）まで。前に すりぬけた 時は 今も すりぬける（前より 弱く なる 所は ない）。
  3. ずらす 向きは、スティックの 横の ずれの ほうを 先に ためす（まっすぐ なら 前と 同じ ＋ が 先）。ずれと 逆の 口しか ない 時は 逆へも ずれる（下から 来て 右へ まがる 時に 右下へ ずれた スティック など）。
- `nudgeStep` の「ずれた 先で 進めるか」を 見る 長さを `max(0.1, 1フレームの いどう)` に。60 フレームでは 歩く・走る・船とも 0.1 以下 なので 前と 同じ。
- `nudgeStep`（前の `Field.nudge`。`Field.nudge` は のこして `nudgeStep` を よぶ）: すりぬける はば（0.2・0.35）・1フレームに ずれる 長さ（`min(sp, はば)`）・かべの たしかめ（`boxFree` で たしかめた 所 だけに 動く）は かえて いない。前の `|ty - cy| <= |me.y - cy| + 0.36` は いつも 正しい（0.35 < 0.36）ので 外した（はたらきは 同じ）。
- **C1班の 月の都 だけの すべり（`c11bCornerSlide`）は 外した**。月の都・塔 8まいで、前の 歩き方 ＋ C1班の すべり と、直した あとの 歩き方が 同じ 数（1マス はばの かど 1400回の うち まがれない 8回。L の かど だけ だと 1008回の うち 8回。8回とも 上の「5% しか 入って いない ＋ 逆へ 25°」）。C1班の テスト（`test/ch11-act2-a.test.js` の「かど」。±25°・入りぐあい 4とおり・ぜんぶ まがれる）は、すべりを 外して 直した 歩き方で そのまま 通る（テストの 中の 歩き方を `walkStep` に かえた）。C1班の マップの 広げた かど 16マスは そのまま。
  - C1班の すべりは 40° まで きいた。直した あとは 30° くらい まで（それより ずれた 時は、前から ある「ずれの 向きへ 歩く」で かべに そって すべる）。

## かわって いない ことの たしかめ

- **かべ**: `walkStep` は `boxFree` で たしかめた いち だけに 動く（前と 同じ）。ランダムな 場所・入力 44万回（ゲームの マップ ぜんぶ）で かべの 中に 入った 回数 0。ブラウザの ボットも 毎回 体の 4すみが かべに かかって いないか 見た（0回）。
- **速さ**: ひろい 所（すりぬけ なし）では 前と まったく 同じ いち（44万回の うち 違ったのは 330回 ＝ ぜんぶ かべに 押しつけて いる 時）。1フレームの いどうの いちばん 大きい 値も 前と 同じ（歩く 長さの 1.84ばい ＝ すすむ ＋ すりぬけ）。走る・船・スティック 弱は `sp` を そのまま わたす だけ。
- **止まる・すべりすぎ**: 入力 0 では 動かない。すりぬける はば（0.35）より 遠い 口へは ずれない。キーの ななめ（45°）は 前と 同じ（すりぬけない）。ずれが 30° より 大きい 時は すりぬけない。
- **1マスの 入口に まっすぐ 入る 時・イベントの マス**: まっすぐ 歩いて いる 時は、かべに 押しつけて いない かぎり 前と 同じ いち。ブラウザで 各マップの 出入り口へ まっすぐ・±10° で 歩いて 入った（下の 表の「出入り口」）。
- **サーバーの 見はり**: いちの 形（`t: 'move'`・`x`・`y` の 小数3けた・`dir`・`moving`・`run`・`seq`・`follow`）は かえて いない。ブラウザの ボットの あいだ、サーバーが いちを もどした（`setPos`）回数は 前・あと とも 同じ（スマホの ルミナの町で 3回ずつ・ほかは 0。前と あとで 同じ なので 歩き方の 直し とは かかわらない と 見る。わけは しらべて いない）。
- **氷・流れ・トロッコ・大鳥・ひとふで書き**: その 道すじは `walkStep` を 通らない（前と 同じ コード）。

## 気を つける 所

- 歩く 1フレームを かえる 時は `client/walk.js` を。`field.js` の `update` に いどうの 行を 足さない（マップ だけの しくみを 足したく なったら、`walkStep` の 前に 入力を かえる 形に）。
- すりぬける はば（0.2・0.35）を 広げると、止まりたい 所で 横へ すべる。ずれの 角度（`NUDGE_SLANT` 0.58）を 大きく すると、ななめに 歩きたい 時に かべの はしで 引っぱられる。
- のこりの 「かどの 5% 手前で 逆へ 25°」は、上下へ まがる 時だけ（体が 横に 広い）。家族から 声が あれば、体の 横はばか、上下へ まがる 時 だけの はばを 考える。
