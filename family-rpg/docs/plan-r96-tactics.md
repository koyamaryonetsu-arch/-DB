## 2. 作戦の 一覧（`public/js/shared/ai.js` の `TACTICS`）

キー と 今の 名前は かえて いない（セーブ・引っこしコードに 入って いる）。新しい キーは `savemp` だけ。
ならびは 画面の じゅん（バッチリ → ガンガン → いのち → MPせつやく → じゅもん → めいれい）。

| キー | 名前 | 画面の 1行の せつめい（`desc`） | 動き方（`mode`） |
|---|---|---|---|
| `balanced` | バッチリがんばれ | よく効く技を使いながら、強くする技・弱くする技・回復もする | `balanced` |
| `aggressive` | ガンガンいこうぜ | いちばん大きなダメージの技で攻める（弱点もねらう）。MPは気にしない | `aggressive` |
| `heal` | いのちだいじに | HPが8わり以下の仲間がいたら回復を先にする。ほかはバッチリがんばれと同じ | `heal` |
| `savemp`（新） | MPせつやく | 回復の分のMPをのこして、少ないMPでよく効く技を使う。長い戦いでもMPを切らさない | `savemp` |
| `nomp` | じゅもんせつやく | MPをほとんど使わない | `legacy`（前の まま） |
| `manual` | めいれいさせろ | 自分でコマンドを選ぶ（仲間だけ） | オートの 時は `balanced` |

- 「ダメージの 見こみ」は 今の `chooseAttack` の まま（`calcPhys`・`calcMagic` の 見つもり。弱点・耐性・守り・今の 強化・全体／グループ／1体・たおしすぎない〈のこりの HP まで〉）。新しい 計算は 作って いない。弱点は 今の AI と 同じく `t.resist` を 見る（前から 知って いる あつかい）

- 敵の がわで 仲間の AI を 使う うつし身（鏡のうつし身 `mirrorOf`・ノクトの影 `mimic`・ライバル・職業の 試練）は **前の えらび方の まま**（`LEGACY_TACTICS`。ボスの 強さを かえない）

### 2-1. ガンガンいこうぜ（`aggressive`）
- 攻撃の 技・呪文・ふつうの 攻撃を ぜんぶ くらべて、合計の ダメージの 見こみ が いちばん 大きい 物（MP は 見ない。ゆらぎも ±2% だけ。前は ±10% と MP の 重さ で 中くらいの 技が まざって いた）
- MP が 足りない 技は えらべない ので、足りなく なったら 使える 中で いちばん 強い 物
- バフ・デバフ・ねむり などは 使わない。回復は だれかの HP が 3わり いか の 時だけ（`healAt: 0.3`）

### 2-2. バッチリがんばれ（`balanced`）
- ふつうの 戦い: ダメージ ÷（1 ＋ 3 × MP ÷ 最大MP）で えらぶ（`costK: 3`。MP が 3わりより 少ない 時は 3倍）。弱点の 技・敵の 数に 合った 技を よく 使う
- **ボスなど 長い 戦い（`fightWeight` の hard）: MP は 前と 同じ 重さ（`hardMp`・`mpWeight 0.04`）** … 3 の 数字の ため（設計と ちがう 所。5 を 見て）
- バフ（前と 同じ わりあい）・敵を 弱く する 技（`chooseDebuff`。まだ かかって いない・`resist.debuff` が 0 で ない・HP 2わり5分 より 多い 敵。ボス・HP の 多い 敵から。1回の 番で 1つだけ・`DEBUFF_CHANCE 0.06`）。**ボス戦では 敵を 弱く する 技は 使わない**（同じく 3 の ため）
- ねむり・こんらん などは、その 状態が きかない 敵（耐性 0）しか いない 時は 使わない
- 回復: HP 5わり いか

### 2-3. いのちだいじに（`heal`）
- HP が 8わり いか（`<=`）の 仲間が 1人でも いたら 回復を 先に。2人 いじょうは 全体の 回復（前からの `chooseHeal`）。1人を 回復する 技が ない 時も 全体の 回復で（`healFirst`）
- たおれた 仲間が いれば 生き返らせる のが 先（`decideAlly` の 2 … 回復より 前）
- みんな 8わりより 多い 時・回復の 手だてが ない 人は バッチリがんばれと **同じ 行動**（`healAt` の ほかは 同じ 数字。テストで 60回 同じ 行動を たしかめた）

### 2-4. MPせつやく（`savemp`。新しい）
- とって おく MP（`mpReserve`）= いちばん だいじな 回復・生き返らせる 技（1人を 生き返らせる 技 と いちばん よく 回復する 技）の MP と、最大MP の 4分の1 の 大きい 方（最大MP の 半分まで）
- 攻撃・バフ・デバフ で のこりが それより 下がる 技は えらばない（`saveOk`）。回復・生き返らせる・治す・MP を ためる 技は とって おいた 分を 使って よい
- ボスなど 長い 戦いでは、のこす MP を 敵の のこりの HP に 合わせる（`saveFloor` = とって おく MP ＋（最大MP − とって おく MP）× 0.7 × 敵の のこりの HP の わりあい）… はじめに 使い切らない
- 技は ダメージ ÷（1 ＋ 8 × MP ÷ 最大MP）（弱い 戦いは 14）。弱い 戦いで ふつうの 攻撃で たおせる 敵が いれば ふつうの 攻撃
- 回復: HP 5わり いか
