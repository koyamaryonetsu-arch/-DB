## 13-2. 第1幕「赤と 緑」の ねらい
- **はじめての「すきな じゅん」**。星の音さが 2つの 方向を 同時に 指す。
- **赤**: 知って いる 炎の山の「下」。行きは 静かな 探検、**帰りは 溶岩に 追われて かけ上がる**（同じ 道が、行きと 帰りで ちがう）。

- **先に 取った 音が、もう 片方で 役に 立つ**（おまけの 部屋）。どちらを 先に しても そんは ない。
- スピカ: 音が 1つ ふえる たびに 歌が 1ふし ふえ、光が 強く なる。

## 13-4. しくみ
**溶岩に 追われる（赤の 帰り道）**
- 赤の 音を 取ると 始まる（フラグ `c10_red_run`）。溶岩は 下の はしから **3秒に 1だん** 上がる（マップの 行）。場面・メニュー・話して いる 間は 止まる。
- 画面の 下から 赤い 光が せまる・ゆれ・音。画面の 上に「溶岩まで あと ○だん」。
- 追いつかれると、その 階の 入口（階段の 上）に もどって やり直し（**ダメージも お金も へらない**。溶岩も その 階の はじめに もどる）。
- 行きに 引いた レバーの 黒い 石は 近道。引いて いない 人も、**遠回りの 道で 必ず 間に 合う**（テストで、いちばん おそい 歩き方〈スマホの たて・ななめ 見え方〉でも 間に 合う ことを たしかめる。めやすは、歩きつづければ 溶岩と 10だん いじょう 開く）。
- **3回 追いつかれると、溶岩が おそく なる**（5秒に 1だん。小さい 子の ため）。
- 家族で 遊ぶと: 1人ずつ にげる（追いつかれた 人だけ もどる）。全員が 火口に 着くと 終わり。先に 着いた 人は 上から レバーを 引いて、下の 人の 近道を 作れる。
- 回線が 切れた 時: その 階の 入口から やり直し。
- にげ終わると 古い 道は 冷えて、何度でも 入れる（宝箱の 取りのこしを 取りに 行ける。追われるのは 1回だけ）。

**音の 草木（緑の 道）**
- 根の国の あちこちに「音の つぼみ」。しらべて 星の音さを 鳴らすと、草木が のびて 道に なる（一度 のびると のびた まま。フラグは まとめて 1つの 数に する か、階ごとに 1つ）。
  - つる … のぼる はしご。
  - 大きな 葉 … 谷を わたる 橋。
  - きのこ … ふむと 高い 所へ はねる（決まった 着地点）。
- 広い マップなので、**高い 所から 見わたす 場所**（見はらし台。しらべると 画面が 広く 引く）を 2か所。行き先の 大木が 遠くに 見える。
- 「行った 所」の 記録は 取らない（セーブを のばさない）。

**共通**
- 新しい マップは 赤 3まい・緑 2まい。どれも みちびきの糸・帰り道の羽が 使える（にげて いる 間だけ 使えない）。
- 2D と 2.5D の 両方・スマホの たて。

  3. **「ぼうぎょ」を えらぶと 水を 飲んで −3**。道具と 回復は ＋0。
  4. メカにも「あつさ」（0〜6）。動く たびに ＋1。**炎の 攻撃を 当てると ＋1**、氷の 攻撃を 当てると −1。6 に なると「オーバーヒート！」: 1回 止まり、その 間 受ける ダメージ 1.5倍。めもりは 0 に。

- 時間に 追われない しくみ（人が ゆっくり えらんでも 同じ）。

**緑の 中ボス「カビだんしゃく モルド と カビカビ号」**（Lv108。きのこの かさの ぼうし・しめった マント・小さな 丸い 飛ぶ メカ。もとは バイキンマン。もとの 絵・名前・せりふ・決まり文句は 使わない）
