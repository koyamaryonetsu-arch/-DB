# シネマ案件管理システム（工程表つき）

設備工事向けの**案件管理＋工程表（ガントチャート）**を、**1つの `index.html`** にまとめた社内用Webアプリです。
ファイルをダブルクリックしてブラウザで開くだけで使えます（インストール・通信不要）。

> アプリを複数に分けず一本化しているので、配布・改修が簡単です。社内（菱熱）専用の想定で、外部へ公開する必要はありません。

## 画面構成
上部ナビで2つの画面を切り替えます。

1. **案件管理**（トップ画面）… 案件の一覧・登録・編集・削除
2. **工程表**（ガントチャート）… 日程の作成

ナビの「工程表」ボタン、またはトップの「📋 工程表を開く」ボタンで工程表に移動します。
※ 案件と工程表は連動していません（独立した機能として一本化しています）。

---

## 案件管理（トップ画面）
- **＋ 新規案件**: 案件名・劇場/施設・工事種別・顧客/元請・担当・開始予定日・工期・ステータス・備考を登録。
- **編集 / 複製 / 削除**: 各行のボタンで操作。
- **検索**: 案件名・施設・顧客・担当で絞り込み。
- ステータス（見積・受注・施工中・完了・保留）は色付きバッジで表示。
- 内容はブラウザに自動保存されます。

## 工程表（ガントチャート）
### 基本設定
- **工事名**: タイトル。
- **開始日**: 1日目を西暦で入れると横軸の日付・曜日が自動で並びます。
- **工程日数**: 列が自動で増減（1〜370日）。
- **土日祝**: 土日と日本の祝日の列が自動で**薄い赤**に（振替休日・国民の休日も計算）。

### バー（工程）の操作
- **作成**: 行の上でドラッグ。**上半分＝日中（青）／下半分＝夜間（赤）**（起点 7〜18時＝日中、19〜6時＝夜間）。
- **移動**: バー本体をドラッグ。 **伸縮**: 左右の端をドラッグ。
- **コピー**: **Ctrl（⌘）＋ドラッグ**。
- **色切替**: バーを**ダブルクリック**で青⇄赤。クリック→下部パネルで作業内容・時間帯・色・削除も可能。
- 日中で連続作業のときは夜間（下段）は空白のまま。夜間連続も同様。

### 縦軸（作業内容）
- 一般的な設備工事の作業を初期登録。名称クリックで編集、「⋮」ドラッグで並べ替え。
- 「作業マスター編集」で追加・改名・削除（一覧選択＋手入力）。

### 保存・出力
- 入力は自動保存。**保存**（JSON書き出し）／**読込**（JSON読み込み）／**印刷・PDF**（A3横推奨）に対応。
- 複数現場の工程表を使い分けたい場合は、工程表を JSON で保存／読込して切り替えてください。

## 技術メモ
- 依存ライブラリなしの単一 HTML（HTML/CSS/JavaScript）。
- データはブラウザの `localStorage` に保存（案件＝`cinema_cases_v1`／工程表＝`koutei_app_v1`）。外部送信は一切ありません。
