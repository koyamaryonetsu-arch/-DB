# 工程表作成アプリ

設備工事向けの**工程表（ガントチャート）作成アプリ**です。
`index.html` をダブルクリックしてブラウザで開くだけで使えます（インストール・通信不要）。

## 使い方

### 基本設定（上部ツールバー）
- **工事名**: 工程表のタイトルを入力します。
- **開始日**: 1日目の日付を西暦（年月日）で入れると、横軸の日付・曜日が自動で並びます。
- **工程日数**: 日数を変えると横軸の列が自動で増減します（1〜370日）。
- **土日祝**: 土曜・日曜・日本の祝日の列は、自動で**薄い赤**になります（祝日は自動計算・振替休日／国民の休日にも対応）。

### バー（工程）の操作
- **作成**: 行の上で**ドラッグ**するとバーができます。
  - 行の**上半分**でドラッグ＝**日中（青）**／**下半分**でドラッグ＝**夜間（赤）**
  - （起点が 7〜18時＝日中、19〜6時＝夜間、という線引きを上下で表現しています）
- **移動**: バー本体をドラッグ。
- **伸縮**: バーの左右の端をドラッグ。
- **コピー**: **Ctrl（Mac は ⌘）を押しながら**バーをドラッグ。
- **色の切り替え**: バーを**ダブルクリック**すると 青⇔赤（日中⇔夜間）が切り替わります。
- **詳細編集**: バーを1回クリックすると下部にパネルが出ます。
  - 作業内容（文字）の入力、時間帯（日中/夜間）、色の変更、削除ができます。
- **削除**: バー選択中に `Delete` / `Backspace` キー、またはパネルの「削除」。

> 日中で連続作業になる場合は上段（青）だけが続き、夜間の段は空白のままになります。夜間の連続も同様です。

### 縦軸（作業内容）
- 一般的な設備工事の作業があらかじめ入っています。
- **名称変更**: 左の作業名をクリックして直接編集（一覧候補からも選べます）。
- **並べ替え**: 作業名の左「⋮」を上下の行へドラッグ。
- **マスター編集**: 「作業マスター編集」ボタンから、追加・名称変更・削除・並べ替え・標準セットへの復元ができます。
  - 追加欄は **▼で一覧から選択**でき、**手入力**も可能です。

### 保存・出力
- 入力内容は自動的にブラウザに保存されます（次回開いたときに復元）。
- **保存**: 現在の工程表を JSON ファイルとして書き出します。
- **読込**: 書き出した JSON を読み込みます（PC を変えたいときやバックアップに）。
- **印刷 / PDF**: ブラウザの印刷機能で紙・PDF に出力できます（A3横推奨）。
- **全消去**: バーだけをすべて消します（縦軸・設定は残ります）。

## 元になった様式
TOHOシネマズ市川コルトンプラザ 熱源更新工事 工程表（Excel）を参考に、
横軸＝日付・曜日、縦軸＝作業内容、日中／夜間の表現を取り込んでいます。

## 技術メモ
- 依存ライブラリなしの単一 HTML（HTML/CSS/JavaScript）。
- データはお使いのブラウザの `localStorage` に保存され、外部送信は一切ありません。
