# 半自動収益ツール構築プロジェクト

週2〜5時間の運用で回る、半自動で収益を生むマイクロSaaSを「リサーチ→構築→集客→運用」まで一気通貫で立ち上げる個人開発プロジェクト。

役割・制約・フェーズ定義などの最上位ルールは **[CLAUDE.md（プロジェクト憲章）](CLAUDE.md)** を参照。

> このリポジトリには `/unreplied`（メール返信アシスタント、`.claude/commands/unreplied.md`）も同居しているが、本プロジェクトとは独立して動く。

## フェーズ全体像

- [ ] **Phase 0**：リサーチとテーマ確定（目安1週間）→ 成果物：候補3案の比較表＋推奨1案
- [ ] **Phase 1**：MVP構築（目安2週間）→ 成果物：動くMVP・デプロイ手順書・5分デモ手順
- [ ] **Phase 2**：集客の半自動化（継続運用）→ 成果物：巡回ルーティン・投稿下書きテンプレ・週次レポート様式
- [ ] **Phase 3**：運用自動化と改善ループ → 成果物：KPIダッシュボード・週次レビュー運用

マイルストーン：**最初の1円 → 月1万円 → 月3〜5万円**（飛ばさない）

## 再開方法（数日空けたとき）

1. Claude Code でこのリポジトリ（ブランチ `claude/revenue-tool-project-39inwd`）を開く
2. 「**CLAUDE.md と README.md を読んで、現在地から再開して**」と指示する
3. Claude が「現在フェーズ／前回からの進捗／今日やること」を3行で宣言してから作業を始める
