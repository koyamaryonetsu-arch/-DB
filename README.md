# 星環の継承者 ―アストラル・レガシー―

**HEIRS OF THE ASTRAL RING** — ブラウザで動作する完全オリジナルの16bit風コマンドRPG（第一章・縦切り版）

空に浮かぶ光の輪「星環」が砕けて生まれた七つの「環晶」を巡り、辺境の島で育った継承者が旅立つ王道ファンタジーRPGです。既存作品の名称・画像・音楽・文章は一切使用していません（グラフィックはすべてコードから手続き生成、BGM/効果音はWebAudioによる自作合成）。

## 起動方法

```bash
npm install        # 依存関係のインストール
npm run dev        # 開発サーバー起動 → 表示されたURLをブラウザで開く
```

本番ビルド:

```bash
npm run build      # dist/ に静的ファイルを出力
npm run preview    # ビルド結果の確認サーバー
```

検証コマンド:

```bash
npm test           # ユニットテスト（80件: ダメージ計算/状態異常/熟練度/継承制限/セーブ/ボスギミック/連携技/スカウト率/バランスシミュレーション等）
npm run typecheck  # TypeScript 型チェック
npm run lint       # ESLint
npm run smoke      # ビルド後、Chromiumで実際に起動して自動操作するスモークテスト（要 playwright-core + Chromium）
```

対応環境: Chrome / Edge / Safari / Firefox（PC・スマートフォン）。内部解像度 320×240 の整数倍スケーリング・ピクセルパーフェクト表示。

## 縦切り版で遊べる内容（30〜60分）

- タイトル → 主人公作成（名前・性別・外見4種）
- オープニング: 成人の儀式 → 黒天帝国の襲撃 → 環導器の覚醒 → ミレア・ガルド加入
- ルミナ村（道具屋・武具屋・宿屋・星環神殿・昼夜で変わるNPC）
- ワールドマップ（ルミナス島南部・昼夜サイクル・時間帯で変わるエンカウント）
- ダンジョン「星影の森」2フロア + 宝箱
- ボス「森喰いのバルグロウ」——根を断って守りを崩し、光熱を当てすぎると暴走する
- 撃破後、最初の環晶「生命の環晶」が北の帝国を指し示すエンディングまで

### システム

- ターン制コマンドバトル（たたかう/特技/術式/防御/道具/装備変更/にげる、前列・後列）
- 属性9種・状態異常13種（ボスは完全無効ではなく耐性蓄積+効果時間短縮で調整）
- レベルアップ（性格パラメータが成長に小さく影響。弱体化はしない）
- 職業熟練度8ランク（見習い〜極星）とランクアップでの技習得。弱すぎる敵からは職業経験値が減る
- 転職（村の星環神殿。基本職6種: 環剣士/重装兵/星術師/生命官/気鋼闘士/影走り）
- 技セット: 戦闘持込8枠・継承技（他職の技）最大4枠・職固有奥義は継承不可・パッシブ4枠
- 奥義ゲージ（攻撃・被弾・回復で蓄積。主人公奥義「天環終刃」はゲージ最大+HP半分以下で発動）
- 連携技「双星交差」: 主人公が剣技+ミレアが攻撃星術を同じターンに選ぶと発動（メニュー「れんけい」にヒントあり）
- 昼夜サイクル（歩数で時間が進む。色調/NPC/店/エンカウントが変化。宿で朝に）
- セーブ3スロット+オートセーブ、JSONエクスポート/インポート、改ざん検知、バージョン移行
- 設定: 文字/戦闘速度・BGM/SE音量・常時ダッシュ・画面揺れOFF・フラッシュ軽減・難易度3種（敵能力+AI+経験値補正が変化）・キーコンフィグ

## 技術構成

- TypeScript (strict) + Phaser 3 + Vite + Vitest + ESLint + Prettier
- `src/core/` … Phaser非依存の純ロジック（戦闘エンジン・成長・セーブ等）。戦闘は「コマンド→イベント列」を返す決定的な純関数で、シード付きRNGにより全テストが再現可能
- `src/data/` … ゲームデータJSON（職業/特技/術式/モンスター/マップ/会話/装備/アイテム/エンカウント/状態異常/属性/クエスト）
- `src/game/` … Phaser表示層（シーン/UI/手続き生成グラフィック/合成サウンド/入力）
- `src/tests/` … ユニットテスト80件（バランスシミュレーション含む）

## 著作権・オリジナリティ方針

- 呪文・特技・職業・モンスター・地名・人名はすべて本作独自の名称
- 画像アセットは一切同梱せず、全スプライト・タイル・背景・UIをコードのパレット+描画手続きから実行時生成
- しずく型モンスター・顔だけの丸い体・既存作品特有の目/口/配色/輪郭は不使用。モンスターは「動物+植物」「獣+鉱物」「遺物+機械」等の2要素以上の組み合わせでデザイン
- BGM・効果音はWebAudioのオシレーターによる自作の短いループ/ジングルのみ
- フォントはOS標準の等幅フォントスタックを指定（フォントファイルを同梱しない）
- 禁止名称（既存作品の固有名詞等）はリポジトリをgrep検査して不使用を確認

## 実装上の仮定・既知の制限（縦切り版）

指示書に「不明点があっても作業を止めず、合理的な仮定をREADMEへ記録する」とあるため、以下を記録します。

- 転職は基本職6種のみ体験可能。獣奏士・錬具師・専門職（星剣将/聖衛官）はデータ・転職条件の表示のみ先行実装（神殿でプレビュー可能）
- 仲間モンスターのスカウト/図鑑はコアロジック+テストのみ（縦切り版UIには未搭載。図鑑用の「遭遇記録」はセーブに保存済み）
- 天候システム・融合職・複合奥義の一部・控えメンバー(交代)は次章スコープ（戦闘コマンド「交代」はUI上グレーアウト）
- 歩行アニメは4方向×3フレーム。戦闘中の「装備変更」は武器のみ対象
- 状態異常は戦闘終了時に全回復（フィールド毒なし）
- 奥義ゲージは戦闘開始時に0から蓄積
- 性格パラメータはオープニング等の選択肢で変動し、レベルアップ成長へ小さな正のボーナスのみ与える（取り返しのつかない弱体化なし）
- ふりがな表示・色覚補助モードは未実装（設定枠のみ将来対応）。フラッシュ軽減・画面揺れOFFは実装済み
