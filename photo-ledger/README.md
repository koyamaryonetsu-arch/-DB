# 写真台帳メーカー（single-file / オフライン可）

添付の見本（TOHOシネマズ西新井 コンセッション環境改善工事 写真台帳）と同じ体裁で、
A4・1ページ3枚の写真台帳をつくるアプリです。**`index.html` を開くだけ**で動きます。
インストール不要・サーバー不要。AI仕分け以外はネット接続も不要です。

## 画面は3つだけ

| タブ | やること |
| --- | --- |
| **📷 写真** | 現場の写真をまとめて取り込み、**並べ替え・仕分け**をして、使う写真を選ぶ |
| **📄 台帳** | 選んだ写真が並んだ台帳を仕上げる（文字入力・ページ増減・印刷/PDF） |
| **⚙ 台帳の設定** | 物件名・工事名などの共通項目、体裁、表紙、AI設定、データの書き出し／読み込み |

## いつもの流れ（3ステップ）

### ① 写真を入れて、アプリの中で並べ替える
- 「＋写真を追加」で**複数まとめて**選択（PCは Ctrl / Shift、スマホは長押しで複数選択）。
  ドラッグ＆ドロップ、<kbd>Ctrl</kbd>+<kbd>V</kbd> の貼り付けも可。
- 取り込むと**撮影日時（Exif）の順に自動で並び**、時間があいたところで「撮影のまとまり」に分かれます
  （区切り時間は設定で 10/20/30/60分/3時間 から選択）。
- 並び順は **撮影日時順 / ファイル名順 / 工種順 / 手動** をワンタップで切替。
  各写真の ↑↓ で手動移動、複数選んで「↕ 選んだ順に並べる」も可。
- スマホ写真の向き（Exif回転）は自動補正。長辺1600px（既定）に自動縮小して保存するので軽いままです。

### ② 仕分けして、選んで台帳へ
- 写真の ✎ で **工種・撮影対象・工事区分・備考** を入力。複数選んで「🏷 タグ・工事区分をつける」でまとめて設定。
- **🤖 AIで工種を判別**（任意）：APIキーを設定すると、写真を見て
  「工種／撮影対象／工事区分／読み取れた数値」を自動判定してタグ付けします。そのまま**工種順に並べ替え**られます。
- 使う写真をタップで選び、下の「📄 台帳に入れる」。**選んだ順（＝並べ替えた順）**にページへ貼られ、
  工種・撮影対象・工事区分・備考が台帳の欄に**自動で入ります**。
- 「台帳済」バッジと「未使用」フィルタで、貼り忘れ・二重貼りを防げます。

### ③ 台帳を仕上げて印刷
- 物件名・工事名は**1か所直せば、表紙・全ページの見出し・全写真の欄が一斉に変わります**。
- 行ごとに ▲▼移動／＋行／複製／削除、写真は ↻回転／差替／✕。ページの追加・削除も各ページ下から。
- 「🖨 印刷 / PDF」→ **A4・余白なし・背景グラフィックON**で見本どおりに出力。

## コピペまわり
- 行の「⧉」でコピー →別の行で「貼」。「↑同」で前の行と同じ文字に。
- 「⧉ 全文コピー」で台帳全体をタブ区切りコピー（Excelにそのまま貼れます）。
- 「📋 まとめて貼り付け」で Excel の表を一括反映（1行＝写真1枚／列は 工事区分・撮影箇所・備考／備考の改行は `｜`）。
- 一度使った撮影箇所は入力候補として再利用。<kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せます。

## AI仕分けについて
- 使うには Claude の APIキー（`sk-ant-…`）が必要です（[console.anthropic.com](https://console.anthropic.com/) で発行）。
- キーは**その端末のブラウザ（localStorage）にだけ**保存され、書き出しJSONには含まれません。
- 判定のたびに、対象の写真を長辺640pxに縮小して Anthropic の API に送ります（学習には使われません）。
- モデルは Opus 5（既定）/ Sonnet 5 / Haiku 4.5 から選択。1回に送る枚数も変更できます。
- **ネット接続が必要**です。claude.ai 上のアプリ版では外部接続がブロックされるため、AI仕分けは
  `index.html` をダウンロードして開いた場合のみ動作します（それ以外の機能は両方で使えます）。

## 保存とバックアップ
- 入力するたび自動保存（端末のブラウザ内 / IndexedDB）。台帳は複数持てて、上部のセレクタで切替。
- 別端末へ移すときは⚙の「書き出し(.json)」→移した先で「読み込み」（写真も一緒に入ります）。
- ブラウザの「サイトデータ削除」で消えるので、大事な台帳は .json で控えを取ってください。

## レイアウト（見本に合わせた寸法）
- A4縦 210×297mm、左右余白3mm・上5mm
- 見出し（物件名　工事名）＋外枠、1行 86.4mm（3枚/ページ。1〜4枚に変更可）
- 左：写真セル 121.3mm ／ 右：文字セル（物件名・区切線・工事名・工事区分・撮影箇所・備考）
- 下中央にページ番号（既定 `{n}/{t}ページ`）

## 動作環境
Chrome / Edge / Safari の新しめのバージョン。PCは用紙(A4)表示、スマホはカード表示で自動起動します（切替可）。
