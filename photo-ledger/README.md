# 写真台帳アプリ（single-file / オフライン可）

添付の見本（TOHOシネマズ西新井 コンセッション環境改善工事 写真台帳）と同じ体裁で、
A4・1ページ3枚の写真台帳をつくるアプリです。**`index.html` をダブルクリックで開くだけ**で動きます。
インストール不要・サーバー不要・ネット接続不要。

## 開き方

| 使う場所 | 方法 |
| --- | --- |
| パソコン | `index.html` をダブルクリック（Chrome / Edge 推奨） |
| スマホ | 同じ `index.html` をスマホに送る（メール添付・LINE・Drive など）→ ブラウザで開く |
| 社内共有 | 共有フォルダに置いて、各自がブラウザで開く。データは各自の端末に保存されます |

## できること

### 1. 同じ文字は1か所入れれば全部に入る（自動反映）
- ⚙**共通設定**の「物件名」「工事名」を入力すると、**表紙・全ページの見出し・すべての写真の欄**へ自動で入ります。
- 台紙の上で直接書き換えても、同じ項目が一斉に書き換わります（リンク項目）。
- 「日付・会社名・住所・電話番号」も表紙へ自動反映。

### 2. 写真を複数選択して一気に入れる
- 「🖼 写真をまとめて追加」で複数選択（PCは Ctrl / Shift、スマホは長押しで複数選択）。
- **ドラッグ＆ドロップ**（PC）、**Ctrl+V の貼り付け**（スクショなど）にも対応。
- 並び順は **ファイル名順 / 撮影日時順（Exif）/ 選んだ順** を⚙で選択。
- 枚数に合わせてページを自動で増やします。スマホの縦横（Exif 回転）も自動補正。
- 写真は長辺 1600px（既定）に自動縮小して保存するので、枚数が多くても軽いままです。

### 3. コピペしやすい
- 行の「⧉」でその行の文字をコピー →別の行で「貼」。
- 「↑同」でひとつ前の行と同じ文字にする。
- 「⧉ 全文コピー」で台帳全体をタブ区切りでコピー（Excel にそのまま貼れます）。
- 「📋 まとめて貼り付け」に Excel からコピーした表を貼ると、**1行＝写真1枚**で一気に反映。
  列は「工事区分 →撮影箇所 →備考」。備考の改行は `｜`（縦棒）で区切ります。
- 一度使った「工事区分 / 撮影箇所」は入力候補として再利用できます。

### 4. ページ・行の増減、編集
- 「＋ページ」／各ページ下の「＋このページの後にページを追加」「🗑 このページを削除」。
- 行ごとに「▲▼（移動）」「＋行」「複製」「削除」。
- 写真は「↻回転」「差替」「✕外す」。
- 1ページあたり **1〜4枚** に変更可（既定3枚）。表紙は付ける／外すを選べます。
- **Ctrl+Z（↩︎戻す）**でひとつ前に戻せます。

### 5. 複数選択してまとめて操作
- 各行 左上のチェックを付けると上部に一括バーが出ます。
- 選択行へ「工事区分・撮影箇所の一括入力」「写真をまとめて挿入」「まとめて削除」。
- 「⋯ その他 → ☑ 全部の写真を選択」で全行選択。

### 6. 保存・印刷
- 入力するたび**自動保存**（端末のブラウザ内 / IndexedDB）。台帳は複数持てて、上のメニューで切替。
- 別端末へ移すときは⚙の「書き出し(.json)」→ 移した先で「読み込み」（写真も一緒に入ります）。
- 「🖨 印刷 / PDF」→ **用紙A4・余白なし・背景グラフィックON** で見本どおりに出力。
  PDF にするときは送信先を「PDFに保存」。スマホは 共有 → 印刷 → PDF保存。

## 画面のしくみ

- **用紙（A4）表示**：PC 既定。画面上でそのまま A4 の仕上がりを見ながら編集。
- **カード表示**：スマホ既定。写真1枚＝1カードで、指で入力しやすいレイアウト。
- 「⋯ その他 → 📱／🖨 表示切替」でいつでも切り替えられます（印刷は常に A4）。

## レイアウト（見本に合わせた寸法）

- A4 縦 210×297mm、左右余白 3mm、上5mm
- 見出し（物件名　工事名）＋外枠、1行 86.4mm（3枚/ページ）
- 左：写真セル 121.3mm ／右：文字セル（物件名・区切線・工事名・工事区分・撮影箇所・備考）
- 下中央にページ番号（既定 `{n}/{t}ページ`、書式は変更可）

## 注意

- データは**開いている端末のブラウザ**に保存されます。端末やブラウザを変えると見えません（.json で移動してください）。
- ブラウザの「閲覧履歴データの削除（サイトデータを含む）」を行うと消えます。大事な台帳は .json で控えを取ってください。
- Chrome / Edge / Safari の新しめのバージョンで動作します。
