# 楽天ROOM「コレ!」自動化 方式検討メモ

作成日: 2026-08-09

## 結論（おすすめ）

**「コレ!ボタンを押す」部分の完全自動化はやらない。その手前（商品選び・紹介文づくり）を全部自動化して、毎朝スマホに「今日コレ!する商品リスト＋コピペ用紹介文」を届ける方式にする。**

理由は下記の通り、ボタン操作の自動化は規約違反でアカウント停止（＝アフィリエイト収益ゼロ）のリスクがあり、かつコレ!には回数上限があるため「無限に自動でコレ!する」こと自体に意味がないから。

## 調査結果（前提知識）

1. **楽天ROOMに公式APIは存在しない**
   - コレ!・投稿・フォローを外部から操作する公式手段はない。
   - 一方、楽天ウェブサービス（商品検索API・ランキングAPI）は公式に無料で使え、アフィリエイト目的の利用もOK。

2. **自動コレ!/自動いいねツールは規約違反**
   - 楽天の規約は bot・自動化ツールによる操作を禁止。過去に bot がランキングを荒らして問題化し、楽天側も対策を続けている。
   - 発覚時はコレ!制限〜アカウント停止。ROOMで積み上げた収益基盤が消えるのが最大のリスク。
   - 他人の投稿文の丸パクリコレも規約違反対象。

3. **コレ!には回数上限がある**
   - 1時間あたり約100回 / 24時間あたり約200回 / アカウント累計2万回。
   - 超えると「ご利用上限数に達しています」エラー。リセットは0時ではなく最終投稿から24時間サイクル。
   - → 自動化しても1日200回が天井。「200回分をいかに質良く・安全に使うか」が本質。

## 選択肢の比較

| 方式 | 内容 | 規約 | BANリスク | スマホ対応 |
|---|---|---|---|---|
| ① クラウド完全bot | Playwright等でログインして自動コレ! | 違反 | 高（データセンターIP・機械的間隔で検出されやすい） | ○（放置） |
| ② 端末内オートクリッカー | スマホの自動タップアプリでコレ!連打を半自動化 | 違反寄りのグレー | 中（端末内動作だが、速度・パターン次第） | ○ |
| ③ 選定・文章の自動化＋タップは人間 | 商品選び・紹介文・タグ生成を自動化し、毎朝スマホに配信。ROOMアプリでポチポチするだけ | **規約内** | なし | ○ |

- ①は非推奨。ROOM側のUI変更にも弱く、保守コストも高い。
- ②をやる場合は自己責任で、Android なら MacroDroid / オートクリッカー系、iPhone ならスイッチコントロールの「レシピ」で実現可能。ただし速度は人間並み（数秒に1回）に抑え、深夜の連続稼働はしないこと。
- **③が本命。** 実際にROOMで時間を食っているのは「何をコレ!するか探す」「紹介文を考える」工程であり、ここは規約内で100%自動化できる。

## 推奨方式③の設計（このリポジトリで実装する場合）

既存の `unreplied`（メール返信ルーティン）と同じ構成で作る:

```
毎朝 7:00 の Routine
  │ 1. 楽天ランキングAPI・商品検索APIで対象ジャンルの売れ筋・急上昇を取得
  │ 2. 過去に紹介済みの商品を除外（履歴はこのリポジトリ or Notion に記録）
  │ 3. Claudeが各商品の紹介文（オリジナル文）＋ハッシュタグを生成
  │ 4. 「今日の投稿リスト」（商品リンク＋コピペ用文面）を Gmail下書き or Notion に配信
  ▼
スマホ（通勤中など10分）
  Gmail/Notionを開く → 商品リンクをタップ → ROOMアプリでコレ! → 紹介文をペースト
```

- 1商品あたり30秒程度で投稿でき、文章はオリジナルなので丸パクリ違反の心配もない。
- 週1で「今週のコレ!数・フォロワー・売上」を集計するレポートRoutineも追加可能。

### 実装に必要な準備（ユーザー側）

1. **楽天ウェブサービスのアプリID取得**（無料・楽天IDでログインして https://webservice.rakuten.co.jp/ から発行）
2. 攻めたいジャンル・キーワードのリスト（例: キッチン用品、コスメ、防災グッズ…）
3. 配信先の選択: Gmail下書き / Notionページ のどちらか
4. 1日の投稿目標数（上限200回を踏まえ、まずは20〜30件/日程度を推奨）

## 採用方式（2026-08-09 決定）

ユーザー判断で **②端末内オートクリッカー方式** を採用（端末は iPhone）。以下の手順で運用する。

### iPhone での実装手順（スイッチコントロール）

iPhoneはオートクリッカーアプリがApp Storeで許可されていないため、標準のアクセシビリティ機能「スイッチコントロール」の**レシピ**（指の動きを録画して再生する機能）で実現する。

**初期設定（1回だけ）**

1. 設定 → アクセシビリティ → スイッチコントロール → **レシピ** → 新規レシピを作成（名前: ROOMコレ）
2. 「スイッチを割り当てる…」→ **フルスクリーン** → **カスタムジェスチャ**
3. 録画画面で「ROOMの1周ぶんの指の動き」を実演して保存:
   - コレ!ボタンの位置をタップ → 1〜2秒待つ → 投稿カード1枚ぶん上へゆっくりスワイプ
   - ※事前にROOMのフィードのスクショを見てコレ!位置を確認しておく。コレ!後にポップアップが出る場合は、それを閉じるタップも録画に含める
4. スイッチコントロール設定に戻り「**繰り返し**」をオン、間隔を4〜6秒に設定（画面に触れている間ジェスチャが繰り返される）
5. 設定 → アクセシビリティ → **ショートカット** → スイッチコントロールにチェック（サイドボタン3回押しでON/OFFできるようになる）
6. 設定 → 画面表示と明るさ → **自動ロック → なし**（低電力モードもオフ。稼働中に画面が消えると止まるため）

**毎日の使い方**

1. ROOMアプリでフィード（またはハッシュタグ検索結果）を開く
2. サイドボタン3回押し → スイッチコントロールON → 画面の余白に指を置きっぱなしにする（タッチペン等を固定でも可）→ 自動でコレ!が回り出す
3. 終わったらサイドボタン3回押しでOFF

**運用ルール**

- 投稿ごとに高さが違うため座標がズレて誤タップする。**放置せず近くで監視**し、ズレたら止めてジェスチャを録画し直す（スワイプ距離は短めが安定）
- 1回15〜30分、**1日100コレ以下**（上限200/24hの半分で止める）。就寝中は稼働させない
- 精度・安定性に限界を感じたら、中古Android端末を「コレ!回り専用機」にするのが上位互換（ランダム間隔対応のオートクリッカーアプリが使えるため）

## やらないこと

- ログインセッション（Cookie）を使ったブラウザ自動操作によるコレ!・フォロー・投稿の自動実行
- 他ユーザーの紹介文の流用
- 上限（1h100回/24h200回）に張り付くような高頻度運用
