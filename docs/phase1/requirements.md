# Phase 1 MVP要件定義：LINEでつくる見積書・請求書（開発コード：ラクミツ）

- **作成**：2026-07-18 ／ **ステータス**：v0実装中
- **正式名称はオーナー選定待ち**（候補：ラクミツ／ミツモリン／ポケット見積。出品前に商標・既存サービス名の重複チェック要）

## 1. プロダクト定義

**「PCを開かず、LINEに乱れたメモを送るだけで、インボイス対応の見積書・請求書PDFができて、そのままお客さんに送れる」**

- 買う人：軽貨物・便利屋・清掃・修理業などの現場系ひとり事業主（Misocaを使いこなせていない／現場ではスマホしか触らない層）
- 売り物：**買い切りのGAS+スプレッドシート製テンプレ＋導入手順書**（購入者が自分のLINE公式アカウント・自分のGoogleアカウントで動かす）
- 販路：ココナラ／BOOTH（ハンドルネーム＝匿名運用）
- 価格仮説：本体 ¥9,800（導入代行オプション +¥5,000、業種カスタム +α）※出品前に相場の現物最終確認

## 2. なぜこの形か（設計判断の記録）

| 判断 | 理由 |
|---|---|
| 購入者側アカウントで動かす「テンプレ納品」型 | 当方の固定費・サーバー・個人情報保持をゼロにする（手離れ最優先・月3,000円制約）。naokun先行例と同型 |
| ルールベース解析＋聞き返し（AI APIなし） | 購入者にAPIキー取得をさせない＝導入障壁を下げる。誤解析は生成前の確認ステップで防ぐ。AI解析はv1のオプション（希望者のみ無料のGemini API等） |
| 返信はLINEのreply API中心 | replyメッセージは無料枠の消費対象外のため、購入者のLINE費用も月0円で回る想定（**Phase 1実機テストで要確認**） |
| PDFはDriveリンクで返す | LINE Messaging APIはPDF直接送信不可。リンク共有（閲覧のみ・ファイル単位）で顧客転送を可能にする。プライバシー注意は手順書に明記 |

## 3. ユーザーフロー（MVP）

1. **初期設定（1回だけ）**：手順書に沿って ①スプレッドシートをコピー ②GASをデプロイ ③LINE公式アカウント（無料）を作りWebhook接続 ④LINEで「設定」→ 事業者名・インボイス登録番号・住所・振込先を登録
2. **見積**：トークに「田中様 エアコンクリーニング2台 15000ずつ 出張費3000」のようなメモを送る → 解析結果の確認メッセージ（明細・小計・税・合計）→ 不足があれば**聞き返し**（宛名がない、金額がない等）→「OK」で見積書PDFのリンクが返る
3. **請求**：「請求書にして」→ 直近の見積を請求書に変換（番号採番・支払期限・振込先入り）。見積を経ずメモから直接請求書も可
4. **記録**：発行した帳票は台帳シートに自動記録（番号・宛名・金額・状態）

## 4. 機能要件（v0）

- 入力解析：宛名（様/さん/御中）、品名・数量・単位・単価/金額、「ずつ/各」= 単価、「◯万」= ×10,000、値引き（マイナス）、出張費等の単発金額行
- 消費税：標準10%／軽減8%（行に「※軽減」）、税別入力→外税加算をデフォルト、端数は切り捨て（設定で変更可）
- インボイス記載要件チェック：①発行者名＋登録番号 ②取引年月日 ③取引内容（軽減税率の旨） ④税率区分ごとの合計 ⑤税率ごとの消費税額 ⑥宛名 —— 不足があれば発行時に警告
- 帳票：見積書（有効期限付き）／請求書（支払期限・振込先付き）。テンプレはシート上にあり購入者が自由に装飾変更可
- コマンド：「設定」「ヘルプ」「クリア」「OK」「請求書にして」
- 台帳：発行履歴の自動記録

**非対応（v0ではやらない）**：入金管理・複数スタッフ・手書き写真OCR（v1候補）・郵送・英語

## 5. 無料→有料の導線（憲章必須要件）

- **無料版**：見積書のみ・帳票フッターに「Powered by（プロダクト名）」入り・台帳なし——BOOTH/noteで無料配布し、乱れた入力→PDFの体験をさせる
- **有料版**：請求書＋インボイス要件チェック＋台帳＋フッター削除＋導入サポート
- note記事（半自動執筆）で「インボイスの記載要件6つをLINEで済ませる」系の検索流入を狙う（Phase 2）

## 6. 法規・安全ガードレール

- 税務判断はしない（税理士法配慮）：記載要件の**形式チェックのみ**。「税率・税務の個別判断は税理士へ」を帳票・手順書・販売ページに明記
- 購入者データを当方が預からない構成（購入者のGoogle/LINEアカウント内で完結）
- チャネルアクセストークン等の秘密情報はスクリプトプロパティに保存（シートに書かない）
- 出品・公開・アカウント作成はすべてオーナーが実行（Claudeは成果物と手順書まで）

## 8. マイルストーン（保守的）

最初の1円 = マーケットプレイス初成約。月1万円 = 月1〜2本。月3〜5万円 = 月4〜6本＋導入代行/カスタム加算。「完全放置で売れる」想定はしない（出品文・note記事・改善は手で作る）
