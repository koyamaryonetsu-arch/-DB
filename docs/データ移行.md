## URL を変える所（cinema-cases.vercel.app → 会社のドメイン）
- GAS（mail-intake/*.gs）: CaseMail.gs の CASE_MAIL_APP_URL（通知メールの案件の URL）、Code.gs・Notify.gs・TheaterInfo.gs の URL、flush-notifications を呼ぶ所
- API（api/*.mjs）: LINE の通知の案件の URL（APP_URL）
- Supabase: Database Webhooks（案件の登録・更新 → /api/case-created など）の宛先、Authentication の Site URL・Redirect URLs
- LINE Developers: Webhook URL（/api/line-webhook）
- 書類（DEPLOY.md・SETUP_*.md・CLAUDE.md）
- 使う人: 新しい URL で1回ログインし直す（ブラウザの覚えが URL ごとのため）。客先にも新しい URL を知らせる

## Cloudflare に移す時に気を付けること
- API は Vercel の書き方（handler(req, res)）→ Cloudflare の書き方（Request → Response）に直す。line-webhook は node:crypto（署名の確かめ）→ nodejs_compat か Web Crypto
- AI の処理は1〜2分かかるものがある（作業申請書・安全書類・写真台帳）。無料プランは CPU の時間が足りないので有料プラン
- 送れる大きさは Vercel の 4.5MB → Cloudflare は 100MB（作業申請書の大きい PDF で止まっていたのが楽になる）
- 環境変数: ANTHROPIC_API_KEY・SUPABASE_URL・SUPABASE_SERVICE_ROLE_KEY・SUPABASE_WEBHOOK_SECRET・LINE_CHANNEL_ACCESS_TOKEN・LINE_CHANNEL_SECRET・LINE_TARGET_GROUP_ID（値は小山さんが入れる）
