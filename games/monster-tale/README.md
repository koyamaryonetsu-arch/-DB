# まものがたり 〜よみがえりし魔王〜

iPhoneのブラウザでそのまま遊べる、レトロ風コマンドバトルRPGです。
倒したモンスターが仲間になり、最大4人(勇者+まもの3体)のパーティで魔王討伐を目指します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド不要・依存なし)。
スマホでは **ホーム画面に追加** するとフルスクリーンで快適に遊べます。

### 操作

| 操作 | 内容 |
|---|---|
| 十字キー / 矢印キー / WASD | 移動・カーソル |
| A / Z / Enter / 画面タップ | けってい・しらべる・メッセージ送り |
| B / X / Esc | メニュー・キャンセル |

メニュー項目は**直接タップ**でも選べます。

## ゲームの流れ

1. **ハジマリのむら** 周辺の草原で戦って仲間とレベルを増やす
2. 東の橋の**ばんにんガーディアン**を倒して港町へ
3. 北東の**ほのおのどうくつ**でドラゴロードを倒し「じゃのカギ」を入手
4. 北西の**まおうじょう**でゾルデを討伐(残りHPで本気モードに変化)

## システム

- **仲間システム**: 戦闘勝利後、まものが起き上がって仲間になることがある。
  「まもののおやつ」を戦闘中に使うと仲間になる確率2倍。控えは「ほこら」に預けられ、メニューの「なかま」でいつでも入れ替え可能
- **とくぎ・じゅもん**: 種族ごとの特技(ねむりこな・ひのいき・きゅうけつ 等)、勇者はレベルアップで回復・攻撃呪文を習得
- **状態異常**: ねむり・どく
- **レアモンスター**: 東の地方に低確率で出る「メタルぷに」は経験値180。仲間にできたら超ラッキー
- **オートセーブ**: 戦闘後・買い物・イベント後などに自動保存(localStorage)。メニューから手動セーブも可
- **クリア後**: そのまま冒険を続けてコンプリートを楽しめます

## 技術メモ

- 素の HTML + Canvas + WebAudio。外部ライブラリ・外部アセットなし(完全自己完結)
- ドット絵は全てコード内のピクセル定義から生成(オリジナルデザイン)
- BGM/SEはWebAudioのチップチューン(オリジナル曲)
- `data.js` … スプライト・マップ・種族・スキル・アイテム定義 / `game.js` … エンジン
