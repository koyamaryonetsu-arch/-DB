# まものがたり 〜よみがえりし魔王〜 (v3)

スマホ・PCのブラウザでそのまま遊べる、DQ6風コマンドバトルRPGです。
兄妹ふたりの主人公が、倒したモンスターを仲間にしながら**馬車**のキャラバンで魔王討伐を目指します。
クリア後には裏ボス「りゅうじんカイザー」が待ち構えています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド不要・依存なし)。
スマホでは **ホーム画面に追加** するとフルスクリーンで快適に遊べます。

### 操作

| 操作 | 内容 |
|---|---|
| 十字キー / 矢印キー / WASD | 移動・カーソル |
| A / Z / Enter / 画面タップ | けってい・はなす・しらべる |
| B / X / Esc | メニュー・キャンセル |

メニュー項目は**直接タップ**でも選べます。

## v2の主なシステム (DQ6ベース)

- **馬車システム**: 主人公+仲間7体(戦闘メンバー4+馬車4)。あふれた仲間は「ほこら」へ。
  フィールドでは戦闘メンバーが後ろをついてきて、最後尾を馬車が走る
- **ならびかえ**: メニュー「なかま」で隊列・馬車・ほこらを自由に入れ替え。
  **隊列の前の方ほど敵に狙われやすい**ので、かたい仲間を前へ
- **装備6部位**: けん・たて・あたま・からだ・アクセサリー×2。モンスターも全員装備可能。
  「そうびぶくろ」で管理、店で売買
- **転職 (ダーマしんでん)**: 北東の神殿で転職。せんし/ぶとうか/まほうつかい/そうりょ/とうぞく/まものつかい の基本6職。
  戦闘に勝つと職の熟練が上がり「とくいわざ」を習得(**転職しても忘れない**)。
  せんし+ぶとうかを極めると**バトルマスター**、まほうつかい+そうりょを極めると**けんじゃ**に
- **とくいわざ**: 呪文と特技を統合。種族固有わざ+勇者の呪文+職業で覚えたわざが1つのリストに
- **歩ける街**: 村・港町・キャンプ・神殿の中を自由に散策。宿屋や店は建物のドアから。
  NPCがたくさんいて、話しかけると攻略のヒントをくれる
- **仲間システム**: 戦闘勝利後にモンスターが起き上がって仲間に。
  「まもののおやつ」「なだめる(まものつかい)」「なつきのすず」で確率アップ

## ゲームの流れ

1. ハジマリのむら周辺で仲間とレベルを増やす
2. 東の橋の番人ガーディアンを倒して港町へ → 北東のダーマ神殿で転職
3. 炎の洞窟でドラゴロードを倒し「じゃのカギ」を入手
4. 北西の魔王城でゾルデ討伐(HP半分で本気モード)。クリア後も冒険を続けられる

## 技術メモ

- 素のHTML + Canvas + WebAudio。外部ライブラリ・外部アセットなし(完全自己完結)
- ドット絵・BGM・モンスター・呪文名はすべてオリジナル
- v1セーブデータは自動でv2に引き継がれる
- `data.js` … スプライト・マップ・街・種族・職業・わざ・装備定義 / `game.js` … エンジン

## v3の追加要素

- **兄妹の2人主人公**: 兄(攻撃呪文タイプ)と妹(回復呪文タイプ)。それぞれレベルで固有の得意技を習得し、職業の技と両立
- **戦闘中いれかえ**: 戦闘コマンドから馬車の仲間と交代できる(兄は不可)
- **職業をDQ6式に拡充**: 基本8職(おどりこ・しょうにんを追加)+上級4職(パラディン・レンジャーを追加)、
  上級をマスターした人間だけが就ける最上位「ゆうしゃ」。熟練度に段位名つき
- **買い物プレビュー**: 装備を買うとき「だれがそうびする?」で能力の変化(▲▼)を表示
- **SFC風フィールドメニュー**: 2列コマンド+パーティ窓+所持金窓
- **装備可能部位がモンスターごとに違う**: ゴブリン・ガイコッツは人間と同じフル装備、
  ゴーレム・ドラゴキッズは頭+体+アクセ、コウモリ・ハチ・ゆらびはアクセのみ 等
- **仲間になる確率を引き下げ**(おやつ・なだめる・なつきのすず・まものつかい/レンジャーで補正)
- **裏ボス**: クリア後、炎の洞窟の最深部に「りゅうじんカイザー」出現。勝てば「りゅうじんのたま」入手
- 左右移動時のキャラの向きを修正
