# Claude in Chrome 手順書：シネマPJ LINEへ新規案件を投稿する

この手順書は **Claude in Chrome（ブラウザ側の Claude）** 向けです。
Claude Code 側の `/anken-line` が Notion の送信キューに投稿文を積みます。あなた（Chrome）はそれを LINE に流します。

## 役割分担（前提）

- **Claude Code（`/anken-line`）**：新規案件の検出 → 初期対応診断の生成 → Notion送信キューに投稿文を登録。
- **Claude in Chrome（この手順書）**：送信キューを読み、シネマPJ の LINE グループへ投稿し、送信済みにする。
- **人間（小山さん）**：初回のLINEグループ作成・メンバー招待・「初期対応診断」アカウント追加（後述）。

## 事前設定（人間が一度だけ行う）

1. LINE グループ **「シネマPJ 新規案件」** を作成。
2. メンバーを招待：小山・金子・細萱・山口・若山・大和。
3. 「初期対応診断」用のアカウントをグループに追加（下の運用方式のいずれか）。
4. Chrome で LINE（`https://line.me` のブラウザ版、または LINE 公式アカウントマネージャ）にログインした状態にしておく。

## 毎回の手順（Claude in Chrome）

1. Notion ページ **「📤 LINE送信キュー（シネマPJ）」** を開く（URLはClaude Codeの出力に含まれます）。
2. **未送信項目 `- [ ]`** を上から順に処理する。各項目直下の引用ブロック（`>`）が投稿本文。
3. LINE の **「シネマPJ 新規案件」グループ** を開き、投稿本文を**そのまま貼り付けて送信**。
   - `@here 至急ジャッジ希望` が付いている項目は最優先で送る。
4. 送信できたら Notion 側のチェックを **`- [x]`** に更新する（二重投稿防止）。
5. 全項目を処理したら、要約（送信 n 件／至急 m 件）を残して終了。

### 注意

- 文面は**改変しない**（Claude Code が初期対応診断まで含めて整形済み）。
- 送信に失敗した項目はチェックを付けず、理由をメモして人間に報告。
- LINE 個人情報・グループ内容を外部に出さない。

## 「初期対応診断」アカウントの運用方式（2案）

### 方式A（今すぐ・追加費用なし）：Claude in Chrome が診断ボット役を兼ねる
- 上の投稿文には既に Claude Code 製の「🧭 初期対応診断」が含まれている。
- メンバーが LINE で追加質問（例：「これ誰に頼むべき？」）した場合、Chrome 側 Claude が
  Notion の案件ページと過去案件を参照して**返信を下書き** → 人間承認の上で投稿、という運用にできる。
- LINE 上は「中の人（Claude in Chrome）」が初期対応診断を担う形。専用アカウント不要で開始できる。

### 方式B（本格運用）：LINE Messaging API で専用ボットアカウントを作る
- LINE Developers でチャネル（Messaging API）を作成し、Bot を「シネマPJ 新規案件」グループに参加させる。
- Webhook を受けるサーバ（例：Cloud Run / GAS）を用意し、新規案件の Push 送信・質問への自動診断応答を実装。
- これは Claude Code/Chrome だけでは完結しない**インフラ構築**が必要（小山さんの意思決定事項）。
- 本格運用に移すと「新規案件登録 → 完全自動で LINE 通知＋診断ボット常駐」が実現する。

> まずは方式A で運用開始 → 効果を見て方式B（完全自動・専用ボット）へ、が現実的な順序です。
