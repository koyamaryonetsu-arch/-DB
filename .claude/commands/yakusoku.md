# 約束トラッカー（自動）

送受信メールと議事録から、小山さん（菱熱）が**相手に約束したこと**と、**相手の回答待ちになっていること**を期限付きで抽出し、Notion の約束トラッカーを最新化する。振り返りDBが「過去」なのに対し、これは「これから果たすべき宿題」を取りこぼさないためのもの。

- 社内メンバー（参考）: 金子 `r.kaneko0511@gmail.com`、若山 `s.wakayama1327@gmail.com`、山口 `hs.yamaguchi0404@gmail.com`、大和 `a.oowa@ryonetsu-ai.com`
- トラッカーページ名（既定）: `📌 約束・宿題トラッカー（小山）`
- 無い場合の作成先: 「koyama Daily Dashboard」配下（`https://www.notion.so/35fd405a0cb48192adabf9f4301d50c0`）

## 実行ルール（重要）

- **OK 確認は不要**。抽出したらそのまま Notion を更新（または新規作成）する。
- メールは読むだけ（送信・下書きはしない）。
- 期限が明示されていない場合は本文の文脈から推定。推定できなければ「期限未設定」とし、捏造しない。
- 完了後はサマリーを表示して**そのまま終了**。

## ステップ1: 既存トラッカーの確認

`notion-search` で `約束・宿題トラッカー` を検索。あれば `notion-fetch` で現在の登録内容を取得（重複・完了判定の基準にする）。

## ステップ2: ソース収集（並列実行可）

1. **自分の送信**: Gmail `search_threads` → `in:sent newer_than:21d`
2. **重要な受信**: `in:inbox is:important newer_than:21d -from:noreply -from:mailer-daemon`
3. **議事録**: `notion-search`（query_type: internal）で直近の議事録要約（「文字起こし」配下、おおむね過去3週間）。`created_date_range` で期間を絞る

ヒットしたスレッドは `get_thread`（FULL_CONTENT）、議事録は `notion-fetch` で本文確認。

## ステップ3: 抽出ルール

各メッセージ/議事録から以下を抽出する:

- **自分ボール（要対応）**: 小山さん・菱熱側が発した「〜までに回答/提出/お送りします」「追って（改めて）ご連絡します」「確認して折り返します」「見積を出します」等の約束
- **相手ボール（待ち）**: 取引先が「〜までに回答します」「確認して連絡します」と述べ、当方が回答待ちの事項

各項目の記録フィールド:

`期限` / `相手（会社・担当）` / `案件・物件` / `内容` / `種別`(自分ボール｜相手ボール) / `出典`(メール件名 or 議事録名・日付) / `状態`(未対応｜対応中｜完了)

- 期限はメール/議事録の日付＋本文の言い回し（「今週中」「5/19まで」等）から具体日付に正規化。不明は「期限未設定」。
- その後のメールで既に履行済み（回答送信済み等）と判断できるものは `完了`。

## ステップ4: Notion 更新

- 既存ページがある場合: `notion-update-page` で内容を最新化。同一案件・同一内容は1件に統合、履行済みは `完了` に更新、新規は追加。
- 無い場合: `notion-create-pages` で既定の作成先に `📌 約束・宿題トラッカー（小山）` を新規作成。

体裁: 表形式。**期限の昇順**、`自分ボール` かつ `未対応/対応中` を上部に。完了分はページ下部に簡潔にまとめる。

## ステップ5: サマリー報告（表示して終了）

```
✅ 約束トラッカー更新完了。
Notion: <ページURL>

⚠️ 期限が近い/超過（自分ボール）:
- <期限> <相手> / <内容>（出典: <件名/議事録>）
...

相手ボール（待ち）: M件 ／ 今回 新規 a件 / 更新 b件 / 完了化 c件
```

該当が無くてもサマリーを表示し、そのまま終了する。
