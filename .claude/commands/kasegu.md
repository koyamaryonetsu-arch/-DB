# /kasegu — 半自動副業ツール

ユーザーが「ほぼ自動」で月3万円を目指せるよう、トレンドリサーチ→コンテンツ生成→保存→収益ログ更新までを半自動で実行する。
**Claude は独断で投稿・販売しない。** 生成物はすべて Google Drive に保存し、ユーザーが最終確認のうえ note.com / メルカリ / KDP / X に手動で投稿する前提。

## 全体ルール

- 各ステップで生成物を提示し、**必ずユーザーの「OK」「修正指示」「skip」を待つ**。独断で次工程に進まない。
- 著作権侵害・薬機法・景品表示法・各プラットフォーム規約に反するコンテンツは生成しない。判断に迷ったら確認する。
- 金額・効果・ランキングなど **断定的・誇大表現** を避け、体験ベース・引用ベースで書く。
- アフィリエイトリンクを含める場合は **PR 表記** をユーザーに案内する（景品表示法・ステマ規制対応）。
- 引数 `$ARGUMENTS` を見て分岐:
  - 空 または `menu` → メニュー表示（後述）
  - `setup` → プロフィール初期設定
  - `note` [トピック] → note記事生成（メインモード）
  - `mercari` → メルカリ出品文生成
  - `kindle` [トピック] → Kindle短編企画
  - `sns` [記事名 or URL] → SNS拡散素材生成
  - `report` → 月間進捗レポート

## ステップ共通: プロフィール読込

毎回最初に Google Drive で `副業ツール/profile.md` を `search_files` → 見つかれば `read_file_content` で取得。
無ければ「`/kasegu setup` を先に実行してください」と案内して該当モードを終了（`setup` モードを除く）。

プロフィールには以下が入る:
- ニックネーム
- 得意分野 / 経歴
- 興味分野（記事ジャンルのベース）
- 目標月収（既定 ¥30,000）
- 想定読者像
- 文体の好み（です・ます / だ・である / カジュアル）
- アフィリエイト ID（A8 / もしも / Amazon Associates — 任意）

## モード: setup（初回設定）

1. 以下を 1 問ずつ対話で聞く（既に Drive にプロフィールがあれば差分更新モード）:
   - ニックネーム（記事署名用）
   - 得意分野・職歴（例: SEエンジニア15年、簿記2級）
   - 興味のあるジャンル 3つ（例: 在宅ワーク、節約、副業）
   - 月の目標額（既定 ¥30,000）
   - 想定読者（例: 30代会社員 副業初心者）
   - 文体（です・ます / だ・である / フランク）
   - アフィリエイト ID（持っていれば。無くても可）
2. すべての回答を YAML 形式の markdown にして `副業ツール/profile.md` として Google Drive に保存（`create_file`）。
3. 同時に `副業ツール/log/sales.csv` を空のヘッダ付きで作成: `date,channel,title,price,units,revenue,note`
4. 「セットアップ完了。次は `/kasegu note` で初記事を作りましょう」と案内。

## モード: note（メインモード・おすすめ）

### Step 1: トレンドリサーチ

プロフィールの興味分野から、`$ARGUMENTS` の追加引数を優先キーワードとして使う。
未指定なら興味分野を1つ自動選択（or ユーザーに選ばせる）。

WebSearch で以下を **並列実行**:
- `note 人気 [興味分野] 2026`
- `[興味分野] 悩み 検索ボリューム`
- `[興味分野] 副業 やり方`

検索結果から **読者が今困っていそうなテーマ** 3つを抽出し、以下フォーマットで提示:

```
今週の note トピック候補:

[1] タイトル案: <30字以内>
    切り口: <なぜ今これが刺さるか 1行>
    想定読者: <誰の何の悩みを解決>
    競合: <既存note記事の本数・価格帯の所感>
    推定難易度: 低 / 中 / 高

[2] ...
[3] ...

どれで進めますか?  番号 / `他案` / `修正` を返してください。
```

ユーザー選択を待つ。

### Step 2: 構成設計

選ばれたトピックについて以下を提示:

```
タイトル案（3つから選んでください）:
  A: <SEO 重視>
  B: <感情訴求 重視>
  C: <数字・具体性 重視>

価格設定の推奨: 無料 / ¥500 / ¥980  → <理由 1行>

構成案:
  リード（共感フック）
  H2-1 <見出し>
  H2-2 <見出し>
  H2-3 <見出し>  ← ここから有料（¥500以上の場合）
  H2-4 <見出し>
  H2-5 <見出し>
  まとめ + 行動喚起

想定文字数: 2500〜3500字
```

「OK / 修正指示 / タイトル◯番」をユーザーから受ける。

### Step 3: 本文生成

確定した構成・タイトル・価格・文体に従い、全文を生成。

ルール:
- 冒頭 200字以内で **読者の悩みに共感し、得られる結論を予告**
- 本文は **体験談 + 具体的な手順** を中心に
- 数字・固有名詞は **検証できないものは書かない**（プロフィール未記載の経歴を捏造しない）
- 有料記事の場合、無料部分の最後に「ここまでが無料パート」マーカーを入れ、有料パートに **再現可能な手順・テンプレ・チェックリスト** を入れる
- 文末にプロフィールリンクの差し込み位置 `【プロフィール】` を残す
- アフィリエイトリンクの差し込み候補位置を `【AFF: <商品ジャンル>】` で残す（次ステップで埋める）

### Step 4: アフィリエイト提案

記事内容に合わせて、A8.net / もしも / Amazon Associates から関連ジャンルを 3-5 個提案（具体的なURLは提示せず、ユーザーが自分のIDで取得する前提）:

```
アフィリエイト候補（あなたのアカウントで取得して差し込んでください）:
- [Amazon] <書籍名 1-2冊>
- [A8.net] <該当しそうなプログラム名 1-2件>
- [もしも] <該当しそうなプログラム名 1件>

※ PR表記の例文:
「※本記事にはアフィリエイトリンクを含みます」 を記事冒頭に必ず明記してください（景表法・ステマ規制対応）
```

### Step 5: SNS拡散素材

note記事を投稿後に拡散するための X(Twitter) 投稿 3案を生成:

- A案: 結論 + 共感フック（120字以内）
- B案: 数字訴求（120字以内）
- C案: 質問形式（120字以内）

各案にハッシュタグ候補 2-3 個。

### Step 6: Drive に保存

ユーザーの「OK」を受けて、Google Drive に保存（`create_file`）:

- `副業ツール/note/YYYY-MM/YYYY-MM-DD_<slug>.md` — 本文
- `副業ツール/note/YYYY-MM/YYYY-MM-DD_<slug>_sns.md` — SNS素材
- `副業ツール/log/sales.csv` に行を追加（売上単価・本数は空欄、後日 `/kasegu report` で更新）

保存完了後、note 投稿の手順をユーザーに案内:

```
保存完了。次の手順で投稿してください:

1. https://note.com/ にログイン
2. 「投稿」→「テキスト」を開く
3. Drive の <ファイルパス> をコピー&ペースト
4. タイトル・価格設定を確認
5. 公開ボタンを押す前に: PR表記・誤字・アフィリリンクを最終確認
6. 投稿URLを後で `/kasegu report` に登録してください
```

## モード: mercari（メルカリ出品文）

ユーザーから以下を対話で受ける:
1. 商品名（型番含む）
2. 状態（新品/未使用に近い/目立った傷なし/やや傷あり/傷や汚れあり/全体的に状態が悪い）
3. 購入時期・購入元（不明可）
4. 付属品の有無
5. 出品希望価格

ステップ:
- WebSearch で `<商品名> メルカリ 相場 売れ筋` を検索し、相場感をフィードバック
- 以下フォーマットで出品文を生成:

```
【商品名】
<検索キーワードに強い商品名+型番+色+サイズ>

【商品の状態】
<選択した状態>

【商品の説明】
- 購入時期: <ユーザー入力>
- 使用頻度: <推定 or 確認>
- 付属品: <ユーザー入力>
- キズ・汚れ: <ユーザー記述に基づき具体的に>

【発送】
- 配送方法: <推奨>
- 発送までの日数: <推奨>

【値下げ交渉】
コメントにてお気軽にどうぞ。常識の範囲内で対応いたします。

【ハッシュタグ案】
#<関連タグ1> #<関連タグ2> #<関連タグ3>
```

- 写真撮影のチェックリストも提示（正面/横/裏/ロゴ/傷/付属品の6枚推奨）
- `副業ツール/mercari/YYYY-MM-DD_<商品名>.md` として Drive 保存

**禁止事項を必ず案内**: 偽ブランド・チケット高額転売・医薬品・現金・たばこ等の出品禁止物に該当しないか確認。

## モード: kindle（Kindle短編企画）

プロフィールの得意分野と `$ARGUMENTS` から短編 Kindle 本の企画を生成:

```
書名案 3つ:
  A: <検索意図に強い書名>
  B: <感情訴求>
  C: <ターゲット明示>

サブタイトル例:
ターゲット読者:
価格戦略: ¥250 / ¥500 / ¥980 のいずれを推奨
ページ数目安: 30〜60 ページ（短編）
章立て（推奨 5〜7章）:
  1. <章タイトル>
     - <章内見出し x 3>
  2. ...

差別化ポイント（既存本との違い）:
出版後のマーケ動線: note記事 → Kindle、X固定ポスト誘導、KDPセレクト90日特典
```

ユーザーが OK したら、`副業ツール/kindle/<書名slug>/outline.md` として Drive 保存。
**本文執筆は別途 `/kasegu kindle write <書名slug> <章番号>` で章単位に生成**（コンテキスト圧迫回避のため）。

## モード: sns（既存記事のリパーパス）

引数で受けた記事名 or URL からコンテンツを取得:
- URL なら WebFetch
- 記事名なら Drive `副業ツール/note/` 配下を `search_files`

取得した本文から、以下を生成:

```
X(Twitter) スレッド（5ツイート）:
  1/5: <フック>
  2/5: <結論先出し>
  3/5: <根拠1>
  4/5: <根拠2>
  5/5: <CTA + 記事リンク>

X 単発投稿 3案:
Threads 投稿 1案:
LinkedIn 投稿 1案（ビジネス向けの場合）:

投稿スケジュール推奨:
  記事公開直後: スレッド投稿
  公開3日後: 単発A
  公開1週間後: 単発B
```

Drive の元記事と同じフォルダに `_repurpose.md` として追記保存。

## モード: report（月間進捗レポート）

1. Drive `副業ツール/log/sales.csv` を読み込む（無ければ「ログがありません。`/kasegu setup` を実行してください」）
2. 今月分を集計:

```
=========================================
 副業レポート  YYYY年MM月
=========================================
目標額:      ¥30,000
今月実績:    ¥XX,XXX  ( XX% )
記事公開数:  N本（note: A、Kindle: B、メルカリ: C）

チャネル別売上:
  note:    ¥XX,XXX  ( N本販売 )
  Kindle:  ¥XX,XXX  ( N冊販売 )
  mercari: ¥XX,XXX  ( N点販売 )

TOP3 売上記事:
  1. <タイトル>  ¥X,XXX
  2. ...
  3. ...

来月の推奨アクション:
- <売れ筋ジャンルの深掘り提案>
- <稼働が止まっているチャネルへの提案>
- <未投稿のドラフトが Drive にあれば指摘>
```

3. ユーザーに今月の追加実績入力を促す（売れた記事・金額・本数）。入力があれば CSV に追記。
4. Notion が設定されていれば（環境変数や profile.md にトップページIDがあれば）同じ内容をページとして追記。

## エラー時の動作

- Google Drive MCP が利用できない場合 → ローカル `/tmp/kasegu/` に同じパス構造で保存し、後で Drive にアップする旨を案内
- WebSearch がブロックされた場合 → ユーザーに既知のトピックを直接指定してもらう
- いずれのモードでも、ユーザーが `cancel` / `中止` と入力したら即終了

## 重要な注意（必ず冒頭または最後に1回ユーザーに表示）

- 本ツールは **副業の自動化補助** であり、収益を保証するものではありません。
- 投稿・販売・税務申告の最終責任はユーザーにあります。
- 各プラットフォームの利用規約（特に AI 生成物の取り扱い、note の自動投稿禁止、KDP のAI開示義務など）を必ず守ってください。
- 著作権・肖像権・商標・薬機法・景品表示法・ステマ規制に抵触しないよう、投稿前にユーザーが最終確認してください。
- 年間20万円超の副業所得は **確定申告** が必要です（給与所得者の場合）。
