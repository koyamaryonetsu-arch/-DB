# ブレイヴ・レガシー 〜第一章 はじまりの島〜

ドラゴンクエストIIIの世界観（16歳の旅立ち・王様への謁見・酒場での仲間集め・職業・昼と夜・コマンドバトル）に
オマージュを捧げた、ブラウザで遊べるオリジナルRPGです。
グラフィック（ドット絵）・音楽・効果音・シナリオ・固有名詞はすべてコードで生成したオリジナルで、既存作品の素材は使っていません。

## あそびかた

- `dist/brave-legacy.html` をダブルクリックで開けばそのまま遊べます（1ファイル完結・オフライン可）。
- 開発時は `index.html` をブラウザで開きます（`src/*.js` を順に読み込みます）。

| 操作 | キーボード | スマホ |
|---|---|---|
| いどう | ↑↓←→ / WASD | 画面下の十字パッド |
| けってい・はなす・しらべる | Z / Enter / Space | A |
| キャンセル・コマンド | X / Esc | B |

## 第一章の内容

- オープニング：星の声による性格診断 → 16歳の誕生日の朝、母に起こされる
- ソレイア城下町：王様への謁見、マルタの酒場（仲間の加入・離脱・新規登録）、武器屋・防具屋・道具屋・宿屋・教会、宝物庫、井戸の底の「ほしのかけら」収集家
- オープンワールドのソレイア島：昼夜サイクル（夜は強い魔物が出現）、地形ごとのエンカウント、毒の沼、隠しアイテム
- ノルデ村／みさきの洞窟（湖の地下道）／ささやきの塔（5階建て・中ボス「いしのばんぺい」）／いやしのほこら／しるべの洞窟（ボス「ボルザーク」）
- メインクエスト：王様 → 塔の賢者から「ふるびたカギ」 → ドーランから「ばくれつだま」 → 封印の岩を爆破 → ボス撃破 → 旅の門（第一章クリア）
- やりこみ：島に10個ある「ほしのかけら」を集めると報酬（はがねのつるぎ 等）
- 職業：勇者・戦士・武闘家・僧侶・魔法使い・商人・遊び人（性格で成長が変化）
- セーブ：教会／王様／メニューの「きろく」（3スロット、ブラウザに保存。claude.ai のアーティファクト上ではアカウントにも保存）

## ファイル構成

```
index.html            開発用エントリ
src/core.js           画面スケーリング・入力（キー/タッチ）・シーンスタック・フェード・描画ヘルパ
src/audio.js          WebAudio チップチューン（BGM/ジングル/SE を MML 風データから合成）
src/gfx_chars.js      キャラクタードット絵（16×16、4方向×2フレーム、44種）
src/gfx_monsters.js   モンスタードット絵（26種、ボス含む）
src/gfx_tiles.js      マップタイル（地形・町・ダンジョン・小物）
src/data.js           職業・性格・呪文・アイテム・装備・モンスター・出現テーブル・お店
src/game.js           パーティ／成長／所持品／フラグ／時間／セーブ
src/ui.js             メッセージウィンドウ・メニュー・名前入力・ステータス窓
src/maps.js           ワールドマップと町・ダンジョン（ASCII レイアウト＋NPC・宝箱）
src/field.js          フィールド探索（移動・隊列・NPC・昼夜ライティング・エンカウント）
src/menu.js           フィールドのコマンドメニュー（じゅもん・どうぐ・そうび・つよさ・きろく・ちず…）
src/battle.js         コマンドバトル
src/events.js         ストーリーイベント・施設（酒場・店・宿・教会）
src/main.js           タイトル・起動
tools/build.mjs       1ファイル版の生成（dist/brave-legacy.html）
tools/preview_*.html  ドット絵・サウンドの確認用ページ
```

## ビルド

```bash
node tools/build.mjs            # dist/brave-legacy.html を生成
node tools/build.mjs out.html   # claude.ai アーティファクト用（body 断片）も出力
```

## 拡張のしかた（第二章に向けて）

- マップ追加：`src/maps.js` の `MAPDEFS` に ASCII レイアウトと `warps` / `npcs` / `chests` / `hidden` を追加
- 会話・イベント：NPC の `talk` に文字列・配列・`{day, night}`・async 関数のいずれかを指定。大きなイベントは `src/events.js`
- モンスター：`src/data.js` の `MONSTERS` と `ENCOUNTERS`、見た目は `src/gfx_monsters.js`
- 呪文・装備：`SPELLS` / `ITEMS`、職業ごとの習得レベルは `JOBS[job].spells`
