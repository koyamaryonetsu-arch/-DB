# ラクミツ（開発コード）— LINEでつくる見積書・請求書

LINEに乱れたメモを送るだけで、インボイス対応の見積書・請求書PDFを返すGAS製ツール。
購入者が自分のGoogleアカウント＋LINE公式アカウント（無料枠）で動かす**買い切りテンプレ**として販売する。

要件定義：[docs/phase1/requirements.md](../../docs/phase1/requirements.md)（リポジトリルート側）

## 使用イメージ

```
あなた：田中様
        エアコンクリーニング 2台 15000ずつ
        出張費 3000
ボット：【確認】田中 様
        ・エアコンクリーニング 2台 @15,000 = ¥30,000
        ・出張費 ¥3,000
        小計 ¥33,000 ／ 消費税 ¥3,300 ／ 合計 ¥36,300
        このままでよければ「OK」→見積書 …
あなた：OK
ボット：✅ 見積書を作成しました（番号 M20260718-01）PDF：https://…
あなた：請求書にして
ボット：✅ 請求書を作成しました（番号 R20260718-01）PDF：https://…
```

## 構成

```
src/
  appsscript.json  GASマニフェスト（V8・ウェブアプリ設定・スコープ）
  main.gs          Webhookエントリ（doPost/doGet）
  dialog.gs        対話フロー（下書き・聞き返し・コマンド・発行指示）
  parser.gs        乱れた入力→明細の解析（純粋JS。Nodeでテスト可能）
  document.gs      帳票生成（テンプレ流し込み→PDF→Drive共有リンク→台帳）
  setup.gs         初期セットアップ（設定/台帳/テンプレシートの自動生成）
test/
  parser.test.js   パーサーのローカルテスト（node test/parser.test.js）
docs/
  setup-guide.md   導入手順書（オーナー実機テスト用＝購入者向けドラフト）
```

## 解析の約束事（テストで固定済み）

- 「2台 15000」＝数量2×単価15,000 ／「2台**で**30000」＝合計30,000 ／「ずつ・各」＝単価
- 「1.5万」→15,000、全角・カンマ・×・円は自動正規化
- 「様/さん/御中」→宛名、「値引き」→マイナス、「※軽減」→8%、「税込」→内税計算
- 金額のない品目・宛名なしは**聞き返し**（生成前に必ず確認ステップを挟む）

## 開発メモ

- パーサーのテスト：`node test/parser.test.js`（26件）
- GAS側はLINEチャネルがないと実機確認不可 → 導入手順書の手順でオーナーが接続後にテスト
- 税務判断はしない（形式チェックのみ）。v0の非対応：入金管理・写真OCR・明細11行以上の帳票
