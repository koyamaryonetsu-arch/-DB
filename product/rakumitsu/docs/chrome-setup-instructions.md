# Claude in Chrome 用：ラクミツ実機セットアップ＆テスト指示文

使い方：下の枠内を丸ごと Claude in Chrome に貼る。所要約20分。
役割分担：**Claude in Chrome＝画面操作の補助と誘導／オーナー＝アカウント作成・規約同意・秘密情報・承認ボタン**。
スマホでの最終デモ（友だち追加〜メッセージ送信）はオーナーが手動で行い、結果を Claude Code に報告する。

```
【ラクミツ実機セットアップ補助】
あなた（Claude in Chrome）への依頼です。私のブラウザで、LINE見積ツール「ラクミツ」のセットアップを手伝ってください。全5ステップ、各ステップ完了時に一言報告してください。

■ 大原則（必ず守る）
- 新規アカウントの登録ボタン、利用規約・プライバシーポリシーへの同意、支払い・課金に関わるボタンは、絶対に自分でクリックせず私に交代する
- チャネルアクセストークン等の秘密情報は、私が自分でコピー＆貼り付けする。あなたはチャットや報告文に書き写さない
- この指示にないサイトへのアクセス、投稿、購入、設定変更は一切しない
- エラーや想定外の画面が出たら、操作を止めて画面の状況を報告する

■ ステップ1：コードの設置（Googleスプレッドシート＋Apps Script）
1. sheets.new を開き、新規スプレッドシートの名前を「ラクミツ」にする
2. メニュー「拡張機能」→「Apps Script」を開く
3. 左の⚙「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
4. 別タブで GitHub の次のフォルダを開く（私のログイン済みセッションで見える）：
   https://github.com/koyamaryonetsu-arch/-DB/tree/claude/revenue-tool-project-39inwd/product/rakumitsu/src
   6ファイルを1つずつ「Raw」表示で開き、全選択コピーして Apps Script に貼り付ける：
   - appsscript.json：既存の中身を丸ごと置き換え
   - main.gs / dialog.gs / parser.gs / document.gs / setup.gs / line.gs：エディタの「＋」→「スクリプト」で同名ファイルを作成して貼り付け（拡張子は自動）
   ※GitHubが開けない・権限エラーの場合は私に交代
5. 保存（Ctrl+S）し、ファイルが6つ＋マニフェストで揃っているか確認して報告

■ ステップ2：初期セットアップと解析テスト
1. エディタ上部の関数プルダウンで initialSetup を選び「実行」
2. Googleの権限承認画面が出たら私に交代（承認は私がクリックする）
3. 完了後、スプレッドシート側に「設定」「台帳」「T_見積書」「T_請求書」タブができたことを確認
4. 関数 testParse を選んで実行し、実行ログに明細（エアコンクリーニング…）と合計が出ることを確認して報告
5. 「設定」タブを開いた状態で私に交代（事業者名・インボイス登録番号・振込先は私が入力する）

■ ステップ3：LINE公式アカウント（私がメイン、あなたは誘導のみ）
1. https://www.lycbiz.com/jp/service/line-official-account/ を開く
2. アカウント開設の入力・登録・規約同意はすべて私が行う。あなたは「次に押す場所」「入力欄の意味」を案内するだけ
3. 開設できたら https://developers.line.biz/ja/ を開き、該当チャネルの Messaging API を有効化する画面まで誘導する
4. 「Messaging API設定」タブ最下部の「チャネルアクセストークン（長期）」は、発行ボタンも コピーも私が行う。あなたはトークンを読み上げたり書き写したりしない

■ ステップ4：トークン設定とデプロイ（Apps Script）
1. 「プロジェクトの設定」→「スクリプト プロパティ」→「スクリプト プロパティを追加」まで誘導。プロパティ名に
   LINE_CHANNEL_ACCESS_TOKEN
   と入力し、値の欄は私がトークンを貼る（あなたは触らない）
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」→ 説明は任意、
   「次のユーザーとして実行：自分」「アクセスできるユーザー：全員（匿名ユーザーを含む）」を選んでデプロイ（最終ボタンは私が押す）
3. 表示されたウェブアプリURL（https://script.google.com/macros/s/…/exec）をコピーして手元に控えるよう私に伝える

■ ステップ5：Webhook接続（LINE Developers）
1. 「Messaging API設定」→ Webhook URL にステップ4のURLを貼り、「検証」を押して「成功」を確認 →「Webhookの利用」をONにする
2. 「LINE公式アカウント機能」の「応答メッセージ」を必ず「オフ」にする（編集リンクから LINE Official Account Manager が開く。オフ切り替えの最終クリックは私でもあなたでも可だが、変更内容を先に説明すること）
3. 友だち追加用QRコードを画面に表示した状態で作業終了。以降のテストは私がスマホで行う

■ 完了報告の形式（最後にまとめて）
- 完了したステップ番号
- エラーが出た箇所と画面の状況
- 私への引き継ぎ事項（トークンやURLの「値そのもの」は書かない。どこにあるかだけ）
```

## Claude in Chrome 終了後：スマホでの5分デモ（オーナー手動）

LINEで友だち追加し、以下を順に送って動作確認する：

| 送る | 期待する返事 |
|---|---|
| `ヘルプ` | 使い方が返る |
| `田中様`＋改行＋`エアコンクリーニング 2台 15000ずつ`＋改行＋`出張費 3000` | 明細と合計 ¥36,300 の確認 |
| `OK` | ✅見積書PDF（番号 M…）→ リンクを開いてA4帳票を確認 |
| `請求書にして` | ✅請求書PDF（番号 R…）→ 振込先・支払期限入りを確認 |
| `作業一式`（金額なし） | 「金額を教えてください」と聞き返される |

**結果は Claude Code（このプロジェクトのセッション）に報告**：うまくいった／いかない場合はボットの返事の文言・Apps Scriptの「実行数」画面のエラー・スクショのどれかを貼る。
