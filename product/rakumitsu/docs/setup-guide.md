# ラクミツ 導入手順書（v0）

対象：オーナーの実機テスト用。そのまま購入者向け手順書のドラフトを兼ねる（販売時はスクリーンショットを追加）。
所要：約20分。費用：0円（Google・LINEとも無料枠内）。
⚠️ アカウント作成・外部サービスの操作はすべて**人間が実行**してください（Claudeは手順書まで）。

## 手順1：スプレッドシートとGASを用意（5分）

1. [Google スプレッドシート](https://sheets.new)を新規作成し、名前を「ラクミツ」にする
2. メニュー「拡張機能」→「Apps Script」を開く
3. エディタ左の「プロジェクトの設定」⚙ → 「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
4. `src/` の各ファイルをエディタに作成して貼り付ける：
   - `appsscript.json`（表示されたものを丸ごと置き換え）
   - `main.gs` `dialog.gs` `parser.gs` `document.gs` `setup.gs` `line.gs`（「ファイル＋」→スクリプトで同名作成）
5. 保存（Ctrl+S）

## 手順2：初期セットアップ（3分）

1. エディタ上部の関数選択で `initialSetup` を選び「実行」→ 権限承認（自分のアカウント）
2. スプレッドシートに「設定」「台帳」「T_見積書」「T_請求書」タブができる
3. **「設定」タブに事業者名・インボイス登録番号（T＋13桁）・住所・振込先を入力**
4. 動作確認：関数 `testParse` を実行 → ログに明細と合計が出ればパーサー正常

## 手順3：LINE公式アカウントを作成（5分・人間承認事項）

1. [LINE公式アカウント](https://www.lycbiz.com/jp/service/line-official-account/)を無料開設（メール登録でOK・個人名不要、屋号で可）
2. [LINE Developers](https://developers.line.biz/ja/) にログイン → 該当チャネルの **Messaging API** を有効化
3. 「Messaging API設定」タブ最下部で**チャネルアクセストークン（長期）を発行**しコピー

## 手順4：トークンを設定してデプロイ（4分）

1. GASエディタ「プロジェクトの設定」⚙ → スクリプト プロパティ → 追加：
   - プロパティ：`LINE_CHANNEL_ACCESS_TOKEN` ／ 値：手順3のトークン
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員（匿名ユーザーを含む）**
3. 発行された **ウェブアプリURL** をコピー

## 手順5：Webhookをつなぐ（3分）

1. LINE Developers「Messaging API設定」→ Webhook URL に手順4のURLを貼り「検証」→ 成功を確認 → **Webhookの利用：ON**
2. 同画面またはLINE Official Account Manager「応答設定」で：
   - **応答メッセージ：オフ**（これを忘れると定型文が混ざる）
   - あいさつメッセージ：任意
3. QRコードから自分のLINEで友だち追加

## 手順6：5分デモ（オーナー確認用）

| 送る | 期待する返事 |
|---|---|
| `ヘルプ` | 使い方が返る |
| `田中様`＋改行＋`エアコンクリーニング 2台 15000ずつ`＋改行＋`出張費 3000` | 明細と合計¥36,300の確認 |
| `OK` | ✅見積書PDF（番号 M…）のリンク。開いてA4帳票を確認 |
| `請求書にして` | ✅請求書PDF（番号 R…）。振込先・支払期限入り |
| `作業一式`（金額なし） | 「金額を教えてください」と聞き返される |

## トラブルシュート

| 症状 | 対処 |
|---|---|
| 返事が来ない | Webhook ON？ 応答メッセージOFF？ URL検証は成功？ デプロイは「全員（匿名）」？ |
| 「LINE_CHANNEL_ACCESS_TOKEN 未設定」 | 手順4-1のスクリプトプロパティを確認 |
| 「テンプレートがありません」 | `initialSetup` を実行 |
| PDFリンクが開けないと言われた | Driveの共有が「リンクを知っている全員」になっているか（自動設定）。社外秘の案件では共有リンクの扱いに注意 |
| コードを直したのに反映されない | 「デプロイ」→「デプロイを管理」→ 既存デプロイを**編集して新バージョン**にする |

## 運用メモ

- 返信はLINEの reply API のみ＝**無料メッセージ枠を消費しない想定**（初回実機テストで要確認）
- 帳票データはすべて自分のスプレッドシート・Drive内。外部サーバーなし
- 税率・税務の個別判断はできません。不明点は税理士へ（本ツールは書式の形式チェックのみ）
