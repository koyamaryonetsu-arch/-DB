# Claude for Chrome 用 出版指示書（KDP）

このファイルは、Amazon KDP での出版作業を **Claude for Chrome（ブラウザ操作版Claude）** に任せるための指示書です。
下の「■ Claude for Chrome に貼り付ける指示文」を **まるごとコピーして** Claude for Chrome に渡してください。

> 重要：Claude for Chrome はブラウザを操作できますが、**本人確認・銀行口座・税務情報・最終的な「出版」ボタン・価格の確定**といった「お金と本人に関わる操作」は、必ずあなた自身が確認してから進めます。指示文の中にその停止ポイントを組み込んであります。勝手に身元情報や口座情報を入力させないでください。

---

## 0. 事前にあなた（人間）が用意するもの

Claude for Chrome に渡す前に、これだけは人間側で準備します（自動化できない／させてはいけない部分です）。

1. **原稿ファイル**：`原稿_非エンジニアのためのAI仕事術.md` を、Word または Google ドキュメントに貼り付けて体裁を整え、**.docx 形式**で書き出す。
   - 見出し（#）はWordの「見出し1/2」スタイルに、本文は標準スタイルに。
   - 章の区切りで改ページを入れる。先頭にタイトルページ、目次（任意）。
2. **表紙画像**：縦長 1:1.6（推奨 1600×2560px 以上）の JPG/PNG を1枚。
   - Canva 等で作成。タイトル「非エンジニアのためのAI仕事術」と筆名「AI活用戦士」が読めること。
   - 自分で用意できない場合は、KDP の「Cover Creator（無料表紙作成）」を後述の手順内で使う。
3. **Amazonアカウント**：KDP（kdp.amazon.co.jp）で使うAmazonアカウントのログイン情報。新規でも既存でも可。
4. **支払・税務情報**：振込先銀行口座、税に関する情報（マイナンバー等の本人情報）。
   - これは **あなた自身が入力** します。Claude には入力させないでください。

## 1. 出版後の販促タスク（Claude for Chrome に続けて依頼してよい範囲）

出版が承認されたあと、以下も Claude for Chrome に依頼できます。同じく確認ルールは適用してください。

### A. KDPセレクト 90日特典の設定
- KDPの本の管理画面で「プロモーション」を開く。
- **無料キャンペーン（5日間）** または **Kindleカウントダウン** を、出版承認の翌週開始で予約設定する。
  - 推奨：初週は無料キャンペーン5日 → 通常価格に戻す → 90日内に1回カウントダウン。
- 日付の確定前に必ず私に確認すること。

### B. X（旧Twitter）の固定ポスト下書き
Claude for Chrome に下書き作成のみ依頼（投稿は人間が最終確認）。本文案：

> 非エンジニアでAI活用が「続かない」人へ。
> 原因は意志じゃなく、プロンプトの“置き場所”でした。
> メール・要約・稟議など12場面の型＋定着の仕組みを短編にまとめました。
> （1時間で読めます。期間限定 無料キャンペーン中）
> ▶ 【Kindleリンク】
> 目次はリプ欄に👇

- 投稿後、これをプロフィールに固定する操作まで依頼可。
- ※「レビューしてください」等の依頼文は入れないこと（規約のため）。

### C. note 導線
- note.com/ai_katsuyosenshi のプロフィール欄・関連記事末尾に Kindleリンクを追加。
- 既存の母体有料記事には「12本の体系版＋コピペ早見表はKindleで」と一文だけ追記（記事の共食いを避けるため、本は再構成版である旨を明記）。
- 出版から数日後に「制作の裏話／没にした章」noteを1本公開して相互送客。

## 2. コンプライアンス・規約に関する注意（必読・1行ずつ）

- **AI開示**：KDPの「AI生成コンテンツ」質問には、Amazonの定義（AI-generated／AI-assisted）に沿って正直に申告する。本書はAI生成＋人間の構成・確認のため、虚偽申告はしない（これは人間の判断事項としてClaudeに自動回答させない）。
- **レビュー**：Amazonの規約上、金銭・便宜と引き換えのレビュー依頼や、家族・関係者による評価操作は禁止。販促文にレビュー誘導を入れない。
- **KDPセレクト**：登録中の90日間は、同一電子書籍を他ストアやnote等で「全文」配信しない（独占条件）。本は再構成版で母体noteとは別物にしてある。
- **個人情報**：原稿・プロンプト例に実在の社名・個人情報を入れない（本文は一般化済み）。
- **各プラットフォーム規約**：note・X・Amazonそれぞれの規約（誇大表現の禁止、無断引用の禁止、スパム的相互送客の禁止）を順守すること。
